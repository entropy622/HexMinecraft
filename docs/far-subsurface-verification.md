# 远距 SSS 补偿与草花环境透光

0.98 补齐 Photon 在阴影距离外的主 SSS 响应，改善中远冠层发黑，并将环境透光接到装饰草丛与三类世界花。沿用 v16 存档及既有画质设置；普通地面、生物的阴影覆盖范围未扩展，完整 MC/Photon 目标继续推进。

## 固定来源与宿主适配

只读对照 Photon 提交 `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [diffuse_lighting.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/diffuse_lighting.glsl#L259)。源代码在范围过渡中将 SSS 厚度混合到零，再乘如下响应，作用于主透射与 sheen：

```text
depth = thickness * (1 - fade)
response = mix(1, (AO + pi * ambientSSS) * (0.8 * clamp(NoL, 0, 1) + 0.2), fade)
```

`leaf-transmission.js` 的近/远光程均使用过渡后的厚度；完全远距变为可见性查询，仍沿真实体素检查屋顶、半砖、液体及未知边界，玻璃与云的入射过滤继续走共享路径。移除原来叶层累计超过 32 就直接视为遮挡的捷径，深叶层由可见性与源公式处理。近远两条路径仍按宿主覆盖混合，光程并不等于 Photon 的 PCSS 平均 blocker 深度；0.2 几何响应尺度及线性 sRGB 适配见 [0.96 记录](leaf-primary-verification.md)。

`leaf-lighting.js` 计算范围响应，NoL 来自实际世界法线和日月方向。该响应允许大于 1，没有将它截为普通透射率。角点 AO 与环境 SSS 分别作为输入，完整入射能量、本地点光、体素 RGB 和发光的既有规则保持。

环境 SSS 使用同一局部可见性字节的半值。叶片原有天空附加项等价于 `2 * ambientSSS * skyUp`，草花按材质强度 0.5 接入；这与 [源环境光公式](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/diffuse_lighting.glsl#L180) 的系数对应。实际可见性仍来自宿主半径 2、十八方向的体素路径，AO 仍来自几何角点；它们与 Photon 的 [GTAO](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/ao/gtao.glsl) 和 [AO/ambient SSS/bent-normal 历史](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/d3_ao.fsh) 不同，相关迁移状态仍为部分。

## 数据与失效

草丛批次和花朵几何使用与叶片一致的归一化 Uint8 属性及绝对体素范围。`VoxelLight` 收集花朵接收点，并预备不透明地面上方可能出现草丛的位置；这样石块/泥土换成草时，可直接上传既有可见性，保留光学相同替换不重建光照场的规则。拓扑、介质、区块边界变化仍会更新数据；手持光或发光 RGB 变化复用可见性缓存。

固定森林的可见性缓存仍为 2166784 字节，接收点从 51888 增为 68732，范围表等 CPU 数据相应增加。该列表现在包含草花及预备位置，分布均值不能直接解释为叶片本身更通透。

## 验证

独立无头 Chrome / RTX 4060 / ANGLE D3D11，单批串行运行。已有 DOM Pointer Lock fixture 接管设备边界，未占用前台鼠标，未操作玩家的 5173 服务。每批按 PID 和 UTC 创建时间核对退出，5191/5193 端口释放。

- **205 项 Node 测试、生产构建通过**。新增实际世界的花朵/潜在草丛接收点验证，与独立光程 oracle 对照，并检查地面换草、花朵换种、遮挡开闭和缓存复用。
- **23 项完整功能浏览器回归通过**，包含既有叶片、材质、软阴影、表面间接光和恢复流程，以及新增草花环境光、真实网格缓存、阴影相机边缘验证。两个尺寸的 12 组完整 HDR/深度对照仍零差异。
- **固定森林、生产 UI 存档导入/再导出及实际草地玩法通过**，合计 **26 项不同的功能浏览器检查**；重复开发检查与性能窗口另计。草地检查覆盖羊吃草、暂停/恢复、重新长草、地毯保留草地、不透明覆盖使草死亡、侦测器与灯、区块卸载、存档继续及 GPU 光照数据上传。最终各批页面、shader、GL 错误及 shader 警告为零。

数值检查包含 **100 条光程/厚度过渡样本**、**144 组范围补偿**和 **606 个范围边缘样本**。光程与遮挡由独立细步积分求得；63 层深叶柱在完全远距不再被错误归为不透明，真实屋顶、半砖、水、未知/界外与水平射线门禁保持。Float32 范围公式误差保持 1e-5 门槛。

真实材质的阴影相机横移 **25 个位置**，读取 **23650 个植物像素、70950 个 RGB 通道**；每个像素使用独立读取的 AO、环境 SSS、NoL、颜色与范围值，按半浮点输入/输出量化区间验证源公式，过渡覆盖 0 到 1。原来的远距固定吸收比例门槛改为源补偿公式检查，近距吸收门槛保持。实际远叶 897 像素的环境 SSS 均值约 0.499934→0.411621，对应响应约 0.635863→0.567472，屋顶和半砖新增透光为零。

草花环境 SSS 另以两种真实 SH 场、相机旋转、天光、AO 和字节值检查材质强度 0.5 的附加项。原生花朵及新生草丛的属性与缓存字节逐元素一致，屋顶改变可见性，移除后恢复；光学相同的地面替换不改变光照 revision，手持光复用缓存。

首次边缘测试逐通道生成大量 Playwright 断言记录，触发 360 秒超时；记录中浏览器读取仅百毫秒级，大部分时间位于断言之间。已改为遍历全部通道后汇总违规数量，保留全部 25 机位、每个像素、有限值和相同量化界限，修正后及完整回归均通过。原始超时、trace 与成功结果保留。

额外草地玩法检查最初未在渲染帧中读到短脉冲。逐逻辑步的只读诊断确认，草死亡后侦测器和灯同时通电 0.1 秒，开、关发生在同一帧的不同物理步；该次 RAF 最大间隔约 653 ms，逐帧采样漏掉了事件。测试改为记录真实红石逻辑步，仍由原有真实输入放置覆盖物，检查草死亡、同时通电、随后关闭及 0.1 秒脉冲的物理步量化上限。游戏时钟、红石实现与脉冲时长均未调整，原始失败和诊断保留。
