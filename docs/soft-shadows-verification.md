# 接触硬化软阴影验证（0.76）

## 实施前判断

1. 结构：在现有太阳 / 月亮阴影图上搜索遮挡深度，再按实际分离距离过滤地表与模型阴影。
2. 负担：沿用光影档，不增加玩家开关、素材或第二盏太阳；均衡保留现有 PCF，流畅仍关闭阴影。
3. 可推导：光源角大小来自可见日月盘，纹素、投影宽高与深度范围来自实际阴影相机。
4. 复杂度：复用已有阴影图、材质编译和 TAA，不增加屏幕模糊层或持久化状态；原始深度同时供体积光读取。
5. 泛化：接触 / 悬空、倾斜接收面、昼夜、移动模型、水面捕获、重建 / 缩放 / 画质和上下文恢复使用同一路径。

最小完整实现是光影档的遮挡搜索与距离相关过滤、真实接收面深度校正、所有接收阴影材质接入，以及体积光采样同步。固定半径放大或整屏模糊不能提供接触硬化。

参考 [Photon 的 PCSS 与可变半影](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/shadows/pcss.glsl)，独立适配当前正交阴影图。保留自己的六棱几何与现有光照；不声称完整 Photon 对等。

## 实施前失败类别

- 贴地与悬空物体阴影宽度相同，或仅靠暗度变化伪装变软；半影增宽同时丢失遮挡中心。
- 日月角大小混用、傍晚闪烁；无阻挡区域变黑；坡面自身遮挡和阴影脱离物体。
- 材质链覆盖现有体素光、风、加工动画、水面、透明模型或昼夜光照。
- 阴影图采样类型与体积光不一致，切换画质 / 维度 / 上下文恢复出现 GL 错误或旧阴影。
- 阴影图边缘越界、远处接收面 NaN、相机移动后阴影滞留，过滤引入明显帧间闪烁。
- 新建无必要缓冲、设置或库存 / 存档字段；验证占用前台鼠标。

## 结果

半影使用真实世界方块、生产材质和线性 HDR 读回测量。低悬方块底部距地 1 格，高悬距地 9 格；以移除遮挡物的同一地面为基准，比较直接光遮挡率 10%–90% 的边缘宽度，单位为世界坐标单位。日月光分别做开 / 关的真实场景绘制，排除材质纹理和体素环境光的影响；夜间从阴影伸出的另一侧观察，避免扫描射线被方块本体挡住。

## 范围与限制

- 使用一张正交方向光阴影图。中心加 16 次遮挡搜索，宽半影最多 32 次过滤；近接触使用四点比较插值。搜索和半影半径上限为 2 个世界单位，以限制成本；不复刻 Photon 的投影扭曲、透明彩色阴影、多级阴影或完整 LabPBR。
- 光源角大小来自实际日月盘，接收面使用深度导数修正；极端斜率和退化导数受到限制。量测覆盖低悬 / 高悬两个间距，没有分别量化所有零间隙接触、斜面和日落角度。
- 按世界位置固定旋转采样核，并接入现有 TAA；没有新增阴影专用历史、运动矢量或去噪器。生物运动和镜头切换继续使用现有时域规则，不宣称解决所有动态阴影重建问题。
- 只改现有可接收阴影材质的过滤方式，模型既有投射 / 接收规则保持。没有可见日月盘的维度使用固定比较过滤；流畅关闭阴影，均衡保留原 PCF。
- 原始深度也由体积光读取，四点比较重建原有硬件比较过滤。既有体素光、天空亮度、云影、雨后反射和水下光学分别保留；没有新增 GPU 渲染目标。
- 光影档增加纹理采样，截图和检查使用软件渲染；没有对用户显卡帧率作承诺。本轮没有扩展 MC 生物或生产方块，持续目标仍未完成。
