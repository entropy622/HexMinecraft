# 发射器验证（0.77）

## 实施前判断

1. 结构：复用投掷器九槽、八向放置与 0.2 秒红石脉冲，增加实际射击、放置和使用物品的动作。
2. 负担：沿用工作台、容器 UI、红石控制、物品堆叠和磨损，不增加模式、过滤配置或额外库存。
3. 可推导：动作取决于真实槽位中的物品、出口和目标格；返回的空桶 / 水瓶仍进入原库存，放不下才散落。
4. 复杂度：共用真实弹射物、流体、营火 / 门框、植物、船、护甲和潜影盒；不注册只会掉落物品的同名方块，也不把所有玩家右键强行套在机器上。
5. 泛化：覆盖本项目已有的箭、雪球 / 鸡蛋、桶 / 玻璃瓶、骨粉、点火工具、烟花、船、护甲、剪刀与潜影盒；普通物品保留默认喷出，未加载目标保留库存。

最小完整范围是可合成 / 摆放 / 使用的发射器及本项目现有物品的专用行为。已有方块无完整火焰、TNT、刷怪蛋或喷溅药水时，不伪造这些系统；现有可用行为必须走真实世界与实体。普通投掷器仍只负责转入容器或掉落物品。

规则依据为 [Minecraft 官方发射器介绍](https://www.minecraft.net/pl-pl/article/block-week-dispenser)、[官方投掷器对比](https://www.minecraft.net/tr-tr/article/block-week--dropper)与 [Cuberite 的实际发射行为](https://github.com/cuberite/cuberite/blob/master/src/BlockEntities/DispenserEntity.cpp)。数值适配六棱世界，不声称 Java 版逐刻复刻。

## 实施前失败类别

- 工作台材料量不对，弓未真正消耗；朝向、九格 UI、手持 / 图标 / 世界口部混同；垂直朝向不保存。
- 持续通电连发，短脉冲被取消，延时未冻结 / 恢复；重载重复扣库存；普通投掷器变成武器。
- 箭只会掉落或不伤玩家 / 生物；近距离脚部射线漏判；药箭丢失药效，盾牌挡箭仍扣血 / 加药效；自动伤害错误归因给玩家。
- 不同发射器和玩家共用投掷物冷却；雪球 / 鸡蛋变普通掉落；珍珠错误把玩家传走；烟花无视出口。
- 桶复制、液体源丢失、液体侵入实心机器；堵住时错误插入前方箱子；空桶 / 水瓶溢出丢失；流动液体被当源收集。
- 骨粉无效仍消耗、错误作用在土壤内部，剪羊毛 / 点营火不扣真实工具耐久或抹去附魔与名字。
- 装备覆盖已有护甲、丢失磨损；船穿墙 / 重叠；潜影盒放置丢内容或嵌套；普通物品元数据丢失。
- 漏斗与比较器读另一份库存，拆除 / 爆炸重复掉落，非法计时 / 库存 / 朝向进入存档；验证抢占前台鼠标。

## 结果

- `npm run check`：**95 项逻辑测试通过，0.77.0 生产构建通过**。新增 5 项使用真实 World、库存槽位、物品实体、合成、耐久、流体和 v16 校验器，覆盖八向出口、未加载保持、替换物溢出与无效存档。
- 新增 **9 个浏览器玩法场景，分批通过**：真实工作台合成 / 放置 / 九格装填 / 缓慢箭脚部命中与持续供电单发；桶与玻璃瓶循环 / 满库存溢出 / 细雪往返；堵住出口的箱子不接收物品、珍珠不传送且桶可拾取；施肥与营火点燃 / 工具损耗；保留元数据的穿甲与潜影盒放置；待发向上脉冲继续游戏一次完成；盾牌格挡 / 已消耗的箭回收；剪羊毛 / 普通生物自动击杀有物品而无玩家经验；两台同时射出同种投掷物、雪球、水平烟花与船体空间检查。
- 既有系统 **17 个浏览器场景，分批通过**：弓箭 4、投掷器 3、漏斗 4、渲染 / 画质 2、日月软阴影 / 上下文恢复 2、骷髅 / 流浪者 2。移动端漏斗样本原先会在退出蹲伏的视点变化中穿过开口瞄到后方箱子；改为等待真实站姿并瞄准实体底部后通过，保留五格与完整库存断言。失败快照只保存目标坐标和类型，避免循环引用遮蔽原始错误。
- 正式 `dist/` 另通过 **1 个真实 UI 场景**：没有 `window.__hexwild` 开发接口，实际启动、光影 / 均衡切换和 WebGL 检查正常。因此共覆盖 **27 个不同运行场景**，没有把同场景重跑计作新增。
- 初始版本在真实配方册中找不到发射器，失败记录保留。满库存测试固定外部 RNG 选择空桶槽；待发存档样本调用真实红石调度器的零时步，避免软件渲染一帧跨过整个 0.2 秒延时。未替换自有系统或伪造动作回调。
- 所有浏览器使用后台无头 Chrome 和现有 Pointer Lock 设备替身；开发测试为 5174、正式预览为 5176，未使用用户的 5173 页面或前台鼠标。

## 范围与实施后复核

- 新增动作集中在游戏已有的实际调用链，沿用九格槽位、八向几何和红石调度；不增加依赖、玩家配置、行为注册器或存档版本。
- 新的弹射物归属用于区分玩家与机关的伤害 / 挑衅 / 经验；工具磨损提取为同一函数，仍读写真实物品；箭的玩家碰撞采用实际站姿、蹲伏与滑翔高度。烟花方向保存在现有短生命周期实体中。
- 液体不能进入实心投掷器 / 发射器。普通喷出物在出口堵住时优先使用机器相邻的空面，保留原有物品元数据；完全密封时仍保留物品实体，不跨越远墙寻找出口。
- 装备仅作用于现有玩家护甲 / 鞘翅槽，盾牌保持普通物品喷出。打火石支持既有营火与下界门；树苗和洞穴藤蔓复用现有生长规则。门框、树木、所有液体 / 朝向的组合没有逐项进行浏览器穷举，已验证的操作见上文。
- 火焰方块、TNT、刷怪蛋、喷溅药水、完整生物装备和准连接仍未实现。箭、雪球 / 鸡蛋与烟花沿用原有临时实体规则，不新增离线追赶、跨维度或重载后的飞行保存。
- 本轮按文件复核产品、数据、材质、保存和测试变更，保留既有 Photon 风格光影；净行数在最终验证清单中分别记录产品 / 测试 / 文档 / 配置，未把验证工具当作产品框架。
