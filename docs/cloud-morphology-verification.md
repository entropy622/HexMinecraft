# 0.89 分层云形与天气

目标仍是用户森林参考图及 Photon 的可迁移能力。本轮改善偏尖的云体、高积云和高空条带，沿用 0.88 的覆盖缓存、体积积分、光学、历史、曝光与资源接口。视距 10、晴天地形雾 87.32–118 保持不变，v16 存档和既有天气/画质/云控件继续使用。

## 对照与实现

参考本地 Photon 固定提交 `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的[积云形态](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/cumulus.glsl)、[高积云与高层云](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/altocumulus.glsl)、[卷云](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/cirrus.glsl)和[天气派生](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/weather/clouds.glsl)，独立适配本项目的种子场和世界尺度。

- 主积云由天气控制层深度，去掉局部覆盖率对高度的二次压缩，保留连续的上缘、软底和层云包络。粗侵蚀云块从约 416 m 改为约 139 m，复用同一 64³ R8 Worley 数据与两次读取，改善厚云内的团块数量。
- 高积云使用独立的非线性斑块与高层云薄片混合；细节和高度塑形分开处理，再用约 42 m 的三维云块侵蚀。仍使用原覆盖图及种子头，只有一次三维纹理读取。
- 主层层云倾向由温度与风共同派生，湿度继续影响覆盖率，避免暖湿森林仅因湿度高就变成连续层云。高层云有独立的温度混合；雷暴保留主层的天气增强，风位移保持解析、确定和连续。
- 卷云使用三层旋涡扭曲、双频基底和四层细节侵蚀；旋转本项目五次插值标量噪声的解析梯度构造连续流场，复用精确种子。卷积云保留独立覆盖和细碎斑块，不再使用贯穿天空的单向各向异性条带。

纹理频率按实际 512×512 参考噪声的尺度关系与本项目 20 m/local 换算；参考图像只读取尺寸，没有复制素材。生产资源没有新增图片、采样器、渲染目标、保存字段或玩家参数。更多程序运算的实际成本见下节。

## 画面诊断与基线

生产基线为已发布 `6d8728f`（0.88），固定森林与天空使用既有自然种子 624、时刻 30、FOV 72、曝光 1 和光影档 1.7。0.88 的四个固定镜头作为配对控制。

云体探针保持原来 320×320 本地单位的范围，将采样提高到 128×128×64，以分辨更小的云块；高度要求没有放宽。修改产品前在 0.88 运行该探针通过，连通体最高 50.625 local（1012.5 m），体积占用 5.081%。记录每层高度的占用率和平均密度，辅助区分厚度与细节变化。

参考镜头新增实际云历史 MRT 的最近贡献层标记图，红/绿/蓝对应积云/高积云/薄高云，亮度按总云不透明度显示。它读取原生产数据，不隔离渲染层，也不代表主导光学贡献；读回在计时窗口之后。

第一版只改主积云包络，近处形态改善，远处仍有尖峰。实际标记图表明这些区域的最近贡献层为高积云，因此增加其独立形态。第二版改善小块高云后，显露了原有卷云的直线条带；第三版加入旋涡与细节侵蚀，条带打散，三个层的外观更易区分。三版的 900×650 森林与天空都实际查看并保留，技术通过不等于参考图艺术验收。

## 验证范围

完整 199 项 Node、生产构建及修改文件格式检查通过。云相关检查包含暖湿天气的积云、冷天气的独立高层云以及雷暴、风位移、维度和开关行为。

15 项真实 GPU 功能回归分组通过：首组四项覆盖图形恢复、覆盖缓存精度/生命周期和静态历史；一项修正场景后的移动/建筑/恢复历史；其余十项覆盖三层视角、远坐标锚定、连续天气、云体与光学、月光、彩色结构透射、深度、导入天气/种子、水面和材质恢复。产品源码在这些组之间保持不变，修改仅涉及建筑测试的场景选择与探针元数据。水面检查按原测试主动注入一次 `cloud GPU boundary failure`，恢复断言通过，预期日志保留。

同范围的一百万个生产密度样点中，新天气/形态的最高连通体为 29.0625 local（约 581.25 m），占用 4.193%。最大连通体宽/深约为 107.5 / 87.5 local，高 28.125 local；与旧控制的 105 / 85 / 49.6875 相比更平展。这里同时包含新的天气塑形，不能把变化只归因于侵蚀频率，也不代表所有群系/天气下的固定高度。

移动场误差约 0.01003。实际低云密度采样选择了 Y=59.96875、密度 0.08765 的可建造位置，保持相机位置和天气，只改变朝向；Y=47 为完整屋顶，Y=61 为部分屋顶。部分遮挡 T 约 0.3561，冷历史控制约 0.3554；完整与部分屋顶移除后，两帧显露误差约 0.00701 / 0.00119，设备恢复约 0.000085。原有 0.025 / 0.03、部分透射小于 0.999、两帧显露和有限值门槛均保留。

原始失败保存在 `cloud-regression` 和 `history-building-density`。旧 Y=54 屋顶只在新云底的空隙/微弱碎边中，T 约 0.999956，未形成有效部分遮挡；新夹具先读取独立的实际 GPU 密度再选场景，不通过待测历史结果挑位置。调整视角时首次漏同步了最后的恢复对照，错误地与旧移动镜头比较；随后统一到同一视角和相位，`history-building-phase` 完整通过。没有更改产品去迎合旧屋顶位置，也未放宽误差门槛。

候选 C 的两个 900×650 镜头与最终两个 1920×1080 镜头通过，四张图均实际查看；产品云源码、相机、曝光、种子、时刻相同。生产构建通过原生 UI 导入/导出，v16、种子 624、时刻 30 保持正确，页面错误与警告为零，生产页面没有开发接口。最终计时、其余十项功能、FHD 镜头和生产 UI 期间的 335 个源码/测试/文档文件哈希一致，进程与独立端口均已释放。

## 1080p 成本与限制

使用与 0.88 相同的固定森林、预热及 120 帧/4200 个实际 GPU 批次测量。单位为 ms，中位数 / p95。

| 阶段             |            0.88 |            0.89 |
| ---------------- | --------------: | --------------: |
| 主场景           |  9.724 / 10.349 | 10.489 / 11.071 |
| 水面场景         |  9.149 / 10.623 | 10.413 / 10.739 |
| 主视图云积分     |   5.657 / 5.815 |   6.406 / 6.571 |
| 水视图云积分     |   5.673 / 5.874 |   6.424 / 6.598 |
| 观测批次按帧求和 | 33.290 / 35.333 | 37.009 / 37.807 |

这组窗口的 GPU 中位数增加约 3.7 ms，包含更细形态和不同云分布的成本。每个视图的云历史仍约 0.066 ms。CPU 提交观察为 18.6 / 22.8 ms，不能据此宣称 CPU 优化。计时排除每批第一次 draw 前的清屏，不等于浏览器整帧或稳定 FPS；实际游玩还有世界更新与系统负载。

已知渲染目标存储仍为 232735464 字节，与 0.88 相同；不是进程总显存。一次原生跨格移动的缓存重建约 0.115712 ms。实际硬件为 RTX 4060 / ANGLE D3D11，计时 disjoint、busy、GL、页面错误和警告均为零。本轮保留云形改善，后续仍需降低高质量云影与细节计算成本。

所有浏览器使用独立无头 Chrome、ANGLE D3D11 和 DOM Pointer Lock 设备边界，不接管前台鼠标或使用用户的 5173 服务。每批串行执行，期间冻结源码和测试，结束核对所属 PID 的创建时间及独立端口。首个进程快照曾因父 PID 复用包含一个更早启动的 Git 监控进程，按创建时间排除并保留原始记录，没有操作该进程。

原始证据位于 `C:/Users/aentrozhou/.codex/artifacts/hexminecraft-photon-0.89/` 的 `shape-control`、三版 `shape-candidate-*`、`layer-diagnostic-a`、`cloud-regression*`、`history-building-*`、`profile-fhd`、`final-fhd-reference`、`production-ui` 和 `node-199.log`。当前仍有整体光色、冠层照明、低空 RGB 介质和更多 Photon 功能需要推进，厚积云散射、跨层输运与实际游玩性能也未达到完整对等验收。
