# Photon 雨雪光色与云空气透视（0.114）

本批接入源雨雪颜色、雾入射光的天气混合，以及云空气透视的雨天混合与去色。它改变雨雪天气，尚未完成用户参考图的整体森林光色或云形验收。

## 来源与迁移范围

Photon 固定在 `6e67b36e818bacde0304edd49f28e2bb70e33f04`，本地 `D:/Git/photon` 只读。主要依据 [weather_color.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/colors/weather_color.glsl)、[天空入射光](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/d0_sky_map.vsh) 和 [clouds_aerial_perspective](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/common.glsl#L87)。

三条源曲线均使用 `smoothstep(-0.1, 0.5, sun_dir.y)`，亮度乘源工作空间中的太阳颜色和 `(0.49, 0.65, 1.00)`。

| 用途         | 夜间系数 | 日间系数 |
| ------------ | -------: | -------: |
| 雨色         |    0.033 |     0.66 |
| 雪区雾入射色 |    0.060 |     1.60 |
| 降雪粒子色   |      0.5 |     1.60 |

这些常量已经是源工作空间数值，转换到宿主线性 sRGB 时不再次做 gamma 解码。雾入射光从独立晴空的倾斜方向采样，以降雨量混合天气色，并沿用原雪区连续权重；没有从已经合成雾的环境图反向取光。相应的源 `tau` 与宿主相位归一化相消。

每层云继续保留自身透射率，空气背景按源雨天权重趋向天气入射色，全雨时晨昏保留 10% 晴空差异；空气 RGB 透射按 `0.8 * rain` 趋向红通道。主视图与环境图共用该内核。云自身的天空/地面补光仍沿用已有半球模型，这一批不代表完整移植了 Photon 云内照明。

原生雨线、雪粒与落水花读取已发布的颜色；落水花沿用雨色是宿主适配。现有线段/点精灵、透明度、屋顶限制、邻近雨雪列与风保持原机制，尚未移植源天气贴图四边形及完整预乘天气层合成。

## 同步、资源与验证

雨雪色与日月、SH、雾参数一起随完成的天空快照发布；环境图构建使用本轮的入射色，视图云使用已发布色。云历史的光照变化判断也包含这一项，避免天气变色后积累旧颜色。

生产归约从 20×1 扩为 22×1 RGBA16F，目标数据和每次异步读回分别增加 **16 B**。复用原目标与缓存，不增加纹理数量或云积分步数；本批没有完整帧性能基准。

- 一项新增 GPU 检查包含 **37 个公式输入样本**，覆盖昼夜曲线、雨雪过渡、雨天云空气透视与空云边界；独立 CPU 参考与生产 GLSL 最大绝对差 `2.460e-7`。样本数不是游戏场景数。
- 同一项检查另外覆盖实际森林昼雨、同镜头夜雨和天然雪原夜雪三组画面。固定 seed 624、FOV 72、曝光 1；森林时间 120/450，雪原时间 450。发布并传入雨粒材质的线性光色，其昼夜绿通道比例约 20；夜雪粒子与雾的输入光色比例约 8.33。这些是材质输入比例，不是最终截图像素亮度比。材质、空气和云读取正确快照；三张截图已查看。
- 延迟 GPU 读回的时间推进回归通过，90 个有雾渲染帧中的雾快照误差为零，取样阶段的雨雪颜色误差为零。另一项实际云运动、建筑遮挡和 WebGL 丢失/恢复回归通过，恢复后归约宽度、天气材质和云入射光正确，云场误差约 `8.22e-5`。
- 生产包通过普通 UI 导入森林降雨与天然雪原降雪的 v16 存档，验证实际群系/天气标签、渲染及导出位置、时间、天气和编辑。生产包没有开发 API，暂停控件截图只作流程证据。

220 项逻辑检查与生产构建通过。最终是三项不同的开发 GPU 检查及一项生产 UI 检查；没有重跑未改动的 3456 输入高光矩阵。保留首次失败：新增雪区 uniform 缺少 GLSL 声明，真实浏览器编译失败后补齐，重新构建并重跑，没有放宽断言。

修正后三批 GPU 检查期间冻结并审计 784 个文件，无漂移；结束后才补本文、README 与迁移矩阵。浏览器串行后台运行，使用模拟 DOM Pointer Lock，不操作桌面鼠标或用户的 5173。每批所属 PID/UTC 创建时间实例和独立 5191/5193 端口均清零。证据位于 `C:/Users/aentrozhou/.codex/artifacts/hexminecraft-photon-0.114/`。
