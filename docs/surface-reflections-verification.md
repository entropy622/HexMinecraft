# 固定材质的环境反射

0.105 在光影档为金属、宝石与黑曜石等 Photon 固定反射类别加入场景/天空反射。复用已有湿面追踪和表面保护绘制，不增加场景捕获；完整 MC/Photon 目标及用户森林参考图仍未完成。

## 路径与范围

参考只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 `lighting/specular_lighting.glsl`、`lighting/bsdf.glsl`、`surface/material.glsl` 和 `utility/dithering.glsl`。移植改进 GGX VNDF 采样、四射线、Smith `2 NoL V2/V1` 权重、Fresnel 和原生固定材质反射开关。源粗糙分支受 `SPECULAR_MAPPING` 约束；宿主将它用于已映射的固定反射材质，而不是声称默认配置逐项相同。普通岩石、木板、叶片、草花仍不启用通用环境镜面。

在原表面保护 draw 中增加两个 RGBA8 附件，存储真实贴图/材质颜色的 sRGB 编码与源类别、八面体世界法线和原始天光。数据来自原材质的贴图、alpha test 与风动顶点路径，早退不执行光照；不从已照亮的画面反推 albedo。区块和部分建筑在生成真实三角形时记录是否含反射类别，无该类别的对象跳过材质输出。透明/手部保护和湿面覆盖继续使用同一遮罩，原对象材质与 layers 在 finally 中恢复。

命中使用现有同帧 HDR/depth、40+6 步湿面追踪、厚度/边缘/距离置信度；未命中使用已发布的共享天空图，按源 `pow12(linear_step(0,0.75,skylight))` 抑制室内漏天光。每帧采样随源 IGN 推进，现有 TAA 继续积累。湿面反射覆盖按原规则合成，避免底层环境镜面重复叠加。主世界水上光影档启用；均衡/流畅保持直接高光且不分配这些后处理资源，水下和其他维度沿用原路径。视距 10、晴天雾 87.32～118、v16 保持。

宿主仍没有源颜色 mip、反射路径空气散射校正、反射专用历史或完整资源包 PBR 通道；离屏物体不可被 SSR 看见，天空图也没有最终体积云合成。粗糙表面依赖四射线和当前 TAA，不能视为完整光追或无噪声高采样参考。动态独立模型和资源包材质后续继续接入。

## 验证

原生金属/宝石平面、红蓝羊毛墙和干燥石头检查通过。真实反射 pass 边界隔离 SSR/天空源，避免后续 composer 重用 HDR 纹理影响读回；更换墙色后金属 SSR 的红/蓝通道随之变化，干石头环境反射为零。围合房间的天空反射约为室外的千分之一，记录的平均原始天光从 1 降至约 0.368。已实际查看室外、室内和 1080p 开/关合成画面。

保留一次失败：最初四周敞开的高顶棚仍有约 28% 的天空反射，未达到预设 15% 门槛。该回退依赖包括侧面传播在内的实际天光，不是顶棚几何射线；后续用围合房间检查室内抑制，原门槛保留。没有把小顶棚下的近似漏光说成已解决。

原水洼的颜色、孔隙率、屋顶、竖直面、沙漠/雪原、雨滴暂停、质量/尺寸/水下变化和 TAA 更新回归通过。实际冠层/水捕获的上下文恢复、三个画质档和跨维度检查通过；表面数据绘制异常时，原材质、layers、相机、场景及渲染状态均恢复，水捕获的既有失败恢复也通过。完整 207 项 Node、10 项不同浏览器功能检查、2 项独立成本检查和生产构建通过；生产包使用真实控件导入/导出 v16 森林存档。
