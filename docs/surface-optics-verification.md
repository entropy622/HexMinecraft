# Photon 表面光学与日月高光

0.104 为原生地形、树叶、草花与复用地形材质的部分建筑加入源固定材质分类和直接镜面光。整体 MC/Photon 目标、用户森林参考图及完整 PBR 仍未完成。

## 实现与范围

固定只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [material.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/surface/material.glsl)、[bsdf.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/bsdf.glsl)、[specular_lighting.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/specular_lighting.glsl) 和源设置。`photon-specular.js` 移植硬编码 roughness/F0/metal、介质 Fresnel、金属 Schlick、GGX/Smith、有限角盘 NoH² 及逐通道响应上限 4。上限位于乘日月光能量之前，实际 HDR 高光允许超过 4。

Three 的物理材质提供 GGX、能量补偿与环境支持；Photon 默认漫反射路径保留自己的入射角和 SSS 模型，源 Hammon 仅定义、没有默认调用。本批复用 Three 现有材质、纹理/阴影和 `ReflectedLight.directSpecular` 通道，接入源光学核，继续保持已验证的漫反射和透光，未重建一套材质管理框架。

高光读取经过真实阴影、玻璃/云/水过滤的入射光，再独立于漫反射 lift、AO 与 SSS 分配计算。叶片透光强度变化不再次衰减高光；普通几何面着色与湿面暗化继续作用于漫反射，高光单独加入。源金属保留一半漫反射的规则也同步接入。

`surface-optics.js` 将本项目 block ID 映射到源类别：铁/金/铜块为金属，钻石块为宝石，沙、橡木/丛林/白桦木板、黑曜石、末地石、叶片/草花等使用相应参数。矿石保持岩石分类。普通实体和独立模型尚未接入。固体/相应建筑的分类使用每顶点 1 byte，叶片与草花共用材质常量；227 种原生 block 的映射在消除逐单元数组/正则分配后逐项保持一致。类型由存档中的原 block ID 重建，沿用 v16。

这是宿主适配：光照仍使用线性 709，按 IEC 曲线还原颜色贴图的 sRGB 最大通道，匹配源误命名 `rgb_to_hsl().z` 的实际 HSV 含义。完全光滑面使用 alpha² 最低 `1e-8`，退化角盘分母有有限定义。尚无 labPBR/F82 特殊金属解码、通用环境 BRDF/粗糙 SSR、法线贴图或 POM。现有水/雨后水洼反射继续独立工作，不计作通用 PBR 已完成。

日/月角半径使用源默认 2°/3°，可见月盘同步到 3°并保留原相位图。新月仍保留源漫反射月光，直接高光关闭；依照天空已发布的相位与方向快照判断，避免与异步天空不同步。主世界/末地和三个画质档接入直接高光；下界保留原路径。视距 10、晴天雾 87.32～118 保持。

## 验证证据

公式验证是 **1 项测试中的 3456 组输入**：4 种颜色 × 12 类源参数 × 3 个观察角 × 4 个入射角 × 2 个方位 × 3 个光源半径。实际 GPU 核在两次批量渲染中输出数值，与独立双精度 CPU 源参考比较；高光最大误差 `4.115e-5`，参数 `1.620e-7`，角盘 `2.039e-7`，非有限/范围异常和 GL 诊断为零。它只证明光学核一致性，不代表几千个游戏场景或美术验收。

原生九方块场景验证真实 uint8 分类从 CPU 三角形进入片元、贴图决定参数、关闭高光后实际通道为零、红/蓝三层玻璃过滤、石屋顶遮蔽及移除后恢复。半精度读回的贴图/参数耦合最大误差约 `4.203e-4`。日光和满月都有高光，新月的月光强度仍大于零而高光为零；角盘与可见盘几何一致。已实际查看材质样片。

实际叶片在 SSS 0/0.5/1 时保持高光逐位一致，漫反射保留 1/0.75/0.5，局部点光不变。原生草花、固定森林、三个画质档、水捕获、两次上下文恢复与跨维度检查通过。完整 207 项 Node、生产构建、9 项不同浏览器功能检查，以及独立的 1080p 成本检查通过；生产包使用真实控件导入/导出原生森林存档，旧存档和参数保持。

保留三次原生检查失败：原探针将插值后的分类浮点数直接写入半精度，7 可读成 6.996；现在读取生产分类的取整结果。单层玻璃约 1.31 的红/蓝透射比不满足既有三层压力场景的 1.5 门槛，场景改用明确的 `[2,3.5,5]` 三层，门槛保留。相位测试最初写入 API 的状态快照，未推进真实时间，现使用已有 `step` 接口。原始 trace 和数据均保留。

证据目录 `C:/Users/aentrozhou/.codex/artifacts/hexminecraft-photon-0.104/`。所有 GPU 批次串行、后台 Pointer Lock fixture 验证，不操作前台鼠标；终态后核对所属 PID/UTC 创建时刻与独立端口。原始 Photon/Bruneton/AMD 文本保留，改编范围见 [notice](../public/licenses/PHOTON-NOTICE.md)。

## 固定场景画面与成本

已实际查看材质样片、900×650 自然森林及 1920×1080 高光开/关对照。森林的地面和冠层有更明显的角度反光，整体仍偏暖、偏橄榄色，树形/冠层关系和用户参考图尚有明显差距。两张对照各等待现有时域采样稳定，不是同一份冻结 HDR 的差分；镜头、seed624/time30/FOV72/曝光1、原纹理和天空照明保持。

RTX 4060 / Chrome ANGLE D3D11，同进程每个窗口预热后测 120 帧，按开启、关闭、恢复开启的 A/B/A 顺序，另有无 GPU 查询的 CPU/RAF 窗口。仅切换真实方向光 GGX 高光分支；材质分类、粗糙度与源金属漫反射比例保留，因此不将此差值称为全部 PBR 的增量。计时窗口内无截图/读回，disjoint/busy 与页面/GL 诊断为零。

| 光影，高光关闭 | 33.774 / 34.469 ms     | 33.6 ms      |

光影档两个开启窗口相对关闭窗口的中位差为约 0.13～0.46 ms，分布重叠，不能把它作为所有设备/场景的固定成本。均衡档窗口波动更大，未稳定量出独立 GPU 增量。无查询的光影/均衡 CPU 中位为 36.4/16.1 ms，RAF 中位为 33.4/16.7 ms；这是固定相机的观测，不是移动/所有游戏场景的 FPS 承诺，CPU 提交仍需优化。

该固定场景几何属性为 **351337732 B**，比 0.103 增加 **1707258 B，约 1.63 MiB**，恰好等于新分类属性的大小；扣除它恢复原 349630474 B。渲染目标 **234743560 B**、独立纹理 **12483771 B**、生产程序 51 个保持，无新增生产 pass 或渲染目标。这是已知公开资源预算，不是进程总显存。

最终构建只嵌入一份原始 393216 B 散射表，SHA-256 `d4834ef3babc1376f923f39d495d69dd9d7099f56feb40335a184af8a6b98fc6`，四份许可文本与构建副本逐字节一致。源文件和固定参考检出均保持可追溯。
