# 远景地形与雾的交接（0.127）

本批继续改善用户 Photon 森林参考图中的远近层次。新增的是本项目的远景生成与合成，复用既有 Photon 参考的天空、材质和封边曲线；没有把这项地形功能称为 Photon 源码的逐项移植。完整 MC/Photon 目标仍在开发。

## 实际行为

近处完整玩法视距仍为 10。晴天 87.32～118 是完整方块与远景背景的交接段；远景自身在 176.12～238 向天空淡出，约为原封边距离的两倍。主世界相机远平面改为 480，下界、末地保留 220。物理空气模型和天气仍使用既有共享参数，这些数值不能全部统称为一个雾滑杆。

后台 Worker 使用同一个 `World` 生成器和种子，带入已保存的方块、状态、流体修改与村庄排除。每个任务生成一片 32×32 轴坐标区域及正向边界，临时持有 25 个真实区块；结果以可转移的类型数组返回。显示窗口为 13×13 片，随玩家移动更新，并保留一片行走余量。传送超过余量时先退回完整近景封边，等可见核心补齐后再接入远景。

每个 4×4 柱组保留实际最高表面和类型，地面另外剔除天然树木，避免把高树直接连成绿色山丘。树冠、树干用有贴图的分层六棱体表示。高处玩家建筑和水源会贡献到最高表面，修改相同坐标也会触发更新。代理不参加瞄准、碰撞、生物和玩法模拟；并非完整精度的远处建筑或地下洞穴。

远景先渲染到一份 HDR 颜色/深度目标，近景封边和天空读取同一视角的背景。背景深度至少位于近景交接终点之后，避免近远几何互相切掉造成白点。远景沿用图集、群系色、共享日月光和云影；显卡恢复时重建目标并预编译其场景。

## 验证与保留的失败

新增 3 项 Node 检查覆盖真实生成器在负坐标相邻片的主表面/地面数据一致性、细柱建筑与同坐标替换/挖除/水源，以及编辑版本与归一化群系颜色进入几何属性的约定。完整 254 项 Node 与生产构建通过。

最终开发版为 **1 项场景流程**，包含自然丛林的远景开启/关闭对照、远处同坐标建筑修改、传送、三个画质档和一次真实上下文丢失/恢复。可见窗口 169 片，生成任务临时区块上限 25，完整玩法区块保持 529。恢复前后的时间、位置、编辑记录与远景片数一致，页面及 GL 诊断无异常。恢复截图保留正常暂停面板，不能拿它替代无面板的画面验收；已实际查看此前的丛林对照与各档截图。

发布版另有 **1 项真实控件流程**，通过界面导入/导出带远处木柱的 v16 存档。开发 API 始终不存在，通过观察实际 WebGL `airDistantBlend=1` 提交确认远景已接入，而后才测量和导出。时间、位置、天气、库存及地表编辑保持一致，页面/GL 无异常，未锁鼠标。

固定 900×650、光影档、同一丛林镜头的 80 个正常渲染帧记录 GPU 中位 **25.523 ms**、p95 **31.465 ms**，CPU 提交中位 **31.0 ms**，RAF 间隔中位 **33.3 ms**，查询 busy/disjoint 均为零。这是最终版本的单场景观测，没有配对旧版计时，不能据此宣称性能提升或所有场景帧率。截图与像素读回不在计时窗口中。

该丛林的远景几何为 1,566,672 个非索引顶点，已知属性约 **115 MiB**；一份 900×650 的半精度 HDR 颜色与 32 位深度目标约 **6.70 MiB**。图集与既有光照参数共享。这些是显式资源估算，不是进程峰值显存，几何体积仍有优化空间。

首个原型虽然保留了生成数据，但把森林连成光滑绿色山体，且抖动剔除造成白色孔洞，因此没有发布。改为分离地面和冠层、背景颜色与深度合成后，白孔消失。后续实景发现群系颜色字节未归一化，远处大面积发白；修正为与原生材质相同的归一化属性，同时给生成后的网格补上云影。保留这些失败截图，不能把“浏览器断言通过”作为画面正确的充分证据。

一次恢复脚本在同一个丢失事件轮次中立即调用 `restoreContext`，被浏览器拒绝；已停止那一批的所属进程，改为独立界面步骤后重试。该失败不能登记为成功恢复。

## 限制
