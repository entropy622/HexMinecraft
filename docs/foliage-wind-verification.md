# 天气驱动的树叶与草花风动

0.137 将近景树叶和原生草花接入 Photon 参考的定向阵风、多频摆动与持续天气风强。可见材质、阴影材质与水面捕获共享位移，草花根部固定，落叶粒子同步主风向。存档仍为 v16，视距与雾距保持；按用户请求，本批提交、推送后暂时停止开发。整体 MC 和 Photon 目标仍未完成。

## 来源与宿主适配

对照只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [vertex/displacement.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/vertex/displacement.glsl) 和 [weather/core.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/weather/core.glsl)。派生范围见 Photon notice。

`src/foliage-wind.js` 使用源 30° 主风向、数值噪声 G 通道的平方阵风、三阶频带摆动和 `0.3 × 世界时间`。强度采用 `(0.25 + 0.66 × 雨量) × (0.5 + 天气风强)`，树叶为草花的一半。世界坐标保持邻接面与平移后的区块相位一致，时间沿用现有存档时钟；暂停不累积新的风时钟。

天气风强直接来自已经用于云与雾的 `cloudWeather` 气候快照，包含绝对世界时间与湿润度。植物共享其风强标量，云层继续使用各自的速度和方向。即使关闭云绘制，气候快照仍正常生成，植物风动继续工作。

宿主 `skylight` 顶点属性已经是 `(光级 / 15)^2`，直接作为源平方天光响应使用，避免再次平方导致过强衰减。草花沿用原生高度锚定并消除根部微小位移，玩家接触弯折继续保留；零天光处的风位移为零。落叶粒子的方向与强度是宿主外观适配。

噪声采样复用当前 graphics owner 已拥有的 Photon 数值纹理头部，保持与云覆盖缓存切换独立。没有新增生产纹理、渲染目标、pass、几何属性、玩家设置或存档字段。独立农作物模型、远景植物、源高植株上下段分类仍待统一，不能据此宣布所有植物风动迁移完成。

## 实际顶点与生命周期

`tests/foliage-wind.spec.js` 的一个浏览器流程读取实际树叶、草花及各自阴影顶点程序的位移。诊断仅替换最终投影位置和片元输出，保留真实风动代码、纹理与 uniform；独立 CPU 参考对数值噪声作双线性采样并计算源位移。

每次探测包含 96 个采样值，覆盖两个时间、模型平移、部分天光、零天光、草根与不同世界位置；这些值不计为更多独立场景。可见 / 阴影位移逐值一致，草根和零天光风位移为零。首次及真实设备恢复后的最大 CPU / GPU 位移误差均约 `0.00006033`，GL 错误为零。探测时玩家位置设远，用于隔离风与接触弯折。

实际 graphics frame 在光影、均衡、流畅及返回光影时，均读取同一气候风强。时间 70、晴天风强为 `0.429171`，植物强度约 `0.232293`；雨量 / 湿润度为 1 时，风强约 `0.759171`，强度约 `1.145846`。时间 700 的晴天风强约 `0.708002`，确认晴天也随持续天气变化。各画质档和设备恢复后均保持噪声纹理引用正确。

已有 `tests/foliage-depth.spec.js` 流程通过，在 900×650 与 713×509 检查静止、风动和水面保护边界。主视图与水面捕获在启用 / 关闭深度预绘制时的 HDR、深度逐值一致，页面错误和警告为空。

## 自然森林与成本

改生产代码前先采集 0.136 基线；新旧都使用自然种子 624、日间森林同一镜头、时间 70 / 71 / 72、固定曝光 1、1920×1080、光影档 1.7。没有地形编辑，显示 441 个近景区块、529 个加载区块和 169 片远景。截图保留原始 PNG，整体冠层与参考图的差距仍在。

RTX 4060、Chrome ANGLE D3D11 下，各版在时间 72 另取 120 帧 GPU 计时。截图和读回位于计时窗口之外，最终窗口的 busy、disjoint 均为零。

| 场景阶段 | 0.136 中位数 ms | 0.137 中位数 ms |
| -------- | --------------: | --------------: |
| 主视图   |        5.719040 |        5.720064 |
| 水面捕获 |        5.657600 |        5.620736 |

当前镜头未显示明显额外场景阶段成本；不同运行有波动，不能据此宣称性能提升。每个版本中的 4560 次查询对应渲染批次，不是独立测试场景。已知资源估算中，渲染目标为 `301568680` 字节、独立纹理为 `14983610` 字节、几何属性为 `440832748` 字节，新旧一致；这些估算不等于进程显存。

首次对照脚本误写只读快照中的时间，且计时出现 9 次 busy，结果保留为无效基线。修正为正式时间推进接口并增加时间断言，允许该捕获指定更大的有限查询队列；其他调用仍默认 256。重新采集的 `baseline-final` 与新版同条件，全部查询有效。首轮原生流程在测试手动调用 graphics frame 时缺少天气列缓存而失败，补齐真实 `WeatherColumns` 后重跑通过。实现核对中另修正了宿主天光平方编码的映射。
