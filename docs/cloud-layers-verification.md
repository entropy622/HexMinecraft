# 天空尺度、多层云与天气形态验收

基线 0.85 / `3edc8ea0f07716671fbe756f41acdad46d91125b`。本批独立改写云场与积分，参考 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的云层合成、形态和天气派生关系，不复制其源文件或噪声素材。天空大气与 SH 由另一分支实现。

## 动手前五判断

1. 结构性：天空与地形的射程分离、按最近云层重投影以及共享密度/透射规则，解决低仰角空白、远云历史拒绝和云影不一致这一类问题。
2. 调用负担：沿用现有画质、云开关、种子、时刻与天气输入，不增加玩家设置或存档字段。
3. 可推导性：温湿形态来自现有世界的连续温湿噪声和天气强度，三层风位移从种子与游戏时刻解析计算，不引入天气计时器。
4. 最小复杂度：扩展已有一个半分辨率 MRT 积分与每实际视图历史，不建无限层注册器，不为每层分配一套历史。
5. 泛化范围：同时覆盖地面、云内、云间、云上、前景与水捕获；固定的三种云有不同密度形态，避免只针对一幅参考图调亮。

最小改动是保留现有通道与低档云，在云场中明确三个有限云带、天空交点与风，并修正既有历史数据语义；仅增大相机远平面会改变地形成本，复制三套 pass 会增加分配和维护，单改亮度无法解决形态或层序。

## 实施前完整失败类别

- 射线：天空误用地形 far；低仰角无云；近地形误被远云覆盖；相机在层内/层间/上方时交点符号或顺序错误；近水平射线除零；大世界坐标、负坐标、极高相机出现 NaN。
- 密度：三层复用同一外观；积云没有平底/团块、高积云没有细小分块、卷云没有纤维；宏覆盖只靠全局亮度；湿热与干冷没有形态差别；种子周期、噪声接缝；极端雨/雷强度导致无限密度。
- 光学：层顺序反转；透射率不在 0..1；最近代表距离平均到层间空处；上层遮光缺失；负太阳高度黑云/发光错误；空气透视重复乘云透射或擦掉轮廓；浓云底部与薄边没有层次。
- 风/天气：三层同向同速；相机移动改变云锚定；天气强度变化把风场瞬移；时刻/种子重载不确定；跨群系切换有边界跳变；暂停时仍漂移；另造保存状态造成回读分叉。
- 历史：sky sentinel 被当近地形；最近层风补偿错误；层分类变化重用旧层；新建筑或新地形穿云、拆除后鬼影；投影 jitter 抹平细节；大位移、时刻跳变、质量/开关/维度切换未冷启动；主视图和水捕获互相污染。
- 共享场：可见云、表面/水/雾的云影不一致；层间透射没有相乘；云上仍有下层云影；低档几何云被新体积规则替换；禁用云或非主世界残留阴影。
- 生命周期：resize、DPR、真实上下文丢失/恢复、dispose 后目标或 history 泄漏；异常中 renderer target/autoClear 未还原；捕获反馈回路；新增纹理 CPU/GPU 成本失控。
- 验收：相机/曝光/时刻不同却宣称配对；只看截图无 HDR/深度/历史数据；软件 renderer 当硬件性能；忽略首轮失败、GL 警告或实际 renderer；截图没逐张审阅。

## 先写的真实场景

`tests/cloud-layers.spec.js` 从首页进入创造世界并用现有测试入口固定游戏时刻/镜头，使用真实 Graphics、SceneFrame、云 MRT、地形深度和水捕获。只在 DOM Pointer Lock 设备边界使用已有 fixture。保存固定曝光截图与稳定 JSON，读取生产半浮点 MRT 的辐亮度、透射、代表距离、层号与历史年龄。

场景包含低仰角远云与近屋顶、各层相机/层序、天气渐变与独立风、主视图/水捕获、质量/维度/尺寸/上下文恢复。既有 clouds/cloud-history 场景继续检查结构透光、历史收敛与真实前景遮挡。CPU 测试只补解析天气/风与噪声边界，不代替图像验收。

`tests/fixtures/cloud-field-probe.js` 只探测当前生产 GLSL、共享 uniforms 和真实纹理，样本坐标从实际云 MRT 反投影取得。正负远坐标各横移 12 轴向格后，比较固定 world 点与随相机移点的密度/云影误差，要求固定点显著更稳定，且移点产生实际变化；仅断言 wind 未变或有限值不能证明世界锚定。另读出三层真实光程的 T，验证总阴影的乘积规律并要求上层实际影响不为零。云上视图应优先见到最近的卷云，位于中高层之间仰望应只见卷云，避免仅累加三层像素数。

CPU 准备阶段尚未运行 GPU，当时没有图像或帧耗通过的证据。实跑时记录首轮失败、实际 ANGLE D3D11 renderer、errors/warnings/GL、成对图像、真实计时、保留路径与进程/端口释放。

## 实施坐标与当前检查

大气接口约定 1 本地距离单位 = 20m，虚拟地球半径采用 6371000m / 20。三层基底分别为 52、160、300，即 1040m、3200m、6000m；主层保留已有高度，另外两层与参考实现的量级一致。天空射程按当前相机到最高/最低云带的最大水平切线距离推导，加 1000 本地单位覆盖缓冲，上限 60000 保持既有半浮点 MRT 距离有限；视线遇虚拟地球先截止，避免云出现在地平线下面。地形相机 far、区块半径和世界碰撞不变。

世界地形是平面。云的球壳因此是当前主视图的局部切平面适配，球心 xz 跟随主相机，密度 xz 始终使用世界坐标；水、地面与雾共用同一个曲率锚。历史先扣实际层风，再保持球壳高度映射到前一视图的局部切平面，不把相机平移误当云风。20m 平移在距 20km 的固定云点约带来 0.063m 高度差，属于明确的小量曲率变化；测试允许它，但必须能排除整片密度随相机移动。这里没有实现球形地形或全球绕行，不宣称逐像素复刻 Photon。

新增一个按种子惰性生成的 64³ R8 Worley 纹理，GPU 数据 0.25MiB；两次细节采样共用它，不复制参考纹理。三层仍使用既有半分辨率 MRT 和每实际视图两份历史，没有增加独立层目标。体积积分按仰角分配积云 24..40、高积云 12..20、薄卷云 6 步，各密度命中用原有四步二次分段光程估计；实际硬件成本待 GPU timer query，不用步数推测帧率。

CPU 阶段：现有 Node 183/183、新增 3/3、生产构建、目标文件格式与语法通过。首次新增检查因使用 Three 默认 far=2000 的测试相机而失败，已改为生产相机的 72° / near .08 / far 220；没有改产品射程去迎合 fixture。构建仍有原有大 chunk 提示。该 CPU 阶段尚未运行 GPU 场景，后续结果见末节。

交付复杂度检查：新增 uniforms 均由现有世界输入派生并供真实云场/积分/历史消费；没有玩家选项、存档格式、兼容读取或测试参数。固定三层用有限数组表达，不新增注册器或第二天气系统。纹理种子标记只避免低档无用生成与每帧重复生成，旧未使用的 3D 切片值噪声已删。

## 共同天空整合

先运行真实满月/新月 E2E `tests/cloud-sky.spec.js`。同一自然森林镜头、曝光 1，时刻 450 与 2850 的日月方向完全相同。天空亮度降至约 37.5%，云环境光却从 0.10874 仅降到 0.10838，原有白色底光压过了实际月光。首轮在预期的环境光响应断言失败，截图、JSON、trace 和全部所属进程/5193 释放记录保存在 `hexminecraft-photon-0.86/cloud-sky-red`；RTX4060 / ANGLE D3D11，GL 0、页面错误 0，天空模块的 X4122 编译警告原样保留。

整合后，云使用地形同一份已发布 SH 的朝上半球辐照度 / π，不再插入固定白色底光，也不再次乘一套昼夜/降雨亮度。闪电继续独立产生瞬时照明。几何云与体积云都读取共同天空的方向辐亮度及 RGB 空气透射；体积层采用 `Lcloud * Tair + Lsky * (1 - Tair) * (1 - Tcloud)`，保持云透射不变，再按近远合成。此处是云前分子空气透视，既有近地高度湿霾仍单独积分，并未宣称完成整套 Photon 低空介质。

依赖直接从已有 `SkyAtmosphere.probe` 传给 `HexClouds`，同时删除旧 cloudZenith/cloudHorizon、固定白色资源和旧 frame 颜色/昼夜参数；没有新增玩家字段、保存状态或兼容分支。生产代码净减行数。整合后 Node 188/188 和构建通过；本段记录时尚未运行整合 GPU 绿测，不表示画面、云历史或性能验收通过。

## 0.86 串行 GPU 结果

组合检查 14/14 通过，包含三层视角、正负远坐标世界锚定、连续天气、月相环境光、部分透射及历史收敛。三层视角、晴雨天空和最后的森林镜头已实际查看。云历史收敛的误差比为 0.4313，平均误差为 0.00830；这些数值仅验证重建行为。

早期高云固定视线落在天然覆盖空洞，后来由真实云 MRT 选取可见样点，断言仍要求高云实际参与积分。风场样点使用生产天气函数。晴天主层和高积云覆盖有所降低，卷积云有独立斑块覆盖。原始失败和修正后的图像均保留，没有将错误与编译警告静默过滤。

当前画面仍存在主云层过薄、条带明显和薄高云偏弱的问题。主层厚度约 160 m，Photon 默认积云的量级约 1200 m；目前的双 HG 加一次低消光回散也未覆盖 Photon 的多阶散射、前向峰和粉末效应。它们仍是后续目标。[参考镜头记录](photon-reference-scenes-verification.md)列出实测显卡成本及一次未复现的黑帧捕获，技术通过不代表参考图艺术验收。
