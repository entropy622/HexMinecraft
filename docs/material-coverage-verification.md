# 默认材质覆盖与分类

0.140 为当前 236 种方块建立明确的材质路径，扩展原生表面细节，并补充建筑、地下和自然场景预览。此处的完整覆盖指本项目已支持的方块，不等于新增全部 Minecraft 内容，也不代表 236 种方块均重新绘制了独立 PNG。

## 当前覆盖

| 路径             | 方块数 | 实现                                                                   |
| ---------------- | -----: | ---------------------------------------------------------------------- |
| 源图             |    141 | Voxels Reworked 与既有 Pixel Perfection / VoxeLibre 图像               |
| 材质复用         |     28 | 地毯对应同色羊毛、装有液体的炼药锅对应铁质锅体、切面与机关对应实际基材 |
| 专用绘制         |     46 | 原生六棱形体、洞穴植物、机关、发光部件与补充像素图案                   |
| 透明或着色器路径 |     21 | 十八种玻璃及传送门类，保留专用透射或着色器                             |

`native-material-catalog.js` 的路径被实际图集创建与像素绘制调用。新增未分类方块会明确失败；图像载入会检查所需方块源图，避免缺失文件静默变成随机底纹。236 种方块的顶面和侧面均从实际图集中读回并检查非空，同时输出带名称的完整材质图。

## 贴图和表面细节

Voxels Reworked 的固定 release 33761 选择从 27 张扩大至 52 张原始 PNG，共 17,691 字节。新增选择包括金属块、原矿块、紫水晶块与母岩、末地石、丛林原木、下界岩与菌盖、萤石、红石矿及烟熏炉表面。源文件与逐文件哈希保留；动画条带使用首帧，源图的透明像素保持。来源与 CC BY-SA 4.0 许可见 `public/textures/voxels-reworked/NOTICE.md`。

另外补充原生玻璃的细边与反光像素、仙人掌上下表面、苔藓层次、洞穴藤蔓和孢子花纹理，以及三维晶体侧面的连续色带。晶芽不使用平面透明植物贴图，以保留现有三维轮廓。丛林原木开始使用源图，其余丛林木作继续使用原生绘制。

实际图集中的 181 种方块具有法线数据，上一批的候选范围为 64 种。其中 144 种同时提供原生粗糙度，37 种金属、宝石、雪等保留已有光学类别，只增加法线。其余 55 种继续使用透明、植物、自发光或机关的专用路径。

这些是图集侧的覆盖统计，自有表面程序负责消费这些数值通道。独立门等仍走宿主适配；全部独立模型的完整 PBR 尚待迁移，不能把图集覆盖统计理解成所有模型都已完成 PBR。

标记纹理 B 为 `255` 时使用原生法线和粗糙度，为 `128` 时仅使用原生法线并保留原有反射参数，为 `0` 时按外部 labPBR 语义处理。两种原生类型都不会把数值图 B 误当作天空 / 方块光 AO。外部颜色会清除该表面的原生凹凸，外部 `_n` / `_s` 优先级保持。

默认 normal 图集仍为 256×2112 RGBA8，数据仍为 2,162,688 字节，附件数量和全屏 pass 未增加。更多表面会执行已有法线采样，不能据此推断帧率无成本或性能提升。

## 一致性与验证

地毯直接使用同色羊毛，装有液体的炼药锅共用锅体材质。MC 资源包导入补充地毯、门的上下半部、木围栏与炼药锅的正确贴图名称。库存图标与世界使用同一表面图集。

Node 检查覆盖全部方块路径、别名循环、源图文件、52 张资源的哈希与帧尺寸、细节强度、织物、光学保留策略，以及既有 PNG / labPBR 和表面程序接口，共十三项测试。

GPU 验证范围包括 1280×800 的建筑材质、地下材质和自然森林三个场景；完整图集读回；金属 / 宝石 / 木材与玻璃光学；资源包覆盖、恢复默认及显卡恢复。新场景在 0.139 保存同相机、同时间和天气的旧版截图，周围均为自然 seed 624 世界。所有预览和验证使用后台 Microsoft Edge、独立端口与 Pointer Lock DOM mock。

金属 / 宝石 / 木材的实际参数、高光、彩色玻璃过滤和不透明遮挡检查通过。石材与木材的粗糙度改为原生贴图后，旧检查的固定类别假设不再适用；增加独立的原始数值贴图读回，并保持原有 0.003 误差阈值。自发光的材质外壳、源辐亮度、点亮 / 熄灭与显卡恢复检查通过。

设备恢复后的记录探针最初读到零；补齐同一浏览器回合中的场景深度绘制，并恢复调用前的渲染目标后，恢复前后严格相等。产品材质与渲染代码在这些检查修正期间保持冻结，三组画面无需重新生成。

发布构建的自发光和表面程序两项检查通过，覆盖普通 UI、生产材质绘制、显卡恢复及 v16 存档导出。实际运行结果和构建哈希保存在证据目录。前后对照页为同目录下的 `comparison.html`，完整材质表为 `all-block-materials.png`，原始分类和数值为 GPU 输出中的 `coverage.json`。
