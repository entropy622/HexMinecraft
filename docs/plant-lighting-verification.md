# 草丛与野花的 Photon 透光响应

0.97 将主世界光影档的装饰草丛、装饰野花，以及世界中的虞美人、蒲公英、仙人掌花接入共享主 SSS 和透射 sheen。独立花朵从门材质改用植物材质，可见面与自定义阴影深度材质共用草根锚定和风动画。沿用 v16 与现有画质设置。

## 来源与实现

只读对照 Photon 固定提交 `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [material.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/surface/material.glsl#L181) 与 [diffuse_lighting.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/diffuse_lighting.glsl)。小植物采用 **SSS 强度 0.5、sheen 1**；叶片保留强度 1、sheen 0.5。方向天光按植物强度在原有面朝向响应与半强度向上天空辐照度之间混合。

`foliage-shader.js` 共用叶片的主相位、吸收与光程程序，分别保留叶片环境 SSS 和薄片植物的天空响应。颜色、归一化相位、实际辐照度、0.2 几何射线响应尺度及线性 sRGB 适配见 [0.96 记录](leaf-primary-verification.md)；没有把宿主光程或工作色域描述为与 Photon 完全相同。普通日月漫反射在强度 0.5 时变为 0.75，完整入射能量继续用于透射和反弹，本地点光与体素 RGB 保留原有响应。

近距允许花朵自身空气格中的交叉薄片使用既有 0.06 微观厚度，避免将其直接归为不透光模型；屋顶、半砖、未知边界和远距真实体素查询继续阻挡透射，玻璃、云与水的光场过滤沿用共享路径。薄片内部和非体素模型的精细光程仍是近似，尚未实现 Photon 的 SSRT。

深度预绘制通过材质标记限定到厚叶片。花朵保留自定义风动阴影深度材质，主视图与水面捕获各绘制一次；装饰草丛沿用原来的阴影接收方式。没有分配新纹理、几何顶点缓冲或渲染目标。

- **204 项 Node 测试、生产构建与修改文件格式检查通过**。
- **20 项完整功能回归通过**，覆盖三项新增植物检查，以及叶片深度/透射/环境光、独立光程与太阳响应数值核、材质、软阴影与表面反弹光。两个尺寸的 12 组完整 HDR/深度对照继续零差异。
- **自然森林与生产 UI 存档导入/再导出通过**，合计 **22 项不同的功能浏览器检查**；重复执行的开发检查与性能窗口不重复计数。最终各批页面、GL 和 shader 错误及 shader 警告为零。

实际原生材质的中心区域选中虞美人 946、蒲公英 961、仙人掌花 961、草丛 299 个有效像素，四类均有太阳透射。正面方向光漫反射保持预期的 0.75 比例，误差不超过 1 半浮点 ULP；真实点光的有效像素 RGB 逐元素相同。

近距和阴影范围外分别检查三层叶片、实心屋顶、上半砖、三层红/蓝玻璃及移除恢复。叶层衰减透光，屋顶/半砖的新增透光为零，玻璃显示对应的 RGB 过滤，移除后恢复在原有 3% 门槛内。实际云场 T 为 0.3798828，新增植物透光比例约 0.3799781。月光保持有限正值，暂停风的能量一致，推进时钟改变实际像素。

植物在 1.7/1/0.65/1.7 画质间切换，太阳 SSS 强度分别为 0.5/0/0/0.5。713×509 水面场景捕获选中 938 个植物像素；真实图形上下文恢复后仍为 938 个，透光能量均约 0.20822145，GL 错误为零。

首轮测试的背光机位落在支撑地面下方，选中零个植物像素；已修正为地面上方的机位，并保留真实支撑与原有可见像素门槛。该失败及原始记录保留，没有通过降低检查标准交付。

## 画面与成本

实际复查了最终 900×650 默认明暗适应和 1920×1080 固定曝光森林，以及近景草丛和花朵。植物有更清楚的背光层次，部分花朵形成明显亮点；冠层暗部、整体偏暗黄绿与用户参考图的差距仍在。曝光、饱和度和默认明暗适应设置没有调整，本轮不代表整体艺术验收完成。

固定种子 624、时刻 30、FOV 72、1920×1080、光影档与曝光 1，预热后各采 120 帧。最终 GPU 绘制批次合计中位数 / p95 为 **32.330 / 33.025 ms**，与 0.96 的 32.182 / 32.744 ms 接近。关闭叶片预绘制的同程序对照为 42.620 / 43.494 ms；它继续执行本轮完整植物与叶片光照。

初版让花朵也进入深度预绘制，记录帧 2912 次提交；最终回到 **2676 次**，减少 236 次，叶片预绘制继续工作。初版与最终版属于独立窗口，不能把 GPU 中位数约 32.837 → 32.330 ms 解释为所有场景的稳定提速。

CPU 提交中位数开启/关闭预绘制分别为 32.5/15.7 ms；关闭 GPU 计时查询后仍为 **33.0/15.1 ms**，此前的 CPU 回退未解决。无查询 RAF 间隔中位数约 35.1/35.9 ms，不用于推导稳定游玩帧率。GPU 数字排除初始清屏、全部浏览器和合成成本，CPU 包含原生 WebGL 调用。
