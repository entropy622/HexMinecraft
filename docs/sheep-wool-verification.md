# 彩色绵羊与羊毛验证（0.82）

## 实施前判断

1. 结构：以已有十六色调色板连接绵羊颜色、剪毛 / 击杀掉落、再生、繁殖和可摆放羊毛；不只增加创造菜单色块。
2. 负担：玩家沿用主副手使用、喂养、剪刀和合成；只为实际绵羊保存颜色，不增加设置、依赖、保存版本或工具参数。
3. 可推导：新生羊颜色由父母和现有染料配方推导，自然色由实际群系和随机数推导，材质与物品名均取已有调色板。
4. 复杂度：原有 `wool` 作为白羊毛的唯一 ID 并成为可摆放方块，其他十五色新增独立 ID；沿用已有合成材料选择、Fauna、体素几何和保存入口，不引入通用遗传或染色框架。
5. 泛化：覆盖十六色、主副手 / 创造、同色不消耗、剪毛 / 幼崽限制、草地再生、可混色和不可混色父母、死亡 / 自动剪毛、区块与维度保存及材质恢复。

最小完整改动须把真实动物互动、持久化和羊毛方块连起来。颜色仅放在 UI、只改模型 tint、或只让白羊掉彩色物品都不能满足该流程。已有 v16 存档中羊没有颜色字段，缺省白色具有真实历史输入；新保存写出明确颜色，拒绝非法颜色，不另建迁移或第二种物品别名。

参考 [Minecraft 染色与繁殖](https://www.minecraft.net/en-us/article/craft-colourfully-dyes)、[1.21.5 群系自然羊色](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-5)、[1.20 预发布的任意色羊毛重染](https://www.minecraft.net/nl-nl/article/minecraft-1-20-pre-release-1)、[Mojang 绵羊行为样例](https://github.com/Mojang/bedrock-samples/blob/main/behavior_pack/entities/sheep.json)（2026-10-28 核对）。借鉴染色、传色、吃草恢复和温寒暖自然色规则，独立接入本项目。保留项目已有三份剪毛、120 秒草地恢复和 180 秒幼崽成长时长，不声称所有 AI 时序与原版相同。

## 实施前失败类别

- 主手 / 副手染料不能作用于真实羊，重复同色仍扣料；剪毛羊或非羊被染、幼羊无法染、创造模式消耗；一只羊变色污染其他羊。
- 动画伤害闪色把染色冲掉，剪毛后毛层仍显示、裸身错误变成整张纯色；保存 / 远离加载 / 维度往返丢失颜色或剪毛倒计时。
- 剪毛、击杀和发射器掉错颜色；剪毛后再杀重复掉毛、幼崽掉成羊材料、背包满吞掉产物、剪刀耐久丢失。
- 草地恢复时变回白色，不在草地仍恢复；吃草完成后地表未改变 / 画面未更新，两个羊反复消耗同一块草、暂停仍计时。
- 同色父母变成白色；红黄不产橙色、父母顺序改变混色；不能混色时生成任意第三色；自然色无群系差异或粉羊不稀有。
- 羊毛仍只有材料而不能摆放，十六色缺项；世界 / 物品 / 手持色不一致；透明、错误遮光、剪刀效率或正常掉落错误。
- 羊毛与染料制作少付 / 复制、混色羊毛不能重染；满库存吞料、非羊毛冒充原料；旧床 / 线配方被材料分类扩宽或旧配方索引改变。
- 绵羊颜色保存值越界或非羊颜色被接受；现有无颜色 v16 羊不能正常继续。
- 测试触发原生 Pointer Lock 或抢占前台鼠标。

首先从真实右键互动复现羊不能染色；隔离检查再覆盖自然色阈值、配方材料和数量、掉落、繁殖与保存边界。实际回归走现有 World / Fauna / 主副手 / 合成 / 保存继续和发射器，设备边界沿用后台 Pointer Lock fixture。

## 结果

- `npm run check`：123 项逻辑检查通过（原有 115 项和新增 8 项），0.82 生产构建通过。新增检查使用实际 World、Fauna、库存、合成、光照、红石和完整存档解析，覆盖 256 种羊毛重染组合、九种双亲混色及顺序、三种群系各十万离散自然色阈值、非法颜色和无颜色旧 v16 输入。两个实际羊同时恢复时，一块草只让其中一只长毛。
- 后台浏览器相关回归：11 项通过，包括七项新牧场流程、发射器彩色剪毛、移动生物与水下照明、实际药箭及上一轮染色玻璃合成。最终修正吃草姿态后，再跑染羊采集与吃草两项，均通过；这些复测与上述场景重合，不算新增独立场景。
- 玩家染红羊只用一份染料，同色重复不扣料，剪下三块红羊毛；放一块后存档继续剩两块，再用剪刀采回一块，共三块。满背包剪毛产生三份散落物，腾出一槽后全数收回。发射器沿用真实命名剪刀及耐久，剪白羊 / 蓝羊后分别掉三块对应颜色，随后自动击杀已剪毛羊不重复掉毛、不计玩家经验。
- 主手石头、副手蓝染料只染目标羊，另一只保持白色。实际受伤闪色结束后 HDR 生物像素仍以蓝通道为主；创造染红不扣料，经过下界 / 主世界往返后像素和存档仍为红色。真实喂食红黄双亲产橙色幼崽并随继续保留；蓝黄双亲只传父母之一的颜色。
- 真实个人合成 UI：两块红羊毛加两份蓝染料得到两块蓝羊毛，四份线织一块白羊毛，材料完整扣除。原有白羊毛床和捻线配方未被扩宽。
- 吃草场景从真实原生存档的剩余 1.7 秒恢复计时开始；石地和暂停菜单均不扣时。恢复后羊低头、脚下实际草块变泥土、毛层长回蓝色，再剪得三块蓝羊毛。实际模型口鼻距脚下地面大于 0 且小于 0.35 格，截图核对朝向和毛层。
- 生产预览在 5176 端口通过真实 UI 搜索十六色羊毛、选择与放置蓝羊毛，并从原生导出核对自然羊色；运行时无开发入口、WebGL 错误为 0、页面 / 控制台错误为空。使用已有光影档，颜色、材质和建造接入现有光照管线。

首次真实右键检查复现染料不能染羊，之后才加入实现。过程中纠正了非法数组颜色被字符串化接受的问题，以及误删仍被蘑菇图标使用的 Cloud 导入。相机切换后等实际渲染帧、暂停后取羊当前脚下坐标属于测试夹具修正，没有放宽材料、子代颜色或草消耗断言。首次吃草截图显示头部朝上；补入口鼻世界高度检查后原实现实测为 0.919 格、检查失败，修正头部旋转方向及下移后通过。

逻辑 / 构建、浏览器日志、存档语义 JSON、截图及源码 / 构建哈希保存在工作区外的 `sheep-wool-0.82` 证据目录。11 项回归后的产品差异只有 `src/mob-graphics.js` 的吃草姿态；已保存该轮哈希，再记录最终构建并做上述两项定向复测和生产预览。浏览器使用 headless Chrome，沿用仅替代原生 Pointer Lock 的设备边界夹具，没有操作用户前台鼠标或 5173 标签页。

## 边界与复查

颜色是羊独有的持久身份；`grazing` 由剩余计时和当前地表推导，未写入存档；两份 `woolMaterials` 引用分别更新毛层和裸身，仍由既有材质集合负责动画及释放。自然色和双亲传色虽各只有一个生产调用处，但属于可独立核验的数据规则，不另建遗传框架；混色直接读取已有染料配方。旧版缺省白色、原 `wool` ID、v16 保存版本和旧配方索引均保留。

本轮没有新增依赖、设置、纹理源文件或渲染目标。羊毛和图标沿用现有白羊毛贴图及 CC BY-SA 3.0，生物染色视图沿用现有羊皮肤及 CC BY-SA 4.0，已更新媒体说明。

尚未实现彩色床 / 地毯、草地自然扩散、完整觅食寻路 / 短草食谱及全部原版动物行为与时序。本轮新增玩法沿用现有 Photon 风格光影，未扩展光影算法；后台软件渲染测试也不代表真实硬件帧率验收。整体 MC / Photon 还原目标仍在推进。

复查改动规模：产品 12 文件净增 176 行；测试 3 文件净增 1184 行；文档 4 文件净增 65 行；配置 2 文件净增 0 行。文档记录玩法、证据、限制和媒体许可。测试覆盖实际用户流程、守恒和输入边界，未添加实现文本断言或替换项目自有模块。
