# 日间云边缘重建

0.136 修复体积云射线在薄云边缘漏采样后立即丢弃历史的问题，减少天空中的规则空点。实现位于 `src/cloud-volume.js` 的现有云重建 pass。存档仍为 v16，默认视距 10、地形雾起点 87.32、远裁面 480 保持。按用户请求，本批验证、提交与推送后暂时停止开发；整体 MC、Photon 与森林参考图目标尚未完成。

## 来源与实现

参考只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [d2_clouds_upscaling.fsh](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/d2_clouds_upscaling.fsh)，采用邻域表观云距离辅助重投影的思路。源派生范围见 Photon notice。

当前射线未命中云时，仅允许没有几何前景的天空像素寻找 3×3 邻域中真实命中的天空云距离，作为历史重投影锚点。层风补偿、层标记、前景状态、距离有效性和当前邻域颜色约束继续执行。使用的是重投影后的本像素历史颜色，邻居只提供距离与层信息。没有可靠邻域支持的晴空仍直接返回；有前景的漏采样像素不进入该补全路径。

复用现有主视图 / 水面视图独立 MRT 历史、重置与恢复机制。没有新增生产 pass、纹理、缓冲、设置或存档字段，也没有改变云密度、消光、曝光、宏观频率与采样相位推进。这仍是宿主的保守重建，未迁移源 checkerboard 时域放大。

## 日间自然场景

新增 `tests/fixtures/photon-daylight-scenes.js`，单独保留日间镜头。历史参考镜头的时间 30 接近日出，继续作为晨光基线；它不适合作为附件日间整体光色的唯一对照。

新镜头使用自然种子 624、时间 70，太阳实际高度 35.4218°，固定曝光 1、FOV 72、1920×1080、光影档 1.7，保留正常 TAA、锐化与后处理。森林眼点为轴坐标 `[-120,24.5,4]`，朝向 `[-98,29,-1]`，天空镜头朝向 `[-98,51,-1]`。显示 441 个近景区块、529 个含边界缓存的加载区块和 169 片远景，森林镜头中太阳位于画面内；没有人为地形编辑。

0.135 原生产实现先完成相同条件的基线截图。0.136 再记录森林、天空和修复 / 旧处理 / 恢复修复的天空画面。对照显示云边缘规则空点减少，仍有残余颗粒，森林冠层、远景与参考图的整体层次也仍有差距。日间镜头用于改善比较条件，没有更改游戏默认时间或调整曝光追图。

## 稀疏边缘诊断

`tests/cloud-edges.spec.js` 是一个实际浏览器流程，包含真实设备丢失 / 恢复。诊断使用静态日间镜头，视口 1280×720、真实云纹理 640×360；仅该诊断关闭最终 AA 和锐化，避免投影抖动混入误差，云自己的相位继续推进。

独立旧历史目标仅恢复原先的「未命中立即返回」分支，使用与候选相同的实际当帧云输入；先预热，再统计 8 个相位。选择集合完全由当前原始云输入决定，包含有真实邻域支持的漏采样像素。四倍主光线步数的同场积分作为透射参考，保留同一密度、光照和二次光线，因此它是重建诊断参考，不是独立 Photon 真值。

| 状态       | 旧处理空点 / 受支持样本 | 修复空点 | 旧处理透射 RMS | 修复透射 RMS | 前景泄漏 / 非有限值 / GL 错误 |
| ---------- | ----------------------: | -------: | -------------: | -----------: | ----------------------------- |
| 首次       |           34921 / 34921 |     9834 |       0.022603 |     0.022188 | 0 / 0 / 0                     |
| 设备恢复后 |           34921 / 34921 |    11567 |       0.023219 |     0.022962 | 0 / 0 / 0                     |

这些样本分布在 11505 个像素、8 个相位内，不能计为更多独立场景。空点减少约 67%～72%，透射 RMS 仅小幅改善，不能把空点比例解读为整幅画质提升比例。页面错误与警告记录为空。

## 回归、成本与发布包

既有 `tests/cloud-history.spec.js` 两项流程通过，覆盖投影抖动收敛、风与相机移动、建筑遮挡 / 再显露、部分遮挡、天气和真实设备恢复。收敛记录的晚 / 早方差比约 0.517，空间细节比约 0.953，均值误差约 0.01033；不通过单纯抹平云细节获得收敛。

日间天空在 RTX 4060、Chrome ANGLE D3D11 上进行修复 / 旧处理 / 恢复修复的顺序窗口，每个窗口 120 帧，截图和读回位于计时窗口之外。有效 GPU 查询中 disjoint 和 busy 均为零。

| 窗口     | 主视图云重建中位数 ms | 主视图云积分中位数 ms |
| -------- | --------------------: | --------------------: |
| 修复     |              0.131072 |              6.968320 |
| 旧处理   |              0.121856 |              6.959104 |
| 恢复修复 |              0.131072 |              6.995968 |

本镜头重建阶段增加约 0.0092 ms；这是单设备、静态天空镜头的局部成本，不代表所有运动场景或水面捕获的性能。生产资源数量不增加。

生产 build 后，专用 preview 上的一项真实界面流程通过：没有开发 API，实际绘制云重建着色器，导入、暂停、显卡丢失 / 恢复后继续绘制，导出通过严格 v16 校验；时间、天气、库存、地形编辑、方块状态和炉具数据保持一致。测试中显式启用体积云。另有两项既有参考资产 Node 检查与生产构建通过。

本批最终浏览器检查共五项流程：稀疏边缘诊断一项、日间森林 / 天空与阶段记录一项、已有云历史两项、发布包一项。没有重跑或扩报历史的光学参数矩阵。
