# 细雪验证（0.70）

## 实施前的设计判断

1. 结构：把细雪作为可见但可穿入的雪地材料，连接探索危险、装备防护和可再生收集，而非只加一个白色装饰块。
2. 负担：沿用主副手、桶、炼药锅、装备槽、蹲伏和跳跃，没有新增玩家设置或操作模式。
3. 可推导：脚底支撑、身体接触、皮革保温、降雪及遮挡由实际世界与装备计算，不让玩家指定环境标记。
4. 复杂度：复用体素、容器状态、生存伤害、现有 UI 与生物更新；冻结积累为运行时接触状态，离开后解冻，重载和重生重置，不添加存档版本或迁移路径。
5. 泛化：覆盖雪地自然生成、手动陷阱、主副手、皮靴表面支撑与攀出、玩家和生物、流体冲刷、雨雪和遮挡。

最小实现需要同一接触检测和冻结计时供实际玩家与生物使用；皮靴只提供自上而下的表面支撑，不能将整块细雪变成实体，否则玩家无法从内部攀出或主动蹲伏下沉。材料块与降雪收集使用已有世界和炼药锅编码；不引入新的流体类型、寻路框架或外部资产。

规则参考 [官方细雪说明](https://www.minecraft.net/en-us/article/block-week--powder-snow) 和 [Java 1.17 发布说明](https://feedback.minecraft.net/hc/en-us/articles/4402626897165-Minecraft-Caves-Cliffs-Part-1-1-17-Java)。本项目采用 7 秒积满冻结、之后每 2 秒一次冻伤，脱离后每秒恢复两秒积累；移动速度适配现有六棱物理，不声称逐 tick 等同原版。

## 实施前列出的失败类别

- 降雪仍不填锅；雨、雪、沙漠、屋顶、维度或已有水 / 岩浆 / 细雪混淆；不足三档就能用桶取出，瓶子误取细雪。
- 桶装取放不守恒，主副手、创造模式、满背包或重复交互造成复制 / 吞物；存档继续或卸载后丢失放置物和锅中状态。
- 细雪不可见、可被普通工具采集成非法内部方块物品，或选块得到不存在的物品；材质与普通雪完全无法辨认。
- 无靴仍站在表面；皮靴把整块变成墙；主动蹲伏无法下沉；内部不能攀出；高速落入仍受到普通落地伤害；飞行 / 游泳 / 蛛网 / 潜行及自动抬步回归。
- 冻结不积累、过早伤害、按帧率而非时间计伤；离开、暂停、皮革保温、创造模式、重生和维度变化时残留错误冻结或画面覆盖。
- 皮革只在快捷栏或副手就提供防护；铁甲误保温；单件皮革只防伤却不能解冻；皮靴与其他皮甲的支撑能力混淆。
- 燃烧者未被扑灭或不消耗实际接触细雪；流体不能冲刷或错误掉物；普通雪被一起改为可穿入。
- 生物仍瞬移穿过雪坑、没有减速 / 冻伤、死亡清理失败或飞行与特殊生物更新回归。
- 自然刷新误把动物或敌人创建在细雪内部；已有生物进入玩家建造的雪坑却被全局刷新规则排除。
- 雪地斑块随加载顺序、负坐标接缝或卸载变化；覆盖建筑或其他维度；老世界已记录修改被自然生成覆盖。

### 实际结果

- 实施前，真实雪原降雪仍留下空炼药锅，比较器为 0；实现后得到 `powderSnowCauldron3` 与信号 3。主副手取放后只有一个空桶，继续游戏保留实际锅和方块修改。
- 无装备从高处落入后生命保持 20，继续停留冻伤至 19。冻结积累 1.25 秒时暂停，计时和世界时间均保持不变；穿皮甲解冻且生命不再下降。皮靴支撑时视点高度约 44.645，蹲伏可下沉、按空格可攀出，换铁靴会陷落，脱掉皮甲后重新积累冻结。
- 通过正常存档导入的鸡从高度约 42.4 逐步陷落到 37，生命从 4 降到 3，最终死亡清理并产生 2 根羽毛与 1 块肉。使用既有掉落规则，没有新增测试用生物接口。
- 燃烧玩家实际消耗接触的细雪并熄火；水桶流出后冲掉细雪。长按左键采掘不产生内部细雪物品，创造选块得到细雪桶，放置后继续游戏仍保留。
- 将真实已加载地表覆盖两层细雪，再走正常动物刷新流程，修复前有 35 只动物刷新在细雪内部，修复后为 0。此限制只用于自然刷新和刷怪笼入口，已有生物进入雪坑仍会陷落、冻伤。

### 同轮发现的近战问题

洞穴蜘蛛举盾回归在修改前的提交 `fc01c7a` 独立源码上重放两次，出现一次失败、一次通过。逐帧记录显示，同一只蜘蛛进入攻击距离后继续穿过玩家，背后攻击导致生命降为 16；同时测试默认轮询间隔可能错过仅持续约 0.2 秒的举盾反馈。

本轮让近战生物到达原有攻击距离后停止追赶，攻击判定复用该距离；骷髅保持既有远程移动规则。测试在浏览器动画帧中观察真实 `shieldImpact`，不改写生物或战斗实现，并在成功格挡后继续等待三秒游戏时间确认生命保持 20、没有中毒。放下盾后中毒，保存继续仍中毒，牛奶在自然到期前清除。最终该场景通过。

证据保存在工作区外的 `powder-snow-0.70/`：`check-release.log`、`browser-final-twenty.log`、`browser-release-nine.log`、`browser-shield-head.log`、`format-all.log`，以及 `baseline/`、`twenty-one/`、`release-nine/test-results/` 下的 JSON 和截图。最终数据包括 `player-snow.json`、`bucket-cycle.json`、`mob-snow.json`、`snow-spawning.json`、`snow-melting.json` 与 `poison-shield-milk.json`。

## 范围与复核

冻结计时不写入存档，重载 / 重生重置；当前计时和移动参数是项目规则。雪中白雾与霜边是 UI 表现，尚未实现深度相关雪雾。生物部分覆盖普通地面移动与现有伤害 / 掉落，不包含完整寒冷免疫、骷髅转化、发射器倒雪或所有特殊移动生物的原版行为。

复核了全部产品改动、新增接触模块、冻结计时和测试：接触采样供玩家、生物与刷新入口共用，身体空隙检查从现有规则提取并供地面探测复用。单向支撑仅在玩家碰撞入口调用，用来区分从上方站住与内部穿行，不改变全局实体判定；`snowFall` 只记录已经开始的陷落，离开细雪后继续落到地面，避免悬空。没有新增设置、依赖、存档字段或平行物理框架。

改动净增量：产品 +354 行、测试 +835 行、文档 +77 行、配置 0 行。增长用于接触与单向支撑、冻结反馈、容器循环、生物陷落及实际流程验证；配置仅替换版本和测试命令，没有新增配置项。
