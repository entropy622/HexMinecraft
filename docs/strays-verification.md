# 流浪者验证（0.71）

## 实施前的设计判断

1. 结构：让雪原和细雪改变实际敌人及交战方式，补充群系探索与装备选择。
2. 负担：自然出现与转化由世界计算，缓慢复用状态、移动、牛奶和盾牌流程，无新操作或设置。
3. 可推导：群系、露天条件、头部接触、持续时间和命中结果来自现有世界与碰撞，不由调用者填写环境标志。
4. 复杂度：复用骷髅骨架、弓箭物理与状态效果；只有转化过程需要运行时计时，不新增保存格式或平行战斗系统。
5. 泛化：覆盖雪原露天生成、地下仍为骷髅、细雪转化、脱离后的行为、射击、防御与解毒。

最小实现是在现有骷髅弓手规则中共享远程行为，新增流浪者外观与缓慢箭，连接细雪头部接触和转化计时。只增加一个换色模型不能提供战斗差异；单独写一套 AI / 弓箭或效果计时则会重复已有系统。

参考 [官方流浪者介绍](https://www.minecraft.net/en-us/article/meet-stray)、[官方细雪说明](https://www.minecraft.net/en-us/article/block-week--powder-snow) 和 [Mojang 流浪者行为示例](https://github.com/Mojang/bedrock-samples/blob/main/behavior_pack/entities/stray.json)。本轮沿用项目的骷髅移动 / 射速 / 伤害，采用 7 秒头部入雪后开始 15 秒转化、缓慢 I 持续 30 秒与移动速度降低 15% 的项目规则；不声称与所有 MC 版本逐 tick 对等。

## 实施前列出的失败类别

- 雪原露天仍只有普通骷髅；地底 / 屋顶下或其他群系、维度也误刷流浪者；刷怪笼被全局替换。
- 只有脚触雪就开始转化；不足七秒离开仍保留积累；开始转化后移出雪却永久卡住；暂停继续计时。
- 骷髅先被冻死；转化重复创建生物、丢失当前生命或位置，留下旧模型 / 材质；转化后仍冻伤或仍使用普通近战行为。
- 只有新名称，缺少可识别的寒冷衣物和转化抖动；普通骷髅动画受影响。
- 箭未通过真实碰撞就施加缓慢；盾牌格挡或无敌期间也施加；普通箭误施加；墙后命中。
- 缓慢只有图标，没有实际移动变化；与迅捷错误相加、飞行 / 游泳受误影响；暂停 / 存档继续 / 自然到期 / 牛奶未复用既有状态规则。
- 建造方块与雪中生物重叠时，空隙检测失败导致它穿过原有实体地板。
- 原有弓箭、蜘蛛格挡、细雪动物陷阱与创造模式回归。

### 实际行为与证据

- 刷怪笼路径生成真实骷髅，再将其所在位置布置为细雪陷阱，没有手动构造或替换生物对象。转化后仍为 16 / 16 生命，旧模型离开场景，只存在一只流浪者；复用当前实体的位置、角度与其他运行状态。
- 脚部入雪八秒不抖动；头部四秒接触后离开，重新接触四秒仍不抖动，继续接触才进入颤抖。暂停时世界时间不变；进入转化后移走细雪，十五秒后仍完成。
- 露天雪原生成流浪者，覆盖玻璃屋顶的同一雪原和另一实际沙漠位置生成普通骷髅。只在自然夜间刷新入口采用雪原替换，刷怪笼保留原有种类规则。
- 举盾真实格挡后继续三秒，生命维持 20 且无缓慢；放下盾被箭命中后出现缓慢 I。保存继续时仍余约 29.22 秒。实际行走速度约 3.985，喝奶后的速度约 4.679，比例约 85.2%，不是只显示图标。
- 普通骷髅的真实箭命中玩家但不附加缓慢。原瞄准目标是玩家视点，而碰撞球中心在视点下方 0.65；瞄准改为相同身体中心并保留既有弹道补偿，解决多箭从碰撞范围上方掠过的问题。
- 建造玻璃覆盖雪中生物身体后，脚下仍有石质支撑。修复前生物穿过地面，修复后高度保持 40。下降时复用现有七个身体采样和 `world.groundAt` 查询支撑；站立空隙无效不会令实体地板失效。
- 已查看实际截图。冷色骨骼沿用现有骷髅材质，兜帽与破损披布使用新增程序像素材质和既有六棱骨架，没有下载外部资产。蓝色箭头和缓慢状态反馈区别于普通箭。

证据保存于工作区外的 `strays-0.71/`：`browser-baseline.log`、`browser-first.log`、`browser-six-second.log`、`browser-overlap-red.log`、`browser-release-nineteen.log`、`browser-mine-retry.log` 与 `check-final.log`；对应原始产物在 `baseline/`、`six-pass/`、`overlap-red/`、`release-nineteen/test-results/` 和 `mine-retry/test-results/`。关键文件为 `conversion.json`、`contact-trace.json`、`conversion-boundaries.json`、`ordinary-arrow.json`、`overlap-floor.json`、`converted-stray.png` 与矿井的 `mine.json` / `natural-mine.png`。

## 复核与边界

本轮阅读并复核全部改动：`mob-data.js`、`fauna.js`、`mob-graphics.js`、`texture-pack.js`、`projectiles.js`、`brewing-data.js`、`main.js`、新增 `strays.spec.js` 以及版本和文档。没有新增产品测试接口、用户设置、依赖或存档版本。

共享骷髅定义供两种弓手使用；远程、抗冻和箭效果字段均由实际玩法读取，替换多个按名字判断的分支。`conversion` 由世界接触推导并供更新、动画和 HUD 使用，表示必须跨帧记住的转化进程。地板支撑补查只在站立检测失败时执行，针对已复现的穿透；复用原有身体采样与形状支撑，没有新增物理框架。

敌人及转化进程仍沿用现有敌人卸载 / 不保存规则；缓慢效果使用原有状态保存与牛奶流程。流浪者当前掉落普通箭与骨头，尚无可由玩家使用的缓慢药箭、完整生物装备继承或窒息伤害。外观为本项目的六棱改编，生命、移动、射速和伤害沿用现有骷髅数值。本轮未改变 Photon 光影实现，也未进行全部历史光影场景验收。

改动净增量：产品 +112 行、测试 +525 行、文档 +76 行、配置 0 行。增长用于共享弓手变体、转化、衣物、缓慢命中与实际流程验证；已有计时、投射物、状态和支撑系统均直接复用，没有并行实现。
