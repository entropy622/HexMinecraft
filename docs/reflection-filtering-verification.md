# Photon 投影追踪与反射颜色过滤

0.106 为普通反射材质与水洼接入共享投影深度追踪，加入 HDR 颜色 mip 和可保存的反射设置。完整 MC/Photon 目标、森林参考图与反射专用历史仍未完成。

## 来源与宿主适配

固定只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 `misc/raytracer.glsl`、`lighting/specular_lighting.glsl`、`utility/random.glsl` 与源设置。使用屏幕投影射线、深度容差与逐次减半细化，默认粗糙面 8 步、湿面 16 步、细化 4 步；保留源默认四射线 VNDF/Smith 权重。源粗糙分支原受 `SPECULAR_MAPPING` 约束，宿主仍将它用于已映射的固定反射类别，不宣称配置与 Iris 完全相同。

宿主使用实际 `[0,1]` 屏幕边界和已抖动的当前投影，定义退化方向，保留真实厚度、保护遮罩、边缘/距离拒绝；深度扫描与颜色来自同一帧。射线抖动用独立 IGN 种子和 R1 推进，不占用源噪声纹理。湿面镜面使用固定扫描相位，保留暂停时雨滴冻结。现有水面/折射的捕获与介质路径保持独立。

粗糙反射按源 `floor(min(8*(1-(1-alpha)^8),5))` 选择颜色 mip。视锥内有候选反射网格时才复制一次既有 HDR 并用 Three/WebGL 生成颜色 mip，不增加几何场景捕获。原有保护遮罩使手持物、透明保护面等以零权重进入过滤，再按有效权重恢复颜色与命中置信度，避免前景色污染邻近倒影。无候选网格时不复制，关闭场景反射时释放 HDR mip 目标，画质切到均衡/流畅时整条后处理照常释放。

暂停菜单支持独立场景/天空反射、快速/轻量/标准/精细采样（1/2/4/8 射线）和低/标准/高/极高细节（4/8/16/32 步）。默认 4 射线、8 步。两个反射开关也作用于水洼；都关闭时跳过反射 pass，湿润暗化继续保留。天空单独启用不需要 HDR mip。设置保存在原浏览器偏好中，沿用 v16 存档、视距 10、晴天雾 87.32～118。

8 步是源默认的性能/细节取舍，细小物体可能漏检；更高细节可增加命中机会。尚无反射专用历史、源反射路径雾校正、完整 labPBR 与独立实体覆盖，离屏几何仍不能被 SSR 看见。天空反射图仍不含最终体积云合成，森林整体光色需继续校准。

## 验证与成本

实际金属/宝石红蓝墙、室内抑制、异常材质恢复和水洼建筑反射通过。真实控件、偏好重载、色彩重置保持反射选择、画质切换与关闭时的 HDR 释放通过。64×32 HDR 棋盘在 mip 0/1/2/5 保持平均 `[4,2,1]`；高层过滤消除棋盘方差。保护一半红色信号后，实际生产读取核输出 `[0,4,2]`、有效权重 0.5，没有红色串入。63×35 目标尺寸与释放、实际 1080p 非幂次生成和 GL 检查通过。

最终原生材质、六项湿面/天气/暂停/TAA 回归、冠层/水捕获的两次上下文恢复、三个画质档与跨维度、镜头失败恢复均通过。完整 207 项 Node、12 项不同浏览器功能检查、固定森林与密集材质两种成本检查，以及生产构建通过。生产包在不暴露测试 API 的条件下，用真实控件验证新增反射设置、偏好写入与 v16 存档导入/导出。

保留检查中的问题与修正：冠层综合检查首次耗尽 240 秒整项时限，trace 显示第二次恢复调用已接近截止；总预算改为 360 秒，两个单次恢复的 30 秒门槛保留，最终综合检查通过。首次质量成本脚本只传部分选项，复位了云/AO/柔光，该组质量比较作废；现保留完整设置，并断言每个窗口的后处理和资源预算一致。旧遍历对照最初克隆含渲染目标的 uniforms，触发 Three 警告；改为直接共享帧 uniforms 构造测试材质，诊断门槛保留。失败 trace 和原始数据均保留。

RTX 4060 / Chrome ANGLE D3D11，1920×1080，每个窗口预热后采样 120 帧。有效森林记录来自 `profile-final`，密集材质来自 `profile-corrected`。后者的 A/B/A 只交换当前投影追踪与旧 40+6 遍历，**保留当前颜色 mip、保护、着色与缓冲**，不是运行旧发布版本。另测统一关闭和质量选项。所有计时窗口内无截图/读回，disjoint/busy 和页面/GL 诊断为零。

森林保持 seed624/time30/FOV72/曝光1、441 渲染区块、原云雾和后处理；没有候选反射网格，也没有 HDR mip 目标。无 GPU 查询窗口 CPU 中位 37.2 ms，提交效率仍需优化。不能用此场景的相同结果宣称 SSR 没有开销。

密集案例保持 seed624/time120 的铁/钻石平面与蓝色羊毛墙，云/AO/bloom 关闭，TAA 开启；每个窗口严格保持这些设置。4/8 与旧遍历/关闭窗口分布重叠且有漂移，**不能确认独立提速或固定反射增量**。更高步数/射线数的成本取决于命中与场景，不外推为所有设备的比例。记录的 HDR 复制/mip 查询批次中位约 0.071 ms，也不是进程总帧时间。关闭成本对照保留已分配缓冲；真实 UI 关闭场景反射还会释放 HDR 目标，都关闭会跳过反射 pass。

已查看标准/32 步密集画面和实际设置面板。金属反射天空与蓝墙，近处贴图对比仍明显，粗糙反射的专用历史和细节稳定性需继续完善。截图各自等待时域稳定，不是同一冻结 HDR 的像素差分；不作为用户森林参考图的美术验收。

森林已知渲染目标保持 **251332360 B**、几何属性 **351337732 B**、独立纹理 **12483771 B**、52 个程序。密集案例目标为 **252958736 B**，较相同旧案例增加 **22117240 B，约 21.09 MiB**，等于完整 1080p RGBA16F mip 链；几何 **454574092 B** 和独立纹理保持。生产程序 54 个，旧遍历对照临时为 55，恢复后回到 54。资源估计逐级计入非幂次 mip 像素，仍不包括驱动对齐、二进制或浏览器分配，不是进程总显存。

最终构建与回归的 206 个应用源文件指纹一致；只嵌入一份原始 393216 B 散射表，SHA-256 `d4834ef3babc1376f923f39d495d69dd9d7099f56feb40335a184af8a6b98fc6`，四份许可与构建副本逐字节一致。CPU 提交、密集反射效率、专用历史、完整 PBR 与森林光色仍是持续目标。
