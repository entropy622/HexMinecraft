# Photon 二维云场与天气覆盖率

0.119 将主积云和高积云的二维基础场、天气覆盖率与高度整形继续迁向 Photon。整体参考图、完整天气系统及全部云层仍未完成。

## 来源与适配

固定源为 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04`。`shaders/image/noise.png` 原样保留，512×512 RGBA8，SHA256 `9972ae2cad05ccf00fbe2d81209244e265e3c089e840862f3cf0859443f77c34`。按数值解码，不做 sRGB 转换或预乘透明度。

- `coverage_map.glsl` 的主层覆盖/形状分别读取原 R/A 通道，使用每米 0.000002/0.000027 的频率；沿用 20 m/local 的转换。覆盖率由天气给出区域最小/最大值，再混合积云和层云。
- `altocumulus.glsl` 的区域覆盖、双通道形状和二维细节使用原频率与固定偏移；接入 AC/AS 混合和动态厚度。移除之前额外的 0.48 密度乘数与主/上层额外顶部淡出，高度整形继续跟随源公式。
- `weather/core.glsl`、`utility/random.glsl` 与 `shaders.properties` 提供一维天气噪声、时间权重和较弱的群系影响。晴天湿度基本范围为 0.2..0.8，再乘群系影响；雨量提高湿度和风。群系湿度不再直接充当天气湿度。
- `weather/clouds.glsl` 的双分量覆盖同时进入形态和消光：主层高覆盖读取上端点，上层遮蔽读取加权覆盖。天空捕获 key 和时域历史补充覆盖范围/种子偏移。

宿主仍提供群系连续噪声、600 秒太阳周期、雨量到 wetness 的映射、每层解析风位移及空间种子偏移，均由现有世界状态重建。没有新增存档时钟；格式仍为 v16。卷云、浓积云和夜光云未计为完整源实现。

## 共享纹理

云种子格和原二维噪声共用一个 RGBA8 上传，周期保护边覆盖四边与四角。缓存为 1024×1538 RGBA16F，514 行头部放种子和原噪声，下部继续缓存两层基础场。场外读取同一噪声的解析函数。硬件线性过滤代替四次手动读取，云场仍只占 `cloudNoise` 与 `cloudWorley` 两个采样器；低画质几何的种子格逐字节保留。

## 同镜头画面与成本

seed624，时间 30/120，轴向眼点 `[-120,22.5,4]`，FOV72，曝光1，晴天雾 87.32..118，视距10。四张 900×650 森林/天空图和一张 1080p 晨景沿用上一版输入；时间、位置、旋转、曝光、光源方向及尺寸逐项一致。已查看日间森林/天空与最终 1080p 晨景。云团更连贯，厚云暗底与蓝天空隙同时保留；高处碎云、云底、整体森林光色仍未达到用户参考图。

900×650 晨景，预热后 60 个真实绘制帧，计时内没有截图/读回，disjoint/busy 为零。0.118 的记录为 GPU 中位 27.410 ms；本版最终记录为 36.603 ms、p95 43.100 ms。中间手动/硬件过滤记录约 37.030/37.298 ms，没有观察到稳定提速。不同云场会改变积分负载，这不是受控 A/B/A，不能归因为单个函数的成本，也不代表通用 FPS。性能仍需改进。

构建 JS 为约 3773 kB、gzip 1989 kB，较上一版主要增加原二维 PNG。四份 Photon 二进制资产在包内各出现一次，完整许可证与来源说明随包分发。
