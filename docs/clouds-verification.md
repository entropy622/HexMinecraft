# 体积云验证（0.69）

## 实施前的设计判断

1. 结构：光影档的云改为参与真实场景合成的体积，解决不透明几何云无法表现透射、自阴影和云内视角这一类缺口。
2. 负担：继续使用既有画质、云开关、天气与游戏时钟，不要求玩家填写云厚度、散射参数或历史权重。
3. 可推导：由相机、深度、共享云场和太阳方向推导射线区间、遮挡、散射和透射；云影与外观使用同一场。
4. 复杂度：增加一张半分辨率积分纹理与一张 127 × 127 单通道周期噪声表，合成临时颜色复用现有 composer 缓冲；主画面和水面捕获顺序复用同一流程，没有第二套天空或反射相机。
5. 泛化：从云下、云内和云上观察均按体积求交，支持天气、世界坐标移动、窗口缩放、画质与维度切换。

最小完整实现包含沿视线积分散射与透射、沿光线积分自阴影、按实际场景深度截断、与真实背景合成及水面捕获 / 时域衔接。继续给几何表面调亮度无法形成体积透射；独立图片叠层也无法正确处理前景和倒影。额外积分纹理让采样输入与写入目标分离，避免 GPU 纹理反馈，并允许按深度引导上采样。

周期噪声表来自现有整数哈希，按世界种子更新，不引入图片资产。把同一有限周期的结果上传 GPU，避免沿视线及光线的每一个样本反复执行相同的哈希。

参考 [Photon 固定版本的积云光学厚度与散射积分](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/cumulus.glsl)。独立实现适配本项目云场的近似，不复制完整 Photon 管线。

## 实施前列出的失败类别

- 光影档仍是完全不透明的几何块，改变真实云后物体颜色只能得到全遮住或全透过，缺少有限厚度的部分透射。
- 云下、云内、云上、平行云层和反向射线求交错误；负步长、越界样本、NaN、闪烁或远处硬截断。
- 不按实际地形、建筑和第一人称深度截断，云雾盖住近景、穿入洞穴，或上采样在轮廓周围漏出亮边。
- 只按画面位置造云，移动相机后云场漂移；时间、种子、天气和云影与可见体积不一致。
- 没有沿光线的遮蔽和厚度吸收，亮暗只取决于朝向；暴雨与夜间的云仍恒亮。
- 合成替换真实背景，薄云后太阳、月亮、星空和模型丢失；色调映射或显示转换重复应用。
- 水面捕获中缺少体积云，或主画面重复叠加反射；扩大捕获视野后使用了主视野投影。
- 移动云沿用静态天空历史而留下残影，或者为云全局关闭 TAA，导致稳定地形回归。
- 渲染云时读写同一附件，覆写原场景深度，或失败后未恢复目标 / autoClear / 镜头 / 水体可见性。
- 云开关、尺寸、质量、维度、重建和销毁后使用过期纹理；低档不必要地执行体积积分，或两套云同时显示。
- 新共享云影让既有水面、焦散、水下体积光、时域画质或跨维度材质编译退化。

## 边界与交付复核

- 当前为单层云，24 步视线积分与 4 步光线积分，密度使用共享种子场及沿高度变化的噪声侵蚀；仅用减小消光的附加散射项近似高阶散射。没有完整多层云及其相互投影、地形向云投影或完整多次散射。
- 云使用当前帧与半分辨率深度引导上采样，尚无云专用时域重建；细小轮廓、强运动和不同显卡还需持续画面对照。水面沿用既有屏幕空间追踪及离屏环境近似，未扩展为完整离屏反射。
- 沿用 v16 存档、原有画质与云开关，没有新增玩家参数、依赖或资产。共享噪声表只在种子变化时重建；额外积分缓冲在主视野与水面捕获之间顺序复用，TAA 借用已有 alpha 通道，无额外遮罩纹理。
- `CloudVolumePass` 的直接宿主只有 `SceneFramePass`，但实际处理主视野与水面捕获两次调用，集中管理积分纹理、材质、尺寸与销毁，避免复制两份合成流程；没有额外注册层、兼容接口或测试专用产品参数。两个云路径对应已有画质档位，保留低档成本边界。
- 逐行审阅了新增体积合成模块、共享云场和 4 项 E2E，以及云系统、场景捕获、后处理、TAA、主菜单文案、版本与文档的所有改动。产品净增 256 行、测试净增 612 行、文档净增 73 行、配置净增 0 行。产品增长用于有限体积积分、共享密度及资源生命周期；测试增长主要是实际世界 / 镜头构建、HDR 读回与外部 GPU 故障场景，没有新增内部替身。
- 本次文件的 Prettier 和 `git diff --check` 通过。全仓格式检查只报告两份未修改的历史授权文件 `public/textures/VOXELIBRE-CREDITS.md`、`public/textures/VOXELIBRE-LEGAL.md`；生产构建仍有已有的大包体积提示。
