# 方块视差遮挡与开放材质替换

0.141 按 Photon 固定提交 `6e67b36e` 的 `shaders/include/surface/parallax.glsl` 为方块表面加入视差遮挡（POM）与视差自阴影，并按 `final.fsh` / `dithering.glsl` 在光影档输出加入 8-bit Bayer 抖动。

## 视差

- 最大深度 0.25 方块，距离 0.75..1 倍淡出；均衡档 16、光影档 32 单位，低档关闭。
- 在实际图块内步进（4..40 步），图块边界由屏幕导数求得的切线框架约束，六棱顶面与侧面保持相同世界深度。所有偏移采样使用 `textureGrad`，颜色、法线、粗糙度和群系着色读取同一位移后的纹素。
- 自阴影沿直射光方向步进（2..32 步），在几个高度级内柔化，避免 16 px 台阶在 TAA 下闪烁。
- 原生高度写入法线图 A 通道，最高纹素即表面本身；深度按材质设定：砖、圆石、下界砖等 0.45，树皮 0.45，木纹 0.35，矿石 0.25，普通石材与土壤 0.12。外部 labPBR 资源包的高度直接使用。
- 高度由原生凹凸派生，不是资源作者提供的高度图。树叶、远景、独立模型和坡度法线尚未接入。

## 开放材质替换

草方块顶面、藤蔓和矮草改用 Voxels Reworked release 33761 的原始灰度 PNG（CC BY-SA 4.0），在图集绘制时乘以原有的群系基色，透明像素保留。项目自绘的藤蔓图案与程序矮草移除。源路径与哈希见 `public/textures/voxels-reworked/source.json`。
