# 缓慢之箭开发与验证

## 改动前判断

1. 玩家目前无法获得并使用流浪者的缓慢之箭；弓、回收与 HUD 只识别普通箭。
2. 最小可交付行为是玩家击杀流浪者有机会掉落缓慢之箭，真实背包选箭、拉弓、命中减速与回收保留种类。
3. 现有背包、弓弹道、掉落、像素材质和生物保存入口均复用；只补箭的物品定义与生物缓慢计时，不新增药箭框架或设置。
4. 新箭 ID 需贯穿 UI、库存、弹道、掉落和效果，否则容易把药箭回收成普通箭或无限复制。共享定义是唯一新增数据入口。
5. 正确性以后台真实浏览器的创造物品库、实际拉弓、生物移动、原生保存继续和掉落为准；不新增产品测试开关。

更小的 UI 专用箭或独立调试发射按钮不能完成玩家链路。暂不扩展全部药箭、滞留药水合成与装备掉落框架。

## 先列失败路径

- 创造库缺少物品；只有缓慢之箭时无法拉弓；主副手选箭优先级混乱。
- 无限附魔错误保留药箭或消耗普通箭；创造模式错误消耗；普通箭误附加缓慢。
- 命中仅改 HUD 没有减速；躲闪 / 闭壳反弹仍附加效果；死亡后继续修改已移除实体。
- 背包满时丢失回收箭；回收种类错误；药箭与普通箭合并堆叠。
- 缓慢被存档清除、计时不减或影响攻击时钟；非法计时进入存档。
- 生物掉落未走实际玩家击杀路径，或自然死亡额外产生药箭。
- 原有流浪者射击、盾牌、弓箭与操作回归；测试触发真实 Pointer Lock 抢占鼠标。

## 验证记录

- 基线创造库找不到缓慢之箭，先得到真实界面失败。
- 首轮新增三项通过，奶牛真实箭伤后从 1.40 降到 1.19，速度比 0.85，保存继续保留计时，暂停冻结，到期恢复；非法 31 秒计时被导入入口拒绝。
- 扩大回归首批 13 项中 12 项通过。玩家击杀用例取得两支药箭，复现盾牌反弹把敌箭变为可回收的问题；随后移除反弹对原有回收标记的覆盖。
- 最终源码下创造库与创造射击、奶牛箭伤 / 缓慢 / 保存继续 / 暂停 / 到期、无限弓与满背包回收三项再次通过。追加副手弓与击杀两项时，分别因测试使用了不能选择普通箭的开发入口、玩家停在掉落拾取范围外失败；改为真实快捷栏按键，并先记录地上掉落再走近。
- 仅重跑这两项，全部通过。副手弓先消耗主手药箭，按 2 切换后消耗普通箭且药箭不变，耐久合计减少两点；流浪者举盾阶段药箭数量保持零，玩家击杀得到一支，拾取与后续保存继续成功；玩家缓慢状态和牛奶清除流程通过。
- 合并各批共 14 个不同浏览器场景通过，不描述为一次全绿批次。最终产品源码 83 项逻辑测试通过、生产构建成功，保留已有包体积提示。

所有浏览器检查使用 `tests/browser-fixture.js` 的 Pointer Lock 边界替身，在独立 5174 端口后台无头 Chrome 中运行，没有操作前台鼠标。浏览器运行期间未修改源文件、测试或文档。

外部证据目录为 `arrows-0.73/`。`browser-baseline.log` 与 `baseline/` 记录创造库缺口，`browser-combat.log` 与 `combat-before-fix/` 记录多取得药箭的失败；`browser-final-five.log` / `final-five-first/` 和 `browser-final-two.log` / `final-two/` 保存最终复验与修正后的真实入口。`cow-slowness.json`、`infinity-recovery.json`、`offhand-bow.json`、`conversion.json` 包含实际背包与移动测量；`check-final.log` 记录逻辑测试和构建。已查看实际截图，蓝色箭头沿用现有像素图，无新增外部资产。

## 改动后复核

逐项复核新增 `arrow-data.js`，以及 `core.js`、`mob-data.js`、`mob-graphics.js`、`fauna.js`、`main.js`、`projectiles.js`、`bats.js`、`nether-mobs.js`、`texture-pack.js`、`icons.js`、`inventory-ui.js`、两份浏览器测试、README、开发状态、验证记录和版本文件。

- `ARROW_ITEMS` 同时供物品注册、玩家选箭与弹道效果读取；生物的箭 ID 替换原来的远程布尔值和独立效果载荷，避免同一种箭出现两套定义。
- `slowness` 是跨帧和存档必需的可选计时，零值不写入；`mobSpeedScale` 被普通地面生物、蝙蝠和下界飞行位移读取。没有缩放完整更新时钟或攻击冷却。
- `Fauna.slow` 虽只有一个生产调用点，仍放在实体拥有者中，以检查存活列表，避免致死箭后修改已移除对象；只实现本轮支持的缓慢。
- 弹道 `item` 贯穿材质、命中与回收；`groundLife` 替换旧的落地布尔值，利用既有寿命计算药效散去，无需第二个累计时钟。反弹保留发射时的回收规则。
- 没有新增用户设置、依赖、存档版本或产品测试接口。净行数为 +118 / -43，净 +75；测试 +453 / -0，净 +453；文档 +61 / -3，净 +58；版本配置 +3 / -3，净 +0。

## 原版参考与本轮边界

[官方药箭介绍](https://www.minecraft.net/en-us/article/tipped-arrow)说明命中时保留箭伤并施加药效，且无限附魔不会保留药箭。[官方流浪者介绍](https://www.minecraft.net/en-us/article/meet-stray)说明玩家可取得缓慢之箭；[Mojang 样例掉落表](https://github.com/Mojang/bedrock-samples/blob/main/behavior_pack/loot_tables/entities/stray.json)把这一项限制为玩家击杀的 0–1 支。本项目沿用既有普通箭与骨头掉落，本轮增加独立的 50% 药箭机会，未引入抢夺附魔或完整最后伤害归属。

只开放三十秒缓慢 I。没有追加其余药箭、滞留药水合成或发射器，也没有改变 Photon 光影；此前光影效果保留。飞行生物复用当前位移缩放，尚未逐个对照原版实体速度属性。末影人实际箭躲闪入口阻止药效，所以没有为它增加不可达的移动效果代码。箭实体继续沿用原有四十秒寿命和离开已加载区时清除的规则。
