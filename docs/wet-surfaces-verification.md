# 雨后地表与水洼反射验证（0.72）

## 实施前的设计判断

1. 结构：使实际地表从单一染色变为受天空遮挡、表面吸水性和视角共同控制的湿润材质，接上已有天气与反射链路。
2. 负担：沿用光影画质、天气和世界材质，没有新增玩家设置、方块操作或保存字段。
3. 可推导：露天、群系、朝向和材质由实际世界烘焙，水洼分布来自固定世界坐标，湿度与雨滴取已有天气状态。
4. 复杂度：复用当前帧颜色 / 深度和表面保护遮罩的空闲 B 通道，不再捕获一遍完整场景或新增材质贴图库。
5. 泛化：覆盖石材、木材、土壤、屋顶、墙面、雨停、区块接缝、相机移动、品质切换、水面和水下。

最小实现是在已有材质数据中添加吸水性，将水洼覆盖写入共享遮罩，再用同帧颜色 / 深度追踪反射并做 Fresnel 混合。继续混入固定天空色无法反射真实建筑；每个水洼建立独立反射相机或再建一个 G-buffer 则重复现有资源。

参考 [Photon 雨水洼实现](https://github.com/sixthsurge/photon/blob/main/shaders/include/surface/rain_puddles.glsl) 与 [材质定义](https://github.com/sixthsurge/photon/blob/main/shaders/include/surface/material.glsl)：其处理把露天与朝上表面、湿度、吸水性、低粗糙度、反射和雨滴法线连在一起。本项目独立实现适配 WebGL 的世界噪声和屏幕空间追踪，不声称完整 Photon / LabPBR 对等。

## 实施前列出的失败类别

- 实际建筑改变颜色后，地面反射不变；反射只是染色或纵向屏幕复制，视角或建筑位置变化后对应关系错误。
- 屋顶下、墙壁、干燥地面、沙漠 / 雪原、树叶、玻璃、生物或手持物误出现地面水洼。
- 土壤与石材同样镜面；区块边缘出现条带；水洼跟着相机游走。
- 追踪穿过前景、把近处遮挡物错误拉进远处倒影；离屏 / 无命中时出现拉伸、黑边或无穷值。
- 雨滴即使停雨仍持续扰动，暂停仍在跳动；湿度消退 / 继续游戏没有沿用原有天气状态。
- 共享遮罩破坏 AO、时域抗锯齿、动态模型、发光面或水面的保护通道。
- 水下再次反射空气地面；水面捕获产生反馈纹理、错用上一帧深度；尺寸 / 画质 / 维度切换遗留资源或 shader 错误。

### 画面和数值

- 对 891 个实际倒影采样点，红 / 蓝建筑在湿地中产生约 **0.0133** 的 HDR 平均颜色差异，干地差异为 **0**；已查看对应原始截图。
- 同一世界区域的平均积水覆盖，石材约 **0.3455**、木材约 **0.1330**、土壤约 **0.0211**。进一步直接改变建筑颜色，木地板倒影差异约 **0.00509**，土壤约 **0.000823**，验证最终合成确实消费吸水性。
- 竖直墙面、屋顶下和干地的覆盖采样为 **0**；屋顶下改变建筑颜色，最终地面画面的差异同样为 **0**。移走屋顶后覆盖恢复。
- 相机平移后，相同世界位置的覆盖平均差异约 **0.00710**；负区块接缝两侧的近邻采样差异为 `[0.0392, 0, 0.0118, 0]`，没有观察到区块重置条带。两点并非相同位置，允许场本身的连续变化与像素采样误差。
- 沙漠 21 个采样点和雪原 17 个采样点均无水洼。雪原测试区域横跨平原边界，因此逐点读取实际群系；相邻平原仍可积水，不能只用 HUD 的群系名称代表整个画面。
- 相同时间跨度下，有雨的倒影变化约 **0.00213**，雨停后约 **0.000227**；暂停采样差异为 **0**。后者保留已有湿度，关闭雨滴扰动。
- 开启时域抗锯齿后，对红 / 蓝倒影色差归一化比较换色后的早期帧与稳定帧，旧颜色残留比例约 **0.47%**；16 个明显反射采样点使用当前帧。正常 TAA / SMAA 的亮度采样变化保留为诊断值，不当作旧颜色残留。
- 实际画质切换释放旧反射材质；恢复光影档后，遮罩与场景目标均随视口调整为 **720 × 540**。在真实水源中让相机入水后，地面反射步骤关闭。

证据保存在工作区外的 `wet-surfaces-0.72/`：`browser-baseline.log`、`browser-six-final.log`、`browser-final-two.log`、`browser-regression-nineteen.log` 和 `check-final.log`。对应产物在 `baseline/`、`six-first/test-results/`、`final-two/test-results/` 与 `regression-nineteen/test-results/`；关键文件为 `actual-reflection.json`、`exposure-materials.json`、`climate.json`、`ripple-lifecycle.json`、`wet-temporal.json` 和 `wet-red-building.png` / `wet-blue-building.png`。

## 复核与边界

已逐项复核本轮修改与新增代码，包括 `graphics.js`、`skylight.js`、`wet-surfaces.js`、`surface-protection.js`、`postprocessing.js`、`main.js`、新增浏览器场景、版本和文档。

材质吸水性只在块网格烘焙时分类，作为一个浮点顶点属性供湿润变暗和水洼覆盖共用，避免按片元解码材质贴图库。该分类函数只有网格烘焙这一处调用，用于把固定材质规则与网格构建循环分开。反射步骤采用 Three.js 的标准 Pass 生命周期，仅在已有光影合成入口装配。表面保护绘制沿用原有 R / G 用途，空闲 B 通道承载覆盖；明显反射区域同时拒绝旧时域历史。

没有新增用户设置、依赖、存档字段或版本、材质资产、场景捕获相机或额外纹理目标。雨天光影档会增加地形遮罩绘制与一次全屏追踪；干地和水下跳过反射，均衡 / 流畅只保留湿润变暗。尚未做全硬件性能验收。

当前只覆盖完整、不透明的地形表面；楼梯等单独构建的异形方块不新增水洼。反射有固定追踪预算、深度厚度判断和屏幕边缘衰减，无法补齐离屏 / 被遮挡的完整场景，无命中时使用天空近似。没有 LabPBR 贴图、完整微表面材质、湿面专用时域重建、多次反射或逐方块积水模拟；湿度沿用既有天气保存与渐干规则。

改动净增量：产品 +189 行、测试 +613 行、文档 +75 行、配置 0 行。增长用于有界反射、共享覆盖与实际画面对照；复用天气、几何属性和原有缓冲，没有另建平行渲染管线。
