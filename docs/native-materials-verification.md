# 默认像素材质细化

0.140 已进一步扩展至全部 236 种现有方块的明确材质路径，181 种图集材质提供法线数据，源图扩至 52 张。独立模型的完整 PBR 仍需迁移。新增范围和验证见[整套材质覆盖](material-coverage-verification.md)；下文保留 0.139 的原始范围与证据。

0.139 细化常用地面、建筑与地下方块。接入 Voxels Reworked 的 27 张原始贴图，并在地形、近远景表面共用的材质解码中加入浅凹凸和粗糙度。保持 16×16 像素密度，重点改善纹理组织与受光细节。

## 资源与材质范围

选择的资源包括石头、圆石、石砖、石板、苔石、泥土、砂砾、橡木 / 白桦 / 云杉、六类矿石、方解石、玄武岩、凝灰岩与基岩。方解石、玄武岩与凝灰岩开始使用实际源 PNG。库存图标使用同一图集的表面视图；导入 MC 资源包时，修正项目“石砖”的匹配名为 `stone_bricks`。

资源为 Chiragon 基于 XSSheep 的 Pixel Perfection 制作的 [Voxels Reworked](https://content.luanti.org/packages/Chiragon/voxels_reworked/)，固定到 release 33761 / 0.7.0。27 张 PNG 共 9,038 字节，逐文件保持原始哈希。原始归属、CC BY-SA 4.0 许可、来源路径与压缩包 SHA256 在 `public/textures/voxels-reworked/` 保留。旧资源文件仍保留原归属。

`native-material-detail.js` 按材质类别与像素值生成浅浮雕近似，包含矿物颗粒、木纹与较深的树皮沟槽。白桦侧面使用独立的浅竖向起伏，黑色斑纹只作为颜料。矿物颗粒粗糙度略低，周围石材、泥土和砂砾保持哑光。透明薄片、叶片、自发光与特殊光学材料沿用各自路径。

这是宿主生成的细节近似，不是上游提供的雕刻高度或完整 POM。尚未完成所有方块的逐张人工材质制作，也没有改变森林整体照明模型。

## 共享解码与资源包优先级

原生数值图集复用已有 normal sampler，RG 保存切线法线，B 为粗糙度，A 为保留高度；标记纹理的 B 通道区分原生数值和 labPBR。原生 B 不参与天空 / 方块光遮蔽。

导入的颜色图优先使用自己的法线；只有继续使用原生颜料的回退表面才使用原生凹凸。导入 `_n` 仍按 labPBR 解码 B 可见性，导入 `_s` 优先覆盖光学参数。恢复默认时释放导入的镜面与额外附件，重新使用原生凹凸；原生 normal 纹理不再为空。这一点已同步更新原有资源包恢复检查。

主视图与反射共用几何法线和粗糙度。紧凑材质记录的 geometry alpha 采用 `0=原类别`、`1..254=原生基础粗糙度`、`255=labPBR 镜面附件`。编码保存湿润混合前的基础粗糙度，反射阶段再施加相同湿面响应，防止混合两次。默认仍使用三个附件；有外部镜面图时继续使用原来的第四附件。

默认数值图集为 256×2112 RGBA8，增加 2,162,688 字节的 normal 数据及少量材质标记，未增加全屏 pass 或场景绘制。外部高分辨率包会按实际图集尺寸分配，不能把默认尺寸当作所有资源包的开销。本批没有建立帧率提升结论。

## 实际画面与验证

在同一 seed 624、时间 70、相机和 1280×800 视口下，对十二组实际方块展示做重构前后截图，周围为自然世界；光照、天空和后处理设置相同。石材纹理更规整，木板接缝与树皮分离，铜矿具有铜色与氧化色颗粒。该场景用于材质验收，不要求与真实 Minecraft 生成相同地形。

检查覆盖：

- 27 张资源的哈希、尺寸与不透明像素；凹凸范围、不同材质的粗糙度、半砖继承、白桦斑纹、特殊材料排除，以及既有 PNG / labPBR 和表面程序接口，共十项 Node 检查。
- 实际 ZIP 导入、原生材质数值读回、外部 labPBR 高光 / 倒影、IndexedDB 刷新、显卡恢复与恢复默认；16 / 32 / 64 图集的 UV、缓存单块贴图和稀疏颜色回退。
- 原生材质实际绘制，颜色包替换后清除该表面的原生凹凸标记，未替换表面保留细节；恢复默认和设备恢复后标记、图集大小及三个附件一致。
- 湿面接收路径实际读回 geometry alpha 的原生粗糙度标签；颜色包覆盖后标签回到类别默认，恢复后重现原值。
- 最终生产构建的实际材质绘制、上下文恢复与 v16 存档导出。

第一次新增记录检查在干燥哑光表面读到零，因为这些表面本来不进入反射记录。检查改为临时启用湿面接收后读回，没有为了验证而扩大生产绘制范围。失败和修正记录均保留。
