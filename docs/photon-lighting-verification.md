# Photon 日月照明与大气参数

0.100 将直接照明与 0.99 的实际天空散射表接到同一 Photon 光源函数，推进冠层、云雾和日夜外观。MC/Photon 整体目标仍未完成；本批不宣称用户森林参考图已还原。

## 固定来源

只读对照 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [light_color.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/colors/light_color.glsl)、[atmosphere.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/atmosphere.glsl)、[global.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/global.glsl) 和 [shaders.properties](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/shaders.properties#L528)。新 `photon-lighting.js` 是不依赖浏览器资产导入的纯 GLSL/系数模块。

- 太阳采用源 7 单位基础亮度、晨昏权重、蓝调时段补偿、脉冲色调和默认白色用户 tint；没有通过调整叶片材质或额外全局曝光增益制造变化。
- 月光采用源 0.66 基础亮度、时段补偿、默认 sRGB tint 经 2.2 次方及 709→2020 变换。原样保留八相亮度 `[1, .875, .75, .625, .5, .75, .875, 1]`，包括其不对称和新月 50% 下限；它是游戏照明曲线，不是月面照明面积。
- 直接光采用源太阳光谱色、Chapman 透射、退饱和、地平线渐入和低角度脉冲衰减。早夜 SH 增强 1～1.5 倍接入原有投影。
- 0.99 曾把亮度的 `190/0.09604` 蓝调曲线用于大气饱和度。本批按源 properties 分离为大气的 `150/0.07283` 曲线，修正该偏差。

## 输运与快照

源分子/Mie/O3 系数、8.4/1.25 km 密度高度、臭氧四分量分布及 110 km 上界用于共享输运。直接光在源 Rec.2020 中计算 Chapman 衰减，臭氧柱长按 Rayleigh 近似，沿用源算法；最终光源/天空色组合后转换到宿主线性 sRGB。局部空气仍采用宿主 20 m/单位、八步积分、709 分量运算与雨天气溶胶倍率，不等同于完整源延迟雾模型。

旧 128×64 光学柱长纹理及生成 pass 已移除。三个目标依次为 active/staging 天空小图与 17×1 RGBA16F 归约，异步读回从 104 增为 136 字节。除既有 SH/天顶/地平线/透射，新增直接光、日月盘色和源强度摘要；发布纹理、方向、月相、所有色值后才供下一实际绘制使用。释放时清零已发布光色，旧在途代际不能回写。

Three 日月光仍使用一个方向光；其 intensity 归一为所选源曝光除以 7，color 归一后与 intensity 的乘积恢复 GPU 发布的完整入射色。叶片、云和空气共用该乘积，移除空气原来的额外晨昏亮度倍率。月相 UV 使用已发布 index，太阳/月亮盘沿用宿主几何、相位素材与有限盘近似，尚非源全部程序化光盘。

固定地面散射表、宿主满球 SH、局部空气色域近似以及太阳在地平线时的单方向光切换仍为适配差异。GTAO/bent normal/AO 历史、SSRT、通用 PBR 等也仍待迁移。

## 曝光与设置

源 [settings.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/settings.glsl#L514) 默认 `AUTO_EXPOSURE_OFF`、手动 0 EV，配合上述日夜补偿。新设置现采用固定曝光 1；已有布尔选择继续覆盖默认值，明暗适应保留为可选功能。自动模式仍使用宿主几何平均测光与原有 0.72～2.8 目标范围，尚不是源 histogram 路线。

新光照首次触及自动曝光下限，历史纹理 RGBA16F 的实测值为 0.7197265625。原森林断言误将实数 0.72 当作精确可表示值，现按半浮点下界/上界检查；运行时目标和适应速率未调整。默认关闭与显式开启分别保留图像，普通 UI 的开关、保存、重载和继续另作验证。

## 验证与画面

原生 GPU 192 组条件、5184 条视线覆盖全部八个月相、日高/降雨、五种高度及地面边界。双精度独立参考对照直接光、日月强度/tint、早夜增强和 Chapman 透射；旧 3D 表和相位检查保留。初轮最大源函数归一误差 8.078e-7、透射绝对误差 3.859e-6、坐标误差 1.654e-6，原始分量全部落在按位置计算的过滤精度区间。

450 ms 延迟 GPU 设备读回期间，检查了 148 个实际 Graphics.frame，方向光、叶片、云、空气的完整入射色最大差异 8.882e-16，月相 UV 差异为零；显式切换至相位 4 和 7，GPU/CPU 直接光一致，源月光强度比为 2。最终原生数学复测仍为 192 组、5184 条视线，源函数最大归一误差 8.078e-7、透射绝对误差 3.859e-6、天空 RGB 最大归一误差 0.013058，保留既有 0.015 门槛，没有扩大误差预算。原始表采样没有区间外分量，非有限值、GL 错误和页面诊断均为零。

实际查看固定自然森林的 900×650 和 1920×1080，以及独立场景的正午、满月画面。自然森林沿用 seed 624、time 30、FOV 72、固定曝光 1；太阳高度约 15.53°，源时段色调使受光树冠更暖。没有改动镜头来替代低角度对照。以下是分别腐蚀出的叶片内部区域分布，不是相同像素逐点差分；基线 227152 像素，候选 226943 像素。
