# 白龙娘初版的绘制开销

以下采样使用 15,618 个三角面的初版。腰部修正后的模型使用 12,080 个三角面，比初版减少 22.7%。[当前版本与造型对照](../../pearl-dragon.md)

后台 Edge / D3D11，RTX 4060，1366 × 768。两组运行相同的动画、相机和场景，只切换角色的可见性。

| 角色室，每帧 | 显示角色 | 隐藏角色 |
| ------------ | -------: | -------: |
| 中位耗时     |  0.30 ms |  0.18 ms |
| P90 耗时     |  0.40 ms |  0.22 ms |

每组提交六帧后读回一个像素等待 GPU，交替采样 24 组。含地板为 30 次绘制、15,620 个三角面；其中角色占 29 次绘制、15,618 个三角面。为保留原模轮廓，本版将单角色三角面预算从 3,000 调整到 16,000。六野每张单面贴片只提交 4 个顶点；导入和渲染沿用同一份 YSM 几何。

| 生存世界第三人称，画质 0.65 | 显示角色 | 隐藏角色 |
| --------------------------- | -------: | -------: |
| 中位帧间隔                  |  83.5 ms |  83.4 ms |
| P90 帧间隔                  | 183.4 ms | 883.3 ms |

在同一新世界等近景区块网格队列清空，交错记录各 64 个显示帧间隔。这个场景的中位帧率约 12 FPS，隐藏角色后仍有长帧。角色室数据适合比较角色自身的渲染成本；整世界数据包含区块和生物更新。Minecraft Java 的帧时未测。

复现角色室：`node tools/pearl_hy/profile.mjs`。复现实景：设置环境变量 `PEARL_PROFILE=1`，执行 `npx playwright test -c tests/field-models.config.js -g "back, front"`。转台视频使用固定时间步，不能用来估算游玩帧率。
