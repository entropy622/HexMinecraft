# Photon CAS 与时域输出

0.102 推进 Photon 的可迁移成像功能，替换既有固定锐化。整个 MC/Photon 目标仍在开发，未完成用户森林参考图的整体美术验收。

## 固定来源与接入

只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [final.fsh](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/final.fsh#L73)、[settings.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/settings.glsl) 和 [buffers.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/buffers.glsl)。源 CAS 位于显示转换后；本批保留其 3×3 软极值、权重二次塑形、强度映射，以及**分子先 clamp、再除权重和**的顺序，未换成另一个同名锐化或额外有界 unsharp。

源强度 s 从 0～1 映射到 −1～1，权重因子等价于 `-1 / (11 - 6*s)`。默认启用、强度 0.5；强度 0 仍是最低档锐化，独立开关完全关闭。源顺序允许浮点结果超过 1，强度范围内理论上限为 5，最后显示缓冲再限幅；未移动 clamp 来掩盖这一行为。偏好按有限数和 0～1 范围、0.01 步长规范化，旧偏好补齐源默认值。锐化独立于 AA 和八项色彩，色彩重置保留其选择，v16 世界存档未改变。

`photon-cas.js` 提供源滤波核，`PhotonOutputPass` 在原最终输出中使用 GLSL3/highp sampler 与精确 texelFetch。每个邻域点先通过当前调色和 Photon 显示曲线，再进行 CAS；CAS 结果不再次编码。边缘重复最后有效像素；纯黑通道的零分母定义为零增强，所有正分母保持源值，避免源 0/0 的未定义行为。

这是宿主适配：源在 c19/final 之间使用 R11F_G11F_B10F，当前将点式调色与九个 tap 融合为一次全屏绘制，不存储该打包中间图，精度不同。现有中间光照/材质仍是线性 709，调色阶段转换到 2020。未增加生产 pass 或渲染目标；均衡/流畅继续直接渲染，不运行屏幕 CAS。线性输出分支保留点式调色、不运行显示域 CAS。源非原生 render-quality 的 Catmull-Rom 分支、CAS 放大与 8-bit Bayer dither 均未迁移。

`TemporalResolvePass` 的历史输出改为原像素 RGB 的 texelFetch 复制，alpha 继续重置为场景不透明度 1，历史中的深度/反应 metadata 不传入后续场景 alpha。旧 `.18` 五点有界锐化删除，TAA 重投影和夹取算法未改变。现在只有最后输出的 CAS 承担锐化。

## 数学与真实场景

实际生产输出对照独立双精度源参考：15 张图、7 组配置、47397 个通道，覆盖黑/纯色/灰阶、HDR 白、高反差、纹理、不同强度、关闭、组合调色及 1×1/单行/单列/非方形边界。最大绝对误差 **1.385e-6**，纯色 DC 最大误差 **4.497e-7**，alpha 误差 **4.769e-9**，非有限/超出源理论范围和 GL 诊断为零。真实 TAA history-copy 对 64 像素半浮点输入的 RGB 误差为 **0**，alpha 为 1；不是源码文本断言。原有 20 组调色检查也在关闭 CAS 的独立条件下复测通过。

真实键盘操作开关/强度后，保存、重载、继续、画质切换和上下文丢失/恢复保持实际参数；关闭 AA 后仍可独立开启 CAS，色彩重置保留 CAS/AA 选择。390×780 菜单没有横向溢出。暗室发光体、水下和固定自然森林通过，实际查看同 seed624/time30/FOV72/曝光1 的 900×650 CAS 开/关图。两图各等待原时域采样稳定，不是同一份冻结 HDR 的逐像素差分。

## 时域清晰度的判据

去除旧锐化后，单独关闭 CAS 的 TAA 相对超采样参考仍明显减少误差，但边缘梯度只有参考的约 69.7%。默认 TAA+CAS 约 **96.75%**，而只用 SMAA+CAS 会把锯齿一起增强，梯度约为参考的 **150.25%**；因此用后者作“清晰度真值”会误判。

最终测试固定未锐化的 2×参考，同时采集 SMAA、SMAA+CAS、TAA+SMAA+CAS 和收敛图。误差必须优于两条空间路径中更好者，原 0.95 门槛保留；TAA/SMAA 梯度比原 0.75 门槛保留，另加相对超采样梯度 0.75～1.25 的过软/过锐化约束。原梯度诊断继续保存，没有通过提高锐化强度或放宽图像阈值过关。

最终静态 MSE 为 60.69，最佳空间路径 121.29，误差比 **0.5004**；相对参考梯度 **0.9675**，收敛帧差 **0.00278**，178752 个边缘通道。真实移动生物的历史拒绝与离开轮廓清除通过；相机移动/转向、注入失败绘制后的投影/历史恢复、尺寸变化、实际画质控件、手持物保护和跨维度重置通过。源 TAA 的完整重建核和其他功能仍未完成，CAS 不代替 AA。

初轮旧梯度判据的失败、后续相对增强锯齿基准的失败、120/150 秒启动/生命周期预算超时均保留。实际 trace 显示末次跨维度检查仅剩约 8 秒，采用与图形集成相同的 240 秒窗口后完成；不是观察工具超时后另起同一进程。所有 GPU 批次串行，收到确切终态并核对所属 PID/UTC 创建时刻与独立端口后才继续。

## 固定 1080p 成本

RTX 4060 / Chrome ANGLE D3D11，seed624/time30/FOV72/曝光1、光影档，完成初始化和 120 帧预热后，每窗口测 120 帧。同一进程只切换 CAS，关闭窗口也已删除旧时域锐化；两窗口无截图/读回干扰、无 disjoint/busy、无页面/GL 诊断。

| CAS 关闭               | 32.915 / 34.210 ms     | 0.091 ms     | 33.3 ms      |

关闭叶片深度预绘制的独立控制为 43.886 ms，CPU 27.4 ms；无 GPU 查询的深度开/关窗口 CPU 为 34.4/27.5 ms，RAF 中位为 33.3/50.0 ms。CPU 提交仍重，没有宣称本次解决它。真实默认均衡档无 composer/CAS，GPU 9.821 ms、CPU 12.7 ms；无查询窗口 CPU 13.4 ms、RAF 16.7 ms。与上一版不同运行窗口的均衡成本存在波动，未改该档渲染路径，不能据此宣称优化。

已知渲染目标 **234743560 B**、几何属性 **349630474 B**、独立纹理 **12483771 B**、51 个程序，与 0.101 相同；它们不代表进程总显存。生产包仅嵌入一份 393216 B 原始散射数据，SHA-256 `d4834ef3babc1376f923f39d495d69dd9d7099f56feb40335a184af8a6b98fc6`，四份许可文件与构建副本逐字节一致。
