# Photon 天气云消光与共享云影（0.116）

三层云从统一的 0.9/local 消光改为 Photon 的分层默认曲线，并让可见云、环境捕获和地面云影读取同一参数快照。固定晨景中云缘与暗底分界更清楚；本批没有完成整体参考图的云形与森林光色验收。

## 来源与参数

只读 Photon 固定在 `6e67b36e818bacde0304edd49f28e2bb70e33f04`。主要依据 [weather/clouds.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/weather/clouds.glsl)、[altocumulus.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/altocumulus.glsl)、[cirrus.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/cirrus.glsl) 与源默认设置。

`cloud-optics.js` 在天空构建开始时计算每层的每米消光、单次散射反照率、层云比例和照明响应。

| 条件                          | 主积云消光 / m | 高积云消光 / m | 卷云消光 / m |
| ----------------------------- | -------------: | -------------: | -----------: |
| 高太阳、无层云/上层遮蔽、晴天 |          0.100 |          0.032 |        0.150 |
| 地平线、无层云/遮蔽、晴天     |          0.050 |          0.016 |        0.150 |
| 高太阳、无层云/遮蔽、全雨     |          0.067 |          0.032 |        0.150 |

主积云另外保留源层云减薄、上层遮蔽及高覆盖修正，高积云使用源密度默认值 0.1 和层云系数。雨天反照率分别趋向 0.66/0.75/1.00；卷云密度采用源默认倍率 0.5。上层遮蔽、日间高积云补偿与卷云消光增强也放入同一快照。

云光程仍以 20 m/local 换算。主射线、二次散射和地面云影统一使用每层消光；阴影先累积各层加权光程，再计算总透射，保留原有阴影强度混合。没有把这一比例乘入地形雾。

## 发布与历史

工作数组与已发布数组分别保存三份 Vector4。环境图使用本次工作参数，完成异步读回后，再向稳定的全局向量复制；场景材质、可见云和水捕获保留原 uniform 引用。没有增加第二套天气计时器或存档数据。

每视图历史另外保存光学参数。消光相对变化超过 3%、反照率变化超过 0.02 或层云/照明响应明显变化时，拒绝旧历史；已有三层日月模式、前景与运动拒绝继续生效。

## 实际验证

- 独立源边界值检查覆盖晴天、地平线、降雨、高覆盖与层云遮蔽，另检查连续性及向量身份保持。222 项逻辑检查与生产构建通过。
- 真实森林中把天空交付延迟 1.5 秒。工作参数已经变化时，实际 GPU 仍读到上一份参数；交付后 CPU 与 GPU 才一起切换，工作向量与发布向量互不共享。最终检查还要求视图已用新参数积累至少 16 帧。受控地单独减半消光时，两个视图都在第一帧拒绝旧历史；该项是参数边界检查，不冒充原生天气场景。
- 实际云层的五个高度视角、前景屋顶和正负 10000 远坐标检查通过。在实际积分位置比较地面阴影与三层透射乘积，最大差约 `5.85e-4`；两处上层云的阴影贡献均非零，场保持世界锚定。
- 风、相机移动、完整/部分建筑遮挡及 WebGL 丢失/恢复检查通过。恢复云场误差约 `4.85e-5`，参数绑定保持共享，未放宽图像门槛。该次从发起恢复到浏览器调用返回等待约 **84 秒**，之后的恢复图像检查约 1.6 秒；尚未定位较长等待的原因，不能把这段调用耗时当成 GPU 帧率，也不宣称恢复性能改善。
- 固定 seed 624、晨景 time30、FOV72、曝光1 与天然森林眼位的 900×650/1920×1080 图，以及开阔天空图已查看。基线取 0.115 提交 `7b19bcf` 的同镜头记录；TAA 相位未锁成逐像素控制。实际环境图克隆和远景空气检查通过。
- 生产包通过普通 UI 导入森林降雨、天然雪原降雪的 v16 存档，渲染后导出，天气、时间、位置和编辑保持，GL 与浏览器诊断正常。其暂停控件图只作流程证据。
