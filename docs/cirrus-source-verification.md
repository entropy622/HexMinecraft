# Photon 卷云、卷积云与雨后湿度

0.120 继续迁移高空薄云。晴天的小碎云随源天气覆盖率减少，湿润强风条件仍可形成卷积云。整个 Photon 目标及用户参考图尚未完成。

## 源实现与宿主接入

固定参考 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04`：`sky/clouds/cirrus.glsl`、`common.glsl`、`utility/random.glsl`、`weather/clouds.glsl` 与 `weather/core.glsl`。

- 卷云使用原二维噪声 R 通道的双频基础场、四层细节侵蚀和逐层附加风位移；旋涡改为源 Perlin 梯度与 hash，替换原值噪声梯度。
- 卷积云用 A 通道控制大范围覆盖与主体，用 G 通道侵蚀。覆盖率随温度、湿度、风力变化；低风力的覆盖量可以真正低于出云阈值，移除之前的常驻密度。
- 卷云与卷积云分别使用默认密度 0.5/1.0，不再将两者统一乘 0.5。函数先转换到每 local 20 m 的现有天空比例，再使用源物理频率。
- 源 `day_factor=smoothstep(0,.3,abs(sun_dir.y))` 随现有光学快照发布，用于高层密度整形。它是太阳高度的绝对值权重，不能简单解释为白天/夜晚开关。z 分量在高层保存此权重，低两层继续保存 stratus。
- 渲染天气改读现有 `weather.wetness`。雨停后的湿度与风按既有湿润状态继续变化；卷云的降雨项仍单独读取 rain。没有新增存档时钟、设置项、二进制资产或云纹理采样器，沿用 v16、视距10和晴天雾87.32..118。

宿主仍保留壳层厚度、解析基础风、积分与时域重建。零卷积云覆盖明确返回零，避免源除零边界；后续仅会继续减少密度的侵蚀可提前结束，最终密度与源一致。夜光云、浓积云和完整预计算云影仍未实现。

## 数值与真实场景

21 项相关 Node 检查通过，覆盖独立高云天气、湿润状态、源太阳高度权重及现有云/雾参数。固定镜头检查中的一个 GPU 批次将迁移函数与四个逐字提取的源 density/hash/gradient 函数比较；原噪声/打包已有独立原图 GPU 对照。批次包含不同天气、层内/边界高度和风位移输入，是公式样本，不能计为游戏场景。最大密度误差约 `1.304e-8`，卷云与卷积云都实际产生非零样本，GL 诊断为零。

实际移动/建筑遮挡/设备恢复检查通过。分层测试保留五种观察高度、±10000 远处、世界锚定、总透射和真实屋顶遮挡。高云观察使用原生 clear/rain0/wetness1 存档，从低两层上方寻找真实积分出的薄云；随后恢复干燥天气。原有高云可见像素和场误差门槛保持。上层云影通过低云开口测得，两个远处场的最大影响约0.164/0.178；最近积云下的旧测点也继续记录。天空参数延迟发布与历史重置检查通过。

生产包雨、雪、无降雨且 wetness0.75 的雨后场景全部通过。经真实控件导入/导出v16，时间、相机、天气和世界编辑逐项保持；雨景执行真实设备丢失/恢复，继续暂停且不重锁鼠标，开发API不存在。未经修改的游戏逻辑矩阵与3456输入高光矩阵没有重复运行。
