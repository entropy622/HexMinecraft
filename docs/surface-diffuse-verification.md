# Photon 日月漫反射与几何遮蔽

0.103 补齐普通受光部分与 Photon 的一项差距；完整 MC/Photon 目标和用户森林参考图的整体光色验收仍未完成。

## 固定来源与适配

只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [diffuse_lighting.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/diffuse_lighting.glsl#L238)、[global.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/global.glsl#L156) 和源默认 `SHADING_STRENGTH=1`、`AO_IN_SUNLIGHT`。

地形、树叶、原生草花的日月漫反射由 `max(NoL,0)` 改为源 `lift(max(NoL,0),0.25)`，再使用平方几何 AO。前者保持正对与完全背光端点，在斜入射时适度提高响应；后者仅作用于直接反射，不重复衰减 SSS。沿用既有叶片 `1-0.5*sssAmount` 分配、真实阴影和玻璃/云/水过滤，不改变源入射辐照度、透射、阴影反弹、SH、局部光、发光、曝光或饱和度。

宿主使用原 Lambert 调用，有限因子 `1.25/(1+0.25*NoL)` 与原 NoL 相乘得到源 lift，零入射角没有除零；增加一层 AO 与后续既有一层合成源平方。只包裹方向光调用，不改点光/聚光循环。均衡/流畅也使用同一响应；下界由共享的维度参数回退，主世界/末地启用。新参数没有玩家设置和存档字段，v16、视距 10、晴天地形雾 87.32～118 保持。

范围是几何材质的源直射核心。动态模型继续使用原光照；没有迁移无阴影路径的完整替代公式、源方向面着色、通用 GGX/Hammon PBR 或屏幕空间接触阴影。派生代码继续保留 Photon 许可，见 [notice](../public/licenses/PHOTON-NOTICE.md)。

## 生产材质数值检查

真实地形回调、树叶/薄片植物工厂与方向光、阴影和 Float32 目标，9 个正负/掠射入射角、4 个 AO、叶片/植物 3 个 SSS 强度，共 252 组；另有 3 组真实局部点光控制。独立参考直接求源 lift，不复用生产的因子分解。新响应与旧 Lambert 控制最大误差均为 **8.124e-9**，新响应开/关时局部光之差为 **0**，三种点光控制都具有非零信号，没有非有限、页面或 GL 诊断。原几何遮蔽不改变物理底色/自发光的独立检查通过。

完整 207 项 Node、生产构建和 7 项不同的浏览器功能检查通过，另有 1 项 1080p 性能检查及 1 次针对编译控制的重复。真实叶片与原生草花保持 SSS 分配和局部点光，森林诊断有限，三个质量档、两次上下文恢复、主世界/下界/末地与水面捕获通过；实际维度参数为 1/0/1。最终生产包的真实控件与原生存档导入/导出通过。

已查看 900×650 与 1920×1080 的同镜头开/关图，变化集中于斜入射面和接缝，整体差异较轻，暖橄榄色与用户参考图的关系仍未完成校准。两图分别等待原时域采样稳定，不是同一份冻结 HDR 的逐像素对照。

## 实测成本与限制

RTX 4060 / Chrome ANGLE D3D11，每个窗口预热后测 120 帧。计时是实际 GPU 绘制批次合计，不是完整帧墙钟、FPS 或进程显存。

| 1080p 光影路径                   | GPU 中位 / p95     | CPU 提交中位 |
| -------------------------------- | ------------------ | ------------ |
| 完整性能批次，当前响应           | 36.033 / 37.466 ms | 36.7 ms      |
| 同程序参数关闭控制               | 35.654 / 37.210 ms | 35.5 ms      |
| 编译控制批次，当前响应           | 35.411 / 38.465 ms | 36.4 ms      |
| 编译控制批次，移除新算术的旧路径 | 37.147 / 42.142 ms | 39.2 ms      |

首次参数控制仍执行 `mix` 中的算术，不能以其约 0.38 ms 差值代表新增计算本身。为核查相对上一版场景计时偏高的问题，补充真实几何材质副本的编译控制：仅从最终 shader 删除新增的两句算术，3 类材质共 3 次编译、每次恰好删除一处，原风动、阴影、局部光、SSS 和整条后处理保留。控制后恢复原材质和缓存标识，释放副本，程序数回到 51。

两个控制的差值方向相反、分布明显重叠，现有数据没有稳定量出新公式的独立增量，不据此宣称性能改善或没有成本。原始数据保留在 `profile-final`、`profile-compiled-control`；上一版另一个运行窗口为 33.639 ms，不能把跨窗口变化全部归给公式，也不能忽略这项性能不确定性。

完整批次关闭叶片深度预绘制为 46.939 ms，CPU 22.1 ms；无 GPU 查询的深度开/关 CPU 为 37.1/24.0 ms，RAF 中位为 33.4/50.0 ms。默认均衡档真实启用新响应、无 composer，GPU 9.559 ms；其无查询窗口 CPU 13.2 ms、RAF 16.7 ms。CPU 提交仍重，基准稳定性和实际运行成本继续改善。

已知渲染目标 **234743560 B**、几何属性 **349630474 B**、独立纹理 **12483771 B**、生产程序 51 个，与 0.102 相同。未增加生产 pass 或缓冲；这不是总显存统计。构建仍只嵌入一份原始 393216 B 散射数据，SHA-256 `d4834ef3babc1376f923f39d495d69dd9d7099f56feb40335a184af8a6b98fc6`，四份许可文件与构建副本逐字节一致。

CPU 提交成本、近处冠层的完整材质与环境光、其余可迁移 Photon 能力及 MC 内容继续推进；源公式正确不代表整体参考图验收完成。
