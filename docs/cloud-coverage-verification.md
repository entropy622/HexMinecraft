# 0.88 云覆盖缓存与实际 GPU 成本

本轮保持 0.87 的云体、散射、积分步数、历史和曝光，减少地形与水面捕获重复求云影时的宏观噪声计算。默认视距仍为 10，晴天地形雾仍为 87.32–118，即此前预览起点 34.8 的 2.51 倍。云顶形态和森林光色尚未达到用户参考图。

## 实现

参考 Photon 固定提交 `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [云准备阶段](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/p0_clouds_prep.fsh)及[覆盖图](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/coverage_map.glsl)，独立实现本项目的局部宏观场缓存。没有复制上游纹理或直接移植其投影。

- 一个 1024×1152 RGBA16F 目标，增加 9 MiB 已知纹理存储。底部 128 行保留原始种子噪声的精确整数分子；其余区域分别存放主积云、高积云的宏观噪声与区域变化。
- 复用既有 `cloudNoise` 采样器，实际云片元仍只有 `cloudNoise` 与 `cloudWorley` 两个采样器。原始 R8 种子纹理保留所有权；缓存外围用同一解析函数和精确种子计算，卷云也保留解析路径。
- 主层覆盖 512 本地单位、高积云覆盖 256，间距分别为 0.5、0.25。网格在风场空间固定，中心沿日光方向投影并按 32 单位移动；种子、半径或中心改变时才重建。
- 四次 `texelFetch` 显式插值，保持平移前后的采样连续性。三维侵蚀、光学厚度、天气阈值和各视图历史仍实时计算。关闭体积云、降低画质、销毁管线时释放目标并恢复原种子绑定。

## 真实 GPU 检查与保留的失败

独立无头 Chrome / RTX 4060 / ANGLE D3D11，使用实际生产 GLSL、目标和原生森林存档，不操作前台鼠标或用户的 5173 服务。

每个精度场景读取 8192 个内外样点，并检查原始种子头、实际片元采样器和移动后的重叠纹理。最终独立重复两次，主层/高积云最大误差分别为 0.000582 / 0.000926，小于预设 0.002；外围解析误差为零。4190 个固定世界样点移动后最大变化约 0.000000507，小于预设 0.0001；两层重叠纹理数据完全一致。

原生画质控件、窗口缩放、导入种子 841、真实上下文丢失/恢复也各运行两次，共 4 项通过，种子头、绑定和恢复均正确，GL/页面错误/警告为零。

最终 198 项 Node、生产构建和修改文件格式检查通过。既有云层、历史、散射、天气、月光、水面及材质恢复组合回归 13 项通过；其中水面恢复场景按原测试主动注入 `cloud GPU boundary failure`，验证投影、渲染目标、状态与下一帧恢复，该预期日志保留。900×650 / 1920×1080 的森林与开阔天空共四个镜头通过，四张图已逐张查看；生产构建的原生导入/导出一项通过，v16、种子 624、时刻 30 保持正确，页面错误和警告为零。三个最终 GPU 阶段间的 334 个源码、测试、文档文件哈希一致，结束后所属进程和 5191/5193 端口均已释放。

早期记录保留在下列目录，未放宽精度或警告断言：

- `coverage-gpu-first`：高积云间距过大，误差 0.003282；驱动还报告分支返回值警告。
- `coverage-gpu-precise`：细化高积云并初始化单一返回值后，精度通过，但硬件插值的移动差异为 0.000244。
- `coverage-gpu-manual`：显式插值首轮仍记录 0.000152 的移动差异。后续增加原始重叠纹理检查，放在实际探针绘制之后；三次检查均约 0.000000507。首轮差异的具体触发条件仍保留为观察项。
- `coverage-gpu-grid`：移动检查通过，恢复检查暴露测试计时探针仍使用旧上下文扩展，产生 INVALID_ENUM。现在探针在丢失时丢弃旧查询，并在恢复时重新启用扩展；重复检查同时要求扩展和计数位实际恢复，不过滤警告。

## 性能范围

固定自然森林镜头、种子 624、时刻 30、1920×1080、FOV 72、曝光 1、光影档 1.7。分别预热后测量 120 个真实渲染帧、4200 个 GPU 批次。只观察原生 WebGL 调用，不替换产品渲染；查询在帧缓冲切换处结束，不嵌套整帧查询。首次计时探针枚举拼写错误的运行无效，保留在 `profile-before`；有效基线为 `profile-before-fixed`，产品基线为 `01b502a`。

CPU 提交中位数 25.8 → 25.6 ms，基本持平；每个视图的云历史约 0.064 ms。观测批次求和不含每批第一次 draw 前的清屏，也不是浏览器整帧时间，不能据此宣称稳定 FPS。云积分略慢，收益主要来自两次场景的共享云影计算。前后森林截图已逐张查看，构图、雾层次和云形保持一致；艺术差距也保留。

同页通过原生 teleport 跨一个网格边界，额外 120 帧中测得一次真实覆盖目标重建为 0.116736 ms。它只代表该设备的一次重建，不代表持续行走或所有天气/坐标的上限。两批测量的 disjoint、busy、GL 和页面警告均为零。真实资源枚举的渲染目标存储从 223298280 增至 232735464 字节，差值恰为 9 MiB；不等于进程总显存。
