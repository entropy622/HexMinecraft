# Photon 迁移审计与实施矩阵

目标是用户参考图中的视觉关系，以及本地 Photon 的绝大部分可迁移能力。完成当前 bloom 不代表完成这个目标。本文件先列出真实差距与后续实施批次，不把功能名称、源码存在或技术检查通过当作画面验收。

审计基准：

- Photon：`D:/Git/photon`，固定提交 [`6e67b36e818bacde0304edd49f28e2bb70e33f04`][p-root]。已对照 [README][p-readme]、[settings.glsl][p-settings]、[shaders.properties][p-properties] 的菜单/启用条件，以及对应 program/include 的实际实现。下方所有 Photon 链接固定到该提交。
- HexMinecraft：初始审计基线为 [`bf64bbf855484deb040d56561fc6713b74fa0480`][h-root]，版本 0.85；下方机制状态已按当前 0.122 源码更新。各验证文件保留首次失败与后续结果，本矩阵不替代实际图像和性能验收。
- 参考图：用户附件 `codex-clipboard-332466b9-bff0-4693-9c2d-c219012105ea.png`。实际查看了 1920x1080 图像；场景是向光森林，白色太阳周围薄云发亮，多层积云有明显厚度和暗底，远山与林冠向空气色递进，低洼湿霾保留前景深绿与背光亮叶的对比。不能从单张图确定其资源包、全部开关、时刻或曝光值。

机制表中的本项目源码链接跟随当前检出版本；初始审计基线保留在上方固定提交中。

`已有` 表示真实生产路径存在该行的核心行为，不表示与 Photon 逐像素相同；`部分` 表示已有机制但缺关键能力；`缺失` 针对该行机制，不否认同一子系统已有基础效果；`宿主接口不适用` 表示依赖 Iris/Minecraft/原生 mod 的接口，不能把相关宏或 UI 参数算成已移植功能。优先级 `P0` 直接决定参考图，`P1` 补齐常用可迁移能力，`P2` 覆盖可选摄影、夜景和质量/性能功能，`P3` 是宿主适配或开发工具。优先级不等于放弃低优先级的持续目标。

当前默认是 `quality=1` 均衡档；真实体积云和后处理链只在 `quality=1.7` 光影档启用，均衡档使用几何云。下面体积云、GTAO、TAA、SSR 和后处理的“已有”均受各自启用条件约束。目标图的成对验收明确使用光影档并记录基线成本；便宜的天空、太阳/月亮和方向光改进应按可行性同时覆盖均衡档，不自动替玩家切高档，也不靠改变曝光伪造改善。

## 参考图最先要求的五个变化

0.121 接入[源预计算云影与共享图集](cloud-shadow-map-verification.md)。按源分层准备系数、径向投影、B-spline 和高度/地平线淡出生成双通道图，地形/水/近场雾共用；未增加渲染目标或材质采样器。长天空云隙光、极远处精度和森林参考图仍未完成。

0.88 已加入[局部云覆盖缓存](cloud-coverage-verification.md)，实际复用宏观噪声并减少两次场景的 GPU 成本。它不增加新的云形或光学机制；下方视觉差距和五项优先目标仍然存在。

0.89 加入[分层云形与独立天气塑形](cloud-morphology-verification.md)：天气层深、较细积云侵蚀、高积云斑块/薄层混合及旋涡卷云。它们继续使用原有光学；参考图整体光色、冠层关系和完整层间输运仍未验收。

0.90 加入[RGB 空气输运与材质吸收分离](air-rgb-verification.md)：独立 Rayleigh/Mie 高度、RGB 消光、共享天空均值、归一化相位及四阶直射近似，减少近处灰色覆盖；几何阴影与叶片颜料分开。森林整体照明、长距离空气和完整天气介质仍未验收。

0.91 加入[SH 可见锥与阴影反弹](surface-indirect-verification.md)：原始几何 AO、完整九系数锥卷积及受真实光场过滤的日月阴影反弹；校正渲染属性与原始天光光级的平方关系。冠层仍偏暗，环境 SSS、bent normal 和通用 PBR 继续补齐。

0.92 加入[体素叶片环境透光](leaf-ambient-verification.md)，叶片按共享天空向上辐照度、几何 AO 和局部通透量组合环境 SSS。采用缓存的体素近似，未产生 GTAO ambient SSS/bent normal/专用历史；固定森林仍偏暗，部分厚冠层略暗，不能视为视觉验收完成。远雾起点继续为旧值的约 2.5 倍。

0.93 加入[叶片透射 sheen 与日月光单位修正](leaf-sheen-verification.md)，沿用真实厚度和玻璃/云影过滤，低天光门槛按平方属性修正。近处背光冠层有可见改善，远距 SSS/阴影范围过渡、整体光色和完整 PBR 仍待完善，参考图尚未验收。

0.94 加入[远距叶片体素透射与覆盖过渡](leaf-range-verification.md)，按已加载叶层、屋顶和玻璃计算阴影图外的透光；普通地面与生物阴影覆盖未扩大。未实现 Photon 的远距厚度归零和 AO/环境 SSS 补偿，主 SSS 与 PBR 仍部分缺失。固定 1080p GPU 批次合计增加约 5.9 ms，需继续优化。新增默认明暗适应画面与 GPU 曝光记录，保留固定曝光对照，生产默认未变。

0.95 加入[同程序叶片深度预绘制](leaf-depth-verification.md)，保留叶片厚度、范围与光照参数，减少被遮挡片元的追踪。两种分辨率下 12 组 HDR/深度对照一致；固定森林 GPU 批次合计约 42.4 → 32.8 ms，但 CPU 提交成本明显增加，需继续优化。该批没有完成新的 Photon 光学机制或参考图美术验收。

0.96 加入[Photon 主叶片 SSS 与吸收响应](leaf-primary-verification.md)：归一化 HG 相位、材质强度、颜色消光，以及保留反弹光和本地点光的普通方向漫反射衰减。体素光程采用 Photon 几何射线的 0.2 响应尺度，保留宿主线性 sRGB 工作空间；不等同于 Photon 的阴影深度或 Rec.2020 输出。背光叶片改善，最暗冠层与整体光色仍有差距；远距厚度归零/AO 补偿、草与通用 PBR 尚未补齐，CPU 提交成本仍待优化。

0.97 加入[装饰草丛与三类世界花的 SSS/sheen](plant-lighting-verification.md)，使用 Photon 小植物强度 0.5、sheen 1，并按强度混合方向天光。独立花朵保留风动阴影，昂贵的深度预绘制只用于厚叶片。近远遮挡、云/月光、水面与上下文恢复均已检查；作物、其他植物及手持植物的 SSS、植物 ambient SSS、精细薄片光程和完整 PBR 仍待补齐。整体参考图与 CPU 提交成本继续优化。

0.98 加入[远距 SSS 厚度过渡与可见性补偿](far-subsurface-verification.md)，并为草丛及三类世界花接入缓存的环境 SSS。阴影范围外仍检查真实体素遮挡，实际光源相机边缘的 25 机位逐像素验证通过。环境可见性来自体素代理，AO 仍是几何角点数据，未实现 Photon 的屏幕空间 GTAO/bent normal/专用历史；中远冠层改善，近处深冠层、整体光色与 CPU 提交效率继续推进。

0.99 接入 [Photon 实际 3D 天空散射表](photon-sky-verification.md)、RGB 有限角日月 Mie 相位、源坐标映射和 2020→709 适配，替换单次散射与局部回散项。天空与已有 SH/云雾/反射共享快照。直接/局部空气输运仍为宿主独立模型，源的日夜曝光/tint 已在 0.100 接入，半球 SH 已在 0.108 接入；完整光色标定仍待完成；保留上游许可与原始二进制签名。

0.100 接入[源日月亮度、色调与 Chapman 透射](photon-lighting-verification.md)，统一天空、直接光、叶片、云和空气的入射色，并按源早夜曲线增强 SH。源默认固定曝光用于新设置，保留已有明暗适应选择；以普通设置 UI 验证保存、重载与继续。局部空气仍是宿主 709 积分，满球 SH、盘面几何和完整光色校准仍待补齐。

0.101 接入[源默认调色与白平衡](photon-grading-verification.md)，使用 Lottes、输入/输出调色、源 HSV 分色和显示近似，八项实际设置支持保存与独立重置；均衡/流畅使用相同默认色彩函数。未改变固定森林曝光/照明来制造画面差异，完整工作色域、其他源曲线、夜间色偏和整体视觉校准继续推进。

0.102 接入 [Photon CAS](photon-cas-verification.md)，在最终显示颜色中按对比度恢复细节，移除旧 TAA 固定锐化，并提供保存/恢复的独立开关与强度。静态质量以未锐化超采样为参照，比较两种空间路径并同时约束过软/过锐化；完整 TAA 重建、整体光色和其余功能仍继续推进。

1. 统一天空辐亮度与方向天光。0.86 已接通球壳天空图和 SH；天空、云、雾、叶片和反射仍需在同一时刻、方向和颜色尺度下完成视觉校准，不能仅凭数值通过认定参考图已还原。
2. 建立厚积云、独立第二体积层和薄高云的形态与遮挡关系。0.86 已扩展既有积分和历史路径；各层厚度、内部光学和天空留白仍需按参考图改善。
3. 让低层云接受高层遮光，校准薄云太阳前向亮边、厚云暗底和多次散射近似。Photon 本身也包含艺术近似，不能把它描述为完整跨层 GI。
4. 让远景空气透视与低洼湿霾保留层次。0.90 已分离 RGB Rayleigh/Mie 及高度剖面；尺度标定、更广的天气/群系耦合和沿射线的云影变化仍待完善。
5. 用方向天光、叶片透射/高光和冠层遮挡共同形成绿叶受光关系。当前已有真实叶片厚度透射；继续提高饱和度、曝光或 bloom 无法补齐冠层结构与照明关系。

0.109 加入[群系植被颜色与资源包颜色表](biome-colors-verification.md)，让颜色在进入叶片 SSS、高光和反射前按真实群系混合。默认资源来自固定 VoxeLibre 素材；资源包采用 Minecraft 的温湿查表规则，这是输入材质的改进，不能计作新增 Photon 光学机制。晨景镜头、日光、曝光和远雾保持，整体森林参考效果仍未完成。

## 迁移路径与最小实现约束

Photon 的 OpenGL/Iris 多缓冲、compute/imageStore 和宿主材质标记不能直接搬到当前 WebGL2 forward + EffectComposer 结构。应迁移光学行为与验收结果，沿用已有场景深度、保护遮罩、云 MRT、光体、天气和生命周期。继续独立实现原理，核实复用素材/外部算法的许可；不直接复制许可证受限的整包源码。

- 天空与 SH 优先检查 Three 的 LightProbe/SphericalHarmonics3 与环境预滤工具，复用成熟表示；Photon 的 compute 归约可改为适合 WebGL2 的小型 reduction，不能让同步 GPU 读回成为每帧固定成本。共用天空辐亮度是云/雾/天光/反射多个消费者的基础，不必复制 Photon 的全部附件布局。
- 通用 PBR 先比较 Three 的现有物理材质/环境能力与本项目材质注入点，再决定缺失的叶片、体素光和折射部分；不要只为得到 GGX 再造完整材质框架。已有水/湿面追踪可统一扩展，避免三套 SSR 并存。
- SSAO 与 FXAA 的名称不构成必须增加平行实现的理由。当前 GTAO/SMAA 已覆盖相应能力；CAS 接入后应替代旧固定锐化，新增 TAAU 时应复用真实时域重建。
- 风、温湿度、云型和罕见天象应从已有 time/seed/biome/降雨/湿度派生。先提供一致的默认高画质结果，不复制数十个滑块、另一套天气计时器或天气存档。
- 保持低画质和关闭效果的资源预算；新资源必须接入 resize、DPR、quality、dimension、capture 和真实 context loss/restoration。云与水 capture 继续使用各自实际视图的历史，保护前景和手持表面。

### 天空尺度：初始问题与当前状态

初始 0.85 审计中，`CLOUD_BASE=52`、`cloudFar=130`、`camera.far=220`、天空穹顶半径 180；volume 曾把 sky depth=1 也当作 220 的几何终点，云历史也用该距离比较前景，妨碍直接扩大云层尺度。

0.86 起已建立[球壳云层与独立天空远界](cloud-layers-verification.md)：当前光影档按最高云层与相机的高度推导地平线跨度，`cloudFar` 上限为 60000；无前景天空使用云自己的远界，真实地形仍按深度截断，MRT 明确区分天空与几何距离。基础尺度问题已有生产实现，后续重点是云形、光色与层间输运的校准。参考图中的远山/森林几何纵深仍需场景与 LOD 评估，不能由天空比例或更浓边界雾替代。
