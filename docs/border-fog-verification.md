# 方向封边与远处树冠

0.126 改善已经加载的地形与天空之间的封边。完整 MC、Photon 功能及参考图效果仍未完成，地平线下方的空白也尚未消除。

## 来源与实现

参考固定 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [d4_deferred_shading.fsh](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/d4_deferred_shading.fsh)、[simple_fog.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/fog/simple_fog.glsl) 和 [global.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/global.glsl)，保留 [许可声明](../public/licenses/PHOTON-NOTICE.md)。

旧路径把所有方向混向地平线平均色，并用球形距离封边。现在从已发布的晴空贴图取相应方向的颜色，按源晨昏、降雨、视线高度和平方权重选择地平线色。投影与可见天空共用 `sky-projection.js`，保留下半球的可见天空延伸；SH 和反射所需的原始地面半球没有改写。新贴图绑定随天空纪元、画质分配和恢复更新，晴空入射光仍与雾后环境光分开。

源 `exp2(-8*r^8)` 曲线重映射到既有近远区间。距离使用实际 q/r 区块边界的法向投影，计算三次范数，并限制在旧水平圆以内。这样不会在旧近距阈值以内提前添加封边，也不会暴露未加载的边界。向下截止沿用源 16 单位过渡；缺少更远几何支撑的向上放松、LOD 专用过渡尚未迁移。

默认视距仍为 10，相机 far 220，晴天封边参数仍为 **87.32～118**。它们现在用于区块边界度量，不代表每个方位都在同一个欧氏距离消失；朝轴向区块对角线可保留更多既有几何。本批没有再次乘大雾距、增加世界常驻区块或增加渲染目标。新增一个材质片元天空采样器，读取已有天空纹理；该次运行含此绑定的程序最多使用 9 个采样器，设备上限 16。

主世界三个画质档接入；下界和末地保留原封边，液体介质和洞穴天光门控继续沿用。解析路径仍使用既有表面空气计算，光影档沿用原体积积分和远段上限；本批没有统一两条路径的完整远段距离或完成世界单位标定。

## 实际画面

固定 seed624、FOV72、曝光1，900×650。晨景使用原森林眼位轴坐标 `[-120,22.5,4]`、朝向 `[-98,17,-4]`、time30；丛林使用 0.125 的眼位 `[-177.5,44.65,54.5]`、朝向 `[-157.5,33,54.5]`、time120。前后图在同一运行中仅切换新的封边贡献，材质、照明、雾参数和相机不变；最终截图包含真实天空、云与完整后处理。

已查看最终晨景和丛林成对画面、均衡档画面。晨景右上方原本抹白的远树恢复了可辨认的冠层，丛林远处树线保留更多层次。仅改变方向颜色时改善很小，因此最终实现还包含了边界距离与曲线。前景树叶没有通过提高曝光或饱和度制造差异。地平线下方仍大面积缺少远景，整体叶色、云层和参考图关系继续改善。

## 验证与边界

251 项完整 Node 检查与构建通过；最终 GLSL 曲线改动后，6 项相关状态检查重跑通过。新增的纪元检查确认取色跟随已发布天空，跨维度关闭并在纹理更换后重绑。

最终开发 GPU 是 **1 项场景检查**，包含上述两对图与三个画质档。每档读取实际已发布天空贴图，在八个方向上独立做 CPU 双线性取样和源混色参考，与生产 GLSL 比较；归一化最大误差不超过 0.0002442，封边可见度最大误差约 `7.81e-7`。这些输入不计作独立功能场景。

同一诊断视图的两次离屏绘制保留真实场景、材质回调、相机与阴影，排除透明层，并在预热后仅切换封边。三个画质档各有 42420 个近面像素保持逐位相同；2758 个远面像素的线性 HDR 平均绝对差约 0.052～0.057。这只确认实际路径与作用范围，不是画面质量评分；最终截图继续使用完整场景。

生产 GPU 另有 **1 项 UI 检查**，覆盖原生降雨、降雪、雨后 wetness0.75，真实设备丢失/恢复，以及 v16 导入导出。时间、位置、天气和编辑逐项保持，开发 API 不存在，恢复后保持暂停且不锁鼠标，页面和 GL 诊断为零。
