# 大气天空与方向天光验收

基线是 HexMinecraft `3edc8ea0f07716671fbe756f41acdad46d91125b`（0.85）；目标参考为用户森林图及 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的天空与 SH 行为。此批只做迁移矩阵批次 1，多层云由独立分工继续，不把单次散射近似写成完整 Photon 大气复刻。

## 修改前五判断

1. 结构问题：用同一 RGB 球壳大气输运生成天空辐亮度、日/月透射与九系数天光，修复渐变天空和常量半球照明没有共同方向/颜色依据的问题。
2. 调用负担：沿用既有时刻、月相、天气、相机、维度和画质，不增加玩家设置、依赖或存档字段。
3. 可推导信息：太阳/月亮方向、气溶胶、观察高度、更新时机和低档分辨率都由现有状态确定，消费者不填写另一套天空参数。
4. 最小范围：Three 的 LightProbe/SphericalHarmonics3 已提供 SH 表示与实际材质的余弦卷积；复用它，只补依赖没有提供的 RGB 球壳透射/散射和 GPU 小图归约，不再造 PBR/时域框架。
5. 非单图特调：同时覆盖正午、地平线、日落、月夜、雨天、森林、地下与水面，同一固定曝光下判读；不以曝光、全局抬亮或自动切高画质制造差异。

Three r186 的 `Sky` 为解析日光模型，包含它自己的云形态，不覆盖此批月夜、臭氧球壳输运和现有云共享要求。LightProbeGenerator 能从立方体环境图计算 SH，但需要六面生成/读回；本项目已有全屏 pass，可对一张天空图直接归约为九系数并异步读回小缓冲，再交给原生 LightProbe，避免额外立方体捕获与每帧同步读回。无需新增依赖。

## 生产设计与共享接口

- 固定小型光学深度图存储分子/气溶胶/臭氧的积分柱长；RGB 系数在采样时求 Beer-Lambert 透射。天气改变气溶胶时无需重建光学柱长。
- 与云共用 `worldY=0` 虚拟行星地面、1 local=20 m、半径 6371000 m；观察高度取 cameraY×20 m，在数值边界最低保持 20 m。没有另设海平面偏移。RGB 是 linear sRGB 的三波段近似，太阳使用固定工作 HDR 标定，月光保留游戏可读性标度；不宣称光谱/SI 辐射计量或 Photon Rec.2020 的逐像素等价。
- 小型 HDR 天空图由球壳单次散射、有限角日/月光源和明确的低阶各向同性回散近似生成，保留地平线与地影。它不是 Photon 多重散射 LUT 的完整等价物。
- 天空图之外绘制连续有限角太阳盘及临边昏暗，保留既有月相纹理和星星。天空散射图不包含太阳盘，避免盘面在低分辨率图和 SH 中混叠或重复计入直接光。
- GPU 将真实天空图归约到九个辐亮度 SH 系数，以及供水/雾/云使用的天空摘要和日/月透射；104 字节小缓冲异步读回。只有一个在途提交，普通时间推进时先发布完成快照，再合并当前最新输入；最多 4 Hz，不每帧阻塞 GPU。现有 `time` 相对 simulation `dt` 的不连续、维度/设备代际变化使旧提交失效，避免仅靠方向 key 丢弃持续前进时间下的每个结果。
- 天空图使用 active/staging 两个固定目标；同一提交的纹理、方向/气溶胶/观察高度、CPU 摘要和 SH 完成后一起发布。相对于旧天空零离屏目标，均衡/光影新增 360552 字节（352.1 KiB），流畅 139368 字节（136.1 KiB），不含驱动对象开销。第二张天空图是异步期间维持图像和照明一致性的必要成本。
- `skyEnvironment.uniforms` 与导出的 `skyRadianceGLSL` 提供 `hexSkyRadiance(vec3 worldDirection)` 和 `hexAirTransmittance(float worldDistance, vec3 worldDirection)`。输出为 linear RGB；距离在函数内部转换为大气千米，避免每个消费者自定比例。云的 `L*Tair + sky*(1-Tair)*(1-Tcloud)` 保留云自身 T，由云分工接入。
- Graphics 在 fluidRenderer/wetSky/fog/cloud/Atmosphere 消费者之前统一更新天空来源。静态和动态材质共用 voxelLightingChunk，对 LightProbe 项使用同一 vSkylight gate；地下局部光、夜视与非主世界环境保留。
- 均衡与光影使用同一模型和共享光色；流畅只降低固定小图成本。LUT 不随 DPR/屏幕扩大，也不为低档再造另一种天空。主世界外释放天空输运资源并关闭该探针；context loss 取消旧读回并重建当前状态。

## 修改前完整失败类别

| 类别            | 具体失败与真实验收                                                                                                                                                                       |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 颜色与数值域    | 零辐亮度产生光；有限 HDR 出现 NaN/Inf/负数；RGB 透射超出 [0,1]；长路程反而增透；日落不呈波段差；低精度柱长相减破坏短路程。用真实着色器输入/读回检查，不复制 CPU 积分。                   |
| 几何与边界      | 地平线硬接缝、经度接缝、极点发散、太阳在地影下仍白亮；低/高相机观察高度突变；太阳临边不连续。保存天空实际图片和方向探针。                                                                |
| SH 的归一与方向 | 常量环境随法线改变；DC 缩放/π 错误；一阶方向旋转与相机混淆；负瓣造成实际材质负光；太阳盘重复算入间接光。真实 GPU 天空输入、生产归约与 Three 实际 Lambert 表面求值对解析常量/线性方向场。 |
| 共同色源        | 天空已更新而水/雾/云使用旧渐变；异步结果次序倒流；快速日夜/天气切换套用过时读回。固定曝光实景成对 HDR/PNG 与摘要；相机旋转不能旋转世界照明。                                             |
| 地下/局部光     | SH 绕过 vSkylight 把封闭洞穴染蓝；夜视被探针覆盖；局部彩色灯被环境吞掉；漏到非主世界。密闭箱、原有 colored-shafts 场景与维度往返。                                                       |
| 日夜/天气       | 日落地影瞬变、月相亮度倒置、雨天过曝/非连续、太阳/月盘与阴影方向分离。固定太阳角、满月/新月、晴雨转换，记录源光与材质 HDR。                                                              |
| 生命周期        | resize/DPR/quality 引发纹理尺寸错误、重复分配；维度关闭继续运行；异步读回在 context loss 后回写；恢复黑天/旧 SH；资源无法释放。实际 context loss 与分配/释放观测，不锁死实现目标数。     |
| 性能与输出      | 天空逐屏像素跑重积分、每帧同步读回、后台重复更新、低档反而更贵；双重 tone map/输出转换。固定小图、更新次数与实际 GPU 时间基线，均衡直接输出/光影 SceneFrame HDR 都检查。                 |
| 实际画面        | 仅凭数值绿宣称参考图完成、加曝光掩盖灰天、蓝色阴面过强、夜间火把不可读、云/天空不一致。人工查看旧/新同镜头图及差分，技术和艺术分别判定。                                                 |

## E2E 与证据顺序

`tests/atmosphere.spec.js` 经真实首页/画质设置启动，用既有开发场景 API 建固定向光森林、材质标尺与密闭灯箱，冻结时刻/曝光并留正午、日落、夜景和水面图片、SceneFrame HDR、设备与 GL 诊断。`ATMO_LABEL=old` 在隔离 0.85 checkout 跑同一实景测试；新版本另留目录，保留首次失败。

补充 GPU 契约通过 Vite 静态 import 同一 Three 和真实天空模块。常量/线性方向环境仅替换 GPU 输入像素，然后运行同一个生产 SH 归约和 Lambert 着色器；解析期望是常量 πL 与线性场的 πL0 + 2π/3·L1，不是算法镜像。透射、经度/地平线、更新和资源验收同样用实际生产模块。

持续时钟 E2E 真正恢复 `setPlaying(true)`，仅在外部 GPU 设备的异步读回 Promise 后延迟 450 ms，要求多个不同方向快照成功发布，同时真实 GPU 天顶采样与 CPU 摘要匹配。另用正常生产 update 的显式跳时验证旧在途结果不能回写。低太阳高度的晴天还要求星点不出现，满月/新月和末地外观分别保留。

默认不启动任何浏览器/Vite/GPU；等父分工串行授权后，用专用 5199、隔离 cache/output、headless Chrome D3D11，复用 browser-fixture 的 Pointer Lock 边界。记录真实 RTX 4060 renderer、errors/warnings/GL，禁止屏蔽编译警告。900x650 与 1920x1080 的性能先有旧版基线，再评新成本。

当前 checkpoint 已通过 183 项 Node 回归、生产构建、四项浏览器测试枚举、语法、格式与 diff 检查；尚未运行本批 GPU 验收。主目标画面将复用统一 photon-reference-scenes 的 time30 森林/天空镜头与已保留旧版基线，本文件自建森林/密闭场景只作补充。SH 目前来自晴空/气溶胶与地面回照近似，不含实际云体向天空图的反向照明；既有地表雾仍保留原积分机制，本批只统一其源光色，完整 RGB 低层湿霾在后续范围内。
