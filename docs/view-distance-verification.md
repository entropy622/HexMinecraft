# 大视距、远雾与世界更新

按用户要求，默认渲染半径从 3 提高到 10 个区块，每个区块为 8×8 轴向格。实际渲染 441 个区块，保留一圈邻接数据后驻留 529 个区块。主世界晴天的地形雾从 87.32 开始，到 118 完全遮蔽区块边界；相对前次预览 34.8 的起点为 2.51 倍。雨天、雷暴仍会缩短距离，下界保留自身的浓雾。

视距没有通过缩短物理范围或关闭方块更新来实现。扩大驻留范围暴露了两个既有问题。

- 草变成泥土、仙人掌年龄变化等更新会使整个光照场失效。现在 `blockRevision` 保留红石需要的完整变化序列，`lightRevision` 只随实际光学变化递增。失效判断与光照构建共用 `light-data.js`，包括门、活板门、光源开关、玻璃介质及染色玻璃的调色板编号。流体高度和营火熄灭继续使光照失效。
- 每次载入自然地形都会唤醒所有悬空沙砾。现在生成本身不触发重力，附近方块的放置、移除或状态变化才唤醒相邻方块，并继续传播连锁下落。这与 Minecraft 官方描述的[自然悬空沙触发方式](https://www.minecraft.net/fr-ca/article/block-week-sand)一致。区块返回时检查周围保存的编辑，防止卸载前尚未处理的支撑变化丢失；已在空中的实体继续按原存档恢复。

光照构建还缓存固定范围内的格索引，并只从明暗交界处启动天空光扩散。直接天空光已经解出了每一根垂直列，逐一将所有敞亮空气格放入传播队列没有收益。独立的全源传播 oracle 对照地表、树冠、屋顶、水体、三个维度和变动的区块范围，要求 cost、medium、sky 和 RGB 数组完全一致。
