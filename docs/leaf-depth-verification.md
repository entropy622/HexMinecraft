# 叶片深度预绘制与 GPU 成本

0.95 在光影档加入叶片深度预绘制。0.94 的远距透射沿真实体素追踪厚度，但被更近叶片遮住的片元也可能执行昂贵的光程查询。现在先将叶片写入原有深度附件，再让受光绘制利用深度测试跳过隐藏层。沿用 v16 与已有画质控件，没有新增玩家设置。

## 实现与边界

`FoliageRenderPass` 继承已有 RenderPass，主视图和水面捕获均使用它。预绘制沿用原场景、叶片材质、灯光、接收阴影标志及同一份着色程序；`leafDepthOnly` 在 alpha test 后提前返回，颜色写入关闭。这样保留相同的贴图镂空与风动画，同时跳过该遍的光照和体素追踪。主绘制恢复颜色写入，保留已写深度；真实屋顶、地面、玻璃、模型和水继续按原路径绘制。

预绘制暂缓阴影图更新，将原有待更新标志交回完整场景的主绘制。Color 背景会强制清屏，因此只让主绘制清颜色，深度只在预绘制之前清一次。原场景矩阵每次 beauty 绘制只更新一次。`finally` 复原图层、材质写入、背景、清屏、矩阵与深度分支状态；失败时保留待更新阴影。外部 override、定制 clearColor/clearAlpha/clearDepth 等情况继续走普通 RenderPass。

没有减少体素光程步数、缩短透射范围或改变 SSS、云、曝光与材质参数。该优化只在已有光影档运行；是否划算取决于遮挡和 GPU/CPU 负载，不能据单个森林窗口保证所有场景更快。

## 先前失败与修正

最初复用独立 MeshDepthMaterial，在静止条件下匹配，但风动画中出现漏绘和亮色缺口。900×650 的风场景有 31125 个颜色通道不一致；小幅 polygon offset 仍在捕获 guard band 留下 3 个不一致像素。单独声明 `invariant gl_Position` 也没有通过。[GLSL ES 3.00 第 4.6 节](https://registry.khronos.org/OpenGL/specs/es/3.0/GLSL_ES_Specification_3.00.pdf#page=63) 说明跨程序一致性还要求相关数据流、输入和运算一致；不能仅凭着色器外观相似认定深度一致。本轮没有据此断言驱动缺陷。

这些方案已全部撤回，包括独立预绘制材质、代理场景、深度偏移与 invariant 改动。最终采用同一着色程序的 uniform 分支，并保持颜色、深度必须完全一致的验收条件，未通过放宽误差交付。首次失败、实际 GLSL 与 GPU 输入记录保留在本机 artifacts。

CPU 采样的主要热点出现在原生 WebGL uniform 数组上传调用。随后分别试验跳过深度分支不使用的云数组、缓存相同数组值；整体成本未改善，均已撤回，`clouds.js` 与 0.94 相同。调用栈没有证明具体的驱动等待原因，不能将它描述为已经解决。

## 实际验证

全部浏览器批次使用独立无头 Chrome / RTX 4060 / ANGLE D3D11，串行执行。沿用 DOM Pointer Lock fixture，未占用前台鼠标或操作玩家的 5173 服务；每批完成后按 PID 与 UTC 创建时间核对退出，5191/5193 端口均释放。

- **204 项 Node 测试通过**，0.95 生产构建通过。
- **12 组完整缓冲 A/B 通过**：900×650 与缩放后的 713×509，分别覆盖静止、风和受控水面捕获 guard band，每种均读取主视图与真实水面捕获。合计 5687502 个像素对的 RGBA16F HDR 与读取为 Float32 的深度逐元素一致，颜色和深度差异均为零；实际执行了各模式对应的预绘制，状态复原与 GL 检查通过。这是候选程序开关预绘制的比较，不能扩大为所有场景或跨版本逐像素一致的声明。
- **13 项功能回归通过**：上述 A/B，加上六项原生叶片透射、两项环境 SSS、一项材质反射/颜料分离、三项软阴影检查。覆盖近/远叶片、厚度、屋顶/半砖、玻璃移除、云影、日月光、风、手持光与光体更新，以及水面、建筑、生物材质、画质切换、窗口缩放和真实上下文恢复。
- **自然森林与生产 UI 导入/导出通过**，合计 **15 项不同的功能浏览器检查**；另有 GPU、CPU 与帧间隔的性能窗口。页面、shader、GL 错误及 shader 警告均为零。修改文件单独检查格式，全仓既有未修改格式问题仍见 [0.92 记录](leaf-ambient-verification.md)。

已实际查看最终 900×650 固定曝光、默认明暗适应画面及 1920×1080 森林，并与 0.94 对照。未见原型中的亮色缺口；当前仍偏暗黄绿，云团、冠层光色与用户 Photon 参考图的差距保持，不能把这次性能改动算作参考图已还原。默认明暗适应的实际 GPU 历史曝光为 1.9521484375；曝光默认与参数未改。

## 成本与取舍

同一浏览器进程、种子 624、相机、时刻 30、光影档、1920×1080、固定曝光 1。每个开关窗口预热后采 120 帧，关闭预绘制的对照仍执行完整远距透射。

| GPU 绘制批次合计 p95 / ms           |     43.038 |     33.384 |

GPU 中位数减少约 **22.6%**，主场景与水面捕获的场景组从约 13.0 ms 分别降至 8.203 / 8.350 ms。CPU 提交时间明显增加，关闭 GPU 计时查询及状态轮询后仍存在，不能将这项回退归因于计时器。新增的深度绘制带来额外提交，具体原生调用成本仍待优化。

这个固定窗口的 RAF 节奏改善，仍不能作为长时间游玩帧率或所有硬件的保证。GPU 数字是实际绘制批次的合计，未覆盖初始清屏、全部浏览器与合成成本；CPU 时间也包含原生 WebGL 调用耗时。带 CDP CPU Profiler 的窗口仅用于诊断，不用于上述最终成本表。
