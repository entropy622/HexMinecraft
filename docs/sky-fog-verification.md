# 0.113：天空雾、环境天光与远景空气

基线为 0.112 `6f050d3b5581f35d693b18cafaa04584fb765a8a`。参考固定 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [天空图合成](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/d0_sky_map.fsh)、[原始天空入射光](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/d0_sky_map.vsh) 与 [解析空气雾](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/fog/overworld/analytic.glsl)。保留 [Photon 声明](../public/licenses/PHOTON-NOTICE.md)。

## 改动与合成顺序

原先可见天空经过近处空气积分，但环境 SH 和环境天空反射使用的天空图没有这层雾；空气体积也在 58 local 处停止。现在天空环境图先合成真实云，再以 `L*T+S` 合成解析空气，之后投影 SH。表面环境天光和 PBR 的环境天空反射读取这个完成结果。

可见背景仍读取未加雾的晴空，并由原来的视图云覆盖，主视图随后统一处理一次空气。近处仍为原 24 步积分，保留细部阴影、玻璃光束、彩色方块光及 Mie 噪声；58 local 之后增加不重叠的解析段，直至场景深度或既有天气封边远距。主世界光照体之外的空气以相机天光门控补齐，避免高处/远处直接丢失介质；洞穴不会因此获得室外白光。水中仍走原占水长度积分，未将空气尾段混进水介质。

均衡/流畅档的天空解析计算完整空气；日月和星体的发光只乘透射，散射由背景提供，避免再次加亮。几何的解析雾与封边颜色使用相同柱量；近处未进入封边的片元跳过额外边界计算。默认视距 **10**、晴天地形雾 **87.32..118**、雨天 **81.32..111** 与 v16 格式保持。

## 入射光与快照

空气的环境入射改用未加云、未加雾的晴空倾斜方向 `normalize(0,1,-0.8)`，沿用源 `tau*1.13` 与 `2*isotropic_phase` 合并后的 `1.13` 倍率。它不读取已加雾的 SH，避免天空雾照亮自身。云继续使用原始晴空上/下半球补光，其输入也不会循环累计。

天气/群系雾参数随天空、日月与 SH 的异步完成快照一起发布，实际渲染使用同一纪元的参数和原始雾入射光。连续天气由既有天气状态平滑，游戏中的雾参数现在随天空更新（正常上限约 4 Hz），不再在发布后另加一层独立参数阻尼；独立调用 Atmosphere 的兼容路径保留阻尼。世界切换和显式时间跳跃失效旧纪元，正常行走与时间推进继续合并更新。

## 实景与数值

固定原生森林 seed 624，晨景 time 30，眼位轴坐标 `[-120,22.5,4]`，朝向 `[-98,17,-4]`，FOV 72，曝光 1。保留 900×650 与单独 1920×1080 晨景，没有改成更亮时刻。另查看高处向空中的远景与均衡档黄昏，后者保留该档原有几何云。

读取真实环境图，用实际云 shader 的独立克隆关闭雾，得到同一云场的输入辐亮度；开启雾的克隆与生产环境图全部 4608 像素逐位一致。独立 CPU 中点积分与归一化相位计算在所检位置的最大误差为 **0.0004871**，以 `abs(actual-expected)/max(1,abs(expected))` 定义；原始入射光的最大归一化误差 **0.0001827**。该验证检查合成核与实际数据耦合，不是几十份独立美术场景。

高处清空视线实际深度为 1，Rayleigh 柱量读回 **20.2656**，完整 118 local 数值积分约 **20.2748**；旧 58 local 对应约 **14.9133**。允许半精度和时域抖动造成的小差异，足以确认远段真实参与。封边范围仍为 **87.32..118**。

画面中地平线空气与远处林冠的关系更连贯，近景的输入材质与曝光保持。SH 受雾影响属于本轮预期变化，不能把它说成“只差一个雾颜色”的逐像素消融。云型、树冠台阶及整体 Photon 森林参考仍未完成美术验收。

## 验证、资源与限制

220 项逻辑测试与生产构建通过。新增逻辑检查确认渲染使用已发布雾快照，并且改变雾后 SH 不会反向照亮雾本身。最终运行代码由五项不同开发 GPU 回归覆盖：RGB 高度/合成、1.25 DPR 的画质与上下文恢复、延迟读回时的快照同步、真实云/雾环境图的 SH 与反射、上述天空雾/远段空气及均衡黄昏。延迟设备检查的 90 个有雾渲染帧中，参数与原始雾入射光的快照误差为零。

生产包使用普通 UI 分别导入森林降雨和天然雪原降雪，渲染后导出检查时间、位置、天气和编辑保持，未暴露开发 API。其截图包含暂停控件，只作流程证据。全部 GPU 批次串行并冻结源码；最后审计 781 文件无漂移，所属 PID/UTC 创建时间实例和测试端口清零后才补文档，并澄清一处夹具注释。

保留首轮因 ANGLE `f_airVoxel` 未初始化警告而失败的记录。该轮数值已输出，但未作为通过结果；分支改为显式初始化后，最终回归没有该警告。未重跑没有变动的 3456 输入高光公式矩阵。

开启体积云的光影档复用原来两张 96×48 RGBA16F 云环境图，没有再增加一对图；此前不分配这对图的场景（均衡/流畅档或关闭体积云）现在为了环境天空雾分配它们，已知目标数据 **73,728 B**。归约目标从 19×1 变为 20×1，增加 **8 B**，每次异步读回也增加 8 B。无体积云时环境 shader 编译排除云积分，日月星体增加解析透射；未测完整程序/驱动显存占用。

RTX 4060 / ANGLE D3D11、1920×1080 固定晨景，对实际空气体积与双边合成使用 GPU 计时。新天空/远段分支关闭、开启、恢复关闭的中位数分别为 **1.899 / 2.081 / 1.883 ms**；两轮关闭窗口间也有漂移，观察增加约 **0.18..0.20 ms**。每窗两次预热、六次有效样本，无 disjoint 或 GL 错误。该测量只针对当前版本同一输入下的新分支，不代表完整帧、持续游玩 FPS 或完整旧版/新版性能对照。

这是共享宿主 RGB/local 高度核下的源合成迁移，不是完整 Rec.2020 光谱输运。天空空气距离适配为既有天气封边远距 118/111，而非源游戏任意 far；高度柱量仍使用宿主分段封顶剖面。远段用中点的光场、阴影和云影近似，未增加沿远段的完整多步遮挡积分。雨天原始入射色仍来自宿主的雨天天空，不是源 get_weather_color 的完整移植。SSR 沿反射段与水面平面捕获中的空气尚未统一，银河、极光、沙尘及其余 Photon 功能继续推进。
