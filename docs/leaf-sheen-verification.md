# 叶片透射 sheen 与日月光单位

0.93 参考本地 Photon 固定提交 `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [SSS sheen](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/diffuse_lighting.glsl#L78)、[HG 相位](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/utility/phase_functions.glsl#L23) 和[叶片参数](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/surface/material.glsl#L203)，独立加入叶片透射中的 sheen。上游默认启用 `SSS_SHEEN`、`HARDCODED_SPECULAR`，叶片 sheen 为 0.5。

这属于已有叶片透射的扩展，尚无通用 GGX/PBR 叶片镜面、法线纹理或完整 Photon SSS。仍只在现有光影档开启日月透射，沿用 v16 与原有画质控件。

## 实现

`leafSunColor` 原先先乘 0.2，着色器再当作光源使用。现在它直接接收实际 `sun.color × sun.intensity`；原透射项的 0.2 移入响应函数，保留原有幅度。新增 sheen 使用同一份实际日月光，在真实厚度、玻璃和云影下衰减。

```text
μ = dot(相机到叶片方向, 叶片到光源方向)
HG(μ, g) = (1-g²) / (4π × (1+g²-2gμ)^1.5)

sheen = 0.8 × 0.5 × HG(μ, 0.5) × saturate((μ+0.8)/0.6)
        × albedo/(albedo+1e-6) / π
日月透射 = E_actual × T_cloud × T_glass × T_leaf
           × (原项目透射响应 + sheen)
```

上游 `LoV` 使用从表面到相机的方向，因此这里的 μ 对应 `-LoV`。真正黑色的纹理通道保持零；reciprocal-albedo 与最后乘 albedo 的组合有限。正面观察时 sheen 为零，背光时沿归一化相位增加。厚度继续使用现有六边体素 Beer 积分，只求一次 `T_leaf`，没有新增光程查询、采样器或渲染目标。天空环境 SSS、普通漫反射、方块光和曝光维持现有路径。

Photon 使用原始天光 0.1 作为透射资格阈值，本项目属性已经是 `rawSky²`。条件修正为 `vSkylight >= 0.01`；没有通过统一抬高低天光亮度实现。阴影图范围外、未知或不透明遮挡继续返回零透射，尚未移植上游 `shadow_distance_fade` 的远距 SSS，因此远冠层仍是明显差距。

## 实际验证

全部浏览器检查使用独立无头 Chrome / RTX 4060 / ANGLE D3D11。沿用 DOM Pointer Lock fixture，未占用桌面鼠标或操作玩家的 5173 服务；每批结束按 PID 与创建时间确认退出、5191/5193 端口释放后再继续。

- **203 项 Node 测试通过**，生产构建通过。
- **288 组实际 GPU 核函数输入通过**，覆盖方向和边界、材质颜色/黑色极限、厚度透射、sheen 强度与零光源。独立期望使用双精度公式；RGBA32F 最大归一化误差为 **1.195e-7**，小于 1e-5。生产 RGBA16F 单独按实际精度检查，最大差异 **0.99292 ULP**。
- **原生叶片 sheen A/B 通过**。真实光源与叶片输入逐通道完全一致；943 个叶片像素中，薄叶 sheen 亮度均值 0.058498，厚冠层 0.001242，不透明屋顶和正面视角的增量为零。真实叶网格属性输入分别设置为 `(1/15)²` 与 `(2/15)²`，前者阻挡，后者允许；实际天空属性的平方编码继续由既有生产编码检查覆盖。
- **四项原有叶片回归通过**，包括半砖/屋顶、玻璃、云影、月光、风、水面捕获、画质、上下文恢复与维度切换。两项环境 SSS/字节更新和一项材质反射/颜料分离检查通过。
- **自然森林与生产 UI 存档导入/导出通过**。合计 11 项不同的功能浏览器检查；另有 1080p 性能窗口。页面、shader 与 GL 错误为零。新增和修改文件格式检查通过；全仓格式的三个未修改问题保留在 [0.92 记录](leaf-ambient-verification.md) 中。

首轮核函数检查将半浮点误差与公式误差混在一起，粗设的相对阈值 0.0008 遇到 0.000914 而失败。未放宽该阈值后直接交付；改为更严格的 Float32 算术检查，再独立检查生产格式的一个 ULP，原始失败保留。RGBA32F 只用于测试，生产目标格式未变。
