# 本机帧时间验收

目标硬件为 RTX 4060 Laptop，屏幕为 2560 × 1600、60 Hz。当前版本的 60 FPS 验收待测。开发时的试跑与其他前台 3D 程序争用显卡，不能作为独占前台的基线或成绩。

## 游戏设置

暂停游戏，打开「选项 → 视频设置」。可以给 3D 渲染比例设置 100%、85%、75% 或 62.5% 的上限。开启「目标 60 FPS」后，持续的 GPU 压力会触发降档，持续有余量才会升档。关闭后使用固定上限。分辨率变化会清空体积云和时间抗锯齿的历史。HUD 与物品栏保持独立的界面缩放。

## 采样

在本机分别启动旧版 `65fdfeb` 和待验版本的生产预览。使用新版仓库里的采样工具连接两个本地 URL，分别写入不同目录，例如：

```powershell
node tools/local-frame-budget.mjs http://127.0.0.1:5274 test-results/baseline
node tools/local-frame-budget.mjs http://127.0.0.1:5275 test-results/candidate
```

工具使用单独的 Edge 配置、光影档、种子 624、晴天和相同的起始时间，从游戏菜单导入世界。每段先预热至少 30 秒和 60 个渲染帧，再用 60 秒分别记录森林转头、河岸静止和创造飞行。正常模拟和自动存档全程运行。采样前后核对相机位移，Windows 同时核对前台窗口和屏幕中央的窗口归属。独占前台期间需让游戏保持可见，并关闭其他高负载 3D 工作。

三个 JSON 文件包含逐帧间隔、绘制调用数、GPU 抽样、实际内部尺寸和相机坐标。GPU 每八帧抽样一次，工具为专用浏览器启用 WebGL 计时扩展。正常浏览器未提供精确计时时，游戏可以通过异步 GPU fence 判断负载。设置环境变量 `HEX_FRAME_PROFILE=1` 可在各段正式采样结束后另录 CPU 调用栈与渲染阶段耗时。河岸与水下截图也在计时结束后保存。

每段分别验收平均至少 59 FPS、P95 帧间隔不超过 18 ms、P99 不超过 33.4 ms。GitHub Actions 执行生产构建和 Pages 发布，性能验收在本机进行。
