# Photon 3D 天空散射表

0.99 将旧天空生成器的 32 步单次散射与局部各向同性回散项替换为 Photon 的实际预计算表。完整 MC/Photon 目标继续推进，近冠层和整体光色尚未达到用户参考图。

## 固定来源与适配

只读对照 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [atmosphere.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/atmosphere.glsl)、[phase_functions.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/utility/phase_functions.glsl) 和 [散射表声明](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/shaders.properties#L407)。32×64×32 RGB16F 表的左半保存 Rayleigh 与多次散射，右半保存单次 Mie 分量；原始 393216 字节及 SHA256 保持不变。

WebGL2 纹理扩为 RGBA16F，每个 RGB 半浮点位原样复制，alpha 为 1，增加 524288 字节纹理数据。源表包含 1467 个微小负数分量，保留到插值和颜色转换后才限制输出，避免改变源数据。Vite 将二进制内嵌到模块中，生产包不增加动态资源请求或 CDN；CPU 数据共享，每个实际天空实例拥有自己的可释放 GPU 纹理。

GLSL 迁移 nu、mu、mu_s 的非线性映射、正仰角地平线拉伸、地面分支、日月 RGB Nvidia 有限角相位，以及源默认的大气退饱和。球壳映射改用 km 与差平方乘积，减少 float32 在地平线附近的相减损失。太阳角半径 2°、月相驱动的月亮相位与 2×3° 有效角半径沿用源规则。既有月光 tint 先从 709 转成 2020；光源、散射与退饱和在源 Rec.2020 中组合，再转换到宿主线性 sRGB，最后限制超出宿主色域的负值。

保留宿主原有 7 单位天空散射 HDR 标度、0.015+0.025×月相照度的夜间亮度和满球 SH。Photon 的日出/日落、蓝调时段曝光与用户 tint、半球 SH/夜间 boost 和默认不显示地面的地平线抬高尚未迁移。查表沿源的固定地面半径；宿主的直接日月透射及局部空气透射仍使用既有随高度/气溶胶变化的球壳积分，其系数、臭氧和上界与预计算表不同，不能称为全套统一的 Photon 大气输运。

天空小图、SH、天顶/地平线摘要、透射摘要与已发布方向继续原子发布。新增月相 index 与照度一起进入快照；云、叶片、雾和水反射沿用共享来源。降画质、维度关闭和 context loss 释放/重建表纹理，画质不改变这张固定表的分辨率。存档、曝光设置、视距与雾距保持。

原始表和改编函数的许可与来源在 [Photon notice](../public/licenses/PHOTON-NOTICE.md)，随应用保留 Photon 与 Bruneton 完整许可；项目原创代码的 MIT 不覆盖这些上游部分。

## 验证

二进制与字节视图偏移的两项 Node 检查通过；每个 RGB 半浮点位、alpha、有限性、原表签名与残差统计均核对。首轮真实 GPU 覆盖 96 组日高/降雨/月相、2592 条视线，包括极点、地面交界、太阳/月亮方向、曙暮光和满雨。

原始分量的固定绝对误差门槛最初不适合半浮点原生过滤，保留失败记录。过滤 oracle 改为每个位置的 1/256 纹素权重区间与半浮点误差，并纳入跨纹素中心时的内部格点极值；并未修改运行时或丢弃样本。最终 **15552 个原始 RGB 分量全部位于各自区间内**，最大越界量为 -3.234e-7；原始值与双精度理想插值的最大绝对差仍如实记录为 0.000489843。

最终坐标误差最大 **1.6533e-6**，低于 1e-5；7776 个最终 RGB 通道均有限且非负。辐亮度误差按 `abs(actual-expected)/max(0.01, expected)` 计，最大 **0.00225226**，保留 0.015 门槛；弱暮光的 0.01 分母下限使它不能被解释为所有像素的纯相对百分比。

- **207 项 Node 回归通过**。初次完整 Node 检查暴露云模块间接引入 Vite 二进制导入的问题，已把共享常量/输运 GLSL 拆到纯模块 `sky-transport.js`，四个消费者共用同一公式；未跳过云测试。初始失败和完整成功日志均保留。
- **21 项完整 GPU 回归通过**，覆盖实景日落/月夜、SH/Lambert、延迟读回与持续走时、画质/DPR/维度/context loss、云月光和叶片/草花透光。新表的释放、重建及 shared uniform 绑定单独检查。
- 完整回归之后将蓝调时段的 `pow(x,2)` 改为显式 `x*x`，避免负太阳高度在部分驱动上触发 GLSL 未定义行为；随后 **4 项大气检查与 1 项散射表专项再次通过**。这些是直接相关的重复验证，不增加独立用例数。
- **自然森林与生产 UI 存档导入/再导出通过**，合计 **23 项不同的功能浏览器检查**；另有 1080p 性能窗口。独立无头 Chrome / RTX 4060 / ANGLE D3D11，最终各批页面、着色器错误/警告和 GL 错误为零。未操作玩家的 5173 服务或前台鼠标，每批均按 PID/UTC 创建时间核对退出及 5191/5193 端口释放。

生产构建通过。主脚本约 1948.53 kB，gzip **687.36 kB**，较 0.98 约增加 **234 kB gzip**；较大的主块提示保留，未通过提高警告阈值掩盖。实际生产脚本内可解出恰好一份与源 SHA256 相同的 393216 字节表；三份许可/来源文件也核对打包后的字节签名。最终入口 `index-DJc7_fvA.js` 的 SHA256 为 `af6903dd2a034544f40c34fe48b435167ad9fc847ff9df89b41ecda213bf2318`。

实际已查看同种子 624、时刻 30、FOV 72、900×650、固定曝光 1 的 0.98/0.99 森林。云层偏暖感减弱、冠层暗部变化，近树叶仍偏暗；未调曝光或叶片材质参数，不以测试通过代替参考图艺术验收。
