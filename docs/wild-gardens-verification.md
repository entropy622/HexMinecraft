# 0.85 丛林、仙人掌与 HDR 泛光组合验收

## 整合前的五个判断

1. 结构性：真实丛林资源、植物年龄和碰撞与现有保存、机关和掉落共用入口，泛光替换原有通道。
2. 调用负担：保留现有操作与泛光滑杆；年龄由实际方块类型和模拟决定。
3. 可推导性：可可与仙人掌共用 age 字段，校验根据保存中的类型区分范围，不能由调用者选择另一套格式。
4. 最小性：合并同一状态与流体分类，复用实际形状；不添加新生态框架、兼容格式或依赖。
5. 泛化：天然/人工植物、全部朝向与阶段、各维度/卸载、完整 HDR 范围及渲染生命周期均有对应真实路径。

## 组合前列出的失败类别

- 可可的 0..2 与仙人掌的 0..15 年龄互相丢弃或误判，天然首次成长存档缺少类型，默认年龄制造侦测器假脉冲。
- 小可可荚被当作完整实体或无碰撞装饰；仙人掌邻接、花支撑、物品落地误读同一形状。
- 仙人掌花/可可被液体冲入后没有清理或重复掉落，原有草地/地毯/红石回归。
- 丛林树冠/天然可可因区块顺序不同而变化，旧一维气候测试掩盖真正的天气行为。
- 新泛光在合并后丢失 DC、颜色、低亮点稳定性、手持保护或水下/恢复能力；半浮点精度限制被隐藏。
- 修正阴影缓冲隐式采样时误伤材质 mip、半影和接触遮蔽，或只有无警告而无真实画面证据。
