# 0.85 丛林、仙人掌与 HDR 泛光组合验收

## 整合前的五个判断

1. 结构性：真实丛林资源、植物年龄和碰撞与现有保存、机关和掉落共用入口，泛光替换原有通道。
2. 调用负担：保留现有操作与泛光滑杆；年龄由实际方块类型和模拟决定。
3. 可推导性：可可与仙人掌共用 age 字段，校验根据保存中的类型区分范围，不能由调用者选择另一套格式。
4. 最小性：合并同一状态与流体分类，复用实际形状；不添加新生态框架、兼容格式或依赖。
5. 泛化：天然/人工植物、全部朝向与阶段、各维度/卸载、完整 HDR 范围及渲染生命周期均有对应真实路径。

## 组合前列出的失败类别

- 可可的 0..2 与仙人掌的 0..15 年龄互相丢弃或误判，天然首次成长存档缺少类型，默认年龄制造侦测器假脉冲。
- 小可可荚被当作完整实体或无碰撞装饰；仙人掌邻接、花支撑、物品落地误读同一形状。
- 仙人掌花/可可被液体冲入后没有清理或重复掉落，原有草地/地毯/红石回归。
- 丛林树冠/天然可可因区块顺序不同而变化，旧一维气候测试掩盖真正的天气行为。
- 新泛光在合并后丢失 DC、颜色、低亮点稳定性、手持保护或水下/恢复能力；半浮点精度限制被隐藏。
- 修正阴影缓冲隐式采样时误伤材质 mip、半影和接触遮蔽，或只有无警告而无真实画面证据。

## 实际整合与修正

三条独立分支整合后，可可与仙人掌共用可选 `age`，按真实类型分别校验 0..2 和 0..15。默认零与缺省年龄等价，同类型首次记录保留原生状态，真实阶段变化走已有侦测器通知；仍使用 v16。流体清理保留两种植物与花，掉落物落地复用实际 `groundAt`，全部 18 个可可朝向/阶段的落地与移除后下落均有实际模块检查。

组合复审发现并修正两处真实边界问题，均保留先红后绿的日志。

- 可可本格已进水/岩浆，而相邻支撑区块未知时，原先跳过了已知液体清理。现在湿格走同一阶段采收；干燥未知支撑仍冻结。全部三阶段、两种液体保留 1/1/3 豆与无重复掉落断言。
- 收掉天然成熟可可后，残留的生成状态可使同格新长仙人掌继承 age=2。真实换块与生成后不同类型编辑覆盖现在清除旧天然状态；临时碰撞试放和同类型记录保留原状态。额外真实组合回归在原格下放置 age=15 仙人掌并使其生长，修正前精确失败 `2 != 0`，修正后在直接生长、先卸载再生长、保存恢复三条路径均从零开始。原有朝向、活塞、洞穴与流送检查一起通过。

## 测量修正与画面检查

泛光生命周期原测试使用 EffectComposer 的小数元数据 `(1125,812.5)` 推算半分辨率，错误期望高度 407；实际场景物理尺寸为 `(1125,812)`，正确目标为 `(563,406)`。现在从真实场景目标取整型尺寸，单独保留原元数据；11 个目标的释放、重新分配、尺寸、质量切换与上下文恢复断言原样通过。未增加等待或修改产品分配逻辑。

采花场景在重新载入后恢复真实随机，花可能散落到磁吸范围外。原失败 trace 中花实体仍有一件，距玩家磁吸点约 2.385，阈值为 2.2。场景现在先观察真实一件花的掉落，再用 W 走近采回并确保松键；保留花库存恰好一件、合成后花耗尽与一份粉红染料。产品拾取范围没有改变。

父代理查看了天然丛林与冠层、成熟荚、仙人掌花与染料合成、实际泛光房间/水下对照、恢复后房间、软阴影和生产农园图像。可可有独立阶段体积，花可见且可用；泛光默认画面变化克制，主要改进弱亮点跨采样位置的稳定性。阴影缓冲修正的真实取证、直接光 HDR 对照与半影检查见 [采样验证](shadow-sampling-verification.md)。
