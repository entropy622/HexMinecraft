# 群系植被颜色与颜色表

0.109 修正地表植被始终使用同一烘焙叶色/草色的问题。群系颜色在材质反射率阶段应用，继续参与已有 Photon 叶片吸收、SSS 和高光，以及反射 GBuffer；没有添加调色滤镜、场景渲染目标或额外绘制 pass。

## 范围

- 草地顶面、装饰草丛、橡树和丛林树叶使用世界实际群系。半径 2 的 19 个六边形地表列在 sRGB 字节域平均，边界连续；原生白桦、云杉保留固定树种颜色，花瓣不重染。
- 草侧只改变独立覆盖层，泥土部分保留原色；草底面使用泥土贴图。颜色在镂空裁切和叶片深度预绘制的提前返回之后计算，避免给隐藏叶面增加颜色运算。
- 资源包读取 `assets/minecraft/textures/colormap/grass.png` 和 `foliage.png`，必须为 256×256。支持仅含颜色表的 ZIP，颜色表不会把方块图集提升到 64×；原包仍由既有 IndexedDB 路径保存。
- 导入、重载、恢复默认时刷新已建区块的颜色属性及材质图标。物品、手持与独立贴图使用默认平原颜色，尚未逐个绑定当前玩家所在群系。部分碎屑/独立模型、海拔与沼泽专用修饰、水色尚待扩展。
- 新增每顶点 4 字节归一化颜色属性及 CPU 范围缓存；区块重建时采样，普通帧复用。切换颜色表不复制同分辨率 UV。原有 v16、世界生成与群系分布、视距 10、晴天雾 87.32～118 不变。

素材 SHA256：草 `1bdd73f5b0aa67c5df9c5f424d8935a48b9b42b7415761a5c63e6be3c28b23aa`；叶 `3467a43d320d416f57ec6ae51d4fb72b13f9a123bcf8af01272aef283726be58`。新增素材及派生颜色保留 CC BY-SA 3.0，见[署名](../public/textures/NOTICE.md)。

## 验证与画面

`tests/biome-colors.test.js` 的 3 项检查覆盖两种色表坐标、六类群系的源 float 索引、负坐标边界和缓存刷新，以及颜色表 ZIP 的尺寸限制。`tests/biome-tint.spec.js` 的 2 项真实 GPU 检查覆盖原生方块/资源包颜色、固定树种、泥土覆盖层、草底面、导入恢复、反射 GBuffer，以及固定森林画面对照。生产构建另用 `biome-tint-production.spec.js` 经实际文件选择器导入颜色表 ZIP、刷新和重置，没有开发 API。

固定森林使用 seed 624、time 30、FOV 72、曝光 1；开/关对照只切换本批群系重染，保留本版草侧和草底修正，不能称作完整的 0.108 发行版对照。画面记录同步核对时刻、镜头、日光、SH 和雾；另有明确标记的 time 120 / 1920×1080 日间对照，两种时刻不能混作单因素比较。

已查看首轮原生方块与森林截图。森林较统一烘焙叶色更绿，晨光仍暖；树冠形态、云层结构、整体光色与用户参考图仍有明显差距。公式与功能通过不等于参考图美术验收。

新增 GBuffer 检查保留了三次失败。初次与显式重绘后的中心区域未返回叶类标记，扩大到同样的 23×23 可见区域仍只得到草花类标记 3（407 像素）或背景 0（122 像素），GL 无错误。核对 Three 的 `WebGLBindingStates` 后发现，几何缺少属性时的 `defaultAttributeValues` 写入通用 GL 顶点常量，而这些常量不属于 VAO 状态；缓存的叶片绘制可能继承草花类别。因此叶片/草花改在各自着色器中直接使用固定类别 5/2，避免新增顶点缓冲，并保留实际 GBuffer 检查。

首轮固定森林公开资源记录：颜色属性 18,632,424 B，CPU 范围 877,500 B，覆盖层纹理 1,024 B；没有新增场景渲染目标。这些是已知资源字节数，不是进程总显存，也没有据此承诺帧率。

本批证据保存在 `C:/Users/aentrozhou/.codex/artifacts/hexminecraft-photon-0.109/`。浏览器检查串行后台运行，沿用模拟 DOM Pointer Lock 的 fixture，避免限制桌面鼠标；独立端口 5191/5193，不操作用户正在游玩的 5173。

最终结果：212 项 Node 检查及生产构建通过；修正后的开发版批次 5 项通过（本批 2 项及 labPBR 生命周期、几何明暗、草花散射 3 项回归），生产界面 1 项通过。GBuffer 叶面返回正确类别 6，其颜色与主着色一致。最终晨景和日间截图均已查看；最终两批运行期间 758 个受审计文件的散列保持一致，结束后所属进程和独立监听端口均为零。本批没有重跑未改动的 3456 组高光公式输入，也没有将公式样本数计入功能场景数量。
