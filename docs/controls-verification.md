# 0.55 操作与建造验证

本轮基于 `1fb0a30`，日期为 2026-10-26。新增操作沿用既有输入、移动、碰撞、背包、采掘、鞘翅与保存系统，没有新增依赖或外部素材。

## 行为与证据

- 通过 E 进入 / 退出真实背包，右键打开工作台，Shift 右键在其旁放置泥土；对准实际方块中键取物，验证生存数量不变，创造可以取得缺少的苔藓块。
- 在玩家建造的上半砖通道中蹲伏前行，松键后头顶不足时保持蹲姿，保存重载后仍在低顶下，退出通道后恢复高度；走到平台边缘仍受防坠保护。半格下降允许通行，一格以上边缘由支撑查询保护。
- 创造飞行从地面双击空格开启，上升后松开保持高度，保存重载保持飞行；顶棚阻挡上升，双击空格关闭后落地。
- 基础 FOV 实际改变渲染相机并在重载后恢复，F1 隐藏和恢复 HUD；菜单不受 HUD 隐藏影响。
- 用游戏内经过时间衡量移动，步行约 4.79、Ctrl 冲刺 7.00、双击 W 冲刺 7.00 世界单位 / 秒。结果清单写入浏览器测试的 `interactions.json`。

`npm run check` 已通过，包含 24 项 Node 测试和生产构建。Node 场景包含三组种子共 37 处洞穴的重力稳定后通行。既有大包体积提示仍存在。

浏览器测试使用 `tests/browser-fixture.js` 在浏览器设备边界模拟 Pointer Lock，不向桌面申请原生鼠标锁定。核心回归命令为：

```powershell
$env:PLAYWRIGHT_CHANNEL='chrome'
npx playwright test tests/controls.spec.js tests/caves.spec.js tests/graphics.spec.js
```

本轮八项指定浏览器场景分批通过，覆盖低顶姿态、保存 / 重载、冲刺、上下文交互、视野、中键、飞行碰撞，以及三档画质和三维度的着色器 / JS 错误。触屏与旧采掘场景以 `tests/game.spec.js` 中对应场景补查。截图和规范化清单位于 `test-results/`；未执行所有历史浏览器场景，也不以这些结果宣称原生 Pointer Lock、所有生物战斗或全部 MC 操作已经验收。

## 测试修正依据

原 Node 套件的 7 项失败引用了旧世界中的 beacon / iron / coal、旧木板成本、把每格固定计一件的九材料配方、流动岩浆产石头、单块下界门配方以及 v1 / v3 存档。现改用生产中的 `World`、`PlayerInventory`、七格合成与各系统的 `serialize()`；覆盖填料、工作台条件、失败事务保持原样、九材料压块 / 拆解不丢料，以及当前液体和存档校验。移除把配方定义再次计数的结构断言与遗留门块配方断言，浏览器保留真实交互验证。没有为通过测试修改这些玩法。

旧浏览器采掘场景补入可拾取实体掉落物的操作，材料库使用当前游标 / 槽位交互；触屏测试使用本项目的已配置地址，避免连接同端口的其他 IPv6 服务。

双击窗口以输入事件的毫秒时间戳为准，避免慢帧把按键发生前的时间扣入新窗口；单测先重现该问题再验证修复。软件 WebGL 下独立 CDP 调用可能相隔超过 300 毫秒，因此成对输入由浏览器内的键盘事件一次交付，仍走生产中的按键监听器。搭建采掘 / 低顶夹具后同步重建区块网格，并等待射线命中新目标，避免数据与画面不一致产生假结果。

## 设计复核与限制

结构上由当前姿态统一决定身体、眼高和落脚查询；没有仅移动镜头来模拟蹲伏。用户只增加一个实际可用的视野设置。能否起身、物品是否已有、是否碰撞由系统查询决定。复用既有移动器和库存交换，双击时窗随输入状态清理。场景涵盖低通道、悬崖、菜单、创造与生存，未针对单张截图实现。

蹲伏必须随各维度保存，创造飞行必须随角色保存，因此 v14 新增两个被恢复流程读取的布尔状态；没有保留旧存档读取分支。攻击与箭矢仍使用既有的近似命中范围，本轮没有重新实现所有生物的姿态命中模型。代码审阅范围为本轮所有修改 diff 与新增文件，没有审阅全部历史玩法。

本轮净增按范围为产品代码 / UI 135 行、测试 510 行、文档 76 行、配置 0 行。测试增长用于真实输入、低顶 / 半格 / 悬崖、选块、飞行、恢复与旧夹具替换的闭环验证；没有新增运行时框架、依赖或第二套碰撞路径。
