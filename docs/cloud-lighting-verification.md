# 分层云内照明（0.115）

本页记录 0.115。0.116 已接入[天气云消光与共享云影](cloud-extinction-verification.md)，下文统一 0.9/local 的消光限制属于当时状态。

光影档不再让三层云共用同一个八阶闭式：主积云、高积云与卷云分别接入 Photon 的源散射关系，天空补光和云层日月光也随之调整。固定晨景中厚云底部的蓝灰阴影更清楚，受光边缘仍明亮；整体森林光色与用户参考图仍有差距。

## 来源与实现

Photon 基准为只读的 `6e67b36e818bacde0304edd49f28e2bb70e33f04`。依据其 [cumulus](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/cumulus.glsl)、[altocumulus](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/altocumulus.glsl)、[cirrus](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/cirrus.glsl) 和 [天气云参数](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/weather/clouds.glsl)。

| 层     | 散射阶数 | 每阶消光倍率 | 相位参数倍率 | 选用月光的太阳高度阈值 | 全雨反照率 |
| ------ | -------: | -----------: | -----------: | ---------------------: | ---------: |
| 主积云 |        8 |          0.4 |          0.8 |                 -0.040 |       0.66 |
| 高积云 |        8 |         0.45 |          0.7 |                 -0.045 |       0.75 |
| 卷云   |        4 |         0.25 |          0.5 |                 -0.049 |       1.00 |

恢复源散射系数参与高阶衰减的关系，分别使用各层的粉末响应。相位展宽读取未乘消光的密度长度积分，以米表示；此前用已经乘过消光的深度，无法保持源相位变化。主积云加入源上层遮光及反弹项，主/高积云加入反照率 0.4 的行星反弹，高积云保留高覆盖日间照明补偿，卷云保留天空项 1.41 倍关系。

云天空色来自已发布的独立晴空/天气入射色乘 `tau`，环境捕获则读取本次构建的同一输入，避免从含云 SH 反向照亮自身。日月光在实际云层入口高度及局部径向角计算大气透射，不再直接沿用地面光与地平线衰减。闪电继续读取已有亮度字段。均衡/流畅档的几何云保留既有半球补光。

三个日月切换阈值独立于地面零交叉。每视图云历史记录三位照明模式，任一层切换时拒绝旧颜色；环境图、主视图和水捕获继续共用云积分。

## 实景与检查

修改前在 0.114 提交 `4323c16` 保存基线；修改后重用同一测试、seed 624、晨景时间 30、FOV 72、曝光 1 和天然森林眼位 `[-120,22.5,4]`。最终 900×650 森林、1920×1080 森林及开阔天空图已查看。TAA 相位未锁成逐像素控制，不据此宣称像素完全对应。

- 最终一项 GPU 公式检查包含 30 个分层散射输入与 10 个云高度照明输入，和独立 CPU 源参考比较；最大散射绝对差约 `8.21e-8`，照明归一化误差约 `4.43e-5`。同时覆盖日落后的高云、月光、降雨与高覆盖高积云的照明补偿。这些是公式样本，不是游戏场景数。
- 实际帧钟穿过三层阈值再返回，主视图和另一捕获视图均记录到 `0 → 1 → 3 → 7 → 0`。每次切换第一帧的历史年龄为 1，旧历史未参与混合；没有替换渲染结果。
- 既有有限光源/光程组合、真实云环境图的 SH 与反射、建筑完整/部分遮挡移除、风与相机重投影及 WebGL 丢失/恢复回归通过。恢复云场误差约 `8.22e-5`，沿用原图像阈值。最终天空雾检查也重新执行，实际环境图克隆和远景空气保持正确。
- 生产包通过普通 UI 导入原生森林降雨与天然雪原降雪存档，检查实际标签、渲染、GL 状态，再导出核对 v16、时间、位置、天气与方块编辑；没有开发 API。暂停控件图只作流程证据。

220 项逻辑检查与生产构建通过。保留一次完整云恢复回归超时：追踪显示遮挡等前置阶段已用约 237 秒，恢复事件在约 238 秒收到，原 240 秒预算耗尽。只将该项完整检查预算设为 480 秒，所有图像、冷历史和恢复断言保留；重跑约 212 秒完成，其中恢复事件后约 2 秒得到恢复图像。

基线、首轮光学、历史补齐及最终代码分别留有冻结清单。最后两批对 788 文件审计无漂移，之后才补文档；未将不同代码阶段混称为同一份冻结源码。证据目录为 `C:/Users/aentrozhou/.codex/artifacts/hexminecraft-photon-0.115/`，包括 `baseline-0.114`、`native-final-2`、`final-lighting` 和 `production-ui`。浏览器串行后台运行并模拟 DOM Pointer Lock，不操作桌面鼠标、5173 服务或只读参考仓库。

## 仍需完善

光程仍来自宿主共享的密度、太阳/天空有限步数和地面长度估计。统一消光维持 **0.9/local**，按 20 m/local 输入闭式；源随云层、太阳高度、雨量变化的完整消光曲线尚未接入。源双分量覆盖参数以宿主现有标量近似，上层遮光、卷云增益和高覆盖补偿仍受此适配限制。薄高云仍按宿主六步积分；提前终止与有限太阳盘四点近似继续沿用。

没有新增生产纹理或渲染目标，归约仍为 22×1，主射线步数保持原上限。未测本批完整帧性能，不将恢复测试耗时当作 GPU 帧率。视距 **10**、晴天封边雾 **87.32～118**、曝光与 v16 保存格式保持。更完整的云形、天气消光、森林光色及整体 Photon/MC 目标继续推进。
