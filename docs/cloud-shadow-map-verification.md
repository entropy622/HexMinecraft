# Photon 预计算云影与共享图集

0.121 把光影档的逐地形片元三层云追踪替换为 Photon 参考的预计算云影。总体 MC/Photon 目标与用户森林参考图仍未完成。

## 实现

固定来源为只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 `include/lighting/cloud_shadows.glsl`、`include/utility/bicubic.glsl` 及 `PROGRAM_PREPARE` 密度分支。逻辑 512×512 双通道图记录总透射与主积云透射；光照空间径向压缩范围按宿主 20 米/单位换算为 128，使用源 B-spline 权重、0.8 强度以及地平线/主云层高度淡出。

主积云在四分之一层厚处取样，高积云在半层厚处取样；卷云在基准高度相交，以固定 0.5 层内比例取密度。高积云采用源预计算系数，不复用可见体积的另一组消光。准备阶段使用源常量 0.5 Worley 细节，保留可见云体的原始三维细节。球交点用因式分解保持 WebGL 精度；压缩圆外明确透射为 1。

两个逻辑像素打包进一个 RGBA16F 像素，放在原图集头部未使用的 `(768,0,256,512)` 区域，先解包再过滤。仍使用 1024×1538 图集，没有新增渲染目标、材质纹理采样器或二进制资源。新增一次准备绘制；不读取正在写入的图集。地形、水面和近场体积雾共用结果，低画质几何云保留原路径。

静止世界复用云影；相机位置、光线、风、种子或光学/天气输入改变时重新准备。相机旋转不改变投影。失败、降档和释放会撤销发布状态，并恢复渲染目标、立方体面、mip、视口、裁剪和自动清屏状态。沿用 v16，默认视距 10、晴天雾 87.32～118 保持。

## 实际验证

23 项相关 Node 检查和生产构建通过。浏览器验证包括分层视角/前景深度/两处远坐标/屋顶、光学快照延迟发布、真实水面捕获/尺寸/释放/绘制失败恢复、固定森林画面和正常推进时间。生产包通过原生 v16 导入的雨、雪、雨后湿润场景；真实设备丢失/恢复后保持暂停且不重新锁定鼠标，开发 API 不存在，导出时间、位置、天气和世界编辑保持。

固定森林保留此前六张图的全部输入，晨间、日间、1080p 和参考时刻截图已查看。相同构图下整体观感变化有限，冠层形状、林下明暗与远景流式边界的统一雾色仍需改善。

数值检查独立使用双精度投影/球交点、源准备系数和 CPU B-spline 过滤；云密度仍由生产 GPU 提供，因此它不是独立云形参考或额外场景。最大准备误差约 `4.823e-4`，过滤误差 `8.690e-6`，强度/高度淡出误差 `4.607e-6`；图中总透射约 0.00484～1，上层云确实参与遮光，无非有限值、越界值或 GL 错误。

移动检查分开记录密度向量与云影。可见云场均匀取样，避免旧探针只收集首行稀薄远云；保留密度信号及相对稳定性门槛。固定天气仅移动投影中心约 20.8 单位时，两处远坐标的近场参考平面最大透射差为 0.00684 / 0.01465。正常移动还会改变当地湿度/覆盖率，不能将其全部判为投影漂移；原始变化继续记录。上层遮光检查覆盖实际径向云影图，不要求一个无上层云的局部窗口必须出现阴影。屋顶、前景、历史与画面门槛保留。

保留初次失败记录：探针取错资源所属对象、克隆渲染纹理引发警告、旧密度统计混入不同精度的阴影通道、当地天气变化干扰移动判断，以及首行取样的信号不足。修正检查范围和取样后重跑；未重跑无变化的 3456 输入高光公式矩阵。

## 成本与限制

RTX 4060 / Chrome ANGLE D3D11，900×650、seed624、time60、原森林镜头与曝光，每个窗口实测 60 绘制帧。暂停时云影重建为零；正常推进时云影纹理和风场持续更新。计时窗口内没有截图/读回，disjoint/busy 为零。

| 状态     | 整帧 GPU 中位 / p95 | CPU 提交中位 |
| -------- | ------------------- | ------------ |
| 暂停     | 30.215 / 35.724 ms  | 35.6 ms      |
| 正常推进 | 32.582 / 49.019 ms  | 50.9 ms      |

这是同版的两种运行状态，包含正常推进的其他游戏工作，不是旧版受控 A/B 或单独云影 pass 成本。最终 time30 固定晨景另录得 GPU 36.845 / 44.680 ms；不同窗口仍有明显波动，不据此声称固定性能提升。

极远处径向压缩的云影仍有较低空间精度；源近似不等于完整云光线积分。尚无 congestus、夜光云或长天空云隙光的完整积分。全局天气随当地生物群系变化、启动/切档开销、森林光色与远景地形继续开发。
