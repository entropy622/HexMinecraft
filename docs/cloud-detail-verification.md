# Photon 双噪声云体细节

来源包括固定提交的 [cumulus](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/cumulus.glsl)、[altocumulus](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/sky/clouds/altocumulus.glsl) 与 [天气参数](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/weather/clouds.glsl)。

0.118 为主积云和高积云接入 Photon 的两张原始三维噪声及对应侵蚀/风动。当前仍使用宿主覆盖率和高度包络，整体参考图目标尚未完成。

## 来源与实现

固定只读 Photon 6e67b36e818bacde0304edd49f28e2bb70e33f04 的 shaders/image/worley_bubbly.dat、worley_swirley.dat，每张为 64³ R8、262144 字节。原文件逐字节复制到 src/assets/photon-worley-*.dat，许可与出处记录在 public/licenses/PHOTON-NOTICE.md。

旧实现每个种子生成一张单元 Worley 场，在不同频率重复读取。现在分别读取源云团和旋涡场，移除逐种子的三维噪声生成；世界覆盖仍使用原有种子二维场，沿用 v16。两张源体积在一个 64×64×132 R8 容积中按 Z 堆叠，每层前后增加周期保护切片；共享采样函数在层内循环，避免线性过滤串入另一种噪声。仍只有 cloudNoise、cloudWorley 两个相关片元采样器，没有新增常驻绘制 pass 或渲染目标。名义三维纹理数据从 262144 B 增至 540672 B；这是数据预算，不是进程总显存。

主层按 20 m/local 使用源 0.0009/m、0.005/m 频率，高积云使用 0.003/m；主层细节分别额外沿风偏移 0.2/0.4，高积云为 0.2。地球半径的周期 y 偏移提前折叠，避免放大大坐标的 float 误差。主层使用源依次侵蚀、风撕裂权重和高度锐化；风与天气中每帧相同的量提前计算，共享给视图、环境和地面阴影。

## 画面与数值

先以发布版 0.117 拍摄基线，再替换细节。固定 seed624，眼位 axial[-120,22.5,4]，森林看向[-98,17,-4]、天空看向[-98,52,-4]；time30/time120，FOV72，曝光1，晴天雾87.32～118。四个 900×650 镜头和一个 1920×1080 晨景逐项核对时间、位置、旋转、太阳方向、曝光与雾距，输入一致。没有靠改变相机或曝光制造对比。

已查看晨景、日间和 1080p 画面。云块与细边形态改变，但整体变化克制；晨景仍偏暖偏粉，高层碎云偏多，部分云底过于整齐。宏观覆盖与厚度仍有宿主近似，不能据此宣布 Photon 美术对等。

源资产 SHA256、每个源体素及保护切片逐项检查保持；真实生产纹理的 GPU 读回覆盖纹素中心、层内混合、边界和正负循环坐标，与独立读取源文件的 CPU 三线性参考最大差约 1.669e-4，保留 0.001 的硬件插值误差门槛。没有新增片元采样器。

## 本机成本与保留记录

每轮固定晨景预热后测60个实际绘制帧，计时期间无截图和读回。900×650，原生Chrome/ANGLE D3D11；各窗口 disjoint、busy 为零。

| 版本        | GPU 中位/p95      | CPU提交中位 |
| ----------- | ----------------- | ----------- |
| 原单噪声    | 24.439 /29.203 ms | 29.750 ms   |
| 双噪声RG8   | 30.796 /36.816 ms | 36.850 ms   |
| 共享参数RG8 | 30.953 /36.332 ms | 35.750 ms   |
| 最终R8堆叠  | 27.410 /31.425 ms | 32.800 ms   |

共享参数未量出稳定 GPU 改善；R8布局这次记录比RG8约少3.5ms，仍比旧实现约多3ms。窗口并非受控A/B/A，缓存、系统负载及云形导致的积分工作量也可能影响结果，不作为普遍提速或固定FPS承诺。

保留 final-noise 的GLSL失败：高积云局部变量与已有float detail重名，真实驱动编译及场景GL诊断捕获；改名后 final-noise-2 通过。没有放宽画面、数值或设备恢复的既有门槛。未重跑未改动的3456输入高光公式矩阵。
