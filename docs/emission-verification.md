# 按纹理分区自发光

0.133 将已有方块与局部模型接入 Photon 参考的自发光响应。体素光、随身光、曝光、泛光强度、默认视距和雾距保持；存档继续使用 v16。本次是材质层的改善，没有完成整体森林参考图或 Photon 全部材质迁移。

## 来源与适配

固定参考为 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04`。实际核对了 [block.properties](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/block.properties)、[material.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/surface/material.glsl)、[颜色转换](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/utility/color.glsl)和[周期色调选择](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/global.glsl)。源派生函数保留原许可，见 `public/licenses/PHOTON-NOTICE.md` 与 `photon.txt`。

| 源类 | 本项目实际使用         | 响应                                               |
| ---- | ---------------------- | -------------------------------------------------- |
| 33   | 末地烛烛身             | 按贴图亮度筛选白色发光                             |
| 35   | 萤石、萤灯、通电红石灯 | 饱和度与亮度共同决定暖色发光                       |
| 36   | 火把头、烧炼中的炉口   | 高亮像素发光，保留支架和炉具外壳                   |
| 37   | 洞穴藤蔓上的浆果       | 按饱和度、亮度和蓝色色调窗口选取，茎叶不分配发光类 |
| 55   | 四阶段紫晶芽与晶簇     | 源低强度晶体自发光，随纹理亮度变化                 |

源阈值在贴图 sRGB 中判断，辐射值在线性 Rec.709 中计算，沿用宿主的工作空间；没有声称与源 Rec.2020 管线逐像素相同。着色器保留原 labPBR 发光标量，同时加入 RGB 辐射值，以逐通道最大值合并硬编码发光与资源包发光。贴图 alpha=1 的“不额外发光”语义保留，源硬编码响应不被资源包清零覆盖。

火把与通电灯具并入原生几何材质，移除原来的两种统一抬亮材质。支架、浆果、烛身和底座按真实模型部件分配材质类；炉口只在燃烧且朝向对应面的情况下使用发光类，其他面保持普通材质。运行时没有新增光体、纹理目标或后处理通道；片元仍增加了材质判断工作，未据此宣称帧率提升。

## UV 与交互修正

原末地烛的细长侧面使用了整张贴图的左部区域，误采到基座和空白。现在烛身使用既有 PNG 中实际的 2×15 像素条带，世界、手持模型和 SVG 图标共享归一化 UV 矩形，资源包各通道也沿用该 UV；原始素材未修改。

实机恢复与拉杆操作暴露了合批形状命中后重建空几何的崩溃。半砖、楼梯现在记录三角形所属方块区间，藤蔓复用已有区间，以实际命中三角形解析归属，不再通过偏移交点重新猜测邻格。已消失或无效的形状不作为目标，空几何也保留安全的位置属性。新元数据只存在于渲染几何，不写入存档。

## 验证与画面

10 项相关 Node 检查通过，包含真实局部网格的发光类与 UV、合并几何的 Raycaster 归属、空几何、紫水晶玩法和资源包解码。构建及改动文件格式检查通过，没有重复运行未改动的 3456 输入高光公式矩阵。

新增 **一项原生渲染流程**。人工密闭灯光房间中放入八种实际模型，用同一材质和纹理分别读回原始 beauty、发光辐射、未照明贴图颜色和材质类。独立双精度参考根据实际贴图颜色计算源公式；初次与设备恢复后的最大辐射误差为 `4.1221e-6`，无非法值和 GL 错误，beauty 保留了自发光能量。样本像素数没有计为更多功能场景。

同一流程通过实际拉杆关闭红石灯，并按正常时间步推进炉具到燃烧结束，再检查两者均无自发光；实际导出文件通过严格 v16 校验。恢复后保持暂停，继续操作由测试主动恢复游戏。另有 **一项既有 labPBR 流程**，通过 ZIP 控件导入、原生材质通道、保存、设备恢复和可选资源释放验证。

发布包另有 **一项实际界面流程**。没有开发 API，通过正常控件导入、暂停、真实设备丢失/恢复和导出；观察到含新发光函数的实际链接程序参与绘制，恢复后继续绘制。时间、库存、方块、状态和炉具数据保持，导出通过严格 v16 校验，鼠标未重新锁定，页面无错误或警告。

修改前后使用相同导入场景、镜头、时间430、光影档、固定曝光和关闭体积云的设置，已查看最终两张实机截图。启动时有少量正常模拟与时域收敛，不将整图当作逐像素冻结差分。证据目录中的 `comparison.html` 可拖动查看原始截图；该人工场景用于比较发光与外壳层次，不代表自然洞穴或森林参考验收。
