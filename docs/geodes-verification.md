# 紫水晶洞、望远镜与遮光玻璃

0.132 加入自然紫水晶洞及“采集晶簇 → 获得碎片 → 制作望远镜与遮光玻璃”的生存流程。存档继续使用 v16，完整玩法视距 10、近景交接 87.32～118、远景边界 176.12～238 保持。

## 世界与生长

主世界地下生成平滑玄武岩、方解石、紫水晶内壁和不规则空腔，部分晶洞有裂口；避开出生区、现有洞穴、村庄和遗迹。判定取决于种子与坐标，跨区块顺序保持一致，玩家修改最后覆盖。新生成器适配六棱坐标与 64 格世界高度，未直接复制 Java 的几何或高度分布。

紫水晶母岩随机向八个实际方块面长出小、中、大晶芽和成熟晶簇，四阶段具有不同的尺寸、切面模型与微光。生长保留原朝向，水源中的晶芽保留水；支撑依据真实完整方块面和半砖等实际几何判断，卸载区域不凭空移除附着物。普通骨粉不能直接催熟。

成熟晶簇用镐采掘获得 4 枚碎片，并响应时运；徒手或失去支撑掉落 2 枚。精准采集保留晶芽和晶簇，未成熟晶芽普通破坏无掉落。母岩即使精准采集也不掉落，活塞会将其破坏，无法搬走建立母岩农场。

## 可使用物品

工作台中，两枚铜锭与一枚碎片制作一支望远镜，每槽只存一支。主手或副手按住右键、或触屏「用」开始观察，FOV 变为玩家设置的 0.1 倍，鼠标与触屏转向减速；松开、切槽、打开菜单、失焦或设备丢失均取消缩放。观察时隐藏双手与盾牌，减慢移动，不改写保存的基础 FOV。

四枚碎片与一块普通玻璃制作两块遮光玻璃；四枚碎片也可合成紫水晶块。遮光玻璃的显示保持透明，天光和体素彩光按实心方块遮挡，近景方向阴影使用独立的不透明深度材质；徒手也能收回。普通及十六色玻璃的滤色调色板仍为 17 项。

## 渲染修正

实机截图发现晶簇近乎全黑。控制试验在同一原生场景中给局部形状网格补充显式顶点输入，恢复了正常颜色与光照。最终为使用几何光照的局部网格显式提供环境遮挡、无群系染色标记和材质孔隙率，避免依赖可能被其他绘制程序改写的常量顶点属性；已有藤蔓染色继续保留。半砖等同一路径也获得修正，没有提高曝光或全局环境光。

紫水晶块与母岩映射至固定 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的宝石材质类 13，使用现有高光函数。晶芽微光沿用宿主体素光；本批没有完成 Photon 的全部硬编码发光、地下全局照明或森林参考图验收。晶簇、望远镜、碎片图形与新增程序纹理为本项目独立实现，没有打包 Mojang 材质或模型。

## 来源

玩法依据 [Minecraft Java 1.17 发布说明](https://feedback.minecraft.net/hc/en-us/articles/4402626897165-Minecraft-Caves-Cliffs-Part-1-1-17-Java)及官方 Java 1.21.5 服务端数据和映射核对。后者实际检查了晶洞配置、配方、掉落表、晶芽尺寸、1/5 生长机会和活塞 DESTROY 反应；未将官方代码或资源打包进项目。Photon 的宝石映射参考固定版本 [block.properties](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/block.properties)和 [material.glsl](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/surface/material.glsl)，已有源派生函数继续遵守原许可。

六项紫水晶逻辑检查覆盖生成顺序、自然支撑、八向四阶段生长、含水保存、采掘与活塞、配方及最大堆叠；连同四项既有远景建筑检查，共 10 项相关检查通过。实现初稿还执行过完整 Node 269/269，后续修正使用上述相关检查及真实流程验证，没有重复运行无变化的 3456 输入高光公式矩阵。

最终按功能分别通过两项原生 GPU 渲染对照、一项完整玩法流程和一项发布包 UI 流程。晶簇原始 beauty 与材质探针的照明读回一致，已查看修正后的实景；密闭石顶与遮光玻璃顶房间天光均为 0，普通玻璃顶为 15，遮光玻璃后方的实际标记物仍可见。这些值是三个实体房间的对照，不作为更多场景数量。
