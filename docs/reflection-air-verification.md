# 反射空气光程

0.135 为不透明表面的场景反射补充反射点到命中物体之间的 RGB 吸收与散射。覆盖现有湿面镜面与粗糙 GGX 追踪，复用当前大气系数、独立 Rayleigh/Mie 高度积分、四阶相函数和天空光门控。存档继续为 v16，默认视距与雾距保持；整体 MC、Photon 与森林参考图目标仍未完成。

## 来源和合成顺序

参考只读 Photon `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [trace_specular_ray](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/specular_lighting.glsl) 与 [air_fog_analytic](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/fog/overworld/analytic.glsl)。沿用源命中物体对朝光反射雾的遮蔽近似 `1 - max(dot(ray, light), 0)^2`，并通过共享宿主空气模型完成传输。工作空间为线性 Rec.709；源派生范围见 Photon notice。

本项目的反射输入来自当前帧，位于空气体积合成之前，因此不复制源上一帧散射图的扣除步骤。命中反射先合成 `color × transmission + scattering`，再乘既有 Fresnel 与材质权重；相机到地面的空气仍由后续体积 pass 合成一次。未命中时继续使用共享天空回退，不额外对天空图叠加该有限线段。

零密度、非空气体积路径或未启用主世界天空雾时返回原值。已无贡献的追踪命中会提前返回，避免继续采样和积分。没有新生产 pass、渲染目标、顶点属性、光体或玩家设置；只在已有反射命中路径增加运算并引用现有大气 uniform。

## 实际命中验证

人工低处样片包含金属与石质湿地和红蓝羊毛墙。检查使用原生几何、纹理、深度、追踪和当前帧输入，仅在原 pass 绘制边界暴露命中端点及颜色。独立 CPU 中点积分核对实际光程，包含颜色传输、零天空光、无介质原值和真实设备恢复；样本像素没有计为更多场景。

首次与恢复后的颜色最大误差约 `9.16e-8`，无介质分支精确等于原色；实际采样光程约 4.43～24.02。显卡恢复后继续完成相同路径，页面与 GL 诊断为零。

组件对照仅在反射 pass 中暂时解绑密度 uniform，不修改相机主雾或全局天气。相同镜头、时间、固定曝光和材质下分别截取关闭/开启结果，原始 PNG 未编辑。两图不是不同版本或整个雾系统的开关对照。

既有金属/宝石反射与雨滴流程通过，包含晴天/暂停、模拟时间推进、画质切换、尺寸变化与水下停用。发布包另有一项实际界面流程：没有开发 API，经导入、暂停、真实设备恢复后继续绘制，导出通过严格 v16 校验，时间、库存、地形、状态、炉具和天气数据保持。

## 自然森林与开销

固定种子 624、时间 30、1920×1080、光影档、自然森林镜头，无地形编辑。显示 441 个近景区块、至少 529 个含边界缓存的加载区块与 169 片远景。A/B/A 只切换真实材质湿度 uniform，天气、天空、材质、镜头和场景保持；另设无 GPU 查询的 CPU/RAF 窗口。截图与读回均在计时窗口之外。

基线为 `3315277` 的产品代码。可见湿面约 3.6 万像素，说明镜头实际覆盖受雨地表。旧版湿/干/恢复湿的 GPU 绘制批次合计中位数约 37.71 / 44.89 / 41.89 ms，窗口波动明显，不能从正负差值推导通用性能收益。

候选湿/干/恢复湿的 GPU 绘制批次合计中位数约 31.01 / 29.97 / 30.95 ms。反射阶段基线为 0.128 / 0.102 / 0.129 ms，候选为 0.127 / 0.101 / 0.128 ms；这个镜头未测出超出窗口波动的阶段增量，整帧下降也不能归因于本次改动。这里只统计实际 WebGL 绘制批次及回调 CPU 提交，不是进程总 GPU 时间、总显存或所有设备的 FPS。森林没有密集金属镜面，不能代替反射重负载基准或完整艺术验收。历史时间 30 处于低太阳高度，并不代表用户参考图的晴朗白天，本批不据此做整体亮度或绿相校准。
