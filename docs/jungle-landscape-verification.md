# 自然丛林的高低冠层

0.125 把自然巨树、灌木、分枝橡树与倒木接入丛林生成，沿用可采集的真实原木、叶片和藤蔓。整体 MC 玩法及 Photon 参考效果仍未完成；本批不新增 Photon 光学模型。

## 来源与适配

对照本地 Java 1.21.5 服务端数据的 `trees_jungle`、`jungle_tree`、`mega_jungle_tree`、`jungle_bush` 和 `fallen_jungle_tree`，以及 FallenTreeFeature 字节码中的摆放流程。[官方版本元数据](https://piston-meta.mojang.com/v1/packages/cd7d9c7e497cc3b036ec6aa6e6baba94a4a790df/1.21.5.json) 的服务端 SHA1 为 `e6ec2f64e6080b9b5d9b471b291c33cc7f509733`。原始文件只保存在外部证据目录，仓库实现独立编写。

选择器按顺序执行条件概率 0.1 的分枝橡树、0.5 的灌木、0.33333334 的巨树、0.0125 的倒木，否则为普通丛林树。这些不是最终森林百分比；随机数、候选密度、地形和六边形坐标沿用宿主，因此不声称与原版种子逐块相同。

巨树复用 0.122 的四柱枝冠，三种朝向由种子确定。四根需要兼容的丛林地面，高差不超过一格；整棵树的最低占用列还检查山体、村庄与遗迹空间，失败时不退化成小树。普通丛林树保留可可与藤蔓，巨树仅加藤蔓，灌木使用一格丛林原木和三层橡树叶，分枝橡树使用橡木。普通树高度和宿主地形没有全面改写为原版实现。

倒木由树桩、两至三格间距及二至九格横向原木组成。横木沿固定高度放置，超过两格连续悬空或遇到阻挡时只保留树桩；原木轴向是真实方块状态。树桩可生藤蔓，横木上的红、棕蘑菇装饰尚未实现。

扩大生成范围时只在外圈检查稀疏巨树与倒木候选。相邻区块使用完整的种子树形，仙人掌也检查完整树冠，避免在灌木旁生成后立即脱落。玩家编辑继续最后应用；v16 不变，未编辑的天然植被会按新规则再生。

## 藤蔓几何

贴墙藤蔓从 36 顶点薄盒改为 6 顶点双面矩形，顶面悬挂使用 12 顶点六边形薄片。六向墙面和顶面均检查真实射线命中与所属方块，保留原有非碰撞、群系染色、风动、透光和阴影路径。藤蔓不再分配石匠锯片动画的两组 UV 属性，每区块仍最多合并为一个藤蔓批次。

同一开发运行中的自然藤蔓记录为 9217 格、54 批、61794 顶点，深度材质与群系属性有效，GL 和页面诊断为零。这是当前场景记录；森林生成已变化，不能据此推断相较 0.124 的整帧性能提升。
