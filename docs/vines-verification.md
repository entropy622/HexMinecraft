# 丛林藤蔓：附着、生长与攀爬

0.124 加入普通藤蔓，区别于已有的发光浆果洞穴藤蔓。整体 MC/Photon 目标尚未完成；本批增加丛林的外观与可操作玩法，复用现有光学材质，没有新增 Photon 后处理算法。

## 玩法与规则

- 天然普通丛林树、树苗长出的普通丛林树，以及四株种植的丛林巨树生成真实藤蔓方块。树干附近贴附，冠层边缘可垂挂；云杉和橡树不因此增加藤蔓。天然巨型丛林树的分布尚未加入。
- 同一格保存六个水平附着面和一个顶面。新增一个面消耗一份藤蔓，重复放置已有面不消耗；手持藤蔓对已有藤蔓右键可向下续接。藤蔓没有实体碰撞，玩家沿用 W / 空格攀爬、Shift 停留和松手缓慢下滑。
- 剪刀采集整格只掉落一个藤蔓；空手、精准采集及活塞破坏不产出藤蔓。普通藤蔓不接受骨粉，已有洞穴藤蔓的骨粉结浆果行为保留。
- 附着面失去支撑时逐面删除，最后一面失效才移除该格；下段可继承上段的水平附着面，独立有墙支撑的下段会保留。水、岩浆和断根清理不复制物品；卸载的侧面支撑视为未知，重新加载后再判断。
- 自然蔓延只推进已加载区域。按默认随机刻的平均频率与 1/4 生长机会换算经过时间，选择横向、向上或向下延伸；横向和向上受半径 4、上下各一层的五格密度限制，向下继承不受此密度限制。原版四面加上下的六方向，适配为六边形六面加上下的八方向。

## 生成、材质与存档

普通树原有木材与叶片布局保持。藤蔓候选由完整树形推导，天然生成范围比原树冠多一格，并裁切到所属区块；合并独立锚点后从上到下连接垂挂链，避免越过另一棵树的树冠或地形障碍继续生成下段。正负坐标的区块加载顺序检查覆盖方块、自然状态和藤蔓索引。种植装饰避开已有方块、液体、作物与角色。

新增叶纹为独立绘制的 16px 镂空图案，按群系叶色染色，使用现有草花的透光、风动、深度材质与阴影路径。藤蔓按区块合并，保留每格光照、颜色范围和真实射线命中。最终天然丛林取景记录 56 个藤蔓批次、360216 个顶点，每个区块最多一个批次；这不是总显存或帧率承诺。密集丛林仍有几何成本，当前极薄盒片与部分通用建筑属性还有精简空间。

存档沿用 v16，以 `faces` 的 1～127 位掩码记录附着面；拒绝空掩码、越界、非整数以及其他方块携带该字段。自然藤蔓发生变化后成为普通编辑记录，防止卸载或读档时重新生成已挖除的部分。没有额外的离线生长时钟。
