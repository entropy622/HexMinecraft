# 丛林树叶底色与群系染色

0.123 修正丛林树叶亮纹偏白的一个实际原因。完整 MC/Photon 目标尚未完成；本批是材质底色修正，没有新增 Photon 光学算法，也不作为森林参考图的美术验收。

## 原因与更改

原生丛林叶纹直接绘制绿色像素，而群系染色会先除去材质声明的基色，再乘实际群系色。旧亮纹最高为 `[128,173,70]`，声明基色为 `[77,144,53]`，恢复出的纹理分量达到约 `[1.66,1.20,1.32]`，浅色纹路因此被放大。橡树和导入的灰度树叶采用另一条正常的预染色流程，不能直接把本问题归因于太阳能量或 SSS 强度。

`jungle-art.js` 保留叶纹的空间分布，以旧绿色通道的最大值 173 归一化出灰度层，再按声明的丛林叶色烘焙。群系材质与物品图标恢复底色时，将纹理分量限制在 0～1 后染色；实际天空光、直射光、透光、高光和反射仍读取修正后的材质颜色。像素图案独立绘制，没有新增图片资源。

## 实际画面对照

输入沿用 0.122 从四株真实树苗种植并导出的巨树 v16 存档。对照观察其中第一棵丛林巨树：seed624、time120、900×650、FOV72、光影档、曝光1。它长在玩家建造的种植台上，不是天然巨树林。

修改前后的相机位置与旋转、日光、天空 SH、画质、光学体积范围和雾距记录完全一致；晴天雾距保持 87.32～118。画面分别等待时域采样稳定，属于同场景前后对照，不是同一份冻结 HDR 的逐像素差分。

| -------------------- | ------- | ------- |
| 线性材质颜色亮度中位 | 0.27348 | 0.18082 |

这张实际画面中的浅白纹路减少，叶片呈现更深的绿色。数值下降本身不是美术质量分数；树冠结构、纹理重复、整体森林光色和远景仍与用户参考图有差距。
