# 水下界面光学验证（0.67）

## 实施前的设计判断

1. 结构：根据实际界面的朝向计算入射与出射介质，修复水下背面没有真实光学响应这一类问题。
2. 负担：玩家不填写折射率、临界角或水位；所有信息由水几何、视线、现有水场和物理常量推导。
3. 可推导：临界角由两侧折射率决定，不按屏幕区域或固定海平面绘制伪造的亮圈。
4. 复杂度：复用当前帧颜色 / 深度捕获、体素水位和已有后处理，不增设镜面相机、玩家选项、贴图或存档字段。
5. 泛化：水平水面与水下侧面、不同水位、流水及相机进出水均使用界面法向和同一个折射率来源。

最小完整变化是入水后仍捕获真实场景，计算精确介电菲涅耳与全反射，并在水下界面合成真实屏幕空间反射和折射出射视图。仅把背面变亮或调透明度不能形成正确的临界角与场景倒影。沿用当前帧屏幕信息的范围，离屏反射仍缺少隐藏几何；不能把天空当作水下反射的离屏替代。

参考 [Photon 的介电菲涅耳与全反射判定](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/bsdf.glsl)及[场景镜面反射](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/specular_lighting.glsl)，独立接入六棱世界的渲染路径。

## 实施前列出的失败类别

- 水下仍关闭捕获，水面背面只混合透明底色；不存在真实水下场景反射。
- 沿用空气到水的折射率，超过临界角仍看到水上物体或天空；临界附近出现 NaN、黑边或无界亮斑。
- 背面法线与波纹没有翻转；反射朝向水外或打中错误一侧，垂直界面被当作水平面。
- 反射只追踪屏幕但误用前景深度；物体或第一人称模型反射自己，或者采样正在写入的纹理。
- 反射路径没有额外水吸收，或者相机到界面的水雾重复计算；深处倒影像空气中一样鲜艳。
- 水下折射仍沿直线采样，天空视窗不随折射变化；全反射区域继续泄漏水上颜色。
- 多个水位、流动水、负坐标区块和侧边界出现错误水位假设；临近水面进出时深度 / 时域历史失效。
- 没有可见水却继续重复捕获；其他液体、低画质、缩放、维度切换或销毁后使用失效纹理。
- 新光学让既有水面反射、池底吸收、焦散、水下体积光或手持模型保护退化。
- 低画质没有场景捕获时，侧界面忽略全反射，仍混入水上物体；先用真实截图换色验证，基线泄漏响应为 0.156，正面透射响应为 0.169。
- 水下反射未命中时使用固定亮度的青色环境，夜间不变暗；先用实际昼夜时钟验证，基线夜昼亮度比为 1.0。

## 范围与实现限制

- 高画质复用已有颜色 / 深度目标，水下可见水体时增加一次不含水及第一人称模型的场景捕获。捕获视野扩大，分辨率保持不变，局部采样密度会下降；隐藏几何、相机身后及捕获范围外的信息仍可能缺失，边缘混合只能缓解跳变。
- 水下未命中反射使用随环境变化的水散射近似；空气方向的未命中透射可使用解析天空。低画质遵守全反射遮断，但没有真实场景倒影或高画质的折射追踪。空气侧垂直面的完整场景折射尚未扩展。
- 反射额外水长使用现有体素光体积中的水位，16 个区间估算，受体积范围、薄层及远处细节精度限制。该段的散射是环境近似；相机至界面仍使用原有较完整的体积积分，没有沿反射段另做完整太阳散射积分。
- 仍是单次界面近似，没有完整多层水体交互、多次散射、几何波面位移或辐射亮度折射率平方修正。尚未达到完整 Photon 对等实现。
- 流水、不同水位、深水、维度和存档生命周期由上述既有回归共同覆盖；没有逐一遍历任意复杂池形和全部临界角。截图与性能时间来自无头 Chrome 软件渲染，未测量用户显卡帧率。

## 交付后的设计检查

介质方向由未经双面绘制翻转的实际几何法线与相机位置推导；共用折射率处理焦散、透射与全反射。水面和水雾共用环境散射源，维度环境系数直接引用已有 Atmosphere uniform，没有第二份维度规则。反射段水长复用现有水位编码与光体积，没有新介质缓存。

捕获投影矩阵独立保存，完成或失败均恢复主镜头与 autoClear；水线判断使用最终渲染眼高，物理运动和碰撞保留原坐标。沿用 v16，没有新增玩家配置、依赖、贴图或渲染目标，也没有测试专用产品路径。
