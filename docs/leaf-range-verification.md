# 远距叶片透射与阴影覆盖过渡

0.94 改善阴影图范围外的冠层透光。此前叶片离开单张正交阴影图后，额外的日月透射直接归零；现在使用既有光学体素查询真实厚度和遮挡，再与近处阴影深度路径过渡。仅光影档启用，沿用 v16、现有天气和画质控件。

## 上游参考与本项目实现

对照本地 Photon 固定提交 `6e67b36e818bacde0304edd49f28e2bb70e33f04` 的 [shadow distance fade](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/shadows/common.glsl) 和 [diffuse lighting](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/diffuse_lighting.glsl)。Photon 用投影 XY 与相机距离的 32 次方过渡，远处 SSS 厚度趋于零，再乘 AO、环境 SSS 与面朝向补偿，另有天光生成的远距阴影。

本项目采用相同的 32 次方边缘整形，按宿主正交阴影图的 XYZ 裁剪范围计算权重；近处保留原来的 48 格阴影深度光程，远处沿太阳方向最多穿越 128 格六边体素。叶片累计穿越长度并做原有 Beer 吸收；石头、半砖等部分形状和液体保守阻挡，玻璃由既有共享 RGB 路径过滤一次。没有扩大普通地面或动态生物的阴影图覆盖。

`VoxelLight.opticalTop` 记录当前光体中已加载方块及液体的最高平面，避免对上方已知空域逐格追踪。它随放置、移除、流体和区块卸载重建。到达世界高度上界且位于光体横向范围内的叶面可通向天空；在追踪终点之前遇到未加载区域则返回零。该终点来自已加载数据，不能据此判断未加载远处是否还有更高屋顶。

这仍是部分迁移：远处保留真实 Beer 厚度，没有照搬 Photon 的厚度归零与 AO/环境 SSS 补偿；主透射相位仍为此前的 g=0.6 响应，尚无完整 Photon g=0.7 主 SSS、通用叶片 PBR 或远距实体/alpha 轮廓。体素形状比原生网格粗，接近水平的光线、128 格工作上限、累计叶层厚度大于 32 都保守返回零。天空环境 SSS 继续使用既有路径。

只新增一个 CPU 高度标量和 uniform，没有新增采样器、顶点属性、渲染目标或纹理格式。曾试验空列跳过及字节元数据，固定窗口仅有噪声范围的差异，已撤回；`dynamic-light.js` 与此前相同，RGBA8 光体协议保持。

## 实际验证

使用独立无头 Chrome / RTX 4060 / ANGLE D3D11，所有 GPU 批次串行，沿用 DOM Pointer Lock fixture。未占用桌面鼠标或操作玩家的 5173 服务；每批按 PID 和 UTC 创建时间核对退出，5191/5193 端口均释放。

- **204 项 Node 测试通过**，包括光学高度随屋顶、液体、移除和区块卸载更新。0.94 生产构建及生产 UI 存档导入/导出通过。
- **24 组实际 GPU 光程输入通过**。直接运行生产远距 GLSL，独立 CPU 期望以最近六边中心和 0.0002 步长积分，不复写 DDA 面求交。覆盖薄叶、厚叶、石头、半砖、玻璃、水、未知区、世界顶部和侧界外；厚度容差仅包含既有 0.002 面偏移与积分离散误差。
- **606 个真实 GPU 过渡采样通过**，覆盖 XYZ 两侧，单调且位于 [0,1]；相对独立双精度公式的最大绝对误差为 1.677e-6，小于 1e-5。
- **原生远距叶片 A/B 通过**。测试叶面阴影投影为 `[1.91008, 0.14873, 0.51944]`，已处于覆盖范围外。897 个叶片像素中，新增透射亮度薄叶为 0.043536、厚叶为 0.014464，石头及上半砖为零，拆除后恢复至 0.043585。三层实际红/蓝玻璃分别保留相应通道。这里的零指新增透射，不代表整个场景光照为零。
- sheen、环境 SSS、原有叶片厚度/玻璃/云影/月光/风、材质反射与颜料分离回归通过；画质切换、水面捕获、两次上下文恢复与维度切换通过。合计 **13 项不同的功能浏览器检查**，含自然森林和生产 UI；另有 1080p 性能窗口。最终高度边界修正后重跑远距原生、覆盖边界、生命周期以及森林/性能/生产检查，未把重复执行计入 13 项。

首个原型在 ANGLE 报告 `X4000: use of potentially uninitialized variable`。已将近远分支合流为显式初始化的返回值，后续 shader、页面警告和 GL 错误均为零；原始失败记录保留。新增与修改文件单独检查格式；全仓既有三个未修改格式问题见 [0.92 记录](leaf-ambient-verification.md)。
