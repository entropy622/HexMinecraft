# HEXWILD · 六野

**六个方向，一片可以住下来的旷野。**

一个使用 Three.js 制作的六边形体素沙盒。方块是六棱柱，世界使用轴向六边形坐标；采集、建筑与相邻关系都真实落在六边形网格上。七格蜂巢配方把熟悉的生存循环换了一个角度。

[在线游玩](https://entropy622.github.io/HexMinecraft/) · [开发与部署](#开发) · [操作](#操作)

## 已实现

- **世界**：种子生成的有限海岛、六棱柱地形、林地、沙滩、地下空洞、煤矿、铁矿、萤晶和三座遗迹。六个侧面与上下表面均可采集和建造。
- **生存**：碰撞、重力、跳跃、冲刺、游泳、摔落伤害、生命和饱食度，十分钟一个昼夜循环。
- **工具**：徒手 → 木镐 → 石镐 → 铁镐；工具自动装备。石镐解锁铁矿和萤晶，铁剑提升攻击伤害。
- **合成**：七格蜂巢配方、工作台附近的进阶合成、材料数量校验和工具等级要求。
- **家园**：可交互工作台、煤烧熔炉、储物箱、野营床及重生点；透明琥珀玻璃、石砖和发光萤灯。
- **农牧**：锄地、播种、九十秒小麦生长、收获和面包；绵羊掉落生肉与羊毛，熔炉烤肉，树叶掉落苹果和麦种。
- **夜晚**：六棱夜行者会靠近并攻击玩家，击败后掉落萤晶。床可以跳过夜晚。
- **探索目标**：每座遗迹用 3 萤晶和 6 岩石修复，点亮全部三座信标后继续自由游玩。
- **创造**：无限建筑材料、飞行、随时切回生存，自定义九格快捷栏。
- **体验**：小地图、全屏地图、合成音效、桌面鼠标锁定、手机触控、浏览器自动存档、JSON 存档导入导出。

这是一个完整的小型单人沙盒首版，并非 Minecraft 的全部功能移植。目前世界是半径 32 格的有限岛屿，没有多人联机、红石、流体传播、下界、附魔或无限区块流式加载。工具没有耐久，死亡保留背包，方便探索与创作。自动存档属于当前浏览器；清理站点数据前请导出。

| 移动 / 冲刺                                   | WASD / Shift |
| 跳跃 / 游泳上浮                               | 空格         |
| 采集 / 攻击                                   | 长按鼠标左键 |

手机上使用屏幕方向键移动，拖动画面转向，右侧按钮采集、放置和交互。推荐桌面浏览器获得更好的建造体验。

### 第一夜之前

1. 初始面前有树。采集原木，在 B 菜单中合成木板和木镐。
2. 再做一个工作台，点击背包中的工作台装入快捷栏，然后右键放置。
3. 挖掘岩石，在工作台五格范围内合成石镐。
4. 地下找煤和铁；做熔炉，把铁矿烧成铁锭，升级工具、制作铁剑。
5. 做锄头，E 翻耕土地，再按 E 播种。九十秒后收获小麦，合成面包。
6. 打开 M 地图寻找遗迹。遗迹附近有萤晶矿脉。修复三座信标，把星光带回群岛。

## 开发

需要 Node.js 22.12+（推荐 Node.js 22 LTS）和 npm。

```sh
npm ci
npm run dev
```

```sh
npm run check                   # 核心规则测试 + 生产构建
npx playwright install chromium
npm run test:e2e                # 真实浏览器回归和截图
npm run format:check
npm run build                  # 产物在 dist/
npm run preview
```

本机已有 Chrome 时，可使用 `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`；PowerShell 先执行 `$env:PLAYWRIGHT_CHANNEL='chrome'`。测试用的 `window.__hexwild` 只出现在开发构建中，不会暴露在发布版。

### 文件结构

- `src/core.js`：六边形数学、种子地形、物品、配方及存档校验。
- `src/graphics.js`：按 8×8 轴向区块合并的可见面网格、射线选择、昼夜光照、粒子、生物造型。
- `src/main.js`：输入、物理、生存、物品交互、UI、存档和主循环。
- `src/style.css`：响应式菜单、蜂巢合成与 HUD。
- `tests/`：坐标与资源规则单元测试、Playwright 游戏流程测试。

每次修改方块只重建所在区块及接壤区块；不为每个方块建立独立 Mesh。渲染像素比上限 1.7，萤灯动态光源上限 24。玻璃使用独立透明网格。

### GitHub Pages

`main` 的每次 push 都会执行 GitHub Actions：锁文件安装 → 格式检查 → 规则测试 → 生产构建 → Chromium 游戏流程测试 → Pages 部署。PR 只验证，不发布。

仓库 **Settings → Pages → Source** 使用 **GitHub Actions**。Vite 使用相对资源路径，兼容 `/HexMinecraft/` 子目录。发布目录为 `dist/`，无需后端、数据库或 API 密钥。

## 存档

每十五秒、返回首页及离开页面时保存到 `localStorage`。记录种子、地形改动、背包、工具、床边重生点、作物、箱子、玩家位置、时间和信标。暂停时世界不推进；熔炼只在游戏运行时计时，未完成的熔炼在保存恢复时退回原料。生物状态不持久化，重新加载会重新生成生物。
