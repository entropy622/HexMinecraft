## 0.102：Photon 自适应锐化

## 0.82：彩色牧场

- **给羊染色**：主手或副手染料可染十六色，重复同色不消耗，幼羊也可染色；剪毛后等毛层长回再染。颜色和剪毛状态随保存 / 继续保留，裸身与毛层分开着色。
- **剪毛与繁殖**：成年羊剪下三块对应颜色羊毛，发射器也可自动剪毛；两只羊喂小麦后，按已有染料配方传出混色幼崽，不能混色时继承父母之一。寒冷地区以黑羊、沙漠以棕羊、其他主世界以白羊为常见自然色，也可能遇到罕见粉羊。
- **真正吃草长毛**：沿用约两分钟草地恢复计时，最后低头啃食，把脚下草块变成泥土并长回原色；逃跑、求偶或暂停时不继续啃食。

原有床和捻线配方仍用白羊毛。草地自然扩散与地毯由 0.84 补充；彩色床与完整原版动物 AI 时序仍待补充；光影沿用现有 Photon 风格管线。[验证与限制](docs/sheep-wool-verification.md)。

## 0.72：雨后地表与建筑倒影

- **真实场景倒影**：光影档的露天地面出现斑块水洼，按当前帧颜色和深度追踪建筑倒影，随视角增强掠射反射；离屏或没有命中时使用天空近似并在边缘衰减。
- **材质与遮挡**：石材、木材和土壤按吸水性呈现不同的积水与变暗。屋顶下、竖直墙面、沙漠和雪原不会出现雨水洼，地表分布固定在世界坐标中。
- **雨滴与恢复**：下雨时扰动倒影，暂停冻结扰动；雨停后仍保留既有湿度并逐渐干燥。复用天气保存和表面保护缓冲，水下关闭地面反射，均衡 / 流畅保留湿润变暗。

当前是有界屏幕空间反射，尚不包含完整离屏场景、LabPBR 贴图、完整湿面时域重建或多次反射。[雨后地表验证记录](docs/wet-surfaces-verification.md)。

## 0.71：雪原弓手与细雪转化

- **流浪者**：雪原露天夜间生成的骷髅多数变为流浪者；屋顶下和其他群系保留普通骷髅。蓝灰兜帽、破损披布、冷色骨骼与眼睛区别于普通弓手。
- **细雪转化**：骷髅头部入雪七秒后开始颤抖，再过十五秒转化；开始前离开会清空积累，开始后离雪仍会完成。普通骷髅和流浪者不再被冻伤。
- **缓慢箭**：实际命中后施加三十秒缓慢 I，地面移动速度降低 15%；举盾格挡不附加，牛奶可清除，暂停和继续游戏沿用既有状态保存。修正了弓手瞄准高于玩家碰撞体的问题。
- **雪坑碰撞**：在雪中生物身上建造方块时，仍检查脚下实体支撑，避免它因身体空隙被阻挡而穿过地板。

沿用 v16。敌人与转化计时遵循现有敌人消失 / 不保存规则，流浪者暂掉落普通箭与骨头，玩家可用的药箭及完整装备继承仍待推进。[流浪者验证记录](docs/strays-verification.md)。

## 0.70：雪地里的陷落与保温

- **自然细雪与桶装收集**：雪原较高的地表出现连续的细雪斑块。它看似雪块，却能陷入；用空桶收起并重新放置，普通采掘不掉落细雪物品，创造选块得到细雪桶。
- **接雪与容器循环**：露天雪原降雪会让炼药锅逐档积雪，满三档可用桶取出；比较器读取真实档位，主副手桶装操作与继续游戏沿用现有系统。
- **冻结与皮革装备**：身体陷入后减速并累积冻结，七秒满冻结后每两秒受到冻伤，界面显示冻结条、霜边和冰蓝生命图标。装备任一皮甲可保温；皮靴另能站在雪面，蹲伏下沉，内部按空格攀出。
- **陷阱与融雪**：普通地面生物会逐步陷落并冻伤；燃烧玩家触及细雪会熄火并消耗接触方块，水流和岩浆可冲刷细雪。自然刷新避开细雪内部；近战生物接近后停止追赶，避免穿过玩家后从背面攻击。

沿用 **v16**，已放置的细雪、锅中内容和桶保存在既有数据中。冻结积累属于运行时接触状态，重载和重生会重置；视野内的白雾为界面近似。骷髅转化、更多寒冷生物和完整细雪雾效仍待推进。[细雪验证记录](docs/powder-snow-verification.md)。

均衡与流畅档继续使用几何云，沿用现有云开关和 v16 存档。当前为单层近似，尚无完整多层云、云专用时域重建或完整离屏反射；相关原理参考 Photon，未实现全部效果。[体积云验证记录](docs/clouds-verification.md)。

## 0.68：接住洞顶的水与岩浆

- **可制作的炼药锅**：工作台七铁合成六棱锅，实际锅沿、锅底与空腔共同参与渲染和碰撞。盛液状态中键选择与挖掘均得到空锅，沿用七格合成与现有物品栏。

## 0.67：从水下看见水面视窗

- **折射与全反射**：光影档中，水下看向水面会形成随波变化的折射视窗，超过临界角后转为水中环境倒影。采用精确介电菲涅耳，水平水面与水下侧界面依据实际法向判断介质两侧，与焦散共用折射率。
- **实际场景与水路吸收**：池底、建筑与模型参与当前帧反射，反射水段按真实水位和水长进行彩色吸收；相机到水面的水雾继续由现有体积积分处理。入水后的捕获增加周边视野，但玩家的镜头视野保持原设定。
- **渲染恢复**：捕获期间隐藏水体与第一人称模型，完成或失败后恢复相机与渲染状态，缩放、画质切换和介质变化沿用现有资源生命周期。
- **环境亮度与低画质**：水下反射缺失处随昼夜、维度与方块光变化；低画质使用环境近似，水下侧面同样遵守全反射，不再透出界面外的物体。

参考 [Photon 的介电菲涅耳实现](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/bsdf.glsl)，独立接入当前六棱世界。沿用 **v16**，没有新增玩家选项、依赖、贴图或渲染目标。反射仍受当前捕获范围和遮挡限制，身后隐藏物体、多层界面与多次散射继续推进。[水下界面验证记录](docs/water-interface-verification.md)。

## 0.66：把箱子接成生产线

- **可制作的漏斗**：工作台消耗五铁锭和一个箱子，得到带五格库存的六棱漏斗。Shift 右键容器旁放置；点击侧面让出口朝向该方块，顶面或底面放置时出口朝下。漏斗可悬空，口部、斜壁和出口使用实际形状碰撞。
- **自动运输与收集**：每 0.4 秒最多送出一件，并从上方容器取入一件；口部能吸入散落物品。连接箱子、潜影盒、其他漏斗、三种熔炉和酿造台，遵守接收面、容量及物品堆叠限制。工具耐久、附魔、命名和潜影盒内容随物品保留。
- **红石与操作**：通电停止漏斗自身推送、抽取和吸入；其他漏斗仍可访问它。比较器按五格容量读数，容器界面实时显示自动变化，支持原有鼠标与触屏取放。漏斗上方不需要箱盖空间，下面的普通箱子也能打开。
- **回收与恢复**：拆除散落库存；自动抽出的熔炉成品把经验留在炉内，之后手动取成品或拆炉领取。沿用 **v16**，保存实际库存、出口和剩余冷却，暂停、未加载区域及其他维度不补算离线运输。

这一轮补充生产玩法与原创铁质像素材质，光影沿用已有 Photon 风格水面、水下焦散与时域效果。尚无漏斗矿车、含水漏斗、自动物品筛选器界面或 Java 版逐刻更新顺序复刻。[漏斗验证记录](docs/hoppers-verification.md)。

## 0.65：水纹落在池底

- **水下焦散**：光影档中的日光经过真实水层折射、吸收和聚散，池底与水中的模型会出现随波移动的明暗光纹。该效果接入材质的直射光，环境光、发光方块与镜头水雾各自保留原有计算。
- **共用水面波形**：水面反射、折射与焦散使用同一组三方向波面和游戏时钟；光线按水位与太阳方向找到局部水面，不假设固定海平面。浅水、流动水、高处水池和负坐标区块使用现有液体数据。
- **遮挡与档位**：实心遮挡会抑制日光；干地、空气间隙与其他液体不产生水焦散。夜间、其他维度和低画质档跳过该聚散路径；继续使用已有阴影、TAA、体积光与明暗适应。

参考 [Photon 的水折射面积变化](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/shadow.fsh)，独立实现接收表面的六向体素近似。沿用 **v16**，没有新存档字段、玩家选项、图片、依赖或渲染目标。当前仍受体素遮挡精度、有限步长与单层连续水体近似限制，尚无全反射、多次散射或完整 Photon 对等实现。[焦散验证记录](docs/caustics-verification.md)。

## 0.64：读懂容器的信号

- **六向比较器**：读取后方 0–15 信号，四个侧向邻格取最强输入。比较模式在后方不弱于侧面时保留后方强度；右键 / 触屏「交」切换减法模式，输出后方减侧面，最低为零。前端箭头指示输出，三根小火把区分输出与模式，HUD 显示实际数值。
- **真实容器联动**：读取箱子、潜影盒、熔炉 / 高炉 / 烟熏炉和酿造台的槽位充满度，按物品实际堆叠上限计算。可隔一块完整导电方块读取；线路和强供电保留数值，中继器仍将信号恢复为 15。开箱存取与炉具加工时线路继续响应，Esc 暂停与卸载区域冻结计时。
- **下界石英与生存合成**：下界地层和顶层自然生成石英矿，镐采石英并获得经验，支持时运、精准采集与炉具烧炼。三根红石火把、一份石英和三块石头在工作台制作比较器；可正常摆放、切换、采回、被水冲落和保存。

参考 [Minecraft 官方比较器说明](https://www.minecraft.net/en-us/article/taking-inventory--redstone-comparator)，沿用七格合成与六向网格，模型与石英图案独立制作。继续使用 **v16** 存档，新增可选的模式 / 输出字段。当前尚无双箱合并、漏斗、书架等其他可测方块、活塞和 Java 版精确更新顺序。本轮扩展建造玩法，光影沿用现有 Photon 风格管线。[比较器验证记录](docs/comparators-verification.md)。

## 0.63：水下的光

- **随距离变化的水色**：光影档把屏幕色罩替换为真正读取场景深度的水中吸收与散射。远处红光衰减更多，近处表面保留细节；水面与水下共用消光系数，空气、岩浆和萤晶液不会计入水的光程。
- **水下体积光**：沿视线采样现有体素介质、彩色光和太阳阴影，加入随时间变化的束状散射。遮顶会削弱太阳散射，局部光源照亮周围水体，移除后消退。水中的天光按实际水层厚度指数衰减，避免数层水就使池底近乎全黑。
- **连续的水体**：修复叠放水块内部的虚假空气缝隙。网格、玩家身体检测、镜头介质与体素水位共用实际高度；水位改变会刷新介质数据，跨越水面或切换液体会重置时域积累。

参考 [Photon 的水中体积积分](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/fog/water_fog_vl.glsl)，独立实现本项目的六向体素版本，复用现有半分辨率雾目标与双边合成，没有新增玩家选项、依赖或存档字段。沿用 **v16**。均衡 / 流畅档保留原有水下色罩；尚无水下全反射、池底焦散光斑、多次散射或完整 Photon 对等实现。[水下光影验证记录](docs/underwater-verification.md)。

## 0.62：蛛网之下

- **分岔废弃矿井**：按种子生成最多三条主巷与侧巷，包含高差、木支架、支巷补给箱和逐格升高的地表入口。交叉口留出身体通路，洞顶稳定层防止自然砂砾落下堵路；区块加载顺序不改变布局，采空的箱子不会重新补货。
- **真正的蛛网**：身体接触蛛网会降速，并减慢下落；蜘蛛免疫网的拖慢。蛛网能选取、携带、摆放和保存，剑采下线，剪刀采回蛛网，水冲走后留下线，岩浆烧毁。交叉网面与物品图标共用原创网丝图案。
- **洞穴蜘蛛与中毒**：矿井巢穴刷出体型较小的蓝色蜘蛛，可穿过低矮缝隙。盾牌正面挡住的咬击不会施毒，命中后中毒七秒，毒伤优先消耗吸收生命并最多降至一点生命。中毒剩余时间随存档恢复，牛奶解除；在刷怪笼附近放火把可抑制刷新。

玩法参考 Minecraft 官方的[废弃矿井](https://www.minecraft.net/en-us/article/mineshaft)、[洞穴蜘蛛](https://www.minecraft.net/en-us/article/meet-cave-spider)和[蛛网](https://www.minecraft.net/en-us/article/block-week--cobweb)说明，生成、图案与行为独立实现。沿用 **v16 / `hexwild-save-v16`**，已有世界的方块修改继续覆盖自然生成；旧矿井布局没有冻结，推荐新建世界体验。仍无铁轨矿车、蜘蛛爬墙和完整亮度寻路，刷怪光照沿用附近火把 / 灯笼检查。本轮使用现有 Photon 风格彩色光、体积散射、明暗适应和 TAA，没有新增光影算法。[矿井与蛛网验证记录](docs/mineshafts-verification.md)。

## 0.61：信号与熄灭

- **红石火把**：可站立或装在墙面，输出强度 15，但不给自己的支撑块供电；支撑块被供电后约 0.1 秒熄灭，断电后再亮起。上方实心块得到强供电，其余有效邻居得到弱供电。模型、随身光和红色体素光随实际状态变化，熄灭会移除周围的红光。
- **六向中继器**：只读取后方，向前方恢复强度 15，隔离反向输入。按玩家朝向摆放，箭头指向输出，右键 / 触屏「交」循环调整 1–4 红石刻（0.1–0.4 秒）；串接的延迟相加。短的通电脉冲会延长到所选延迟，较短的断电间隔被过滤。
- **侧向锁定与时钟**：四个非轴向邻格的中继器正对侧面输出时，锁住当前通电 / 断电状态；普通红石粉、火把或拉杆不构成侧锁。锁定时有横杆，解除后按当前输入重新调度。真实反馈线路可以闪烁，火把在三秒内熄灭八次后冷却八秒，其他火把不受影响；暂停和卸载区域冻结计时。
- **生存闭环**：一份原木和一份红石粉制作一根火把；两根火把、一份红石粉和三块石头在工作台制作一个中继器。延续七格填料、主副手、选块、采掘掉落、支撑检查和液体冲刷。中继器为 1/8 格高的六棱底板，指示火把的位置显示延迟。

参考 [Minecraft 官方红石指南](https://learn.microsoft.com/en-us/minecraft/creator/documents/redstoneguide?view=minecraft-bedrock-stable)，图形与六向调度独立实现。存档升级 **v16 / `hexwild-save-v16`**，保存中继器延迟、待执行切换、火把近期熄灭记录与冷却。旧 v15 浏览器记录保留，不读取或迁移，需新建世界体验。仍无比较器、活塞、Java 版更新优先级 / 准连接和精确过热唤醒链；本项目使用物理时间步、固定冷却与四个侧向邻格。光影沿用 0.60 的 TAA / SMAA、彩色体素光与明暗适应。[机关验证记录](docs/diodes-verification.md)。

## 0.60：更稳定的远景

- **时域抗锯齿**：光影档增加八相位亚像素采样，将相机重投影与深度检查后的 HDR 历史画面积累到当前帧。在柔光和明暗适应之前处理，再用有局部范围限制的轻锐化与 SMAA 收尾，降低围栏、建筑斜边和远处地表的闪烁；界面文字与图标保持原来的绘制路径。
- **运动与历史拒绝**：移动生物、第一人称手持物、透明表面及水面使用当前帧；深度变化、画面边界与亮度 / 色度邻域限制历史颜色。快速转头、传送、视野突变、进出水面、缩放窗口或重建世界会重置积累。渲染结束或异常时恢复相机投影，采集与建造使用正常射线。
- **沿用画质选项**：Esc →「光影」→「时域抗锯齿」。继续保存原有抗锯齿偏好，均衡 / 流畅档释放后处理目标，不增加存档字段或依赖。

参考 [Photon 的时域解析](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/c4_taa_exposure.fsh) 的重投影、HDR 压缩和颜色邻域限制，独立实现当前分辨率 TAA，没有复制上游代码。在固定测试场景中，相对两倍渲染分辨率参考图，边缘均方误差比 SMAA 降低约 **50%**；这是该场景的图像指标，不代表所有场景或显卡的质量 / 性能结论。动态物体采用保守拒绝，尚无逐物体速度缓冲、时间上采样或水面反射的独立历史积累。[时域验证记录](docs/temporal-verification.md)。

## 0.59：水与石的洞室

- **滴水石洞**：主世界新增第三种有地表入口的洞室，包含滴水石块、朝下的钟乳石、朝上的石笋、相接石柱与浅水洼。保留入口到洞室的通路，部分钟乳石上方有独立水源。生成取决于种子；玩家修改和移除的液体继续优先覆盖自然结果。
- **可以采回的尖锥**：滴水石锥支持完整顶面 / 底面摆放、同向续接、中键选取、手持、掉落、保存与四根合成一块滴水石。六棱锥形在画面、图标和碰撞中采用同一缩放定义；侧面可以绕行，相邻的相反尖端会合拢成柱。
- **地下的危险**：失去底座的石笋碎落，断根的钟乳石坠下并在落地时碎裂，击中下方玩家或生物会造成伤害。真正跳落 / 跌落到尖端时伤害增加，站稳后不反复扣血；已合拢的柱没有裸露尖端。局部断根检查优先于自然砂砾队列，坠落实体在卸载区域冻结，并可在半空保存恢复。
- **滴落与再生**：钟乳石有受空间阻挡的水滴，顶上岩浆改变滴落颜色，粒子数量固定上限 96。滴水石块上方有水源时，下面的钟乳石及十格内的石笋有缓慢生长机会；不进入液体或玩家 / 生物身体，最长七段。

行为参考 [Minecraft 官方滴水石说明](https://www.minecraft.net/en-us/article/caves---cliffs--part-i-out-today-java)，程序纹理、六棱几何、物理与生长代码独立实现。沿用 **v15** 存档。当前生长平均每 1800 秒一次机会，伤害按碰撞速度估算；尚无炼药锅集液、尖锥含水、三叉戟破坏及 Shift 阻止合拢。本轮延续既有彩色体素光、阴影和明暗适应，没有新增 Photon 的时域算法。[滴水石验证记录](docs/dripstone-verification.md)。

## 0.58：洞中的生命

- **洞穴藤蔓与发光浆果**：苔光溶洞的顶面自然长出藤蔓，果实发出暖色体素光。右键采摘保留藤蔓，果实落地后可拾取；骨粉使所指的空藤段结出浆果。浆果可食用，也可种在完整方块底面或藤蔓下方，生长中的藤蔓可攀爬。断根和液体冲刷会使下方链条脱落，只有带果实的藤段掉落浆果。
- **孢子花**：可从洞顶采集并重新悬挂，粉色花瓣下有缓缓飘落的孢子。附近最多显示 128 个粒子，共用一个绘制缓冲；花本身不发光。
- **蝙蝠**：地下洞室附近出现少量蝙蝠，安静时倒挂，玩家靠近或攻击时惊飞。飞行逐段检查已加载空间的固体与液体，支持在阶梯状洞顶下下降和转向；不攻击玩家、不掉物品或经验。蝙蝠属于临时环境生物，不占用存档里的家畜记录。

玩法参考 Minecraft 官方的[洞穴藤蔓与浆果说明](https://www.minecraft.net/en-us/article/caves---cliffs--part-i-out-today-java)和[蝙蝠介绍](https://www.minecraft.net/en-us/article/bat)。模型、浆果像素图、植物纹理和行为代码独立制作。沿用 **v15** 存档；藤蔓以普通方块修改保存，卸载区域不生长。当前生长采用平均 90 秒一次的随机机会，最长 26 段；环境蝙蝠按附近洞室生成，尚未模拟原版季节、独立亮度阈值与精确随机刻。[地下生态验证记录](docs/cave-ecology-verification.md)。

## 0.57：倒影之下

- **水面场景反射**：光影画质档读取当前帧的场景颜色与深度，水面可以映出屏幕内的建筑和发光表面。反射按波浪法线求交、细化命中并在画面边缘渐隐；离屏部分使用天空近似。反射线保持在实际水面上方，避免掠射角误采池底形成黑斑。
- **折射与水深**：波纹扭曲水下景物，深度检查避免取到水面前方的岸边；颜色随水中路径吸收和散射，深水吸收更多红光，浅水保留池底。菲涅耳响应让平视更容易看到倒影，俯视更容易看到水底，高光也受此响应约束。
- **沿用当前操作**：Esc 将画质选为「光影」即可启用。没有视锥内水网格时跳过额外捕获，切换低档释放捕获目标；水下沿用现有渲染。水面的实际高度、液体流动与碰撞保持当前玩法规则。

参考 [Photon 的镜面反射](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/specular_lighting.glsl) 与[折射层合成](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/program/c1_blend_layers.fsh) 的深度求交、边缘衰减、前景拒绝思路，扩展本项目的水材质与场景捕获，独立实现当前帧光学。尚无时域积累、离屏场景反射、水面几何位移、焦散与水下全反射；屏幕空间缺失和边缘渐变仍然存在。

## 0.56：石间的信号

- **可以搭建的红石线路**：红石粉可手持铺线、中键选取和采回。线路沿六个水平方向连接，支持有净空的一格升降；输入信号 15，每延伸一段线衰减 1，多输入取较强信号，断线与循环线路都会正确失电。完整实心方块区分强供电和弱供电，弱供电不会隔着石块继续驱动另一段线。
- **开关与机关**：拉杆持续供电，石按钮发出一秒脉冲，石质压力板由玩家或生物踩下，离开半秒后释放。拉杆和按钮可装在地面、墙面、顶面；红石线和压力板需要完整顶面支撑。右键 / 触屏「交」操作开关，Shift 右键在旁建造。门、栅栏门和活板门随信号变化，保留手动操作；有人或船挡住开合时等待重试。
- **灯与可见照明**：红石灯包含原创亮 / 暗纹理，通电时灯面自发光，并接入现有彩色体素光与散射。开关附近的区块优先刷新光照，熄灯会同时移除表面发光与环境照明。红石线以颜色显示信号强弱，瞄准时 HUD 显示 0–15。
- **生存闭环**：四种元件都可合成、建造、采集与保存。灯需要工作台、四份红石粉和一块萤石；本项目尚无独立木棍物品，拉杆柄沿用原木材料。元件失去支撑或被液体冲入时掉落对应物品，线路掉落红石粉；暂停及卸载区域冻结按钮 / 压力板计时，重载后继续。

规则参考 [Minecraft 官方红石指南](https://learn.microsoft.com/en-us/minecraft/creator/documents/redstoneguide?view=minecraft-bedrock-stable)，模型、六向传播、照明和代码独立实现。当前采用游戏时间的物理步进，尚无中继器、比较器、活塞、红石火把或 Java 版准连接 / 更新顺序模拟；红石灯熄灭没有额外延迟。本轮没有增加 Photon 的反射或时域效果。

## 0.53：工匠的火候

- **高炉与烟熏炉**：高炉只收矿石和原矿，烟熏炉只收生肉、生鳕鱼 / 鲑鱼及马铃薯；各自 **5 秒 / 件**，燃料也以两倍速度消耗，每份燃料的产量保持相同。普通熔炉改为统一 **10 秒 / 件**，继续处理木炭、玻璃、石材与爆裂紫颂果。三种炉具分别保存输入、燃料、产物、余火和经验，取产物时结算经验；满产物槽停止加工但余火仍消耗，岩浆桶留下空桶，打开面板时照常加工。
- **不用燃料的切石机**：放入一份石材、点击带图标的产物，再取出完整一批才扣料。一份石材可切 **两块半砖或一段楼梯**；石头也能直接加工石砖及其半砖 / 楼梯，末地石能直接加工末地石砖及其形状，紫珀可切柱材。保留材质本身，木材不进入切石机。Shift 连续加工，完整一批装不下就停止；右键、拖动、双击归拢、数字键与 F 继续使用统一容器规则。关闭界面归还原料，满包则落地。
- **平滑石和更多石材形状**：石头再烧一次得到平滑石，三份平滑石制六块半砖，也可一份切两块。补上末地石砖、苔石砖、切制铜的六向楼梯与半砖，既可蜂巢合成，也可切石。高炉由 **5 铁锭 + 1 熔炉 + 3 平滑石** 制作；烟熏炉使用 **4 原木 + 1 熔炉**，接受不同树种与去皮原木；切石机为 **1 铁锭 + 3 石头**。高炉九份材料通过蜂巢格中的数量堆叠呈现。
- **六棱机器与村庄工坊**：三种新机器有独立像素图标、手持和掉落模型。炉门跟随六向朝向、点亮状态与暖色体素光；切石机为 **9/16 格高**的六棱底座和三帧镂空锯片，碰撞只取底座，不伤害站上去的角色。新村庄铁匠使用高炉，公共区域提供烟熏炉和切石台。新增十三张未修改的 CC BY-SA 3.0 材质，保留来源和运行时裁切许可。

本版存档升级为 **v13 / `hexwild-save-v13`**，保存炉具类型与切石暂存输入，不读取或迁移旧格式，请新建世界。参考 [VoxeLibre 高炉](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ITEMS/mcl_blast_furnace/init.lua)、[烟熏炉](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ITEMS/mcl_smoker/init.lua)和[切石机](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ITEMS/mcl_stonecutter/init.lua) 的分类加工、速度和选产物思路，六向模型、槽位、配方与代码独立实现，没有打包上游代码。验证仅生产构建与 GitHub Actions，未运行浏览器、云端、玩法或性能测试。

## 0.52：弦与涟漪

- **双手右键拉弓**：主手和副手都可按住右键蓄力、松开发射，触屏按住并松开「用」。约 **1 秒**满弓，拉力按 `(t² + 2t) / 3` 增长，过短拉弓不消耗箭或耐久；左键恢复采集 / 近战。保留三阶段像素弓弦，加入双手拉弓姿势、支撑手、移动减速与地面 / 船上拉弓视野收紧。换手、移走实际弓、打开菜单、失去输入或开始攻击会取消，取消不会射箭。

- **飞行中的箭**：玩家满弓初速 **60 世界单位 / 秒**，增加空气阻力和更明显的重力，伤害随命中速度、力量附魔与满弓随机暴击结算。骷髅仍使用原先的发射参数。普通插地箭回收优先补入副手的箭堆，背包满且无法补入时保留在地面，不再先销毁箭或另生成一份物品；仍受现有 32 支箭预算与 40 秒寿命约束。
- **左手垂钓**：钓竿支持任一手，右键 / E 抛线与收杆，鱼线从实际竿尖连到浮漂；鱼获、挂钩磨损和损坏绑定抛线的那一根竿。主手采掘不会直接收回副手鱼线，移走实际钓竿或换手仍会收线。弓、钓竿和盾牌普通敲击不再磨损，分别由射击、收杆与防御结算耐久。
- **两面六棱盾**：盾牌在主手或副手均有独立模型、附魔光泽、举起和受击反馈。右键使用有优先权的那只手；R 直接举盾，优先副手。防御与磨损绑定实际盾牌，换盾 / 换格位后重新准备 **0.25 秒**，损坏后同帧的后续攻击不会继续被已消失的盾挡住。HUD 显示使用的是主手还是副手及其真实耐久。

## 0.51：两手之间

- **能实际使用的副手**：游戏中 **F** 交换主副手，右键优先使用主手；主手没有适用动作时使用副手。副手支持普通 / 特殊建筑、半砖合并、潜影盒放置、桶与水瓶、食物与药水、珍珠 / 蛋 / 雪球、烟花助推、播种 / 骨粉、营火、去皮 / 翻耕、剪羊毛与挤奶。F 替代旧的自动选食物快捷键，食物需真实拿在一只手中，按住右键食用；E 和触屏「吃」仍可使用食物。弓和钓竿这版仍需主手，沿用原有操作。

- **带着灯挖矿**：两只手都可提供彩色体素照明，冷暖光取每个颜色通道的较高值，两支火把不会重复加亮；暂停菜单保留双手光照。副手有水桶时，主手采掘仍瞄准水后的方块，装倒液体才选择液面。动物也会被任一手中的食物吸引。

## 0.49：矿石里的宝藏

- **圆石与烧炼**：石头普通开采掉圆石，深板岩掉深板岩圆石。两类圆石可混合制作石制工具和熔炉，也能用于石制工具的铁砧修复；分别有六向半砖、楼梯和独立图标。烧炼圆石 / 深板岩圆石可还原石头 / 深板岩；粗铁 / 粗金 / 粗铜与对应矿石均可烧成锭。矿石烧炼每件 **10 秒**，经验随配方结算。水与流动岩浆生成圆石，水接触岩浆源仍生成黑曜石。
- **时运 I–III**：镐、斧、铲、锄可附魔，煤、钻石、青金石、原矿按矿物倍率增加产量，红石追加数量；不增加经验。时运 III 的单份矿物最多四倍，铜最多二十份。砂砾掉燧石概率为 **10% / 约 14% / 25% / 100%**，萤石粉最多四份，树叶提高树苗与苹果概率；剪刀仍只收叶块。

## 0.43：木纹与横梁

## 0.42：活着的树冠

## 0.37：贝壳与浮空

- **闭壳与开壳**：独立六边形底壳、旋转升起的上盖、会看向玩家的头与公开紫色像素皮肤。闭壳时减少 **80%** 受到的伤害并反弹箭矢，开壳后可以正常攻击；不受普通击退与火焰伤害。潜影贝可以附着在地板、天花板和六个水平朝向的实心表面，低生命受攻击时有机会瞬移，失去支撑或接触液体时也会尝试寻找干燥的新表面。只在已加载地形寻找落点，检查真实形状和展开空间。
- **六向追踪弹**：看见约 **18 米**内的生存玩家后开壳，间隔约 **2.5–5.5 秒**射击。浅色星形潜影弹沿六个水平方向和上下转向追踪，尝试绕开近处障碍；碰到地形会破碎。可用近战、弓箭、雪球、鸡蛋或珍珠击落，正面举盾可以挡下伤害与状态。投射物最多同时 24 枚，十二秒消散，离开加载区、死亡、重生、传送或切换维度时清理，暂停冻结。
- **漂浮与反制**：追踪弹命中玩家造成 **4 点基础投射物伤害**，附加 **10 秒漂浮 I**，护甲与保护附魔仍生效。漂浮逐渐把竖直速度拉向每秒一米上升，沿用实际身体与顶头碰撞，期间停止鞘翅、不能重新展开，也不产生下落暴击。牛奶可以解除；结束后恢复重力，注意落地高度，可在效果结束后展开鞘翅。漂浮期间不受摔落伤害，相机高度仍以 160 为上限，图标与剩余时长显示在状态栏，并随存档保存。

## 0.36：风过末地

## 0.32：掷向远方

## 柔影入微

- 暂停菜单选择 **「光影 · 柔影与晨雾」**，在已有体积雾、日照阴影与柔光之外加入 **GTAO 屏幕空间环境遮蔽**。根据当前帧深度重建法线，强化墙角、建筑接缝、树根、台座与物体相接处的近景层次；采用约 1.15 米的采样半径，限制最深暗化，保留像素材质与洞穴已有光色。
- 接触阴影以半分辨率计算，使用 Three.js 的 GTAO 和八点 Poisson 滤波，再按深度约束回到完整分辨率；近处、远处与屏幕边缘逐渐淡出，避免将轮廓直接糊成黑边。透明水面、玻璃、传送门、发光基础材质与第一人称手持物通过保护层排除阴影接收，进入液体时跳过此效果。
- 加入 **SMAA 边缘抗锯齿**，在线性颜色阶段处理，位于柔光之后、最终 ACES 映射与 sRGB 输出之前。改善六棱轮廓和斜线边缘，不改为平滑纹理；像素图仍使用最近邻放大，界面文字与图标不经过场景后处理。
- 画质菜单可单独调整 **接触阴影 0–100%**、**边缘抗锯齿开关**与 **柔光 0–50%**，默认分别为 60%、开启与 24%。阴影或柔光设为零会跳过对应计算；均衡与流畅禁用这组细节。设置保存在本机浏览器，切换画质后仍保留。
- 统一画布与全部后处理缓冲区的像素密度，高画质的**像素比上限为 1.25**，不超过设备像素比，修正过去画布和后处理分辨率不一致时的放大模糊；窗口变化会一并调整深度、阴影滤波、体积雾和抗锯齿缓冲。均衡上限 1，流畅上限 0.65。
- 场景颜色与深度使用独立捕获目标，避免开启/关闭效果或颜色缓冲交换时读取错误深度；切回均衡或流畅时，释放高画质渲染目标、噪声纹理与效果材质，再次启用时重建。世界与存档格式不变。

参考 [Photon 的 GTAO](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/ao/gtao.glsl) 对近景半径、手持物与屏幕边界的处理思路，复用 [Three.js 的 GTAOShader](https://github.com/mrdoob/three.js/blob/r186/examples/jsm/shaders/GTAOShader.js)、PoissonDenoiseShader 与 SMAAPass，保护层、深度捕获和合成由本项目独立实现。没有引入 Photon 代码。屏幕空间遮蔽只能利用当前画面中的表面，不等于全局光照；仍未加入时域积累或屏幕空间反射。本轮仅验证生产构建与 GitHub Actions，未执行浏览器画面或性能测试。

## 锻造与新生

- **铁砧与砂轮**：在工作台合成，放置后按 **E** 使用。铁砧需要 **3 铁块＋4 铁锭**，每铁块可由 9 铁锭合成或拆回；蜂巢配方中心显示叠放数量。砂轮需要 **2 原木＋1 石头＋2 木板**。新生成的铁匠铺也摆有开裂铁砧与砂轮。
- **材料修复**：铁砧每份材料修复最大耐久的约 **25%**，将修复材料放进右槽，最多使用四份，只消耗实际需要的数量；木、石、铁、钻石工具分别使用木板、石头、铁锭、钻石，护甲使用对应皮革或金属，盾牌使用木板。弓和鱼竿通过同类合并修复。
- **同类装备合并**：左侧装备保留，右侧副本消耗，耐久相加并获得最大耐久 **12%** 的额外修复，封顶满耐久。附魔取较高等级，同等级合并升一级，不超过各自上限；例如两把效率 IV 钻石镐可合成效率 V。结果、耐久、附魔和费用均先预览，取出产物前不消耗物品。
- **等级费用与铁砧损耗**：费用包含材料数量、修复、升级附魔、命名与两件装备已有的加工惩罚。修复或合并后的惩罚按 **0 → 1 → 3 → 7 → 15 → 31 → 63** 增长；费用达到 40 级时生存模式不能加工。每次成功使用有 **12%** 概率让铁砧进入下一阶段，完好、开裂、损坏之后消失，损耗阶段按方块类型保存，拆下再放不重置。
- **命名装备**：铁砧可为任意已有耐久装备设置最多 24 字的名称，留空恢复原名。单独命名不增加加工惩罚，费用最多 39 级；名称随具体装备保存，在背包、快捷栏、装备栏、箱子与加工面板显示。磨损、掉落和跨维度转移会保留名称。
- **砂轮祛魔与修复**：单件祛魔，或合并两件同类装备并获得最大耐久 **5%** 的额外修复，均免费。移除现有附魔、重置加工惩罚、保留左侧名称，并按被移除的附魔强度返还部分经验球；可重新放入附魔台。砂轮不能保留附魔，取出前会显示完整结果及经验返还量。
- 新增六向朝向的六棱铁砧、裂纹顶面、木架六角砂轮、加工动画、粒子与程序音效，使用九张新增授权像素材质，接入世界光照与阴影。创造模式免等级费用，仍消耗槽内的实际装备与修复材料，不返还砂轮经验。逐件记录名称与加工惩罚；打开界面不会把物品留在隐藏槽位。

## 经验与秘法

- **经验等级与六棱光球**：开采天然煤、钻石、青金石和萤晶、拆除天然刷怪笼、击败成年生物、繁殖、钓鱼和村民交易可获得经验。烧炼经验保存在炉内，取出产物时按数量释放；小数经验累计，不因分批取出丢失。光球可沿无遮挡路径吸向玩家，五分钟后消失，未加载区域与暂停时冻结。

## 晨雾流光

- **全部画质** 加入高度雾：水边与低地更浓，高处更清透，晨昏和雨天增强，沙漠减淡、雪原略增强；雾色随天空与太阳变化，洞穴维持暗部层次，进入液体时关闭空气雾。

- 随身光使用与建筑灯光相同的六向传播和材质遮挡，从玩家所在格发出，不会因挥手穿模而把光源送进墙后。光照随玩家跨格移动更新，最多每 0.25 秒一次；移动时复用静态天空光和世界灯光。
- 动物、敌人、村民、船体与船桨、手臂和手持物、掉落物、箭矢、作物以及鱼漂都接入世界光照。进入洞穴会变暗，走近火把或彩色灯源时染上对应光色；共享材质的多个模型也各自按所在位置受光。
- GPU 共享一张约 1.27 MiB 的三维光照纹理（默认 81 个数据区块），在六边形网格上插值并排除实心格，移除原有的八个近距离点光源。打开背包、地图或熔炉界面时，光照仍可完成更新，手持灯的照明保持。

继续参考 Photon 的体素光照与法线偏移取样思路，独立实现适合当前引擎的动态模型光照。随身照明属于视觉功能，不代替放置火把对作物与刷怪笼的现有玩法判定。自发光眼睛、火焰、粒子与天空保留自身表现；0.22 补充高度雾和体积散射，屏幕空间反射与时域抗锯齿尚未实现。

## 光落六野

- 新增 **15 级天空光与 RGB 方块光传播**，沿六个水平邻格和上下方向扩散。洞穴入口、窗户与门口可透入天光，实心墙与关闭的木门阻挡传播；树叶与水逐层削弱光线，玻璃透光，围栏和梯子允许减弱后的光通过。
- 火把、萤灯、燃烧中的熔炉、萤石、萤晶、刷怪笼、两种传送门、岩浆和萤晶液各有光色。附近地形受所有已加载发光单元影响，不再依赖离相机最近的八个点光源；光色随距离衰减，可在建筑内布置暖灯与彩光。
- 地形、木门等建筑、草丛、玻璃和液面共用光照场；挖墙、开关门、放置/移除光源、熔炉燃灭及液体流动会更新照明。地下水面的天空倒影随天光减弱，洞穴远雾也不再保持室外亮度。
- 光照只在变化后计算，最多每 0.25 秒一次，网格光照属性分帧上传，不为光照变化重建地形。所有画质档均启用，已有的高画质柔光仍可使用。

主要参考 [Photon 的 LPV 光传播与表面采样](https://github.com/sixthsurge/photon/tree/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/lpv)，独立实现适用于 Web 六棱柱世界的 CPU 光照场，没有复制其 GLSL 源码。0.17 建立方块照明，0.18 补齐动态模型与随身光。

## 六面行舟

- 工作台用 **5 木板** 制作橡木船，手持后对水面 **右键 / E** 放置。船占背包一格；对准空船 **E 上船**、**Ctrl+E 收回**，也可以用左键拆船。
- **W/S** 前后划行，**A/D** 按船头方向转向，鼠标独立观察周围，**空格** 刹船。前进最高约 8.5 m/s、倒退约 4 m/s，具有加速和滑行惯性，水面船桨动画、尾流和划水声随移动变化。
- **Shift 下船**；未手持鱼竿时也可按 E 下船。优先寻找附近能站立的岸边，其次水面；周围没有安全位置时留在船内。触屏使用方向、跳跃、下降和 E 按钮控制。
- 六边形木船采用现有像素木材，拥有实体船体碰撞与载客净空检查。船不能穿过岸边、围栏、其他船或低矮障碍，搁浅后可收回重新放置；不提供陆上划行。
- 支持在船上钓鱼：空格刹停，再换鱼竿，右键/E 抛线收杆；Shift 仍可下船。船只位置、朝向、速度、生命与乘坐状态按维度保存，未加载区域或暂停时冻结；跨维度旅行会把船留在原地。
- 船有 20 生命，斧拆船更快；爆炸会摧毁并掉落船，岩浆会烧毁且不掉落。不提供岩浆航行、动物乘客或运输箱，目前每艘船单人乘坐、每维度最多 128 艘。

本轮对照 [VoxeLibre 的 mcl_boats](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ENTITIES/mcl_boats/init.lua) 阅读了浮水判定、乘客分离、碰撞高度与速度衰减的处理方式。游戏中的 JavaScript 载具逻辑与六边形模型为独立实现，没有复制上游 Lua 代码或船模型。

## 水畔时光

- 工作台用 **3 原木 + 2 线** 制作鱼竿，也可向村庄渔夫购买。手持鱼竿，面向水面 **右键 / E** 抛线，再按一次收杆，**左键** 收起；触屏使用交互按钮。
- 抛出的六棱浮漂受重力影响，会落入水中或挂在岸上。鱼线连接手中鱼竿；等待时有涟漪，鱼群靠近后浮漂下沉并发出水花与声音，在提示窗口内收杆即可获得鱼获。错过后可留线继续等。
- 露天等待约 9–25 秒，再有 2.2 秒靠近过程；雨中加快 40%，有顶棚时变慢。鼠标收杆窗口 1.6 秒，触屏为 2.1 秒。水被填掉、鱼线受阻或距离超过 24 格时收回；切换手持物也会收起。
- 新增鳕鱼、鲑鱼、热带鱼与两种烤鱼，带像素图标。**按住 F 食用**，生鳕鱼/鲑鱼恢复 2 饱食，热带鱼 1，烤鳕鱼 5，烤鲑鱼 6。雪原更容易钓到鲑鱼，沙漠水域更容易钓到热带鱼。
- 一般鱼获占 90%，杂物占 10%；半径两格的六边形水域、两层平静水体、上方两格无遮挡时，变为 85% 鱼获、10% 杂物、5% 宝物。宝物包括书、绿宝石、末影珍珠或钻石，可建造自己的钓鱼池。
- 村庄新增两格深六边形鱼塘与戴草帽的渔夫，出售鱼竿和烤鱼、收购三种鱼。成功收杆消耗 1 耐久，挂住后收回消耗 2；鱼竿共 64 耐久。背包满时鱼获落在脚边。
- 暂停时冻结钓鱼，退出或切换维度后收起鱼线；已获得的物品正常存档。鱼竿支持耐久附魔，暂未加入水下游鱼、海之眷顾、饵钓或自动钓鱼。

## 炉火不息

- **E 打开熔炉**，从背包放入原料和燃料，自动连续烧炼；使用游标拿放、右键分半 / 单件或 Shift 快速转移。产物保存在炉内，Shift 取出时背包满则留在炉内，普通点击仍可拿在游标。
- 煤与木炭各燃烧 80 秒，原木和木板 15 秒，岩浆桶 1000 秒并留下空桶。可烧铁、金、铜、肉与马铃薯；新增原木烧木炭、沙子烧玻璃。
- 每台炉子的存货、进度和剩余燃烧时间随维度保存。炉子面板打开时仍工作，暂停菜单、后台、未加载区域及离开的维度暂停模拟，不结算离线时间。
- 原料耗尽或产物满时余火仍消耗，不会继续点燃新燃料；熄火后未完成的进度逐渐冷却。拆除和爆炸散落炉内物品，已点燃的燃料不返还。
- 正面朝向放置者，燃烧时切换像素炉火并照亮周围。面板提供实时火焰与烧炼进度，新增木炭像素图标。

当前尚无植物踩踏、自动收割或自然树叶衰减；书架可以装饰建筑，也能增强附魔台。

## 天气与氛围

- 主世界在晴朗、雨天与雷暴之间按种子轮换，天气平滑过渡并保存。雪原降雪、雷暴时雪势增强；沙漠保留阴云，不下雨。
- 加入六棱云团、雨线、像素雪花、地表溅水与远处闪电；阴云会削弱日光、遮住星月、改变天空与水面反射颜色，雨后露天地面的湿润高光会慢慢消退。
- 屋顶、玻璃和树冠遮挡雨雪，地下没有降水；进入屋内或水下后雨声变轻，雪原使用低沉风声。暂停菜单与后台暂停环境声。设置可单独关闭闪电与天空闪光。
- 露天且非雪原/沙漠的作物在足量降雨时额外获得约 50% 生长速度；阴雨抑制僵尸与骷髅日晒伤害，强雷暴允许白天生成敌对生物。主世界在雷暴中也能睡觉，醒来后天气逐渐转晴。
- 创造模式暂停菜单可选择天气，生存模式自然轮换。流畅画质使用较少的天气粒子，雨雪使用固定缓冲区批量绘制。

天气目前属于氛围与生存环境模拟：闪电不会引燃或损坏建筑，雪不会堆积，雨不会增加液体体积；湿润反光是天空颜色近似，不是屏幕空间或光线追踪反射。

## 流动液体

- **铁桶与液体桶**：工作台用 3 个铁锭制作铁桶。在背包中把桶移入快捷栏，用右键或 E 对准液体源装取；装满后对准地形倒出，生存模式会返还空桶。流动液体不能装桶，创造模式可直接选择三种液体桶。
- **六向流动**：水、岩浆、萤晶液优先向下流，落地后向六个邻格扩散，最远分别为 7、3、5 格。岩浆流速更慢；堵住水道会改道，移走源头后逐步退流。海域与下界熔岩海也由实际液体格组成。
- **液体反应**：水接触岩浆源生成黑曜石，接触流动岩浆生成圆石。工作台用 **水桶 ×1 + 萤晶 ×2** 调制萤晶液桶；萤晶液带发光纹理，与岩浆接触生成萤石。
- **身体交互**：站进液体会减速，按空格上浮；岩浆会造成伤害，浸入液体时显示对应颜色的水下效果。
- **持久化**：液体源、流动状态和取走的天然源随区块卸载、维度切换和存档保留。

液体采用源头供给的离散模拟，不是体积守恒的物理流体。每轮有固定计算预算，大型瀑布可能需要更久稳定；离开已加载区域后暂停模拟，返回后继续。液体状态会增加存档大小，仍建议定期导出备份。岩浆与萤晶液参与彩色方块光传播。水与萤晶液不互相反应；目前没有蒸发、压力或无限水源生成。岩浆桶可以用作熔炉燃料。

- **无限水平世界**：8×8 轴向区块按位置生成与卸载，远行后依旧可以挖掘和建造。修改记录独立保存，返回区域会恢复建筑与被挖掉的方块。当前高度为 1–63 格。
- **主世界**：平原、森林、沙漠、雪原、海域、矿脉与地下空洞，昼夜交替。
- **下界**：绯红菌林、玄武岩荒地、岩层穹顶、萤石和熔岩海；熔岩会伤害生存玩家。
- **末地**：末地石浮岛、黑曜石柱、星空与虚空，重力更轻；掉入虚空会死亡并损失落入虚空的物资，随后在当前维度重生。
- **维度往返**：生存玩家搭建黑曜石门框，用打火石点燃后站入或按 E；末地门仍可合成。初次到达生成安全落脚平台和返回门。三个维度分别记录地形、箱子、作物、重生点与上次位置。创造模式可以在暂停菜单直接旅行。
- **纯沙盒**：移除信标任务、任务追踪与通关弹窗。HUD 显示维度、生物群系和六向罗盘。
- **游戏界面**：立体标题、石质面板、九格物品栏、配方搜索、拾取提示、可保存的音量/画质/灵敏度设置。
- **动画与音效**：手持方块和镐、采集挥动、放置动作、行走摆动、受击反馈、作物轻摆、旋转传送门及转场。脚步、碎块、放置、合成、受伤和传送声音由 Web Audio 合成，不依赖外部音频。
- **继续生存**：木→石→铁→钻石工具、铁剑、工作台、熔炉、储物箱、床、锄地播种、小麦面包、食物、生物、生命和饱食度，均可继续使用。

这是独立的单人六边形体素沙盒，不是 Minecraft 完整移植。当前没有联机或红石电路，末地已有可选的末影龙首领战。工具有耐久并可附魔，死亡散落物资与部分经验；动物与首领进度保存，普通敌对生物按环境生成。无限指水平地形持续按需生成，不表示浏览器内存、坐标精度或本地存储没有上限。

### 生存与维度

1. 采集原木，E 合成木板和木镐，把镐装入快捷栏并手持。制作并放置工作台，在五格范围内解锁进阶配方。
2. 木镐挖石头获得圆石，制作石镐与熔炉；石镐挖铁矿石获得粗铁，用煤炭烧成铁锭。铁镐可采集钻石，制成钻石镐后可采集黑曜石。
3. 工作台配方 **3 圆石 + 2 煤炭 + 1 萤晶 → 4 黑曜石**，或用水凝固岩浆源。准备至少十块黑曜石，搭出内部两格宽、三格高的竖直门框，四角可省略。
4. 砂砾中获取燧石，与铁锭制作打火石，对准框内底座右键点燃。站入门面四秒或对准门面 E 进入，目的地会生成完整返回门。
5. 主世界夜间的末影人掉落末影珍珠，下界生物掉落烈焰粉。**3 末影珍珠 + 3 烈焰粉 + 1 萤晶** 在工作台制作末地传送门。
6. 床只在主世界设置重生点并跳过夜晚。别在熔岩里游泳，也别忘了带足够的建筑材料跨越末地虚空。

这些是可自由选择的配方与玩法，没有强制任务或通关目标。

## 遗迹与地下探索

- 野外可发现古老瞭望塔、废弃矿道和苔石地牢；下界有余烬堡垒，末地有紫珀遗址。矿道与地牢有木制阶梯通向地面，沿入口逐级跳下即可探索。
- 遗迹内有食物、金属、火把与稀有材料宝箱。箱子只在首次生成时填充，拿走或破坏后不会重载补货。接近遗迹会记录发现，并在地图以 ◆ 标注；地下遗迹需要进入其高度范围才能发现。
- 刷怪笼在玩家 16 格内活动，每八秒尝试生成守卫。五格内放置火把或萤灯即可压制；石镐能拆除刷怪笼并回收萤晶。
- 煤和原木制作火把。火把是细六棱柱，不阻挡移动；覆盖区域的天空补光更暗，火把与灯具提供独立照明，最多同时显示离玩家最近的八盏局部灯。
- 深层有深板岩与金矿，普通岩层也可找到铜矿。铁镐开采金矿、石镐开采铜矿，熔炉分别炼成金锭和铜锭，可制作金块、切制铜块和金苹果。
- 手持金苹果按住右键或右键 食用，恢复 4 点饱食，并给予生命恢复和伤害吸收。新增苔石砖、砂岩、下界砖与紫珀装饰配方。

## 动物、养殖与敌人

- 主世界可遇见绵羊、奶牛、猪和鸡。手持小麦吸引牛羊、苹果吸引猪、麦种吸引鸡；对动物右键（或右键）喂食。附近两只已喂食的同类会繁殖，幼崽在加载区域约三分钟成年，喂食可加速。
- 两块铁锭制作剪刀，对成年羊右键 得到三份羊毛；在草地上约两分钟长回。铁桶对成年牛右键 挤奶，奶牛休息 30 秒；牛奶可右键饮用，也可与鸡蛋、小麦做蛋糕，制作返还铁桶。
- 成年鸡约每 150 秒产一个蛋，最多暂存八枚；换下麦种后对鸡右键 收集。牛掉皮革，鸡掉羽毛，皮革能制作入门护甲，羽毛做箭更省材料。农夫收购鸡蛋和皮革。
- 动物的位置、生命、繁殖冷却、幼崽成长、羊毛和鸡蛋随维度保存，远离后卸载模型，返回时恢复；不会因为刷新或走远重新生成同一批动物。未加载区域的养殖计时暂停。用方块围栏圈养，动物不会主动跨上整格高的墙。
- 夜间出现僵尸、骷髅弓手、蜘蛛和苦力怕。僵尸近战追逐，骷髅保持距离射箭，蜘蛛更快且白天通常中立；僵尸和骷髅在露天日照下燃烧。
- 苦力怕靠近后闪烁并引爆，破坏半径约 2.7 格的地形与容器；及时拉开距离可让引信熄灭。骨头可磨成骨粉，手持对麦苗右键 催熟。
- 活跃生物有数量上限，持久生物记录最多 2048 只；普通敌人随环境补充，远离或重载后不保留，携带方块的末影人例外。动物与敌人的掉落均以实体物品散落，靠近拾取。

## 装备与战斗

- 工具必须手持才生效：镐采石、斧砍木、铲挖土。木、石、铁、钻石各有速度与耐久差异；重复制作可保留备用工具。
- 使用游标把工具移入快捷栏，护甲放入对应装备槽；Shift 点击可装备到空位，点击装备槽可拿起或交换。铁甲提供 15 点护甲，钻石甲 20 点，每点减少 4% 战斗和灼烧伤害。摔落和饥饿不受护甲保护。
- 羊毛可捻成纤维线；木材与线制作弓，燧石、木棍与羽毛制作箭。任一手持弓按住右键蓄力，松开发射，约 1 秒满弓；先消耗副手的箭。箭受重力和阻力影响，入水减速，普通插地箭可走近回收；无限 / 创造箭不返还。
- 剑攻击快、斧攻击重但恢复慢；下落时近战可暴击。工具、武器和护甲会损耗，快捷栏显示耐久条；损坏后对应格位变空，备用装备需要手动移入。
- 装备耐久随箱子存取、维度切换和保存保留。飞行与插地箭是临时实体，40 秒后消失；退出或切换维度不会保留箭。
- 铁匠出售剑与胸甲，杂货商出售箭矢。

## 存档

每十五秒、返回首页、维度切换和离开页面时，自动写入当前浏览器的 `localStorage`。当前使用 `hexwild-save-v15`，记录 36 个固定格位、七格合成材料、独立装备槽、游标物品、选中的快捷栏及逐件装备的耐久、附魔、名称与加工惩罚、护甲及副手槽、27 格箱子库存、玩家经验与附魔选项种子、药水效果、附魔 / 锻造 / 切石的暂存输入、各维度炉具类型和库存 / 进度 / 经验、酿造台库存与进度、经验球与掉落物、死亡位置、植物生长进度、建筑树叶标记和自然树叶消散倒计时、创造飞行、各维度蹲伏姿态、红石安装面和供电状态及按钮 / 压力板计时；不提供旧格式导入、迁移或旧地形兼容。开发阶段允许存档格式变动，推荐新建世界体验。

暂停时世界不推进。熔炉的库存、烧炼进度、余火与待领取经验随维度保存，未加载区域不结算离线进度。作物按游戏内经过的时间生长。每个维度存储差异记录，不把无限生成的全部方块写入存档。

本地存储由浏览器配额限制；大量建造时建议定期导出 JSON 备份。写入失败会提示导出，不会清除现有存档。清理站点数据或换设备前请先备份。
