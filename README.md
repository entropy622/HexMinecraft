## 0.24：锻造与新生

- **铁砧与砂轮**：在工作台合成，放置后按 **E** 使用。铁砧需要 **3 铁块＋4 铁锭**，每铁块可由 9 铁锭合成或拆回；蜂巢配方中心显示叠放数量。砂轮需要 **2 原木＋1 石头＋2 木板**。新生成的铁匠铺也摆有开裂铁砧与砂轮。
- **材料修复**：铁砧每份材料修复最大耐久的约 **25%**，可选择最多使用 1 / 2 / 4 份，只消耗实际需要的数量；木、石、铁、钻石工具分别使用木板、石头、铁锭、钻石，护甲使用对应皮革或金属，盾牌使用木板。弓和鱼竿通过同类合并修复。
- **同类装备合并**：左侧装备保留，右侧副本消耗，耐久相加并获得最大耐久 **12%** 的额外修复，封顶满耐久。附魔取较高等级，同等级合并升一级，不超过各自上限；例如两把效率 IV 钻石镐可合成效率 V。结果、耐久、附魔和费用均先预览，确认前不消耗物品。
- **等级费用与铁砧损耗**：费用包含材料数量、修复、升级附魔、命名与两件装备已有的加工惩罚。修复或合并后的惩罚按 **0 → 1 → 3 → 7 → 15 → 31 → 63** 增长；费用达到 40 级时生存模式不能加工。每次成功使用有 **12%** 概率让铁砧进入下一阶段，完好、开裂、损坏之后消失，损耗阶段按方块类型保存，拆下再放不重置。
- **命名装备**：铁砧可为任意已有耐久装备设置最多 24 字的名称，留空恢复原名。单独命名不增加加工惩罚，费用最多 39 级；名称随具体装备保存，在背包、快捷栏、装备栏、箱子与加工面板显示。磨损、掉落和跨维度转移会保留名称。
- **砂轮祛魔与修复**：单件祛魔，或合并两件同类装备并获得最大耐久 **5%** 的额外修复，均免费。移除现有附魔、重置加工惩罚、保留左侧名称，并按被移除的附魔强度返还部分经验球；可重新放入附魔台。砂轮不能保留附魔，确认前会显示完整结果及经验返还量。
- 新增六向朝向的六棱铁砧、裂纹顶面、木架六角砂轮、加工动画、粒子与程序音效，使用九张新增授权像素材质，接入世界光照与阴影。创造模式免等级与材料费用，但仍需已有装备，合并仍消耗右侧副本，不返还砂轮经验。存档沿用 v7，逐件记录名称与加工惩罚；打开界面不会把物品留在隐藏槽位。

对照 [VoxeLibre 的铁砧](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ITEMS/mcl_anvils/init.lua) 与 [砂轮](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ITEMS/mcl_grindstone/init.lua) 的修复、合并、命名和祛魔概念，独立编写本项目的规则、UI 与模型。当前尚无附魔书、诅咒、铁砧下落砸伤、砂轮墙面安装或铁砧修理。验证仅生产构建与 GitHub Actions，未执行浏览器测试。

## 经验与秘法

- **经验等级与六棱光球**：开采天然煤、钻石、青金石和萤晶、拆除天然刷怪笼、击败成年生物、繁殖、钓鱼和村民交易可获得经验。烧炼经验保存在炉内，取出产物时按数量释放；小数经验累计，不因分批取出丢失。光球可沿无遮挡路径吸向玩家，五分钟后消失，未加载区域与暂停时冻结。
- **青金石与附魔台**：主世界 Y < 12 的地下新增青金石矿，石镐以上可采出 4–9 青金石。在工作台用 **4 黑曜石＋2 钻石＋1 书** 合成六棱附魔台，清理上方空间后按 **E** 打开。六棱台座使用授权像素材质，上方悬浮翻开的书与六枚紫色符文，台座接入彩色光传播。
- **六边形书架增幅**：在附魔台水平六边形半径两格的环上摆放书架，可与台座同层或高一层；对应的中间一格必须留出两格高的无水空气通道，最高计入 **18 书架**。三档分别需要 **8 / 16 / 30 级**、**0 / 6 / 18 书架**，实际消耗 **1 / 2 / 3 级与同数青金石**，最高档至多给予两种附魔。选项完整显示，关闭重开不刷新，成功附魔后更新。
- 加入 **效率 V、锋利 V、保护 IV、力量 V、耐久 III**：分别提高匹配工具采集速度、剑斧近战伤害、护甲减伤、弓箭伤害与装备使用寿命。不同装备只出现适用的附魔；附魔台只接受未附魔装备，铁砧可以合并，砂轮可以祛魔，尚无附魔书或经验修补。
- 附魔属于具体装备副本。背包可切换实际使用的那一件，箱内存取、整理、丢弃、死亡散落和跨维度保存都保留附魔与耐久。背包、快捷栏与装备格增加紫色流光，手持物和盾牌有柔和微光，附魔掉落物附带六边形光环。附魔面板支持分页和键盘焦点。
- 经验条显示当前等级；死亡清空携带经验，原地留下最多 **100 点**可回收经验。创造模式免除等级与青金石消耗，但仍需已有装备副本及书架。**存档升级为 v7，不兼容旧版，请创建新世界。**

参考 [VoxeLibre 的经验等级](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/HUD/mcl_experience/init.lua) 与 [附魔系统](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ITEMS/mcl_enchanting/engine.lua) 的玩法概念，独立编写 JavaScript 规则和六棱模型；新增四张纹理继续使用 Pixel Perfection / VoxeLibre 的 CC BY-SA 3.0 授权。验证范围为生产构建与 GitHub Actions，未运行浏览器或云端玩法测试。

## 晨雾流光

- **全部画质** 加入高度雾：水边与低地更浓，高处更清透，晨昏和雨天增强，沙漠减淡、雪原略增强；雾色随天空与太阳变化，洞穴维持暗部层次，进入液体时关闭空气雾。
- 暂停菜单选择 **「光影 · 体积雾与泛光」**，启用半分辨率、24 步视线采样的体积散射。采样场景深度、太阳阴影和六边形光照场，光线受树冠、房屋与地形遮挡，逆光方向更明显；火把、炉火、传送门和发光液体可染亮附近薄雾。
- 体积效果在泛光与最终颜色映射前合成；按深度处理半分辨率边缘，减少轮廓漏光。近处手持物保持清楚，实心格与液体格不生成空气散射，远处仍保留区块边界遮蔽。
- 云层加入投影，并以世界坐标缓慢随风漂移；远处循环铺排，近处云影不再跟随玩家平移。太阳阴影改用当前 Three.js 的 PCF 实现。
- 画质选择保存在本浏览器。**均衡 / 流畅** 使用轻量高度雾，**光影** 增加体积采样，显卡开销更高。推荐在晨昏的森林、水边或有窗的房屋里体验。

参考 [Photon 的解析雾与体积雾](https://github.com/sixthsurge/photon/tree/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/fog/overworld) 对密度、散射和阴影的处理思路，GLSL 与 Three.js 后处理由本项目独立实现，没有打包 Photon 代码。此实现尚无时域积累和屏幕空间反射；仅完成生产构建与 GitHub Actions 验证，未运行浏览器画面或性能测试。

## 六面守护

- 在工作台用 **6 木板＋1 铁锭** 制作六棱盾牌，副手为空时自动装备。背包增加第五个装备格，点击盾牌装备/卸下，点击副手格也可切换；点击不同耐久的护甲或盾牌可换用对应副本。盾牌作为背包物品保存，占一格，拥有 **336 耐久**，箱内存取与掉落保留逐件耐久；批量补存会保留副手装备。
- **按住 R 举盾**，触屏按住「盾」按钮。准备约 **0.25 秒** 后生效，防护正面约 160° 的水平范围；近战与箭矢可完全挡下，正面爆炸减轻 70% 基础伤害，随后仍计算护甲与吸收。背后攻击、火焰、岩浆、窒息和摔落需要其他应对。
- 举盾时生存移动速度降至 35%，暂停冲刺、挖掘与攻击；松开 R 可继续挥击。食用会放下盾牌。格挡有声音、屏幕内盾牌震动、状态高亮和耐久消耗，每次消耗「基础伤害向上取整＋1」；损坏后有备用盾牌时自动换用。
- 增加木面、金属包边、中心盾扣、铆钉与握把组成的六棱盾模型，副手显示和举盾动作接入世界彩色光照。盾牌图标使用已有来源的授权像素素材。
- 挡下的箭会弹落，15 秒内可拾取；未挡住的近战、箭矢和爆炸会推动玩家，击退沿现有碰撞与小步物理处理，墙体会挡住推移。蹲行不能抵消外力造成的坠落。
- 新增 **六格挥击恢复条**，对应当前武器的实际冷却；盾牌状态显示举盾进度、格挡反馈和剩余耐久。副手装备随玩家保存与跨维度携带。

对照 [VoxeLibre 的盾牌实现](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ITEMS/mcl_shields/init.lua) 的方向判定、副手与磨损概念，独立编写本项目规则和模型。盾牌支持耐久附魔，暂未加入花纹或斧头破防。验证仅生产构建与 GitHub Actions，未运行浏览器测试。

## 荒野的节奏

- 食用改为 **按住 F 或右键 1.6 秒**，触屏按住 F；手持食物时 E 可启动一次食用。F 优先使用手持食物，否则从背包选择饱和度较高的普通食物。松开、切换快捷栏、攻击、受伤或打开界面会中断，完成后才扣除物品；食用时减速，有手持动画、声音与进度条。所有食物都可装入快捷栏，容器与耕种交互优先。
- 新增 **饱和度和消耗**：移动、冲刺、游泳、划船、跳跃、采矿与攻击会积累消耗，每 4 点先扣饱和度，再扣饱食。普通食物恢复饱食和饱和度；满饱食且有饱和度时约每秒恢复 1 生命，饱食至少 18 时约每 4 秒恢复 1 生命，回血会额外消耗食物储备。饱食不超过 6 时无法冲刺，空腹每 4 秒损失 1 生命，最低保留 1 点。
- 头部浸入液体会消耗 **15 秒氧气**，HUD 用十个六边形气泡显示。耗尽后每 2 秒受到 2 点窒息伤害，浮出水面约 3 秒补满；护甲不能抵消窒息。
- 岩浆中每秒造成 4 点基础灼伤，离开后继续燃烧约 6 秒、每秒 1 点基础伤害。跳入水或萤晶液、站在露天雨中可灭火；画面增加像素火焰、状态倒计时和低生命提示。
- **金苹果** 恢复 4 饱食和 9.6 饱和度，给予 5 秒生命恢复和 2 分钟伤害吸收，最多额外吸收 4 点伤害；满饱食也可食用。**牛奶** 清除状态效果并返还空桶，适合后续药水玩法。
- 饱和度、消耗、氧气、燃烧和效果计时随玩家保存、跨维度保留；暂停和打开界面时冻结。未完成的食用动作不保存。

参考 [VoxeLibre 的饥饿系统](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/PLAYER/mcl_hunger/hunger.lua) 的饱和度与消耗模型，独立编写本项目规则。验证范围为生产构建与 GitHub Actions，未运行浏览器测试。

## 收纳有方

- 储物箱改为 **27 格独立库存**。每格按物品类型堆叠，工具、护甲、装满的桶与船只各占一格；每件装备单独保存耐久，取回哪件就是哪件。箱子位置、槽位顺序与内容按维度保存。
- 新增像素风六边形储物界面，上方为箱子，下方为背包。点击存取，支持 **单件 / 半组 / 整组**；右键快捷转移一件，Shift 点击转移整组。半组按当前槽位数量向上取整，容量不足时只转移能装下的数量。
- **取出全部** 自动装入背包；**补存同类** 把背包中箱子已有的材料补入箱内，保留当前手持物和已穿戴护甲各一件；**整理箱子** 合并同类堆叠并按名称排序，同类装备按耐久排序。
- 背包支持中文名称/物品 ID 筛选与分页，展示实际堆叠和装备耐久条。触屏提供可点选的数量模式，窄屏改为六列；键盘 Tab 可在箱子面板中移动焦点。
- 六棱箱体加入独立箱盖、金属锁扣、六向朝向、开合动画和声音；放置时正面朝向玩家，上方一格被实心物体阻挡时无法打开。箱体和箱盖接入动态光照，开合更新阴影。
- 村庄与遗迹物资直接生成到槽位，拆除或爆炸会散落箱内物品并保留装备耐久。尚未加入双箱拼接和拖拽交换槽位。

## 提灯入野

- **手持火把、萤灯、萤石、萤晶、岩浆桶或萤晶液桶即可照明**，无需放置或额外按键，也不消耗物品。切换到其他物品后光照消失，HUD 会显示“随身照明”。适合夜间赶路、下矿探洞或乘船穿过地下水道。
- 随身光使用与建筑灯光相同的六向传播和材质遮挡，从玩家所在格发出，不会因挥手穿模而把光源送进墙后。光照随玩家跨格移动更新，最多每 0.25 秒一次；移动时复用静态天空光和世界灯光。
- 动物、敌人、村民、船体与船桨、手臂和手持物、掉落物、箭矢、作物以及鱼漂都接入世界光照。进入洞穴会变暗，走近火把或彩色灯源时染上对应光色；共享材质的多个模型也各自按所在位置受光。
- GPU 共享一张约 1.27 MiB 的三维光照纹理（默认 81 个数据区块），在六边形网格上插值并排除实心格，移除原有的八个近距离点光源。打开背包、地图或熔炉界面时，光照仍可完成更新，手持灯的照明保持。

继续参考 Photon 的体素光照与法线偏移取样思路，独立实现适合当前引擎的动态模型光照。随身照明属于视觉功能，不代替放置火把对作物与刷怪笼的现有玩法判定。自发光眼睛、火焰、粒子与天空保留自身表现；0.22 补充高度雾和体积散射，屏幕空间反射与时域抗锯齿尚未实现。

## 光落六野

- 新增 **15 级天空光与 RGB 方块光传播**，沿六个水平邻格和上下方向扩散。洞穴入口、窗户与门口可透入天光，实心墙与关闭的木门阻挡传播；树叶与水逐层削弱光线，玻璃透光，围栏和梯子允许减弱后的光通过。
- 火把、萤灯、燃烧中的熔炉、萤石、萤晶、刷怪笼、两种传送门、岩浆和萤晶液各有光色。附近地形受所有已加载发光单元影响，不再依赖离相机最近的八个点光源；光色随距离衰减，可在建筑内布置暖灯与彩光。
- 地形、木门等建筑、草丛、玻璃和液面共用光照场；挖墙、开关门、放置/移除光源、熔炉燃灭及液体流动会更新照明。地下水面的天空倒影随天光减弱，洞穴远雾也不再保持室外亮度。
- 光照只在变化后计算，最多每 0.25 秒一次，网格光照属性分帧上传，不为光照变化重建地形。所有画质档均启用，已有的高画质柔光仍可使用。

主要参考 [Photon 的 LPV 光传播与表面采样](https://github.com/sixthsurge/photon/tree/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/lpv)，独立实现适用于 Web 六棱柱世界的 CPU 光照场，没有复制其 GLSL 源码。0.17 建立方块照明，0.18 补齐动态模型与随身光。

## 六面行舟

- 工作台用 **5 木板** 制作橡木船，手持后对水面 **右键 / E** 放置。船占背包一格；对准空船 **E 上船**、**Ctrl+E 收回**，也可以用左键拆船。
- **W/S** 前后划行，**A/D** 按船头方向转向，鼠标独立观察周围，**空格** 刹船。前进最高约 8.5 m/s、倒退约 4 m/s，具有加速和滑行惯性，水面船桨动画、尾流和划水声随移动变化。
- **Shift 下船**；未手持鱼竿时也可按 E 下船。优先寻找附近能站立的岸边，其次水面；周围没有安全位置时留在船内。触屏使用方向、跳跃、下降和 E 按钮控制。
- 六边形木船采用现有像素木材，拥有实体船体碰撞与载客净空检查。船不能穿过岸边、围栏、其他船或低矮障碍，搁浅后可收回重新放置；不提供陆上划行。
- 支持在船上钓鱼：空格刹停，再换鱼竿，右键/E 抛线收杆；Shift 仍可下船。船只位置、朝向、速度、生命与乘坐状态按维度保存，未加载区域或暂停时冻结；跨维度旅行会把船留在原地。
- 船有 20 生命，斧拆船更快；爆炸会摧毁并掉落船，岩浆会烧毁且不掉落。不提供岩浆航行、动物乘客或运输箱，目前每艘船单人乘坐、每维度最多 128 艘。

本轮对照 [VoxeLibre 的 mcl_boats](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ENTITIES/mcl_boats/init.lua) 阅读了浮水判定、乘客分离、碰撞高度与速度衰减的处理方式。游戏中的 JavaScript 载具逻辑与六边形模型为独立实现，没有复制上游 Lua 代码或船模型。

## 水畔时光

- 工作台用 **3 原木 + 2 线** 制作鱼竿，也可向村庄渔夫购买。手持鱼竿，面向水面 **右键 / E** 抛线，再按一次收杆，**左键** 收起；触屏使用交互按钮。
- 抛出的六棱浮漂受重力影响，会落入水中或挂在岸上。鱼线连接手中鱼竿；等待时有涟漪，鱼群靠近后浮漂下沉并发出水花与声音，在提示窗口内收杆即可获得鱼获。错过后可留线继续等。
- 露天等待约 9–25 秒，再有 2.2 秒靠近过程；雨中加快 40%，有顶棚时变慢。鼠标收杆窗口 1.6 秒，触屏为 2.1 秒。水被填掉、鱼线受阻或距离超过 24 格时收回；切换手持物也会收起。
- 新增鳕鱼、鲑鱼、热带鱼与两种烤鱼，带像素图标。**按住 F 食用**，生鳕鱼/鲑鱼恢复 2 饱食，热带鱼 1，烤鳕鱼 5，烤鲑鱼 6。雪原更容易钓到鲑鱼，沙漠水域更容易钓到热带鱼。
- 一般鱼获占 90%，杂物占 10%；半径两格的六边形水域、两层平静水体、上方两格无遮挡时，变为 85% 鱼获、10% 杂物、5% 宝物。宝物包括书、绿宝石、末影珍珠或钻石，可建造自己的钓鱼池。
- 村庄新增两格深六边形鱼塘与戴草帽的渔夫，出售鱼竿和烤鱼、收购三种鱼。成功收杆消耗 1 耐久，挂住后收回消耗 2；鱼竿共 64 耐久。背包满时鱼获落在脚边。
- 暂停时冻结钓鱼，退出或切换维度后收起鱼线；已获得的物品正常存档。鱼竿支持耐久附魔，暂未加入水下游鱼、海之眷顾、饵钓或自动钓鱼。

## 炉火不息

- **E 打开熔炉**，从背包放入原料和燃料，自动连续烧炼；点击炉内槽取出物品，支持每次 1 / 8 / 一组。产物保存在炉内，背包满时无法取出。
- 煤与木炭各燃烧 80 秒，原木和木板 15 秒，岩浆桶 1000 秒并留下空桶。可烧铁、金、铜、肉与马铃薯；新增原木烧木炭、沙子烧玻璃。
- 每台炉子的存货、进度和剩余燃烧时间随维度保存。炉子面板打开时仍工作，暂停菜单、后台、未加载区域及离开的维度暂停模拟，不结算离线时间。
- 原料耗尽或产物满时余火仍消耗，不会继续点燃新燃料；熄火后未完成的进度逐渐冷却。拆除和爆炸散落炉内物品，已点燃的燃料不返还。
- 正面朝向放置者，燃烧时切换像素炉火并照亮周围。面板提供实时火焰与烧炼进度，新增木炭像素图标。

## 家与牧场

- 工作台新增橡木门、六向连接围栏、栅栏门与墙面木梯，配有像素物品图标、手持图标和独立几何模型。
- 门占两格高度，按玩家面向选择六个朝向。**E / 右键** 开关门和栅栏门，Ctrl+右键可对门旁建造；开关状态与朝向随存档及维度保存。拆任一半只掉落一扇门，失去地面支撑时也会掉落。
- 围栏向六个邻格的围栏、栅栏门或实心方块连接，高 1.5 格，可围住动物；栅栏门打开后允许通行。玩家、动物、箭矢和掉落物使用建筑形状的碰撞，围栏横档之间不允许身体钻过。
- 梯子贴在实心墙面，靠近后 **W / 空格** 上爬、**Shift** 下爬、**Ctrl** 停住；失去墙面支撑会掉落。支持六种墙面朝向。
- 村庄房屋增加可操作的木门，村民尝试通行时会开门。木制建筑用斧采集更快，新素材沿用 Pixel Perfection / VoxeLibre 许可。

目前门与栅栏门即时切换开关姿态，村民开门后不会自动关门；建筑件所在格尚未实现含水状态，红石控制仍未加入。

## 种植与收获

- 加入胡萝卜、马铃薯、甘蔗和橡树苗；小麦与蔬菜使用四阶段公开像素材质，瞄准植物显示成熟度，**E** 收获或查看条件，**左键** 拔除，土地保持不变。
- 手持麦种、胡萝卜或马铃薯，对耕地按 **E / 右键** 播种。充足光照且三格内有水时，小麦、胡萝卜、马铃薯分别约需 90、100、110 秒；干地为 35% 速度，露天雨水可加速到 150%。夜间或地下需要附近的火把或萤灯。离开加载区与暂停游戏均暂停生长，骨粉可催熟。
- 树叶有概率掉落树苗，在草地或泥土上种下后约 180 秒长成橡树，也可用骨粉催生。长树前检查树干与树冠空间及玩家/动物位置，不覆盖建筑；空间不足时等待。
- 甘蔗种在一格内有水的草地、泥土或沙地上，三格空间中生长约 120 秒。成熟后 E 收取上段并保留根部再生，左键则连根拔除。
- 村庄农田同时提供小麦和蔬菜，农夫出售蔬菜与甘蔗，并收购胡萝卜、马铃薯；村庄箱子含少量树苗和甘蔗。蔬菜也能吸引和繁殖猪。
- 加入烤马铃薯、糖、纸、书与六棱书架。甘蔗制糖和纸，纸与皮革制书；蛋糕配方加入糖。**按住 F 优先食用当前手持食物**，未手持食物时从背包选择。
- 植物种类与生长进度保存在 v5 存档；不兼容旧格式。新增 22 张素材继续使用 Pixel Perfection / VoxeLibre 的署名与许可。

当前尚无植物踩踏、自动收割或自然树叶衰减；书架可以装饰建筑，也能增强附魔台。

## 天气与氛围

- 主世界在晴朗、雨天与雷暴之间按种子轮换，天气平滑过渡并保存。雪原降雪、雷暴时雪势增强；沙漠保留阴云，不下雨。
- 加入六棱云团、雨线、像素雪花、地表溅水与远处闪电；阴云会削弱日光、遮住星月、改变天空与水面反射颜色，雨后露天地面的湿润高光会慢慢消退。
- 屋顶、玻璃和树冠遮挡雨雪，地下没有降水；进入屋内或水下后雨声变轻，雪原使用低沉风声。暂停菜单与后台暂停环境声。设置可单独关闭闪电与天空闪光。
- 露天且非雪原/沙漠的作物在足量降雨时额外获得约 50% 生长速度；阴雨抑制僵尸与骷髅日晒伤害，强雷暴允许白天生成敌对生物。主世界在雷暴中也能睡觉，醒来后天气逐渐转晴。
- 创造模式暂停菜单可选择天气，生存模式自然轮换。流畅画质使用较少的天气粒子，雨雪使用固定缓冲区批量绘制。

天气目前属于氛围与生存环境模拟：闪电不会引燃或损坏建筑，雪不会堆积，雨不会增加液体体积；湿润反光是天空颜色近似，不是屏幕空间或光线追踪反射。

## 掉落与背包

- 采矿、收获、击败生物会产生有像素材质的实体掉落物；靠近时吸附拾取，墙壁会阻挡拾取。水和萤晶液中会上浮，岩浆和虚空会销毁物品。
- 生存背包使用 36 格容量；普通材料每格 64 件，鸡蛋、珍珠、空桶每格 16 件，工具、护甲和装满的桶每格 1 件。快捷栏是背包物品的快捷引用。装备耐久随丢弃、拾取和箱子存取保留。
- **Q** 丢出一件，**Ctrl+Q** 丢出一组；背包 **Shift 点击** 丢出对应一组。触屏可打开「点击丢弃」后点物品。容量不足时无法拾取；合成等操作溢出的物资留在脚边。
- 死亡后背包和身上装备散落在原地，地图以红色 × 标记最近死亡地点及高度。普通物品保留 5 分钟，死亡物资 10 分钟，离开附近加载范围或暂停游戏会暂停计时。死亡标记保留到下次死亡，找回物资后不会自动消失。
- 掉落物与剩余时间按维度保存；最多同时显示 256 个近处掉落实体，超过显示预算的记录仍保存和模拟。存档升级到 v5，不读取旧格式。

## 村庄与交易

- 主世界新增按种子生成的六边形村庄：四栋可进入的房屋、阶梯屋顶、玻璃窗、道路、路灯、中央水井与两片灌溉农田。
- 出生点东侧约 Q24 / R0 有「晨谷村」，远方也会生成聚落；地图上用 ⌂ 标记，进入村庄会显示名称。
- 农夫、铁匠、杂货商和渔夫白天在村中活动，夜晚返回住处。靠近并瞄准村民按 **E** 打开交易；手持鱼竿时先换手，再与渔夫交谈。
- 小麦、原木和煤可换绿宝石，再换取面包、苹果、桶、铁锭或萤灯。每项交易每天限 4 次，库存记录会保存。
- 农田可以收获，屋内有少量初始物资和可使用的床、工作台或熔炉；已经收走的作物与箱子物资不会因重载刷新。

本次以新世界体验为准，不保证旧存档的地形兼容。村民目前为友好交易角色，采用简单的定点往返行为；尚未加入繁殖、袭击、复杂寻路或职业成长。

## 流动液体

- **铁桶与液体桶**：工作台用 3 个铁锭制作铁桶。在背包中点击桶装入快捷栏，用右键或 E 对准液体源装取；装满后对准地形倒出，生存模式会返还空桶。流动液体不能装桶，创造模式可直接选择三种液体桶。
- **六向流动**：水、岩浆、萤晶液优先向下流，落地后向六个邻格扩散，最远分别为 7、3、5 格。岩浆流速更慢；堵住水道会改道，移走源头后逐步退流。海域与下界熔岩海也由实际液体格组成。
- **液体反应**：水接触岩浆源生成黑曜石，接触流动岩浆生成石头。工作台用 **水桶 ×1 + 萤晶 ×2** 调制萤晶液桶；萤晶液带发光纹理，与岩浆接触生成萤石。
- **身体交互**：站进液体会减速，按空格上浮；岩浆会造成伤害，浸入液体时显示对应颜色的水下效果。
- **持久化**：液体源、流动状态和取走的天然源随区块卸载、维度切换和存档保留。

液体采用源头供给的离散模拟，不是体积守恒的物理流体。每轮有固定计算预算，大型瀑布可能需要更久稳定；离开已加载区域后暂停模拟，返回后继续。液体状态会增加存档大小，仍建议定期导出备份。岩浆与萤晶液参与彩色方块光传播。水与萤晶液不互相反应；目前没有蒸发、压力或无限水源生成。岩浆桶可以用作熔炉燃料。

## 像素材质

- 为方块使用 Pixel Perfection / VoxeLibre 16×16 像素材质与程序绘制的补充贴图：六边形顶面与侧面独立映射，包含草皮、树皮与年轮、矿脉、砖缝、工作台、箱子和熔炉等细节。
- 加入地形接触遮阴和实时太阳阴影、渐变天空、块状云、草丛与野花、流动水纹和发光熔岩。
- 手持方块使用对应材质，生物增加表面纹理与面部细节；保留现有物品图标。
- 「流畅」画质关闭实时阴影，保留纹理与接触遮阴。区块共用纹理图集和材质，草丛合批渲染，不影响采集射线或碰撞。
- 美术代码位于 `src/textures.js`，修改调色板或绘制规则即可制作自己的风格。公开材质随游戏打包，署名与媒体许可见 public/textures/NOTICE.md；代码与媒体分别遵循对应许可。

## 世界与玩法

- **无限水平世界**：8×8 轴向区块按位置生成与卸载，远行后依旧可以挖掘和建造。修改记录独立保存，返回区域会恢复建筑与被挖掉的方块。当前高度为 1–63 格。
- **主世界**：平原、森林、沙漠、雪原、海域、矿脉与地下空洞，昼夜交替。
- **下界**：绯红菌林、玄武岩荒地、岩层穹顶、萤石和熔岩海；熔岩会伤害生存玩家。
- **末地**：末地石浮岛、黑曜石柱、星空与虚空，重力更轻；掉入虚空会死亡并损失落入虚空的物资，随后在当前维度重生。
- **维度往返**：生存玩家合成传送门，放置后按 E；初次到达会生成安全落脚平台和返回门。三个维度分别记录地形、箱子、作物、重生点与上次位置。创造模式可以在暂停菜单直接旅行。
- **纯沙盒**：移除信标任务、任务追踪与通关弹窗。HUD 显示维度、生物群系和六向罗盘。
- **游戏界面**：立体标题、石质面板、九格物品栏、配方搜索、拾取提示、可保存的音量/画质/灵敏度设置。
- **动画与音效**：手持方块和镐、采集挥动、放置动作、行走摆动、受击反馈、作物轻摆、旋转传送门及转场。脚步、碎块、放置、合成、受伤和传送声音由 Web Audio 合成，不依赖外部音频。
- **继续生存**：木→石→铁→钻石工具、铁剑、工作台、熔炉、储物箱、床、锄地播种、小麦面包、食物、生物、生命和饱食度，均可继续使用。

这是独立的单人六边形体素沙盒，不是 Minecraft 完整移植。当前没有联机、红石电路或末影龙。工具有耐久并可附魔，死亡散落物资与部分经验；动物持久保存，敌对生物按环境生成。无限指水平地形持续按需生成，不表示浏览器内存、坐标精度或本地存储没有上限。

### 生存与维度

1. 采集原木，B 合成木板和木镐，把镐装入快捷栏并手持。制作并放置工作台，在五格范围内解锁进阶配方。
2. 石镐开采铁矿和萤晶，熔炉用煤烧铁；铁镐可以开采钻石矿与黑曜石。
3. 工作台配方 **3 岩石 + 2 煤 + 1 萤晶 → 4 黑曜石**。再用 **6 黑曜石 + 1 萤晶** 制作下界传送门。
4. 放置传送门，瞄准门体按 E 进入。到达后也可瞄准自动生成的返回门，按 E 回到主世界上次的位置。
5. 主世界夜行者掉落末影珍珠，下界生物掉落烈焰粉。**3 末影珍珠 + 3 烈焰粉 + 1 萤晶** 在工作台制作末地传送门。
6. 床只在主世界设置重生点并跳过夜晚。别在熔岩里游泳，也别忘了带足够的建筑材料跨越末地虚空。

这些是可自由选择的配方与玩法，没有强制任务或通关目标。

## 遗迹与地下探索

- 野外可发现古老瞭望塔、废弃矿道和苔石地牢；下界有余烬堡垒，末地有紫珀遗址。矿道与地牢有木制阶梯通向地面，沿入口逐级跳下即可探索。
- 遗迹内有食物、金属、火把与稀有材料宝箱。箱子只在首次生成时填充，拿走或破坏后不会重载补货。接近遗迹会记录发现，并在地图以 ◆ 标注；地下遗迹需要进入其高度范围才能发现。
- 刷怪笼在玩家 16 格内活动，每八秒尝试生成守卫。五格内放置火把或萤灯即可压制；石镐能拆除刷怪笼并回收萤晶。
- 煤和原木制作火把。火把是细六棱柱，不阻挡移动；覆盖区域的天空补光更暗，火把与灯具提供独立照明，最多同时显示离玩家最近的八盏局部灯。
- 深层有深板岩与金矿，普通岩层也可找到铜矿。铁镐开采金矿、石镐开采铜矿，熔炉分别炼成金锭和铜锭，可制作金块、切制铜块和金苹果。
- 手持金苹果按住右键或按 E 食用，恢复 4 点饱食，并给予生命恢复和伤害吸收。新增苔石砖、砂岩、下界砖与紫珀装饰配方。

## 动物、养殖与敌人

- 主世界可遇见绵羊、奶牛、猪和鸡。手持小麦吸引牛羊、苹果吸引猪、麦种吸引鸡；对动物按 E（或右键）喂食。附近两只已喂食的同类会繁殖，幼崽在加载区域约三分钟成年，喂食可加速。
- 两块铁锭制作剪刀，对成年羊按 E 得到三份羊毛；在草地上约两分钟长回。铁桶对成年牛按 E 挤奶，奶牛休息 30 秒；牛奶可右键饮用，也可与鸡蛋、小麦做蛋糕，制作返还铁桶。
- 成年鸡约每 150 秒产一个蛋，最多暂存八枚；换下麦种后对鸡按 E 收集。牛掉皮革，鸡掉羽毛，皮革能制作入门护甲，羽毛做箭更省材料。农夫收购鸡蛋和皮革。
- 动物的位置、生命、繁殖冷却、幼崽成长、羊毛和鸡蛋随维度保存，远离后卸载模型，返回时恢复；不会因为刷新或走远重新生成同一批动物。未加载区域的养殖计时暂停。用方块围栏圈养，动物不会主动跨上整格高的墙。
- 夜间出现僵尸、骷髅弓手、蜘蛛和苦力怕。僵尸近战追逐，骷髅保持距离射箭，蜘蛛更快且白天通常中立；僵尸和骷髅在露天日照下燃烧。
- 苦力怕靠近后闪烁并引爆，破坏半径约 2.7 格的地形与容器；及时拉开距离可让引信熄灭。骨头可磨成骨粉，手持对麦苗按 E 催熟。
- 活跃生物有数量上限，动物记录最多 2048 只；敌人随夜间补充，远离或重载后不保留。动物掉落仍直接进入玩家背包。

## 装备与战斗

- 工具必须手持才生效：镐采石、斧砍木、铲挖土。木、石、铁、钻石各有速度与耐久差异；重复制作可保留备用工具。
- 在背包点击工具装入当前快捷栏，点击护甲穿戴；四个装备槽可点击卸下。铁甲提供 15 点护甲，钻石甲 20 点，每点减少 4% 战斗和灼烧伤害。摔落和饥饿不受护甲保护。
- 羊毛可捻成纤维线；木材与线制作弓，石头、木材和线制作箭。手持弓按住左键蓄力，松开发射，约 1.1 秒满弓。箭受重力影响，入水减速，插在地面的箭可走近回收。
- 剑攻击快、斧攻击重但恢复慢；下落时近战可暴击。工具、武器和护甲会损耗，快捷栏显示耐久条；损坏后会使用背包中的备用同类装备。
- 装备耐久随箱子存取、维度切换和保存保留。飞行与插地箭是临时实体，40 秒后消失；退出或切换维度不会保留箭。
- 铁匠出售剑与胸甲，杂货商出售箭矢。

## 存档

每十五秒、返回首页、维度切换和离开页面时，自动写入当前浏览器的 `localStorage`。当前使用 `hexwild-save-v7`，记录逐件装备的耐久、附魔、名称与加工惩罚、护甲及副手槽、27 格箱子库存、玩家经验与附魔选项种子、各维度经验球与掉落物、死亡位置和植物生长进度；不提供旧格式导入、迁移或旧地形兼容。开发阶段允许存档格式变动，推荐新建世界体验。

暂停时世界不推进。熔炉的库存、烧炼进度、余火与待领取经验随维度保存，未加载区域不结算离线进度。作物按游戏内经过的时间生长。每个维度存储差异记录，不把无限生成的全部方块写入存档。

本地存储由浏览器配额限制；大量建造时建议定期导出 JSON 备份。写入失败会提示导出，不会清除现有存档。清理站点数据或换设备前请先备份。

需要 Node.js 22.12+ 和 npm。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

本机已有 Chrome 时，可设置 `PLAYWRIGHT_CHANNEL=chrome`；PowerShell 使用 `$env:PLAYWRIGHT_CHANNEL='chrome'`。开发版的 `window.__hexwild` 仅用于确定性回归，生产构建会移除它。

### 实现结构

- `src/core.js`：六边形数学、物品与蜂巢配方。
- `src/structures.js`：跨区块遗迹模板、入口、战利品与探索地点。
- `src/world.js`：确定性分块生成、三维度、生物群系、树冠跨区块边界与差异持久化。
- `src/villages.js`：聚落布局、地形整平、建筑、农田与交易规则。
- `src/fauna.js` / `src/mob-data.js` / `src/mob-graphics.js`：分区动物记录、养殖计时、生物模型与敌人行为。
- `src/villagers.js`：村民模型、昼夜活动与交互射线。
- `src/fluids.js`：液体类型、有限工作队列、源与退流、凝固反应、区块快照。
- `src/fluid-graphics.js`：分块六棱液面、瀑布、材质动画与桶射线。
- `src/save.js`：当前格式存档校验。
- `src/graphics.js`：区块局部坐标网格、可见面剔除、有限渲染队列、光照、粒子、手持物与传送门。
- `src/voxel-light.js` / `src/skylight.js`：六向天空光与彩色方块光传播、材质遮光、表面采样和着色器接入。
- `src/dynamic-light.js`：共享三维光照纹理、六边形插值和动态模型受光，不为移动模型复制材质。
- `src/chests.js` / `src/chest-ui.js` / `src/chest-graphics.js`：27 格库存、容量与耐久转移、像素储物面板及六棱箱盖动画。
- `src/survival.js`：食物营养、饱和度与消耗、自然恢复、氧气、燃烧、生命恢复及伤害吸收。
- `src/combat.js` / `src/shield-graphics.js`：举盾准备、方向防御与六棱副手盾牌，配合 `src/movement.js` 的碰撞击退。
- `src/atmosphere.js` / `src/atmosphere-pass.js`：高度雾、受阴影和彩色体素光约束的体积散射、深度边缘合成。
- `src/experience.js`：经验等级曲线、六棱经验球、吸附拾取与经验持久化。
- `src/enchanting*.js`：附魔数据、六向书架增幅、固定选项、装备副本面板与悬浮书模型。
- `src/smithing*.js`：铁砧材料修复、同类附魔合并、命名、加工费用、砂轮祛魔与修复、预览面板及六棱工作站模型。
- `src/textures.js`：16×16 像素图集、Pixel Perfection 纹理与程序纹理、边缘留白、共享纹理缓存。
- `src/audio.js`：浏览器交互后启动的程序化音效库。
- `src/main.js`：玩家物理、生存与交互、维度状态、输入、UI 和主循环。
- `tests/`：核心规则、负坐标接缝、远坐标生成、卸载恢复、跨维度存档、格式校验、实际射线操作和浏览器回归。

当前活动维度最多驻留 81 个数据区块、49 个渲染区块。移动后优先生成周围数据，再分帧提交新网格；离开的网格释放 GPU 几何资源。区块顶点使用局部坐标，避免远距离全局 Float32 顶点精度丢失。编辑记录会随玩家建造量增长。

### GitHub Actions / Pages

`main` 每次 push 执行锁文件安装与生产构建，通过后部署 Pages。PR 只验证。默认只执行生产构建；保留的本地测试脚本可按需使用，不在云端启动浏览器。

Pages 使用 GitHub Actions，产物目录为 `dist/`。Vite 使用相对路径，兼容 `/HexMinecraft/`，不需要后端或密钥。
