# HEXWILD · 六野

**六个方向，三个维度。没有任务终点，只有你的世界。**

[在线游玩](https://entropy622.github.io/HexMinecraft/) · [操作说明](#操作) · [本地开发](#开发与验证)

## 0.5：旷野邻居

- 主世界新增按种子生成的六边形村庄：四栋可进入的房屋、阶梯屋顶、玻璃窗、道路、路灯、中央水井与两片灌溉农田。
- 出生点东侧约 Q24 / R0 有「晨谷村」，远方也会生成聚落；地图上用 ⌂ 标记，进入村庄会显示名称。
- 农夫、铁匠和杂货商白天在村中活动，夜晚返回住处。靠近并瞄准村民按 **E** 打开交易。
- 小麦、原木和煤可换绿宝石，再换取面包、苹果、桶、铁锭或萤灯。每项交易每天限 4 次，库存记录会保存。
- 农田可以收获，屋内有少量初始物资和可使用的床、工作台或熔炉；已经收走的作物与箱子物资不会因重载刷新。

本次以新世界体验为准，不保证旧存档的地形兼容。村民目前为友好交易角色，采用简单的定点往返行为；尚未加入繁殖、袭击、复杂寻路或职业成长。

## 流动液体

- **铁桶与液体桶**：工作台用 3 个铁锭制作铁桶。在背包中点击桶装入快捷栏，用右键或 E 对准液体源装取；装满后对准地形倒出，生存模式会返还空桶。流动液体不能装桶，创造模式可直接选择三种液体桶。
- **六向流动**：水、岩浆、萤晶液优先向下流，落地后向六个邻格扩散，最远分别为 7、3、5 格。岩浆流速更慢；堵住水道会改道，移走源头后逐步退流。海域与下界熔岩海也由实际液体格组成。
- **液体反应**：水接触岩浆源生成黑曜石，接触流动岩浆生成石头。工作台用 **水桶 ×1 + 萤晶 ×2** 调制萤晶液桶；萤晶液带发光纹理，与岩浆接触生成萤石。
- **身体交互**：站进液体会减速，按空格上浮；岩浆会造成伤害，浸入液体时显示对应颜色的水下效果。
- **持久化**：液体源、流动状态和取走的天然源随区块卸载、维度切换和存档保留。已有 0.1–0.3 存档可继续读取。

液体采用源头供给的离散模拟，不是体积守恒的物理流体。每轮有固定计算预算，大型瀑布可能需要更久稳定；离开已加载区域后暂停模拟，返回后继续。液体状态会增加存档大小，仍建议定期导出备份。萤晶液为自发光表面，不向周围投射动态光。水与萤晶液不互相反应；目前没有蒸发、压力、无限水源生成或液体熔炉燃料。

## 像素材质

- 为所有方块增加原创 16×16 像素贴图：六边形顶面与侧面独立映射，包含草皮、树皮与年轮、矿脉、砖缝、工作台、箱子和熔炉等细节。
- 加入地形接触遮阴和实时太阳阴影、渐变天空、块状云、草丛与野花、流动水纹和发光熔岩。
- 手持方块使用对应材质，生物增加表面纹理与面部细节；保留现有物品图标。
- 「流畅」画质关闭实时阴影，保留纹理与接触遮阴。区块共用纹理图集和材质，草丛合批渲染，不影响采集射线或碰撞。
- 美术代码位于 `src/textures.js`，修改调色板或绘制规则即可制作自己的风格。素材由代码生成，使用项目 MIT 许可，无需下载纹理包。存档格式保持兼容。

## 世界与玩法

- **无限水平世界**：8×8 轴向区块按位置生成与卸载，远行后依旧可以挖掘和建造。修改记录独立保存，返回区域会恢复建筑与被挖掉的方块。当前高度为 1–63 格。
- **主世界**：平原、森林、沙漠、雪原、海域、矿脉与地下空洞，昼夜交替。
- **下界**：绯红菌林、玄武岩荒地、岩层穹顶、萤石和熔岩海；熔岩会伤害生存玩家。
- **末地**：末地石浮岛、黑曜石柱、星空与虚空，重力更轻；掉入虚空会回到当前维度出生点并受伤。
- **维度往返**：生存玩家合成传送门，放置后按 E；初次到达会生成安全落脚平台和返回门。三个维度分别记录地形、箱子、作物、重生点与上次位置。创造模式可以在暂停菜单直接旅行。
- **纯沙盒**：移除信标任务、任务追踪与通关弹窗。HUD 显示维度、生物群系和六向罗盘。
- **游戏界面**：立体标题、石质面板、九格物品栏、配方搜索、拾取提示、可保存的音量/画质/灵敏度设置。
- **动画与音效**：手持方块和镐、采集挥动、放置动作、行走摆动、受击反馈、作物轻摆、旋转传送门及转场。脚步、碎块、放置、合成、受伤和传送声音由 Web Audio 合成，不依赖外部音频。
- **继续生存**：木→石→铁→钻石工具、铁剑、工作台、熔炉、储物箱、床、锄地播种、小麦面包、食物、生物、生命和饱食度，均可继续使用。

这是独立的单人六边形体素沙盒，不是 Minecraft 完整移植。当前没有联机、红石电路、末影龙、附魔或工具耐久。死亡保留背包；生物重新加载时重新生成。无限指水平地形持续按需生成，不表示浏览器内存、坐标精度或本地存储没有上限。

### 生存与维度

1. 采集原木，B 合成木板和木镐，把镐装入快捷栏并手持。制作并放置工作台，在五格范围内解锁进阶配方。
2. 石镐开采铁矿和萤晶，熔炉用煤烧铁；铁镐可以开采钻石矿与黑曜石。
3. 工作台配方 **3 岩石 + 2 煤 + 1 萤晶 → 4 黑曜石**。再用 **6 黑曜石 + 1 萤晶** 制作下界传送门。
4. 放置传送门，瞄准门体按 E 进入。到达后也可瞄准自动生成的返回门，按 E 回到主世界上次的位置。
5. 主世界夜行者掉落末影珍珠，下界生物掉落烈焰粉。**3 末影珍珠 + 3 烈焰粉 + 1 萤晶** 在工作台制作末地传送门。
6. 床只在主世界设置重生点并跳过夜晚。别在熔岩里游泳，也别忘了带足够的建筑材料跨越末地虚空。

这些是可自由选择的配方与玩法，没有强制任务或通关目标。

## 遗迹与地下探索

- 野外可发现古老瞭望塔、废弃矿道和苔石地牢；下界有余烬堡垒，末地有紫珀遗址。矿道与地牢有木制阶梯通向地面，沿入口逐级跳下即可探索。
- 遗迹内有食物、金属、火把与稀有材料宝箱。箱子只在首次生成时填充，拿走或破坏后不会重载补货。接近遗迹会记录发现，并在地图以 ◆ 标注；地下遗迹需要进入其高度范围才能发现。
- 刷怪笼在玩家 16 格内活动，每八秒尝试生成守卫。五格内放置火把或萤灯即可压制；石镐能拆除刷怪笼并回收萤晶。
- 煤和原木制作火把。火把是细六棱柱，不阻挡移动；覆盖区域的天空补光更暗，火把与灯具提供独立照明，最多同时显示离玩家最近的八盏局部灯。
- 深层有深板岩与金矿，普通岩层也可找到铜矿。铁镐开采金矿、石镐开采铜矿，熔炉分别炼成金锭和铜锭，可制作金块、切制铜块和金苹果。
- 手持金苹果右键或 E 食用，恢复 8 点生命和 8 点饱食。新增苔石砖、砂岩、下界砖与紫珀装饰配方。

## 动物、养殖与敌人

- 主世界可遇见绵羊、奶牛、猪和鸡。手持小麦吸引牛羊、苹果吸引猪、麦种吸引鸡；对动物按 E（或右键）喂食。附近两只已喂食的同类会繁殖，幼崽在加载区域约三分钟成年，喂食可加速。
- 两块铁锭制作剪刀，对成年羊按 E 得到三份羊毛；在草地上约两分钟长回。铁桶对成年牛按 E 挤奶，奶牛休息 30 秒；牛奶可右键饮用，也可与鸡蛋、小麦做蛋糕，制作返还铁桶。
- 成年鸡约每 150 秒产一个蛋，最多暂存八枚；换下麦种后对鸡按 E 收集。牛掉皮革，鸡掉羽毛，皮革能制作入门护甲，羽毛做箭更省材料。农夫收购鸡蛋和皮革。
- 动物的位置、生命、繁殖冷却、幼崽成长、羊毛和鸡蛋随维度保存，远离后卸载模型，返回时恢复；不会因为刷新或走远重新生成同一批动物。未加载区域的养殖计时暂停。用方块围栏圈养，动物不会主动跨上整格高的墙。
- 夜间出现僵尸、骷髅弓手、蜘蛛和苦力怕。僵尸近战追逐，骷髅保持距离射箭，蜘蛛更快且白天通常中立；僵尸和骷髅在露天日照下燃烧。
- 苦力怕靠近后闪烁并引爆，破坏半径约 2.7 格的地形与容器；及时拉开距离可让引信熄灭。骨头可磨成骨粉，手持对麦苗按 E 催熟。
- 活跃生物有数量上限，动物记录最多 2048 只；敌人随夜间补充，远离或重载后不保留。动物掉落仍直接进入玩家背包。

## 装备与战斗

- 工具必须手持才生效：镐采石、斧砍木、铲挖土。木、石、铁、钻石各有速度与耐久差异；重复制作可保留备用工具。
- 在背包点击工具装入当前快捷栏，点击护甲穿戴；四个装备槽可点击卸下。铁甲提供 15 点护甲，钻石甲 20 点，每点减少 4% 战斗和灼烧伤害。摔落和饥饿不受护甲保护。
- 羊毛可捻成纤维线；木材与线制作弓，石头、木材和线制作箭。手持弓按住左键蓄力，松开发射，约 1.1 秒满弓。箭受重力影响，入水减速，插在地面的箭可走近回收。
- 剑攻击快、斧攻击重但恢复慢；下落时近战可暴击。工具、武器和护甲会损耗，快捷栏显示耐久条；损坏后会使用背包中的备用同类装备。
- 装备耐久随箱子存取、维度切换和保存保留。飞行与插地箭是临时实体，40 秒后消失；退出或切换维度不会保留箭。
- 铁匠出售剑与胸甲，杂货商出售箭矢。

## 存档

每十五秒、返回首页、维度切换和离开页面时，自动写入当前浏览器的 `localStorage`。当前使用 `hexwild-save-v3`，记录每件装备的耐久、护甲槽和箱内装备；不再提供 v1/v2 存档导入、迁移或旧地形兼容。开发阶段允许存档格式变动，推荐新建世界体验。

暂停时世界不推进。未完成的熔炼在存档恢复或切换维度时退回原料。作物按游戏内经过的时间生长。每个维度存储差异记录，不把无限生成的全部方块写入存档。

本地存储由浏览器配额限制；大量建造时建议定期导出 JSON 备份。写入失败会提示导出，不会清除现有存档。清理站点数据或换设备前请先备份。

## 开发与验证

需要 Node.js 22.12+ 和 npm。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

本机已有 Chrome 时，可设置 `PLAYWRIGHT_CHANNEL=chrome`；PowerShell 使用 `$env:PLAYWRIGHT_CHANNEL='chrome'`。开发版的 `window.__hexwild` 仅用于确定性回归，生产构建会移除它。

### 实现结构

- `src/core.js`：六边形数学、物品与蜂巢配方。
- `src/structures.js`：跨区块遗迹模板、入口、战利品与探索地点。
- `src/world.js`：确定性分块生成、三维度、生物群系、树冠跨区块边界与差异持久化。
- `src/villages.js`：聚落布局、地形整平、建筑、农田与交易规则。
- `src/fauna.js` / `src/mob-data.js` / `src/mob-graphics.js`：分区动物记录、养殖计时、生物模型与敌人行为。
- `src/villagers.js`：村民模型、昼夜活动与交互射线。
- `src/fluids.js`：液体类型、有限工作队列、源与退流、凝固反应、区块快照。
- `src/fluid-graphics.js`：分块六棱液面、瀑布、材质动画与桶射线。
- `src/save.js`：当前格式存档校验。
- `src/graphics.js`：区块局部坐标网格、可见面剔除、有限渲染队列、光照、粒子、手持物与传送门。
- `src/textures.js`：16×16 像素图集、Pixel Perfection 纹理与程序纹理、边缘留白、共享纹理缓存。
- `src/audio.js`：浏览器交互后启动的程序化音效库。
- `src/main.js`：玩家物理、生存与交互、维度状态、输入、UI 和主循环。
- `tests/`：核心规则、负坐标接缝、远坐标生成、卸载恢复、跨维度存档、格式校验、实际射线操作和浏览器回归。

当前活动维度最多驻留 81 个数据区块、49 个渲染区块。移动后优先生成周围数据，再分帧提交新网格；离开的网格释放 GPU 几何资源。区块顶点使用局部坐标，避免远距离全局 Float32 顶点精度丢失。编辑记录会随玩家建造量增长。

### GitHub Actions / Pages

`main` 每次 push 执行锁文件安装与生产构建，通过后部署 Pages。PR 只验证。默认只执行生产构建；保留的本地测试脚本可按需使用，不在云端启动浏览器。

Pages 使用 GitHub Actions，产物目录为 `dist/`。Vite 使用相对路径，兼容 `/HexMinecraft/`，不需要后端或密钥。
