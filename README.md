## 0.39：虚空上的城

- **六角末地城**：首座城固定在 **Q 66 / R −16**，主塔有四层，周围三座不同高度的侧塔，通过十二格高的连桥连接。六面末地石砖墙、紫珀柱、玻璃窗与逐级外挑的紫珀屋檐组成新的天际线。内部环绕半砖阶梯逐次升高半格，换层处留出净空，并有备用内梯；可沿台阶探索、跳过缺口，也可搭建自己的路线。
- **船与城连在一起**：首座城西侧连桥连接现有首艘末地船的船头，折跃门仍通往原外圈浮岛，登船后可以继续进城。外围按种子生成更多末地城，具有两到三座侧塔、不同朝向，约一半附带一艘通过桥连接的末地船；其他区域仍有少量独立末地船和遗址。固定城与中央竞技场附近留出距离，避免随机建筑重叠。
- **分层守卫与宝藏**：主塔和侧塔分布潜影贝，沿用真实生命、附着朝向和击败不重刷的保存规则。每塔上层有一次性宝箱，提供钻石、金锭、绿宝石、烟花及一件附魔钻石装备：镐 / 斧有 **效率 III、耐久 II**，胸甲 / 靴子有 **保护 III、耐久 II**。附属船舱继续提供鞘翅和修复材料。装备使用实际物品数据，拿取、丢弃、放入潜影盒和存档保留附魔。
- **末地建筑材料**：新增 **末地石砖、紫珀柱、末地烛**，均可采集并在创造物品库取得。工作台用 **4 末地石制作 4 石砖**、**2 紫珀制作 2 柱**、**1 烈焰棒＋1 紫珀制作 4 末地烛**；最后一项是六野配方。末地烛使用细六棱模型、冷白色体素照明，能够手持，也有实际形状的物品图标和掉落模型；当前只直立放置。

城市布局和战利品按种子确定，分区生成并在最后应用玩家修改；发现城市时记录地图，允许在城中较高楼层触发发现。首座城加入连片浮岛，不迁移旧地形，建议新建世界体验完整结构。参考 [VoxeLibre 末地城](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/MAPGEN/mcl_structures/end_city.lua) 的塔楼、船、潜影贝和分层战利品概念，几何布局与台阶、生成、桥梁和战利品规则均为独立实现，未使用上游示意文件、模型或代码。新增四张 CC BY-SA 3.0 未修改纹理并保留署名，沿用 v10 存档。本轮只做生产构建与 GitHub Actions，未运行浏览器或云端玩法测试。

## 0.38：仓库随行

- **潜影壳有了用途**：在工作台按「潜影壳—储物箱—潜影壳」上下排布，制作一个紫色潜影盒。每盒占一个物品栏格，不能堆叠，内部有 **27 格**。放置后右键 / E 打开，沿用整组拿放、右键拆分、拖动、Shift 转移、数字键交换与丢弃操作。
- **装满再带走**：拆除潜影盒会掉落装着原物品的盒子，重新拾取、放置后继续使用。物品的槽位、数量，以及装备的耐久、附魔与自定义名称都会保留；Q 丢弃、面板外丢弃、满背包回收、死亡散落、爆炸破坏和保存 / 载入也保留内容。普通箱子可以装潜影盒，潜影盒内部禁止再放任何潜影盒，包括快捷移动和交换。
- **内容预览与外观**：悬停背包、合成或容器中的潜影盒，可查看已用格数和九列三行的图标 / 数量预览。使用已有公开紫色皮肤，分别映射六棱盒身与上盖，手持和掉落也有实际盒体模型；物品图标按同一皮肤投影，开盖上升并旋转，沿用潜影贝的合成开合声音。
- **空间与创造操作**：当前潜影盒直立放置，向上展开半格，开盖检查实际半砖 / 楼梯形状和站在箱顶的玩家。上方堵住时先移开障碍再打开。创造模式可从物品库取得空盒，在物品栏中用中键复制带内容的盒子；拆除空盒不掉落，拆除有内容的盒子会保留物资。

沿用 v10 格式的可选物品内容字段，无旧存档迁移；掉落物中的每只盒子独立保存，不能因合并掉落而覆盖内容。目前只有紫色与向上开启，尚无染色、朝墙 / 朝下放置、盒子命名或自动装卸。参考 [VoxeLibre 潜影盒](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ITEMS/mcl_chests/shulkers.lua) 的合成与携带存储概念，物品流转、六边形模型、图标和预览均为独立实现。没有新增下载素材；运行时紫色皮肤裁切保留 CC BY-SA 4.0。本轮仅生产构建与 GitHub Actions，未运行浏览器或云端玩法测试。

## 0.37：贝壳与浮空

- **末地守卫**：末地船和末地遗址各加入两只潜影贝，生命 **30**，位置、剩余生命与附着朝向持久保存。首次生成后不会因卸载 / 刷新重新补满，击败后也不重刷；创造模式下不主动攻击。玩家击败时给予 **5 经验**，有一半概率掉落一枚有像素图标的潜影壳。
- **闭壳与开壳**：独立六边形底壳、旋转升起的上盖、会看向玩家的头与公开紫色像素皮肤。闭壳时减少 **80%** 受到的伤害并反弹箭矢，开壳后可以正常攻击；不受普通击退与火焰伤害。潜影贝可以附着在地板、天花板和六个水平朝向的实心表面，低生命受攻击时有机会瞬移，失去支撑或接触液体时也会尝试寻找干燥的新表面。只在已加载地形寻找落点，检查真实形状和展开空间。
- **六向追踪弹**：看见约 **18 米**内的生存玩家后开壳，间隔约 **2.5–5.5 秒**射击。浅色星形潜影弹沿六个水平方向和上下转向追踪，尝试绕开近处障碍；碰到地形会破碎。可用近战、弓箭、雪球、鸡蛋或珍珠击落，正面举盾可以挡下伤害与状态。投射物最多同时 24 枚，十二秒消散，离开加载区、死亡、重生、传送或切换维度时清理，暂停冻结。
- **漂浮与反制**：追踪弹命中玩家造成 **4 点基础投射物伤害**，附加 **10 秒漂浮 I**，护甲与保护附魔仍生效。漂浮逐渐把竖直速度拉向每秒一米上升，沿用实际身体与顶头碰撞，期间停止鞘翅、不能重新展开，也不产生下落暴击。牛奶可以解除；结束后恢复重力，注意落地高度，可在效果结束后展开鞘翅。漂浮期间不受摔落伤害，相机高度仍以 160 为上限，图标与剩余时长显示在状态栏，并随存档保存。

目前潜影壳可以收集，尚未加入潜影盒、染色或潜影贝复制；追踪弹命中其他生物只造成伤害。参考 [VoxeLibre 潜影贝](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ENTITIES/mobs_mc/shulker.lua) 的定点守卫、闭壳与传送玩法概念，模型、八面附着、追踪路径、碰撞和声音由本项目独立实现，未打包其代码、模型或录音。新增四张未修改公开素材并保留分项许可，沿用 v10 存档。本轮仅生产构建与 GitHub Actions，未运行浏览器或云端玩法测试。

## 0.36：风过末地

- **更接近原版的物品操作**：沿用背包、箱子与工作站统一的整组拿放、右键分半 / 单件、拖动分配、Shift 转移、双击归拢、数字键交换和 Q 丢弃；加入 **Shift 双击批量转移同类物品**。拖动时显示实际物品图标与预计数量，跳过满格和不接受该物品的槽位；拿两件拖过更多格子时只选前两个有效格。拖动中使用键盘会取消旧分配计划，避免松开鼠标后再次提交。
- **鞘翅与飞行**：将鞘翅放入胸甲格，替代胸甲的防护。在空中重新按一次 **空格**展开，跟随视线转向，俯冲加速、抬头用速度换取高度。支持实际约 0.6 米的低姿态碰撞、高速撞墙伤害与落地减速，视角倾斜、速度视野、风声和尾迹。着陆、入水、上梯、脱下或耗尽鞘翅会停止滑翔；低屋檐下保持缓慢低姿态移动，到开阔处自动站起。
- **烟花助推与修复**：**1 纸＋1 火药制作 3 枚烟花火箭**。滑翔时右键 / E 获得约 **1.5 秒**助推，地面使用则升空绽放六向烟花，不造成爆炸伤害。鞘翅有 **432 耐久**，飞行每秒损耗一点，耐久附魔可减缓损耗；剩一点时破损停飞并保留物品。铁砧每片幻翼膜修复最多 **108 耐久**，支持耐久附魔，不能附加保护。
- **末地船与折跃门**：外围浮岛新增紫珀船体、船舱、栏杆、桅杆、灯与登船梯，宝箱含鞘翅、烟花、幻翼膜和其他补给。首艘船固定在 **Q 48 / R −16**，外围还会程序生成更多船。击败末影龙后，对准中央 **Q 0 / R 5** 的折跃门按 E / 右键，可到首艘船附近，并通过另一端返回中央；同一末地的地形和首领进度保留。
- **存储与画面**：保存飞行速度、助推余时、耐久计时与低姿态，暂停冻结；临时烟花和尾迹不保存。空中雾保留垂直高度层次，同时减弱区块边缘雾的垂直距离分量，让俯瞰地面更清楚。沿用 v10 存档，不做旧地形迁移；飞行高度上限为相机 Y 160。

当前没有潜影贝、完整末地城或幻翼生物，幻翼膜来自船舱补给；折跃门用交互键启动。新增三张未修改的鞘翅、烟花与幻翼膜公开图标，沿用 VoxeLibre 通用 CC BY-SA 3.0 并保留署名。飞行、末地船、烟花与声音均为独立实现。本轮只验证生产构建与 GitHub Actions，未运行浏览器或云端玩法测试。

## 0.35：六柱龙影

- **末地竞技场**：出生岛中央加入平坦浮岛、基岩祭坛和六座不同高度的黑曜石柱，每柱顶有一颗末地水晶。首次进入末地的返回门移到祭坛西侧，中央留给首领活动；外围继续生成浮岛、遗址和末影人。推荐新建世界体验完整竞技场，不提供旧地形迁移。
- **末影龙与阶段**：独立六棱龙身、长颈、头与下颌、细分尾巴、双翼膜和翼骨，公开像素龙皮肤与发光眼。末影龙有 **200 生命**，循环盘旋、低空冲袭、降落、栖息和升空，阶段由紫色首领条显示；创造模式不会受到主动攻击。
- **水晶与弱点**：尚存且无遮挡的最近水晶，每 **0.5 秒**为龙恢复 **1 生命**，显示治疗光束；摧毁正在治疗的水晶还会对龙造成 **10 点伤害**。水晶可用近战、弓箭和投掷物击碎，近处会爆炸。龙的头部承受完整伤害，身体、翼与尾部承受四分之一；栖息阶段免疫箭矢，要靠近攻击头部。
- **龙息与冲击**：冲袭和栖息时向玩家发射紫色龙息球，碰撞后形成持续 **8 秒**、半径逐渐增至约 **2.6 米**的六边形危险区。每秒可造成 **3 点魔法伤害**，普通护甲与盾牌不能挡下，保护附魔与吸收生命仍有效；墙体会阻隔危险区伤害。靠近龙头会受到八点基础近战伤害与现有击退 / 格挡规则影响。
- **胜利与再次挑战**：龙倒下后经历约十二秒消散，首次在中央留下 **12000 点经验、一个可采集装饰的龙蛋**，并在空位补充返回门。后续胜利给予 **500 点经验**，不再重复给龙蛋。工作台用 **5 玻璃＋1 恶魂之泪＋1 末影珍珠** 制作一颗末地水晶；击败龙后带六颗，站在中央附近，对准基岩祭坛或龙蛋按 **E / 右键**，消耗六颗重建晶柱，十五秒后再次召唤。当前水晶物品用于这个仪式，尚不支持任意地点摆放。
- **进度与边界**：生命、被摧毁水晶、胜利次数与召唤 / 消散倒计时沿用 v10 存档保存，离开维度后返回仍保留。暂停或离中央七十米后冻结首领；重载时恢复战斗进度并从盘旋开始，飞行中的龙息和危险区不保存。当前龙不会摧毁建筑，尚无龙息装瓶或末地折跃门，首领挑战是沙盒中的可选内容。

新增三张未修改公开素材：龙皮肤采用上游生物媒体 CC BY-SA 4.0，水晶图标与龙蛋纹理采用通用 CC BY-SA 3.0；保留完整署名。模型、UV、飞行、首领规则、龙息与声音均为独立实现，没有打包上游模型、首领代码或录音。本轮仅生产构建与 GitHub Actions，未执行浏览器或云端玩法测试。

## 0.34：半格之间

- **十二种建筑件**：橡木、岩石、石砖、砂岩、下界砖和紫珀各增加半砖与楼梯。在工作台用 **3 个原材料制作 6 半砖**，**6 个原材料制作 4 楼梯**；配方册可直接填料。创造物品库也可搜索并取用，石质与木质版本沿用对应材料的采集工具和纹理。
- **上下半砖与合并**：瞄准侧面下半部或方块顶面放下半砖，瞄准侧面上半部或底面放上半砖。手持同种半砖点击它空着的顶面 / 底面，消耗一块补为双半砖；拆除双半砖返还两块。上半砖、倒置楼梯和双半砖的完整顶面可放门，双半砖的完整侧面可贴梯子。合并或放置会检查玩家、附近生物与船的占位。
- **六向楼梯**：按玩家面对的六个方向摆放，支持倒置。邻接楼梯的朝向决定 60° / 120° 的内外转角，可混合不同材质；增删邻格后更新形状。绘制、瞄准轮廓、碰撞和地面支持使用相同的六边形裁切轮廓，半砖不会占据空着的半格。
- **半格行走**：站在地面时自动踏上不超过 0.6 米的台阶，整格高墙仍需跳跃；相机短暂缓动，减少半格升高的突跳。落地和顶头碰撞更贴近实际表面。动物和村民也能走过半砖与楼梯，视线判定改用真实形状，保留门、围栏和梯子的规则。
- **屋顶与物品表现**：村庄房屋改为六面楼梯屋顶和半砖屋脊，沙漠村使用砂岩，其他村使用橡木；水井加入薄木顶。新建筑件有由实际轮廓与像素纹理投影的图标，手持和掉落物使用真实模型。同一区块的半砖 / 楼梯合并绘制，仍能逐格瞄准与拆除，露天顶部接入现有雨天湿润效果。
- 朝向、上下位置与双半砖状态沿用 v10 存档保存。当前半砖 / 楼梯按整格阻挡液体，同格不支持含水；没有加入旧存档迁移。新建世界可完整体验新的村庄屋顶。本轮仅生产构建与 GitHub Actions，未执行浏览器或云端玩法测试。

新增形状、投影图标与移动逻辑均为独立实现，继续复用已署名的公开像素纹理，没有新增下载素材。

## 0.33：凝视之间

- **真正的末影人**：主世界夜间与雷暴时较少出现，末地更常见；保留异界夜行者作为六野特色生物。末影人有 **40 生命**，平时中立，靠近不会直接攻击；对准双眼持续约 **0.25 秒**，或攻击它，会激怒它约一分钟。被直视时停步，移开视线后高速追击，近战造成 **7 点基础伤害**。创造模式不主动攻击玩家。
- **瞬移与掩体**：距离较远或受地形阻挡时，会尝试传送到玩家附近；被近战命中也可能瞬移。目的地需要已加载地形、可站立地面、近三格净空且无液体，不会传送进玩家身体或低矮屋檐。箭矢、雪球、鸡蛋和珍珠会被它闪避；无法找到落点时仍不受这些投射物影响。新增高身体的分段命中体积。
- **怕水与避雨**：接触水或萤晶液、在雨中暴露时每半秒受一点伤害并尝试瞬移逃离；雪原降雪与沙漠阴云不会造成雨伤。接触岩浆也会逃离，仍受岩浆伤害。白天未被激怒时尝试寻找阴影，不像僵尸那样直接日照燃烧。

## 柔影入微

- 暂停菜单选择 **「光影 · 柔影与晨雾」**，在已有体积雾、日照阴影与柔光之外加入 **GTAO 屏幕空间环境遮蔽**。根据当前帧深度重建法线，强化墙角、建筑接缝、树根、台座与物体相接处的近景层次；采用约 1.15 米的采样半径，限制最深暗化，保留像素材质与洞穴已有光色。
- 接触阴影以半分辨率计算，使用 Three.js 的 GTAO 和八点 Poisson 滤波，再按深度约束回到完整分辨率；近处、远处与屏幕边缘逐渐淡出，避免将轮廓直接糊成黑边。透明水面、玻璃、传送门、发光基础材质与第一人称手持物通过保护层排除阴影接收，进入液体时跳过此效果。
- 加入 **SMAA 边缘抗锯齿**，在线性颜色阶段处理，位于柔光之后、最终 ACES 映射与 sRGB 输出之前。改善六棱轮廓和斜线边缘，不改为平滑纹理；像素图仍使用最近邻放大，界面文字与图标不经过场景后处理。
- 画质菜单可单独调整 **接触阴影 0–100%**、**边缘抗锯齿开关**与 **柔光 0–50%**，默认分别为 60%、开启与 24%。阴影或柔光设为零会跳过对应计算；均衡与流畅禁用这组细节。设置保存在本机浏览器，切换画质后仍保留。
- 统一画布与全部后处理缓冲区的像素密度，高画质的**像素比上限为 1.25**，不超过设备像素比，修正过去画布和后处理分辨率不一致时的放大模糊；窗口变化会一并调整深度、阴影滤波、体积雾和抗锯齿缓冲。均衡上限 1，流畅上限 0.65。
- 场景颜色与深度使用独立捕获目标，避免开启/关闭效果或颜色缓冲交换时读取错误深度；切回均衡或流畅时，释放高画质渲染目标、噪声纹理与效果材质，再次启用时重建。世界与存档格式不变。

参考 [Photon 的 GTAO](https://github.com/sixthsurge/photon/blob/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/ao/gtao.glsl) 对近景半径、手持物与屏幕边界的处理思路，复用 [Three.js 的 GTAOShader](https://github.com/mrdoob/three.js/blob/r186/examples/jsm/shaders/GTAOShader.js)、PoissonDenoiseShader 与 SMAAPass，保护层、深度捕获和合成由本项目独立实现。没有引入 Photon 代码。屏幕空间遮蔽只能利用当前画面中的表面，不等于全局光照；仍未加入时域积累或屏幕空间反射。本轮仅验证生产构建与 GitHub Actions，未执行浏览器画面或性能测试。

## 锻造与新生

- **铁砧与砂轮**：在工作台合成，放置后按 **E** 使用。铁砧需要 **3 铁块＋4 铁锭**，每铁块可由 9 铁锭合成或拆回；蜂巢配方中心显示叠放数量。砂轮需要 **2 原木＋1 石头＋2 木板**。新生成的铁匠铺也摆有开裂铁砧与砂轮。
- **材料修复**：铁砧每份材料修复最大耐久的约 **25%**，将修复材料放进右槽，最多使用四份，只消耗实际需要的数量；木、石、铁、钻石工具分别使用木板、石头、铁锭、钻石，护甲使用对应皮革或金属，盾牌使用木板。弓和鱼竿通过同类合并修复。
- **同类装备合并**：左侧装备保留，右侧副本消耗，耐久相加并获得最大耐久 **12%** 的额外修复，封顶满耐久。附魔取较高等级，同等级合并升一级，不超过各自上限；例如两把效率 IV 钻石镐可合成效率 V。结果、耐久、附魔和费用均先预览，取出产物前不消耗物品。
- **等级费用与铁砧损耗**：费用包含材料数量、修复、升级附魔、命名与两件装备已有的加工惩罚。修复或合并后的惩罚按 **0 → 1 → 3 → 7 → 15 → 31 → 63** 增长；费用达到 40 级时生存模式不能加工。每次成功使用有 **12%** 概率让铁砧进入下一阶段，完好、开裂、损坏之后消失，损耗阶段按方块类型保存，拆下再放不重置。
- **命名装备**：铁砧可为任意已有耐久装备设置最多 24 字的名称，留空恢复原名。单独命名不增加加工惩罚，费用最多 39 级；名称随具体装备保存，在背包、快捷栏、装备栏、箱子与加工面板显示。磨损、掉落和跨维度转移会保留名称。
- **砂轮祛魔与修复**：单件祛魔，或合并两件同类装备并获得最大耐久 **5%** 的额外修复，均免费。移除现有附魔、重置加工惩罚、保留左侧名称，并按被移除的附魔强度返还部分经验球；可重新放入附魔台。砂轮不能保留附魔，取出前会显示完整结果及经验返还量。
- 新增六向朝向的六棱铁砧、裂纹顶面、木架六角砂轮、加工动画、粒子与程序音效，使用九张新增授权像素材质，接入世界光照与阴影。创造模式免等级费用，仍消耗槽内的实际装备与修复材料，不返还砂轮经验。逐件记录名称与加工惩罚；打开界面不会把物品留在隐藏槽位。

- 食用改为 **按住 F 或右键 1.6 秒**，触屏按住 F；手持食物时 E 可启动一次食用。F 优先使用手持食物，否则从背包选择饱和度较高的普通食物。松开、切换快捷栏、攻击、受伤或打开界面会中断，完成后才扣除物品；食用时减速，有手持动画、声音与进度条。所有食物都可装入快捷栏，容器与耕种交互优先。
- 新增 **饱和度和消耗**：移动、冲刺、游泳、划船、跳跃、采矿与攻击会积累消耗，每 4 点先扣饱和度，再扣饱食。普通食物恢复饱食和饱和度；满饱食且有饱和度时约每秒恢复 1 生命，饱食至少 18 时约每 4 秒恢复 1 生命，回血会额外消耗食物储备。饱食不超过 6 时无法冲刺，空腹每 4 秒损失 1 生命，最低保留 1 点。
- 头部浸入液体会消耗 **15 秒氧气**，HUD 用十个六边形气泡显示。耗尽后每 2 秒受到 2 点窒息伤害，浮出水面约 3 秒补满；护甲不能抵消窒息。
- 岩浆中每秒造成 4 点基础灼伤，离开后继续燃烧约 6 秒、每秒 1 点基础伤害。跳入水或萤晶液、站在露天雨中可灭火；画面增加像素火焰、状态倒计时和低生命提示。
- **金苹果** 恢复 4 饱食和 9.6 饱和度，给予 5 秒生命恢复 II 和 2 分钟伤害吸收，最多额外吸收 4 点伤害；满饱食也可食用。**牛奶** 清除状态效果并返还空桶，也会清除有益药水效果。
- 饱和度、消耗、氧气、燃烧和效果计时随玩家保存、跨维度保留；暂停和打开界面时冻结。未完成的食用动作不保存。

参考 [VoxeLibre 的饥饿系统](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/PLAYER/mcl_hunger/hunger.lua) 的饱和度与消耗模型，独立编写本项目规则。验证范围为生产构建与 GitHub Actions，未运行浏览器测试。

## 提灯入野

- **手持火把、萤灯、萤石、萤晶、岩浆桶或萤晶液桶即可照明**，无需放置或额外按键，也不消耗物品。切换到其他物品后光照消失，HUD 会显示“随身照明”。适合夜间赶路、下矿探洞或乘船穿过地下水道。
- 随身光使用与建筑灯光相同的六向传播和材质遮挡，从玩家所在格发出，不会因挥手穿模而把光源送进墙后。光照随玩家跨格移动更新，最多每 0.25 秒一次；移动时复用静态天空光和世界灯光。
- 动物、敌人、村民、船体与船桨、手臂和手持物、掉落物、箭矢、作物以及鱼漂都接入世界光照。进入洞穴会变暗，走近火把或彩色灯源时染上对应光色；共享材质的多个模型也各自按所在位置受光。
- GPU 共享一张约 1.27 MiB 的三维光照纹理（默认 81 个数据区块），在六边形网格上插值并排除实心格，移除原有的八个近距离点光源。打开背包、地图或熔炉界面时，光照仍可完成更新，手持灯的照明保持。

继续参考 Photon 的体素光照与法线偏移取样思路，独立实现适合当前引擎的动态模型光照。随身照明属于视觉功能，不代替放置火把对作物与刷怪笼的现有玩法判定。自发光眼睛、火焰、粒子与天空保留自身表现；0.22 补充高度雾和体积散射，屏幕空间反射与时域抗锯齿尚未实现。

## 光落六野

- 新增 **15 级天空光与 RGB 方块光传播**，沿六个水平邻格和上下方向扩散。洞穴入口、窗户与门口可透入天光，实心墙与关闭的木门阻挡传播；树叶与水逐层削弱光线，玻璃透光，围栏和梯子允许减弱后的光通过。
- 火把、萤灯、燃烧中的熔炉、萤石、萤晶、刷怪笼、两种传送门、岩浆和萤晶液各有光色。附近地形受所有已加载发光单元影响，不再依赖离相机最近的八个点光源；光色随距离衰减，可在建筑内布置暖灯与彩光。
- 地形、木门等建筑、草丛、玻璃和液面共用光照场；挖墙、开关门、放置/移除光源、熔炉燃灭及液体流动会更新照明。地下水面的天空倒影随天光减弱，洞穴远雾也不再保持室外亮度。
- 光照只在变化后计算，最多每 0.25 秒一次，网格光照属性分帧上传，不为光照变化重建地形。所有画质档均启用，已有的高画质柔光仍可使用。

主要参考 [Photon 的 LPV 光传播与表面采样](https://github.com/sixthsurge/photon/tree/6e67b36e818bacde0304edd49f28e2bb70e33f04/shaders/include/lighting/lpv)，独立实现适用于 Web 六棱柱世界的 CPU 光照场，没有复制其 GLSL 源码。0.17 建立方块照明，0.18 补齐动态模型与随身光。

## 六面行舟

- 工作台用 **5 木板** 制作橡木船，手持后对水面 **右键 / E** 放置。船占背包一格；对准空船 **E 上船**、**Ctrl+E 收回**，也可以用左键拆船。
- **W/S** 前后划行，**A/D** 按船头方向转向，鼠标独立观察周围，**空格** 刹船。前进最高约 8.5 m/s、倒退约 4 m/s，具有加速和滑行惯性，水面船桨动画、尾流和划水声随移动变化。
- **Shift 下船**；未手持鱼竿时也可按 E 下船。优先寻找附近能站立的岸边，其次水面；周围没有安全位置时留在船内。触屏使用方向、跳跃、下降和 E 按钮控制。
- 六边形木船采用现有像素木材，拥有实体船体碰撞与载客净空检查。船不能穿过岸边、围栏、其他船或低矮障碍，搁浅后可收回重新放置；不提供陆上划行。
- 支持在船上钓鱼：空格刹停，再换鱼竿，右键/E 抛线收杆；Shift 仍可下船。船只位置、朝向、速度、生命与乘坐状态按维度保存，未加载区域或暂停时冻结；跨维度旅行会把船留在原地。
- 船有 20 生命，斧拆船更快；爆炸会摧毁并掉落船，岩浆会烧毁且不掉落。不提供岩浆航行、动物乘客或运输箱，目前每艘船单人乘坐、每维度最多 128 艘。

本轮对照 [VoxeLibre 的 mcl_boats](https://github.com/VoxeLibre/VoxeLibre/blob/4492ce6ff8d856daa4567abe2ea689f4e7a39842/mods/ENTITIES/mcl_boats/init.lua) 阅读了浮水判定、乘客分离、碰撞高度与速度衰减的处理方式。游戏中的 JavaScript 载具逻辑与六边形模型为独立实现，没有复制上游 Lua 代码或船模型。

## 水畔时光

- 工作台用 **3 原木 + 2 线** 制作鱼竿，也可向村庄渔夫购买。手持鱼竿，面向水面 **右键 / E** 抛线，再按一次收杆，**左键** 收起；触屏使用交互按钮。
- 抛出的六棱浮漂受重力影响，会落入水中或挂在岸上。鱼线连接手中鱼竿；等待时有涟漪，鱼群靠近后浮漂下沉并发出水花与声音，在提示窗口内收杆即可获得鱼获。错过后可留线继续等。
- 露天等待约 9–25 秒，再有 2.2 秒靠近过程；雨中加快 40%，有顶棚时变慢。鼠标收杆窗口 1.6 秒，触屏为 2.1 秒。水被填掉、鱼线受阻或距离超过 24 格时收回；切换手持物也会收起。
- 新增鳕鱼、鲑鱼、热带鱼与两种烤鱼，带像素图标。**按住 F 食用**，生鳕鱼/鲑鱼恢复 2 饱食，热带鱼 1，烤鳕鱼 5，烤鲑鱼 6。雪原更容易钓到鲑鱼，沙漠水域更容易钓到热带鱼。
- 一般鱼获占 90%，杂物占 10%；半径两格的六边形水域、两层平静水体、上方两格无遮挡时，变为 85% 鱼获、10% 杂物、5% 宝物。宝物包括书、绿宝石、末影珍珠或钻石，可建造自己的钓鱼池。
- 村庄新增两格深六边形鱼塘与戴草帽的渔夫，出售鱼竿和烤鱼、收购三种鱼。成功收杆消耗 1 耐久，挂住后收回消耗 2；鱼竿共 64 耐久。背包满时鱼获落在脚边。
- 暂停时冻结钓鱼，退出或切换维度后收起鱼线；已获得的物品正常存档。鱼竿支持耐久附魔，暂未加入水下游鱼、海之眷顾、饵钓或自动钓鱼。

## 炉火不息

- **E 打开熔炉**，从背包放入原料和燃料，自动连续烧炼；使用游标拿放、右键分半 / 单件或 Shift 快速转移。产物保存在炉内，Shift 取出时背包满则留在炉内，普通点击仍可拿在游标。
- 煤与木炭各燃烧 80 秒，原木和木板 15 秒，岩浆桶 1000 秒并留下空桶。可烧铁、金、铜、肉与马铃薯；新增原木烧木炭、沙子烧玻璃。
- 每台炉子的存货、进度和剩余燃烧时间随维度保存。炉子面板打开时仍工作，暂停菜单、后台、未加载区域及离开的维度暂停模拟，不结算离线时间。
- 原料耗尽或产物满时余火仍消耗，不会继续点燃新燃料；熄火后未完成的进度逐渐冷却。拆除和爆炸散落炉内物品，已点燃的燃料不返还。
- 正面朝向放置者，燃烧时切换像素炉火并照亮周围。面板提供实时火焰与烧炼进度，新增木炭像素图标。

## 种植与收获

- 加入胡萝卜、马铃薯、甘蔗和橡树苗；小麦与蔬菜使用四阶段公开像素材质，瞄准植物显示成熟度，**E** 收获或查看条件，**左键** 拔除，土地保持不变。

- 加入烤马铃薯、糖、纸、书与六棱书架。甘蔗制糖和纸，纸与皮革制书；蛋糕配方加入糖。**按住 F 优先食用当前手持食物**，未手持食物时从背包选择。
- 植物种类与生长进度保存在 v5 存档；不兼容旧格式。新增 22 张素材继续使用 Pixel Perfection / VoxeLibre 的署名与许可。

当前尚无植物踩踏、自动收割或自然树叶衰减；书架可以装饰建筑，也能增强附魔台。

## 天气与氛围

- 主世界在晴朗、雨天与雷暴之间按种子轮换，天气平滑过渡并保存。雪原降雪、雷暴时雪势增强；沙漠保留阴云，不下雨。
- 加入六棱云团、雨线、像素雪花、地表溅水与远处闪电；阴云会削弱日光、遮住星月、改变天空与水面反射颜色，雨后露天地面的湿润高光会慢慢消退。
- 屋顶、玻璃和树冠遮挡雨雪，地下没有降水；进入屋内或水下后雨声变轻，雪原使用低沉风声。暂停菜单与后台暂停环境声。设置可单独关闭闪电与天空闪光。
- 露天且非雪原/沙漠的作物在足量降雨时额外获得约 50% 生长速度；阴雨抑制僵尸与骷髅日晒伤害，强雷暴允许白天生成敌对生物。主世界在雷暴中也能睡觉，醒来后天气逐渐转晴。
- 创造模式暂停菜单可选择天气，生存模式自然轮换。流畅画质使用较少的天气粒子，雨雪使用固定缓冲区批量绘制。

天气目前属于氛围与生存环境模拟：闪电不会引燃或损坏建筑，雪不会堆积，雨不会增加液体体积；湿润反光是天空颜色近似，不是屏幕空间或光线追踪反射。

## 掉落与背包

- 采矿、收获、击败生物会产生有像素材质的实体掉落物；靠近时吸附拾取，墙壁会阻挡拾取。水和萤晶液中会上浮，岩浆和虚空会销毁物品。
- 生存背包使用 36 格容量；普通材料每格 64 件，鸡蛋、珍珠、空桶每格 16 件，工具、护甲和装满的桶每格 1 件。快捷栏是其中九个实际格位，显示各格的堆叠数量。装备耐久随丢弃、拾取和箱子存取保留。
- **Q** 丢出一件，**Ctrl+Q** 丢出当前一组；打开背包后悬停物品也适用。Shift 点击用于快速转移。拿着游标物品点击面板外可丢出，右键只丢一件；容量不足时无法拾取。
- 死亡后背包和身上装备散落在原地，地图以红色 × 标记最近死亡地点及高度。普通物品保留 5 分钟，死亡物资 10 分钟，离开附近加载范围或暂停游戏会暂停计时。死亡标记保留到下次死亡，找回物资后不会自动消失。
- 掉落物与剩余时间按维度保存；最多同时显示 256 个近处掉落实体，超过显示预算的记录仍保存和模拟。存档升级到 v5，不读取旧格式。

## 村庄与交易

- 主世界新增按种子生成的六边形村庄：四栋可进入的房屋、阶梯屋顶、玻璃窗、道路、路灯、中央水井与两片灌溉农田。
- 出生点东侧约 Q24 / R0 有「晨谷村」，远方也会生成聚落；地图上用 ⌂ 标记，进入村庄会显示名称。
- 农夫、铁匠、杂货商和渔夫白天在村中活动，夜晚返回住处。靠近并瞄准村民按 **E** 打开交易；手持鱼竿时先换手，再与渔夫交谈。
- 小麦、原木和煤可换绿宝石，再换取面包、苹果、桶、铁锭或萤灯。每项交易每天限 4 次，库存记录会保存。
- 农田可以收获，屋内有少量初始物资和可使用的床、工作台或熔炉；已经收走的作物与箱子物资不会因重载刷新。

本次以新世界体验为准，不保证旧存档的地形兼容。村民目前为友好交易角色，采用简单的定点往返行为；尚未加入繁殖、袭击、复杂寻路或职业成长。

## 流动液体

- **铁桶与液体桶**：工作台用 3 个铁锭制作铁桶。在背包中把桶移入快捷栏，用右键或 E 对准液体源装取；装满后对准地形倒出，生存模式会返还空桶。流动液体不能装桶，创造模式可直接选择三种液体桶。
- **六向流动**：水、岩浆、萤晶液优先向下流，落地后向六个邻格扩散，最远分别为 7、3、5 格。岩浆流速更慢；堵住水道会改道，移走源头后逐步退流。海域与下界熔岩海也由实际液体格组成。
- **液体反应**：水接触岩浆源生成黑曜石，接触流动岩浆生成石头。工作台用 **水桶 ×1 + 萤晶 ×2** 调制萤晶液桶；萤晶液带发光纹理，与岩浆接触生成萤石。
- **身体交互**：站进液体会减速，按空格上浮；岩浆会造成伤害，浸入液体时显示对应颜色的水下效果。
- **持久化**：液体源、流动状态和取走的天然源随区块卸载、维度切换和存档保留。

液体采用源头供给的离散模拟，不是体积守恒的物理流体。每轮有固定计算预算，大型瀑布可能需要更久稳定；离开已加载区域后暂停模拟，返回后继续。液体状态会增加存档大小，仍建议定期导出备份。岩浆与萤晶液参与彩色方块光传播。水与萤晶液不互相反应；目前没有蒸发、压力或无限水源生成。岩浆桶可以用作熔炉燃料。

## 像素材质

- 为方块使用 Pixel Perfection / VoxeLibre 16×16 像素材质与程序绘制的补充贴图：六边形顶面与侧面独立映射，包含草皮、树皮与年轮、矿脉、砖缝、工作台、箱子和熔炉等细节。
- 加入地形接触遮阴和实时太阳阴影、渐变天空、块状云、草丛与野花、流动水纹和发光熔岩。
- 手持方块使用对应材质，生物增加表面纹理与面部细节；保留现有物品图标。
- 「流畅」画质关闭实时阴影，保留纹理与接触遮阴。区块共用纹理图集和材质，草丛合批渲染，不影响采集射线或碰撞。
- 美术代码位于 `src/textures.js`，修改调色板或绘制规则即可制作自己的风格。公开材质随游戏打包，署名与媒体许可见 public/textures/NOTICE.md；代码与媒体分别遵循对应许可。

## 世界与玩法

- **无限水平世界**：8×8 轴向区块按位置生成与卸载，远行后依旧可以挖掘和建造。修改记录独立保存，返回区域会恢复建筑与被挖掉的方块。当前高度为 1–63 格。
- **主世界**：平原、森林、沙漠、雪原、海域、矿脉与地下空洞，昼夜交替。
- **下界**：绯红菌林、玄武岩荒地、岩层穹顶、萤石和熔岩海；熔岩会伤害生存玩家。
- **末地**：末地石浮岛、黑曜石柱、星空与虚空，重力更轻；掉入虚空会死亡并损失落入虚空的物资，随后在当前维度重生。
- **维度往返**：生存玩家合成传送门，放置后按 E；初次到达会生成安全落脚平台和返回门。三个维度分别记录地形、箱子、作物、重生点与上次位置。创造模式可以在暂停菜单直接旅行。
- **纯沙盒**：移除信标任务、任务追踪与通关弹窗。HUD 显示维度、生物群系和六向罗盘。
- **游戏界面**：立体标题、石质面板、九格物品栏、配方搜索、拾取提示、可保存的音量/画质/灵敏度设置。
- **动画与音效**：手持方块和镐、采集挥动、放置动作、行走摆动、受击反馈、作物轻摆、旋转传送门及转场。脚步、碎块、放置、合成、受伤和传送声音由 Web Audio 合成，不依赖外部音频。
- **继续生存**：木→石→铁→钻石工具、铁剑、工作台、熔炉、储物箱、床、锄地播种、小麦面包、食物、生物、生命和饱食度，均可继续使用。

这是独立的单人六边形体素沙盒，不是 Minecraft 完整移植。当前没有联机或红石电路，末地已有可选的末影龙首领战。工具有耐久并可附魔，死亡散落物资与部分经验；动物与首领进度保存，普通敌对生物按环境生成。无限指水平地形持续按需生成，不表示浏览器内存、坐标精度或本地存储没有上限。

### 生存与维度

1. 采集原木，B 合成木板和木镐，把镐装入快捷栏并手持。制作并放置工作台，在五格范围内解锁进阶配方。
2. 石镐开采铁矿和萤晶，熔炉用煤烧铁；铁镐可以开采钻石矿与黑曜石。
3. 工作台配方 **3 岩石 + 2 煤 + 1 萤晶 → 4 黑曜石**。再用 **6 黑曜石 + 1 萤晶** 制作下界传送门。
4. 放置传送门，瞄准门体按 E 进入。到达后也可瞄准自动生成的返回门，按 E 回到主世界上次的位置。
5. 主世界夜间的末影人掉落末影珍珠，下界生物掉落烈焰粉。**3 末影珍珠 + 3 烈焰粉 + 1 萤晶** 在工作台制作末地传送门。
6. 床只在主世界设置重生点并跳过夜晚。别在熔岩里游泳，也别忘了带足够的建筑材料跨越末地虚空。

这些是可自由选择的配方与玩法，没有强制任务或通关目标。

## 遗迹与地下探索

- 野外可发现古老瞭望塔、废弃矿道和苔石地牢；下界有余烬堡垒，末地有紫珀遗址。矿道与地牢有木制阶梯通向地面，沿入口逐级跳下即可探索。
- 遗迹内有食物、金属、火把与稀有材料宝箱。箱子只在首次生成时填充，拿走或破坏后不会重载补货。接近遗迹会记录发现，并在地图以 ◆ 标注；地下遗迹需要进入其高度范围才能发现。
- 刷怪笼在玩家 16 格内活动，每八秒尝试生成守卫。五格内放置火把或萤灯即可压制；石镐能拆除刷怪笼并回收萤晶。
- 煤和原木制作火把。火把是细六棱柱，不阻挡移动；覆盖区域的天空补光更暗，火把与灯具提供独立照明，最多同时显示离玩家最近的八盏局部灯。
- 深层有深板岩与金矿，普通岩层也可找到铜矿。铁镐开采金矿、石镐开采铜矿，熔炉分别炼成金锭和铜锭，可制作金块、切制铜块和金苹果。
- 手持金苹果按住右键或按 E 食用，恢复 4 点饱食，并给予生命恢复和伤害吸收。新增苔石砖、砂岩、下界砖与紫珀装饰配方。

## 动物、养殖与敌人

- 主世界可遇见绵羊、奶牛、猪和鸡。手持小麦吸引牛羊、苹果吸引猪、麦种吸引鸡；对动物按 E（或右键）喂食。附近两只已喂食的同类会繁殖，幼崽在加载区域约三分钟成年，喂食可加速。
- 两块铁锭制作剪刀，对成年羊按 E 得到三份羊毛；在草地上约两分钟长回。铁桶对成年牛按 E 挤奶，奶牛休息 30 秒；牛奶可右键饮用，也可与鸡蛋、小麦做蛋糕，制作返还铁桶。
- 成年鸡约每 150 秒产一个蛋，最多暂存八枚；换下麦种后对鸡按 E 收集。牛掉皮革，鸡掉羽毛，皮革能制作入门护甲，羽毛做箭更省材料。农夫收购鸡蛋和皮革。
- 动物的位置、生命、繁殖冷却、幼崽成长、羊毛和鸡蛋随维度保存，远离后卸载模型，返回时恢复；不会因为刷新或走远重新生成同一批动物。未加载区域的养殖计时暂停。用方块围栏圈养，动物不会主动跨上整格高的墙。
- 夜间出现僵尸、骷髅弓手、蜘蛛和苦力怕。僵尸近战追逐，骷髅保持距离射箭，蜘蛛更快且白天通常中立；僵尸和骷髅在露天日照下燃烧。
- 苦力怕靠近后闪烁并引爆，破坏半径约 2.7 格的地形与容器；及时拉开距离可让引信熄灭。骨头可磨成骨粉，手持对麦苗按 E 催熟。
- 活跃生物有数量上限，持久生物记录最多 2048 只；普通敌人随环境补充，远离或重载后不保留，携带方块的末影人例外。动物与敌人的掉落均以实体物品散落，靠近拾取。

## 装备与战斗

- 工具必须手持才生效：镐采石、斧砍木、铲挖土。木、石、铁、钻石各有速度与耐久差异；重复制作可保留备用工具。
- 使用游标把工具移入快捷栏，护甲放入对应装备槽；Shift 点击可装备到空位，点击装备槽可拿起或交换。铁甲提供 15 点护甲，钻石甲 20 点，每点减少 4% 战斗和灼烧伤害。摔落和饥饿不受护甲保护。
- 羊毛可捻成纤维线；木材与线制作弓，石头、木材和线制作箭。手持弓按住左键蓄力，松开发射，约 1.1 秒满弓。箭受重力影响，入水减速，插在地面的箭可走近回收。
- 剑攻击快、斧攻击重但恢复慢；下落时近战可暴击。工具、武器和护甲会损耗，快捷栏显示耐久条；损坏后对应格位变空，备用装备需要手动移入。
- 装备耐久随箱子存取、维度切换和保存保留。飞行与插地箭是临时实体，40 秒后消失；退出或切换维度不会保留箭。
- 铁匠出售剑与胸甲，杂货商出售箭矢。

## 存档

每十五秒、返回首页、维度切换和离开页面时，自动写入当前浏览器的 `localStorage`。当前使用 `hexwild-save-v10`，记录 36 个固定格位、七格合成材料、独立装备槽、游标物品、选中的快捷栏及逐件装备的耐久、附魔、名称与加工惩罚、护甲及副手槽、27 格箱子库存、玩家经验与附魔选项种子、药水效果、附魔与锻造的暂存输入、各维度酿造台库存与进度、经验球与掉落物、死亡位置和植物生长进度；不提供旧格式导入、迁移或旧地形兼容。开发阶段允许存档格式变动，推荐新建世界体验。

暂停时世界不推进。熔炉的库存、烧炼进度、余火与待领取经验随维度保存，未加载区域不结算离线进度。作物按游戏内经过的时间生长。每个维度存储差异记录，不把无限生成的全部方块写入存档。

本地存储由浏览器配额限制；大量建造时建议定期导出 JSON 备份。写入失败会提示导出，不会清除现有存档。清理站点数据或换设备前请先备份。

### GitHub Actions / Pages

`main` 每次 push 执行锁文件安装与生产构建，通过后部署 Pages。PR 只验证。默认只执行生产构建；保留的本地测试脚本可按需使用，不在云端启动浏览器。

Pages 使用 GitHub Actions，产物目录为 `dist/`。Vite 使用相对路径，兼容 `/HexMinecraft/`，不需要后端或密钥。
